:::objectives
- Pick Flexbox or Grid for a layout problem and explain why.
- Use `flex` shorthand, `grid-column: span`, `grid-auto-rows`, and `grid-template-areas` in new situations.
- Nest a flex container inside a grid to build a real page section.
:::

Each exercise gives you starter HTML and a sketch of the target. Make a file called `practice.html`, paste the starter in, open it with Live Server, and write the CSS yourself before you peek. When something doesn't move the way you expect, right-click it, choose **Inspect**, and look for the small `flex` or `grid` badge next to the element in the Elements panel. Clicking it draws the lines and gaps right on the page.

## Warm-up: predict the placement

```html preview height="200"
<div class="grid"><div>1</div><div>2</div><div>3</div><div>4</div><div>5</div></div>
<style>
  body { font: 15px system-ui, sans-serif; margin: 10px; }
  .grid { display: grid; grid-template-columns: 100px 1fr; gap: 6px; }
  .grid div { background: #e0f2fe; border: 2px solid #0284c7; padding: 8px; }
</style>
```

:::quiz
Q: Without looking at the result, where did box 5 land?
- [ ] On the right side of row 2, next to box 4
  Box 4 already took that spot. Each row has only two cells.
- [x] In the left, 100px column of row 3
  Two columns per row means boxes 1–2, 3–4, then 5 starts a new row in the first column.
- [ ] Nowhere, because only two columns were defined
  Grid creates extra rows automatically; it never drops items.

Q: What would `gap: 6px` become if you only wanted space between rows?
- [x] `row-gap: 6px`
  `gap` is shorthand for `row-gap` and `column-gap`, so you can set either one alone.
- [ ] `column-gap: 6px`
  That spaces the columns apart, which is the opposite of what you wanted.
:::

### Exercise 1: Center a badge

A product photo box needs a "Sold out" label in its exact center, both across and down.

```html
<div class="photo"><span class="badge">Sold out</span></div>
<style>
  .photo { height: 180px; background: #cbd5e1; border-radius: 10px; }
  .badge { background: #b91c1c; color: white; padding: 6px 14px; border-radius: 999px; font: 600 15px system-ui, sans-serif; }
</style>
```

:::hint
Two properties on `.photo` handle it with Flexbox: one for each axis. Grid can do it with one property, `place-items`.
:::

:::solution
```html preview height="220"
<div class="photo"><span class="badge">Sold out</span></div>
<style>
  .photo {
    height: 180px; background: #cbd5e1; border-radius: 10px;
    display: flex;
    justify-content: center; /* main axis: left to right */
    align-items: center;     /* cross axis: top to bottom */
  }
  .badge { background: #b91c1c; color: white; padding: 6px 14px; border-radius: 999px; font: 600 15px system-ui, sans-serif; }
</style>
```

`display: grid; place-items: center;` works too. `place-items` is shorthand for `align-items` and `justify-items` together. Both versions only work because `.photo` has a height taller than the badge; with no extra space there's nothing to center in.
:::

### Exercise 2: A navigation bar

Put the site name on the far left and the links on the far right, all vertically centered. Remove the list bullets.

```html
<nav class="site-nav">
  <a class="brand" href="#">Riverside Robotics</a>
  <ul>
    <li><a href="#">Events</a></li>
    <li><a href="#">Team</a></li>
    <li><a href="#">Join</a></li>
  </ul>
</nav>
```

```text
Target:
| Riverside Robotics                      Events   Team   Join |
```

:::hint
You need two flex containers: the `<nav>` (two items: the brand and the list) and the `<ul>` (three items). Lists come with padding and margin you'll want to reset to 0.
:::

:::solution
```html preview height="120"
<nav class="site-nav">
  <a class="brand" href="#">Riverside Robotics</a>
  <ul>
    <li><a href="#">Events</a></li>
    <li><a href="#">Team</a></li>
    <li><a href="#">Join</a></li>
  </ul>
</nav>
<style>
  body { font: 16px system-ui, sans-serif; margin: 10px; }
  .site-nav { display: flex; justify-content: space-between; align-items: center; padding: 12px 16px; background: #0f172a; border-radius: 8px; }
  .site-nav a { color: white; text-decoration: none; }
  .brand { font-weight: 700; }
  .site-nav ul { display: flex; gap: 20px; list-style: none; margin: 0; padding: 0; }
</style>
```

`space-between` pushes the brand and the list apart. The `<ul>` is both a flex item (of the nav) and a flex container (for its links).
:::

### Exercise 3: Footer columns that wrap

A footer has three sections. On a wide screen they sit side by side with equal widths. When there isn't room for each to be at least 180px wide, they wrap onto new lines and fill the row.

```html
<footer class="footer">
  <section><h2>Visit</h2><p>12 Mill Street</p></section>
  <section><h2>Hours</h2><p>Tue–Sat, 9 to 5</p></section>
  <section><h2>Follow</h2><p>Newsletter and updates</p></section>
</footer>
```

:::hint
`flex` takes three values: grow, shrink, and a starting size called the basis. Try `flex: 1 1 180px` on the sections, and don't forget the container needs to allow wrapping.
:::

:::solution
```html preview height="220"
<footer class="footer">
  <section><h2>Visit</h2><p>12 Mill Street</p></section>
  <section><h2>Hours</h2><p>Tue–Sat, 9 to 5</p></section>
  <section><h2>Follow</h2><p>Newsletter and updates</p></section>
</footer>
<style>
  body { font: 15px system-ui, sans-serif; margin: 10px; }
  .footer { display: flex; flex-wrap: wrap; gap: 16px; background: #f1f5f9; padding: 16px; border-radius: 8px; }
  .footer section { flex: 1 1 180px; background: white; padding: 8px 12px; border-radius: 6px; }
  .footer h2 { font-size: 1rem; margin: 0 0 4px; }
  .footer p { margin: 0; }
</style>
```

Each section starts at 180px (the basis), then grows to share any extra space. When three 180px sections plus gaps no longer fit, the last one wraps and grows to fill its own line. This is the Flexbox cousin of `auto-fit` and `minmax()`, with one difference: a wrapped item stretches across the whole row instead of lining up with a column above it.
:::

### Exercise 4: A gallery with a featured photo

Make a four-column gallery where every row is 80px tall. The first tile is "featured": it covers two columns and two rows.

```html
<div class="gallery">
  <div class="featured">Featured</div>
  <div>2</div><div>3</div><div>4</div><div>5</div>
  <div>6</div><div>7</div><div>8</div><div>9</div>
</div>
```

```text
Target:
+-----------+-----+-----+
|           |  2  |  3  |
| Featured  +-----+-----+
|           |  4  |  5  |
+-----+-----+-----+-----+
|  6  |  7  |  8  |  9  |
+-----+-----+-----+-----+
```

:::hint
`grid-auto-rows` sets the height of rows the grid creates by itself. On the featured tile, `grid-column: span 2` stretches it across two columns; there's a matching property for rows.
:::

:::solution
```html preview height="300"
<div class="gallery">
  <div class="featured">Featured</div>
  <div>2</div><div>3</div><div>4</div><div>5</div>
  <div>6</div><div>7</div><div>8</div><div>9</div>
</div>
<style>
  body { font: 15px system-ui, sans-serif; margin: 10px; }
  .gallery { display: grid; grid-template-columns: repeat(4, 1fr); grid-auto-rows: 80px; gap: 8px; }
  .gallery div { background: #fef3c7; border-radius: 6px; display: flex; align-items: center; justify-content: center; }
  .gallery .featured { grid-column: span 2; grid-row: span 2; background: #f59e0b; font-weight: 700; }
</style>
```

The featured tile claims a 2×2 block, and the other tiles flow into the free cells around it, left to right and top to bottom.
:::

### Exercise 5: Rearrange a page without touching the HTML

This page has the menu on the left and the "News" box on the right. Change only `grid-template-columns` and `grid-template-areas` so that the menu becomes a strip under the header, and "News" moves to the left of the main content.

```html preview height="300"
<div class="page">
  <header>Header</header><nav>Menu</nav><main>Main</main><aside>News</aside><footer>Footer</footer>
</div>
<style>
  body { font: 15px system-ui, sans-serif; margin: 10px; }
  .page {
    display: grid; gap: 8px; min-height: 260px;
    grid-template-columns: 120px 1fr 140px;
    grid-template-areas:
      "header header header"
      "menu   main   news"
      "footer footer footer";
  }
  header { grid-area: header; } nav { grid-area: menu; } main { grid-area: main; }
  aside { grid-area: news; } footer { grid-area: footer; }
  .page > * { background: #ede9fe; border: 2px solid #7c3aed; border-radius: 6px; padding: 8px; }
</style>
```

```text
Target:
| Header               |
| Menu                 |
| News  | Main         |
| Footer               |
```

:::hint
The target has two columns and four rows. Write four strings, each with two names. A name repeated across a row makes that area span the row.
:::

:::solution
```css
.page {
  grid-template-columns: 140px 1fr;
  grid-template-areas:
    "header header"
    "menu   menu"
    "news   main"
    "footer footer";
}
```

Each string is one row, and each word is one column. The HTML order never changed, which is the point: Grid lets you redraw the page in CSS. One caution for later: keyboard users still move through elements in HTML order, so keep the visual order close to the source order.
:::

### Exercise 6: A dashboard with a toolbar and stat cards

This is the module's big one, and it mixes everything. Build a dashboard with:

1. A 200px sidebar on the left and the main area on the right (Grid).
2. A toolbar at the top of the main area with the page title on the left and a search box plus a button on the right (Flexbox). The search box should grow to fill spare space.
3. Stat cards that fit as many columns as possible, each at least 140px wide (Grid with `auto-fit`).

```html
<div class="dash">
  <nav class="side">Library<br>Members<br>Loans<br>Settings</nav>
  <main>
    <div class="toolbar">
      <h1>Loans</h1>
      <div class="tools"><input type="search" aria-label="Search loans" placeholder="Search"><button>New loan</button></div>
    </div>
    <div class="stats">
      <div class="stat"><b>128</b> out today</div>
      <div class="stat"><b>9</b> overdue</div>
      <div class="stat"><b>41</b> reserved</div>
      <div class="stat"><b>3</b> lost</div>
    </div>
  </main>
</div>
```

:::hint
Work from the outside in. Style `.dash` first and check the two columns. Then `.toolbar` with `space-between`, then `.tools` as its own flex row where the input gets `flex: 1`. For the input to grow, `.tools` itself needs to grow too.
:::

:::solution
```html preview height="300"
<div class="dash">
  <nav class="side">Library<br>Members<br>Loans<br>Settings</nav>
  <main>
    <div class="toolbar">
      <h1>Loans</h1>
      <div class="tools"><input type="search" aria-label="Search loans" placeholder="Search"><button>New loan</button></div>
    </div>
    <div class="stats">
      <div class="stat"><b>128</b> out today</div>
      <div class="stat"><b>9</b> overdue</div>
      <div class="stat"><b>41</b> reserved</div>
      <div class="stat"><b>3</b> lost</div>
    </div>
  </main>
</div>
<style>
  body { font: 15px/1.5 system-ui, sans-serif; margin: 0; }
  .dash { display: grid; grid-template-columns: 200px 1fr; min-height: 280px; }
  .side { background: #0f172a; color: #e2e8f0; padding: 16px; }
  main { padding: 16px; background: #f8fafc; }
  .toolbar { display: flex; align-items: center; justify-content: space-between; gap: 16px; margin-bottom: 16px; }
  .toolbar h1 { margin: 0; font-size: 1.4rem; }
  .tools { display: flex; gap: 8px; flex: 1; max-width: 360px; }
  .tools input { flex: 1; min-width: 0; padding: 6px 8px; }
  .stats { display: grid; grid-template-columns: repeat(auto-fit, minmax(140px, 1fr)); gap: 12px; }
  .stat { background: white; border: 1px solid #e2e8f0; border-radius: 8px; padding: 12px; }
  .stat b { display: block; font-size: 1.6rem; }
</style>
```

Three layouts are nested here: a Grid for the page, a Flexbox row for the toolbar (with another inside it for the tools), and an `auto-fit` Grid for the cards. `min-width: 0` on the input matters. Form fields have a built-in minimum width, and without that line the input refuses to shrink on narrow screens and pushes the button off the edge.
:::

### Challenge: A month calendar

Build a calendar for a month that starts on a Wednesday and has 30 days. Use a 7-column grid with a row of day names (Sun to Sat) on top. Day 1 must sit under "Wed", and day 18 should be highlighted as today. Use only one placement rule for day 1, and let everything else flow.

:::hint
Every cell can be a plain `<div>`, including the day names. Day 1 needs to start in the fourth column; look up `grid-column-start`.
:::

:::solution
```html preview height="330"
<div class="cal">
  <b>Sun</b><b>Mon</b><b>Tue</b><b>Wed</b><b>Thu</b><b>Fri</b><b>Sat</b>
  <div class="first">1</div><div>2</div><div>3</div><div>4</div><div>5</div><div>6</div><div>7</div>
  <div>8</div><div>9</div><div>10</div><div>11</div><div>12</div><div>13</div><div>14</div>
  <div>15</div><div>16</div><div>17</div><div class="today">18</div><div>19</div><div>20</div><div>21</div>
  <div>22</div><div>23</div><div>24</div><div>25</div><div>26</div><div>27</div><div>28</div>
  <div>29</div><div>30</div>
</div>
<style>
  body { font: 14px system-ui, sans-serif; margin: 10px; }
  .cal { display: grid; grid-template-columns: repeat(7, 1fr); gap: 4px; max-width: 480px; }
  .cal b { text-align: center; padding: 4px 0; color: #475569; }
  .cal div { aspect-ratio: 1; background: #f1f5f9; border-radius: 6px; padding: 4px; }
  .cal .first { grid-column-start: 4; }
  .cal .today { background: #2563eb; color: white; font-weight: 700; }
</style>
```

Once day 1 starts in column 4, the browser fills the rest of the row and wraps day 5 to the next line on its own. To change months, you change one number.
:::
