---
title: Build a product card grid for an online snack shop
summary: Build a shop page whose product cards line up in as many columns as fit, with buttons pinned to the bottom of every card and a Flexbox toolbar on top.
---

:::objectives
- Mark up a reusable product card with `<article>`, a heading, a price, and a button.
- Lay out a set of cards with CSS Grid, then let `auto-fit` and `minmax()` choose the column count.
- Use a column flex container and `margin-top: auto` to line up buttons across cards of different lengths.
- Build a wrapping toolbar with `justify-content: space-between`.
:::

Pixel Pantry, the snack shop from the last lesson, needs a product page. Here is where we're headed: a header with a title and filter buttons, and a grid of cards that rearranges itself to fit any screen. Every "Add to cart" button sits on the same line, no matter how long the description above it is.

Make a new folder called `pixel-pantry` with an `index.html` file, and open it with Live Server. Each step below shows the code for that step; type it in, save, and compare your browser with the preview.

## Step 1: Write the HTML for one card

Start with one card and get it right. Everything else is copies.

```html preview height="300"
<article class="card">
  <div class="thumb">Photo</div>
  <h2>Mango Chili Chips</h2>
  <p class="price">$2.99</p>
  <p class="desc">Thin plantain chips with a mango glaze and a slow chili kick.</p>
  <button type="button">Add to cart</button>
</article>
```

Why `<article>`? A product card makes sense on its own, the way a blog post or a comment does, and that's what `<article>` is for. The `<h2>` gives each product a real heading, so screen reader users can jump from product to product.

The `.thumb` div is a stand-in for a photo, so this page works without any image files. In your own shop you'd write `<img src="images/mango-chips.jpg" alt="A bowl of orange plantain chips">` instead. The next module shows how to make images like that scale.

## Step 2: Style the card as a box

Add a `<style>` block (or a `styles.css` file linked from the `<head>`) and turn the card into a white box with rounded corners.

```html preview height="360"
<article class="card">
  <div class="thumb">Photo</div>
  <h2>Mango Chili Chips</h2>
  <p class="price">$2.99</p>
  <p class="desc">Thin plantain chips with a mango glaze and a slow chili kick.</p>
  <button type="button">Add to cart</button>
</article>

<style>
  body { font-family: system-ui, sans-serif; margin: 0; padding: 16px; background: #f8fafc; color: #1e293b; }
  .card { max-width: 240px; background: white; border: 1px solid #e2e8f0; border-radius: 12px; padding: 12px; }
  .thumb {
    aspect-ratio: 16 / 9;
    background: #fdba74;
    border-radius: 8px;
    display: flex;
    align-items: center;
    justify-content: center;
  }
  .card h2 { font-size: 1.1rem; margin: 12px 0 4px; }
  .price { margin: 0; font-weight: 700; color: #15803d; }
  .desc { font-size: 0.9rem; color: #475569; }
  .card button { width: 100%; padding: 10px; border: 0; border-radius: 8px; background: #1e293b; color: white; font-weight: 600; }
</style>
```

Two things to notice. `aspect-ratio: 16 / 9` makes the thumbnail's height follow its width, so you never hard-code a height. And the thumbnail is a tiny flex container: `align-items` and `justify-content` set to `center` put the word "Photo" dead center. That's the most common Flexbox job there is.

The `max-width: 240px` on the card is temporary. Once the grid controls the width, we'll remove it.

## Step 3: Put three cards in a grid

Paste two more cards with different descriptions, wrap all three in a `<section class="products">`, and give the section a grid.

```css
.products {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
```

Delete `max-width: 240px` from `.card` now. Here's the result:

## Step 4: Pin every button to the bottom

Make each card a column flex container, then give the button an automatic top margin:

```css
.card {
  display: flex;
  flex-direction: column;
  /* keep the background, border, radius, and padding from before */
}
.card button {
  margin-top: auto;
}
```

```html preview height="340"

  <article class="card"><div class="thumb" style="background:#fde68a">Photo</div><h2>Sea Salt Popcorn</h2><p class="price">$1.49</p><p class="desc">Air-popped.</p><button>Add to cart</button></article>

<style>

  .card { display: flex; flex-direction: column; background: white; border: 1px solid #e2e8f0; border-radius: 12px; padding: 12px; }
  .thumb { aspect-ratio: 16 / 9; border-radius: 8px; display: flex; align-items: center; justify-content: center; }

```

In a flex container, an `auto` margin soaks up all the free space on that side. The short popcorn card has lots of spare room, so its button gets a big top margin and drops to the bottom. The long mochi card has none, so its button barely moves. Either way, all three line up.

Notice the button lost `width: 100%` and still fills the card. In a column flex container, `align-items: stretch` (the default) stretches every item across the cross axis, which is now horizontal.

## Step 5: Let the grid choose its column count

`repeat(3, 1fr)` is fine on a laptop, but on a 360px phone each card would be about 100px wide, far too skinny to read. Swap the column rule for the self-counting version:

```css
.products {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}
```

Once the frame is narrower than about 430px, two 200px columns plus the gap no longer fit, so the grid drops to one. On a wide screen it fits three or four. You wrote zero media queries.

:::

## Step 6: Add a toolbar with Flexbox

The header has two groups: a title on the left and filter buttons on the right. That's one row of items, so it's a Flexbox job.

```html
<header class="shop-bar">
  <h1>Snacks</h1>
  <div class="filters">
    <button type="button">All</button>
    <button type="button">Sweet</button>
    <button type="button">Salty</button>
  </div>
</header>
```

```css
.shop-bar {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
  margin-bottom: 16px;
}
.shop-bar h1 { margin: 0; }
.filters { display: flex; gap: 8px; }
```

`space-between` pushes the two groups to opposite ends. `flex-wrap: wrap` matters on phones: when the title and buttons don't fit on one line, the buttons drop below the title instead of squishing it. The `.filters` div is its own small flex container, so the buttons stay in a neat row.

The buttons don't filter anything yet. That takes JavaScript, which is a later course. For now they're the layout.

:::quiz
Q: In Step 4, why does `margin-top: auto` on the button only work after the card gets `display: flex`?
- [ ] Buttons ignore margins unless they're inside a grid
  Buttons accept margins anywhere. The difference is what `auto` means.
- [x] In a flex container, an `auto` margin takes up all the free space on that side
  In normal flow, a vertical `auto` margin just becomes 0. Inside a flex container, it absorbs the leftover height and pushes the button down.
- [ ] `margin-top: auto` centers the button vertically
  It pushes the button to the far end. Centering would need `auto` on both the top and the bottom.

Q: Why replace `repeat(3, 1fr)` with `repeat(auto-fit, minmax(200px, 1fr))`?
- [ ] It makes the cards load faster
  Both rules are just layout. Neither changes loading speed.
- [ ] It forces exactly three columns on every screen
  That's what `repeat(3, 1fr)` does, and it's the problem on a phone.
- [x] The browser picks how many 200px-or-wider columns fit, so phones get one column and laptops get several
  `auto-fit` counts the columns from the available width, and `1fr` stretches them to fill the row.

Q: Before Step 4, the three cards were already the same height. What caused that?
- [ ] `aspect-ratio` on the thumbnails
  That sets each thumbnail's shape, but the text below still differs in length.
- [x] Grid stretches every item in a row to the height of the tallest one
  Grid items default to stretching across the row, so the short popcorn card grows to match the mochi card.
- [ ] `gap: 16px` evens out the heights
  `gap` only adds space between cards; it never changes their size.
:::

:::takeaways
- Get one card right first, then copy it. A semantic `<article>` with an `<h2>` makes each product easy to find with a screen reader.
- `repeat(auto-fit, minmax(min(200px, 100%), 1fr))` gives a card grid that adapts to any width without media queries.
- A column flex container plus `margin-top: auto` pins a button to the bottom of a card, so buttons line up across a row.
- `justify-content: space-between` with `flex-wrap: wrap` makes a toolbar that splits to the edges on wide screens and stacks politely on narrow ones.
:::

## Ideas to extend it

- Add a "Sold out" card: give it a class that lowers the thumbnail's opacity and add the `disabled` attribute to its button.
- Make one product a "Featured" card that spans two columns with `grid-column: span 2`. Watch what happens to it when the grid drops to one column.
- Put the price and a small "New" label on the same line using a flex row with `justify-content: space-between`.
- Swap the `.thumb` placeholders for real photos you took, with `alt` text that describes the snack.
