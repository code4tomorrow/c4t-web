## Warm-up: which LEDs light up?

```makecode
for (let index = 0; index <= 4; index++) {
    led.plot(index, 4 - index)
}
```

:::solution
A diagonal line from the bottom-left corner to the top-right corner. When `index` is 0 the LED is (0, 4), the bottom left; when `index` is 4 it's (4, 0), the top right. The `4 - index` flips the direction, because y counts down from the top.
:::

### Exercise 1: Draw the border with one loop

Light every LED on the outside edge of the screen and leave the middle nine dark. Use one **for** loop, not 16 separate plot blocks.

```text
# # # # #
# . . . #
# . . . #
# . . . #
# # # # #
```

:::hint
**for index from 0 to 4** (in **Loops**) gives you 0, 1, 2, 3, 4. Each pass can plot one LED on each of the four sides.
:::

:::solution
```makecode
for (let index = 0; index <= 4; index++) {
    led.plot(index, 0)
    led.plot(index, 4)
    led.plot(0, index)
    led.plot(4, index)
}
```

The top row is every (x, 0), the bottom row every (x, 4), and the side columns every (0, y) and (4, y). The corners get plotted twice, which is harmless: plotting an LED that's already on changes nothing.
:::

### Exercise 2: A dot that wraps around

Change the moving dot from the notes so that it wraps instead of stopping. Moving right from x = 4 brings it to x = 0, and moving left from x = 0 brings it to x = 4.

:::hint
**remainder of ... ÷ ...** in **Math** gives what's left over after dividing. The remainder of anything divided by 5 is always 0 to 4. Be careful with going left: in JavaScript, the remainder of -1 ÷ 5 is -1, not 4.
:::

:::solution
```makecode
let x = 2
led.plot(x, 2)
input.onButtonPressed(Button.B, function () {
    led.unplot(x, 2)
    x = (x + 1) % 5
    led.plot(x, 2)
})
input.onButtonPressed(Button.A, function () {
    led.unplot(x, 2)
    x = (x + 4) % 5
    led.plot(x, 2)
})
```

Going right, `(4 + 1) % 5` is 0, so the dot wraps to the left edge. Going left, adding 4 has the same effect as subtracting 1 on a loop of five positions, but it never makes a negative number: `(0 + 4) % 5` is 4.
:::

### Exercise 3: A two-player scoreboard

A gives player 1 a point and B gives player 2 a point. After each point, scroll the score like `2-1`. The first player to reach 5 wins: scroll `A WINS` or `B WINS` and reset both scores.

```text
A, A, B        ->  1-0, 2-0, 2-1
A, A, A        ->  3-1, 4-1, 5-1, A WINS
```

:::hint
**join** in **Text** (under **Advanced**) glues numbers and text into one string. In JavaScript, `"" + p1 + "-" + p2` does the same thing.
:::

:::solution
```makecode
let p1 = 0
let p2 = 0
input.onButtonPressed(Button.A, function () {
    p1 += 1
    basic.showString("" + p1 + "-" + p2)
    if (p1 == 5) {
        basic.showString("A WINS")
        p1 = 0
        p2 = 0
    }
})
input.onButtonPressed(Button.B, function () {
    p2 += 1
    basic.showString("" + p1 + "-" + p2)
    if (p2 == 5) {
        basic.showString("B WINS")
        p1 = 0
        p2 = 0
    }
})
```

The empty string `""` at the front is what MakeCode writes for a **join** block: it makes the expression text from the very first piece, so the numbers are stuck together with the dash instead of being added. Both scores reset together, so a new game always starts at 0-0.
:::

### Exercise 4: A level meter

A raises a level from 0 up to 5 and B lowers it back to 0. Draw the level as full-width rows lit from the bottom: level 1 lights the bottom row, level 5 lights the whole screen.

```text
level 2:        level 4:
. . . . .       . . . . .
. . . . .       # # # # #
. . . . .       # # # # #
# # # # #       # # # # #
# # # # #       # # # # #
```

:::hint
Let **forever** own the screen and redraw from `level`, like the badge did with `mode`. Visit every LED with a loop inside a loop. Row 4 is the bottom, so a row is lit when `4 - row` is less than `level`.
:::

:::solution
```makecode
let level = 0
basic.forever(function () {
    for (let row = 0; row <= 4; row++) {
        for (let col = 0; col <= 4; col++) {
            if (4 - row < level) {
                led.plot(col, row)
            } else {
                led.unplot(col, row)
            }
        }
    }
})
input.onButtonPressed(Button.A, function () {
    if (level < 5) {
        level += 1
    }
})
input.onButtonPressed(Button.B, function () {
    if (level > 0) {
        level += -1
    }
})
```

`4 - row` counts rows from the bottom: the bottom row is 0, the top row is 4. At level 2, rows with a count of 0 and 1 are lit. Because the loop plots *and* unplots, lowering the level erases the top row instead of leaving it lit.
:::

### Exercise 5: Real dice faces

Pressing A rolls a number from 1 to 6 and draws it as dots, the way a real die looks, instead of as a digit.

```text
1:          4:          6:
. . . . .   # . . . #   # . . . #
. . . . .   . . . . .   . . . . .
. . # . .   . . . . .   # . . . #
. . . . .   . . . . .   . . . . .
. . . . .   # . . . #   # . . . #
```

:::hint
Look for dots that several faces share. Odd numbers have a center dot. Every face from 2 up has the top-left and bottom-right corners. Faces from 4 up add the other two corners. Only 6 has the middle of each side.
:::

:::solution
```makecode
input.onButtonPressed(Button.A, function () {
    let roll = randint(1, 6)
    basic.clearScreen()
    if (roll == 1 || roll == 3 || roll == 5) {
        led.plot(2, 2)
    }
    if (roll >= 2) {
        led.plot(0, 0)
        led.plot(4, 4)
    }
    if (roll >= 4) {
        led.plot(4, 0)
        led.plot(0, 4)
    }
    if (roll == 6) {
        led.plot(0, 2)
        led.plot(4, 2)
    }
})
```

Four separate `if` blocks, not one `if ... else if` chain, because a single face can need several groups of dots: a 5 uses the center and all four corners. **clear screen** first, or dots from the last roll would stay lit. Keep this program: in the next module you'll roll it by shaking.
:::

### Exercise 6: Fill the screen in reading order

Light the LEDs one by one, left to right along the top row, then the next row, and so on down to the bottom right, 80 ms apart. Then turn them off in the same order, and repeat.

:::hint
Number the LEDs 0 to 24 in reading order, as in the chart below. For LED number `i`, the column is the remainder of `i ÷ 5`, and the row is `i ÷ 5` rounded down (**round** in **Math** has a **floor** option).
:::

```python run alt="A 5 by 5 grid with the numbers 0 to 24 written in reading order: 0 to 4 across the top row, 5 to 9 on the second row, down to 20 to 24 on the bottom row. Rows alternate between two pale colors." caption="Reading-order numbers for the 25 LEDs, worked out with x = i % 5 and y = i // 5"
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(4.4, 4.4))
for i in range(25):
    x, y = i % 5, i // 5
    shade = "#f4c7c3" if y % 2 == 0 else "#c6d5f0"
    ax.add_patch(plt.Circle((x, y), 0.4, color=shade))
    ax.text(x, y, str(i), ha="center", va="center", fontsize=12)
ax.set_xlim(-0.6, 4.6)
ax.set_ylim(4.6, -0.6)
ax.set_aspect("equal")
ax.set_xticks(range(5))
ax.set_yticks(range(5))
ax.xaxis.tick_top()
ax.set_xlabel("x = i % 5")
ax.xaxis.set_label_position("top")
ax.set_ylabel("y = i // 5")
for side in ax.spines.values():
    side.set_visible(False)
```

:::solution
```makecode
basic.forever(function () {
    for (let index = 0; index <= 24; index++) {
        led.plot(index % 5, Math.floor(index / 5))
        basic.pause(80)
    }
    for (let index = 0; index <= 24; index++) {
        led.unplot(index % 5, Math.floor(index / 5))
        basic.pause(80)
    }
})
```

Take LED 13: `13 % 5` is 3 and `13 / 5` rounded down is 2, so it's (3, 2), the fourth LED of the middle row. Turning one counter into two coordinates like this is how a long list of things can be laid out on a grid.
:::

### Challenge: A two-player reaction duel

Turn the reaction game into a duel. Press A and B together to start a round. After a random wait the whole screen lights, and the first player to press their button wins: show an arrow pointing at the winner's side. A press during the wait loses the round for whoever pressed it.

:::hint
Keep the same three states and the same forever loop as the build-along. Pressing A and B together doesn't also trigger the separate A and B handlers, so it's safe to use as the start button. Each of the A and B handlers needs a branch for `"go"` (you win) and one for `"waiting"` (you lose).
:::

:::solution
```makecode
let state = "idle"
basic.showIcon(IconNames.Diamond)
input.onButtonPressed(Button.AB, function () {
    if (state == "idle") {
        state = "waiting"
        basic.clearScreen()
        led.plot(2, 2)
    }
})
input.onButtonPressed(Button.A, function () {
    if (state == "go") {
        state = "idle"
        basic.showArrow(ArrowNames.West)
    } else if (state == "waiting") {
        state = "idle"
        basic.showArrow(ArrowNames.East)
    }
})
input.onButtonPressed(Button.B, function () {
    if (state == "go") {
        state = "idle"
        basic.showArrow(ArrowNames.East)
    } else if (state == "waiting") {
        state = "idle"
        basic.showArrow(ArrowNames.West)
    }
})
basic.forever(function () {
    if (state == "waiting") {
        basic.pause(randint(1000, 4000))
        if (state == "waiting") {
            state = "go"
            basic.showLeds(`
                # # # # #
                # # # # #
                # # # # #
                # # # # #
                # # # # #
                `)
        }
    }
})
```

The winner is whoever's handler sets the state back to `"idle"` first. The loser's press then finds the state is already idle and does nothing, so there's never a second, conflicting arrow. A false start points the arrow at the *other* player, because they win that round.
:::
