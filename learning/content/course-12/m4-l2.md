summary: Turn the hazard course into a playable platformer with a Rigidbody 2D player that runs, jumps only when grounded, respawns when a saw hits it, collects coins, and is followed by a damped, bounded Cinemachine camera.

:::objectives
- Set up a Dynamic Rigidbody 2D player with a capsule collider, no friction, Continuous detection, and interpolation.
- Read input in `Update`, apply velocity in `FixedUpdate`, and jump only when a layer-filtered ground check passes.
- Make every saw a hazard by editing one prefab, and add trigger coins.
- Install Cinemachine and build a follow camera with damping, a dead zone, and level bounds.
:::

The hazard course from Module 2 becomes a game. A/D or the arrows run, Space jumps (only from the ground), any saw sends you back to the start, coins vanish when grabbed, and the camera glides after you without showing empty space past the level's edges.

```text
SampleScene
  Main Camera            (Camera, Cinemachine Brain)
  Global Light 2D
  CinemachineCamera      (Cinemachine Camera, Position Composer, Confiner 2D)
  CameraBounds           (Box Collider 2D, trigger)
  Ground, Platform A, Platform B, Wall, Left Wall    (layer: Ground)
  Player                 (Rigidbody 2D, Capsule Collider 2D, PlayerController, PlayerRespawn)
    Eye
    GroundCheck
  Saw, Saw (1), ... BobbingSaw (1)                  (Hazard trigger, from the prefab)
  Coin, Coin (1), ...
```

## Step 1: Widen the level and give it a Ground layer

Open `SampleScene`. A follow camera only matters in a level wider than the screen, so set `Ground` to position (10, -3, 0) and scale (40, 1, 1); it now runs from x = -10 to x = 30.

Add four more Squares, each with a **Box Collider 2D**:

| Name | Position | Scale | Purpose |
| --- | --- | --- | --- |
| `Platform A` | (11, -0.5, 0) | (4, 0.5, 1) | First jump |
| `Platform B` | (17, 1.5, 0) | (4, 0.5, 1) | Second jump |
| `Wall` | (24, -1, 0) | (1, 3, 1) | A wall to jump against |
| `Left Wall` | (-10.5, 2, 0) | (1, 10, 1) | Stops you walking off the left end |

Now the layer. Open the **Layer** dropdown at the top right of the Inspector, choose **Add Layer...**, and type `Ground` into the first empty **User Layer** slot. Then select `Ground` and the four new objects together and set their Layer to **Ground**. Leave the saws on **Default**.

## Step 2: A player that physics can move

1. **GameObject > 2D Object > Sprites > Capsule**, named `Player`, at (-8, -1.5, 0), scale (0.8, 0.8, 1), blue, with the same `Eye` child as in Module 3.
2. Set its **Tag** to **Player**, one of Unity's built-in tags.
3. **Add Component > Rigidbody 2D**. Set **Gravity Scale** to 3, **Collision Detection** to **Continuous**, **Interpolate** to **Interpolate**, and under **Constraints** tick **Freeze Rotation Z** so it can't tip over.
4. **Add Component > Capsule Collider 2D**, which sizes itself to the sprite.
5. **Create > 2D > Physics Material 2D** in `Assets`, named `NoFriction`, with **Friction** 0. Drag it into the collider's **Material** slot.

Press Play: the player drops onto the floor and stays upright. Gravity Scale 3 gives the snappy falls platformers usually have, and zero friction stops walls from pinning you in mid-air.

## Step 3: A ground check at the feet

Right-click `Player` and choose **Create Empty** to add a child named `GroundCheck` at position (0, -1, 0). The Capsule shape is 2 units tall, so -1 in local space is exactly its bottom. The script will ask whether anything on the Ground layer overlaps a small circle there.

## Step 4: Running

Create `PlayerController` in `Assets/Scripts` and attach it to `Player`:

```csharp title="PlayerController.cs (step 4)"
using UnityEngine;
using UnityEngine.InputSystem;

[RequireComponent(typeof(Rigidbody2D))]
public class PlayerController : MonoBehaviour
{
    [Header("Running")]
    [SerializeField] private float moveSpeed = 7f;

    private Rigidbody2D rb;
    private float moveInput;

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
    }

    void Update()
    {
        moveInput = 0f;
        Keyboard keyboard = Keyboard.current;
        if (keyboard == null) return;

        if (keyboard.aKey.isPressed || keyboard.leftArrowKey.isPressed) moveInput -= 1f;
        if (keyboard.dKey.isPressed || keyboard.rightArrowKey.isPressed) moveInput += 1f;
    }

    void FixedUpdate()
    {
        rb.linearVelocity = new Vector2(moveInput * moveSpeed, rb.linearVelocity.y);
    }
}
```

`Update` stores the input in a field, and `FixedUpdate` turns it into velocity on the physics clock. Only x is replaced: keeping `rb.linearVelocity.y` lets gravity work, and setting it to 0 would make the player float. Run into the `Wall` to check that it stops you.

## Step 5: Jumping, only from the ground

Add the jump fields and state below `moveSpeed`:

```csharp
[Header("Jumping")]
[SerializeField] private float jumpSpeed = 12f;
[SerializeField] private Transform groundCheck;
[SerializeField] private float groundCheckRadius = 0.15f;
[SerializeField] private LayerMask groundLayer;

private bool jumpQueued;
private bool isGrounded;

public bool IsGrounded => isGrounded;
```

At the end of `Update`, remember a press:

```csharp
if (keyboard.spaceKey.wasPressedThisFrame) jumpQueued = true;
```

And replace `FixedUpdate`:

```csharp
void FixedUpdate()
{
    isGrounded = Physics2D.OverlapCircle(groundCheck.position, groundCheckRadius, groundLayer) != null;

    Vector2 velocity = rb.linearVelocity;
    velocity.x = moveInput * moveSpeed;
    if (jumpQueued && isGrounded) velocity.y = jumpSpeed;
    jumpQueued = false;

    rb.linearVelocity = velocity;
}
```

`Physics2D.OverlapCircle` returns the first collider on the given layers inside the circle, or `null`. `jumpQueued` carries the one-frame press from `Update` to the next physics step, so no press is lost; it's cleared every step, so a mid-air press is dropped (the practice set improves that).

In Unity, drag `GroundCheck` into the **Ground Check** slot and set **Ground Layer** to **Ground**. `IsGrounded` lets other scripts read the result, such as Module 5's animation code.

How high is a jump? With gravity of 9.81 × 3, the launch-speed formula answers it, and runs backward to pick a speed for the height you want:

```python run title="jump_height.py"
import math

gravity = 9.81 * 3      # Physics 2D gravity times Gravity Scale
jump_speed = 12

height = jump_speed ** 2 / (2 * gravity)
time_to_peak = jump_speed / gravity
print(f"Jump Speed {jump_speed}: peak {height:.2f} units after {time_to_peak:.2f} s")

for wanted in [1.5, 2.5, 3.5]:
    print(f"For a {wanted}-unit jump, set Jump Speed to {math.sqrt(2 * gravity * wanted):.2f}")
```

Platform A's top is 2.25 units above the floor, so a 2.45-unit jump just clears it, a deliberate first challenge.

## Step 6: Face the way you run, and see the ground check

Add Module 3's facing method, called as `FaceDirection(moveInput);` at the end of `Update`, plus a gizmo that draws the ground check:

```csharp
void FaceDirection(float x)
{
    if (Mathf.Approximately(x, 0f)) return;
    Vector3 scale = transform.localScale;
    scale.x = Mathf.Abs(scale.x) * Mathf.Sign(x);
    transform.localScale = scale;
}

void OnDrawGizmosSelected()
{
    if (groundCheck == null) return;
    Gizmos.color = isGrounded ? Color.green : Color.red;
    Gizmos.DrawWireSphere(groundCheck.position, groundCheckRadius);
}
```

Press Play with `Player` selected and watch the circle turn red in the air and green on landing.

:::warning The player can jump forever in mid-air
Check **Ground Layer**. If it's **Everything**, the circle at the player's feet overlaps the player's *own* capsule, which is on Default, so `isGrounded` is always true. If it's **Nothing**, the player never jumps at all. It should be exactly **Ground**.
:::

## Step 7: Saws send you back to the start

Add a respawn component to `Player`:

```csharp title="PlayerRespawn.cs"
using UnityEngine;

public class PlayerRespawn : MonoBehaviour
{
    private Rigidbody2D rb;
    private Vector3 spawnPoint;

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
        spawnPoint = transform.position;
    }

    public void Respawn()
    {
        transform.position = spawnPoint;
        rb.linearVelocity = Vector2.zero;
    }
}
```

A respawn is a deliberate teleport, the one time setting the Transform directly is right, and clearing the velocity stops the player arriving with the speed it died with. Now the payoff from Module 2. Create a `Hazard` script:

```csharp title="Hazard.cs"
using UnityEngine;

public class Hazard : MonoBehaviour
{
    void OnTriggerEnter2D(Collider2D other)
    {
        if (!other.CompareTag("Player")) return;

        if (other.TryGetComponent(out PlayerRespawn respawn))
            respawn.Respawn();
    }
}
```

Open `Saw.prefab` in Prefab Mode and, on its root, add a **Circle Collider 2D** with **Is Trigger** ticked plus the `Hazard` component. Back in the scene, every saw, bobbing variants included, is now dangerous.

## Step 8: Coins

Make a yellow Circle named `Coin`, scale (0.5, 0.5, 1), with a trigger **Circle Collider 2D** and the `Coin` script from the Notes. Make it a prefab and place five, including one in a risky spot near a bobbing saw. Saws and coins need no Rigidbody 2D, because the player's Dynamic body is the one in each pair. Module 5 upgrades `Coin` and `Hazard` with score, sound, and health, so keep these file names.

## Step 9: A Cinemachine follow camera

1. In **Window > Package Management > Package Manager**, choose **Unity Registry**, find **Cinemachine**, and click **Install**.
2. Click empty space in the Hierarchy so nothing is selected, then choose **GameObject > Cinemachine > Targeted Cameras > 2D Camera**. This creates a Cinemachine Camera with a **Position Composer** and adds a **Cinemachine Brain** to the Main Camera.
3. Drag `Player` into the new camera's **Tracking Target** field.
4. Under **Lens**, set **Orthographic Size** to 6.
5. On the **Position Composer**, set **Damping** to 0.5 for X and 0.75 for Y, turn on **Dead Zone**, and set its size to about 0.15 wide by 0.25 tall.

Press Play. The camera trails the player slightly, and small steps inside the dead zone don't move it. The Main Camera's Transform is now driven by the Brain, so make camera changes on the Cinemachine Camera.

## Step 10: Keep the camera inside the level

At the left end the camera shows empty space. Create an empty `CameraBounds` at (10, 3.5, 0) with a **Box Collider 2D** of **Size** (41, 14) and **Is Trigger** ticked. Keep it on **Default**: ground checks detect triggers too, so on Ground it would make the player "grounded" everywhere.

On the Cinemachine Camera, use **Add Extension** to add **Cinemachine Confiner 2D**, and drag `CameraBounds` into **Bounding Shape 2D**. The camera now stops at the edges. If you resize the bounds later, click **Invalidate Bounding Shape Cache** on the confiner.

## The finished controller

```csharp title="PlayerController.cs"
using UnityEngine;
using UnityEngine.InputSystem;

[RequireComponent(typeof(Rigidbody2D))]
public class PlayerController : MonoBehaviour
{
    [Header("Running")]
    [SerializeField] private float moveSpeed = 7f;

    [Header("Jumping")]
    [SerializeField] private float jumpSpeed = 12f;
    [SerializeField] private Transform groundCheck;
    [SerializeField] private float groundCheckRadius = 0.15f;
    [SerializeField] private LayerMask groundLayer;

    private Rigidbody2D rb;
    private float moveInput;
    private bool jumpQueued;
    private bool isGrounded;

    public bool IsGrounded => isGrounded;

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
    }

    void Update()
    {
        moveInput = 0f;
        Keyboard keyboard = Keyboard.current;
        if (keyboard == null) return;

        if (keyboard.aKey.isPressed || keyboard.leftArrowKey.isPressed) moveInput -= 1f;
        if (keyboard.dKey.isPressed || keyboard.rightArrowKey.isPressed) moveInput += 1f;
        if (keyboard.spaceKey.wasPressedThisFrame) jumpQueued = true;

        FaceDirection(moveInput);
    }

    void FixedUpdate()
    {
        isGrounded = Physics2D.OverlapCircle(groundCheck.position, groundCheckRadius, groundLayer) != null;

        Vector2 velocity = rb.linearVelocity;
        velocity.x = moveInput * moveSpeed;
        if (jumpQueued && isGrounded) velocity.y = jumpSpeed;
        jumpQueued = false;

        rb.linearVelocity = velocity;
    }

    void FaceDirection(float x)
    {
        if (Mathf.Approximately(x, 0f)) return;
        Vector3 scale = transform.localScale;
        scale.x = Mathf.Abs(scale.x) * Mathf.Sign(x);
        transform.localScale = scale;
    }

    void OnDrawGizmosSelected()
    {
        if (groundCheck == null) return;
        Gizmos.color = isGrounded ? Color.green : Color.red;
        Gizmos.DrawWireSphere(groundCheck.position, groundCheckRadius);
    }
}
```


:::quiz
Q: Why is the jump press stored in `jumpQueued` instead of jumping directly inside `Update`?
- [x] So the jump is applied on the physics clock without losing one-frame presses
  `Update` catches every press; `FixedUpdate` applies it in step with physics.
- [ ] Because `wasPressedThisFrame` only works in `Update`
  It works anywhere; the problem is that FixedUpdate doesn't run every frame.
- [ ] To add a delay that makes jumps feel heavier
  At most it's one physics step, about 0.02 seconds; the reason is reliability, not feel.

Q: You made the saws dangerous by editing `Saw.prefab`. What would have happened with twelve independent copy-pasted saws?
- [ ] The same thing, automatically
  Independent copies don't share edits.
- [x] You'd add a collider and the Hazard script to each by hand, and likely miss one
  That's Module 2's drift problem; the prefab let one edit reach every saw.
- [ ] They'd become hazards only after restarting Unity
  Restarting doesn't link independent objects.

Q: Why must `CameraBounds` stay off the Ground layer?
- [ ] Cinemachine only reads colliders on Default
  The confiner reads whatever collider you assign, on any layer.
- [x] Ground checks detect triggers too, so the player would be "grounded" everywhere
  Physics queries include triggers by default, and the player is always inside the bounds.
:::

:::takeaways
- The player is a Dynamic Rigidbody 2D with a capsule, zero friction, Continuous detection, interpolation, and frozen rotation.
- Read input in `Update`; in `FixedUpdate`, replace x velocity and keep y unless jumping.
- Ground checks are an `OverlapCircle` at the feet with a `LayerMask` that excludes the player.
- A Cinemachine 2D Camera with damping, a dead zone, and a Confiner 2D follows smoothly and stays in the level.
:::

## Ideas to extend it

-   Set **Lookahead Time** to about 0.3 with **Lookahead Ignore Y** ticked, so the camera leads your running direction without bobbing on jumps.
-   Build a moving platform from a Kinematic Rigidbody 2D moved with `rb.MovePosition` in `FixedUpdate`, and see what happens to a player standing on it.
