:::objectives
- Store a research question as data and check it for missing parts.
- Turn reported accuracies and test-set sizes into Wilson confidence intervals and majority-class baselines.
- Flag weak evidence with explicit rules: no baseline, a baseline inside the interval, random-row splits, too few independent sites.
- Compute Cohen's *d* from reported means and standard deviations, and see why a small p-value can hide a trivial effect.
- Save the table and a falsifiable hypothesis into the project.
:::

A literature review usually ends up as a pile of PDFs and a paragraph that says "previous studies achieved 81 to 97% accuracy." That sentence hides everything that matters: which of those numbers came from 60 test images, which ones beat a real baseline, and which ones were tested on farms the model had never seen.

We're going to build the alternative, a table that recomputes what each paper's own numbers support. Here's where we'll end up:

```text
study  accuracy  95% CI        majority  baseline  flags
A      0.93      0.84 to 0.97  0.80      none      no baseline; random-image split; 3 farms; no code
B      0.84      0.82 to 0.86  0.65      0.78      (none)
D      0.81      0.77 to 0.84  0.60      0.80      baseline inside CI
...
```

The six studies are invented for this exercise, but each one has a problem that turns up constantly in real literature. The question they're all about is the one from the last lesson: detecting nitrogen deficiency in wheat from leaf images.

## Step 1: Write the question down as data

A question that lives in a dictionary can be checked by code and saved with the project. This function lists any of the five parts (plus the test set) that are missing or blank.

```python run title="plan.py"
import json
from pathlib import Path

import numpy as np
import pandas as pd

REQUIRED = ["population", "inputs", "comparison", "outcome", "test_set", "threshold"]

def missing_parts(plan):
    return [part for part in REQUIRED if not str(plan.get(part, "")).strip()]

vague = {"question": "Can AI detect nitrogen deficiency?"}
plan = {
    "question": "Do leaf images detect week-6 nitrogen deficiency better than a chlorophyll meter?",
    "population": "Winter wheat plots, one region, 2025 season",
    "inputs": "Drone RGB images of the canopy at week 6",
    "comparison": "Handheld chlorophyll meter with the agronomist's standard cutoff",
    "outcome": "Accuracy (primary) and recall for deficient plots (secondary)",
    "test_set": "All plots from farms held out of training",
    "threshold": "Accuracy at least 5 points above the meter, with the 95% CI excluding the meter",
}
print("vague plan is missing:", missing_parts(vague))
print("full plan is missing: ", missing_parts(plan))
```

The threshold is concrete enough to fail. If the model beats the meter by 3 points, the answer is no, and the plan says so before anyone has seen a result.

## Step 2: Enter what each study reports

Read each paper for the five referee questions and record only what it actually states. `NaN` means "not reported", which is itself information.

```python run title="studies.py"
studies = pd.DataFrame([
    ("A", 2021,   60, "random images",  3, 0.93, None,                np.nan, 0.20, False),
    ("B", 2022, 1200, "new farms",     40, 0.84, "chlorophyll meter", 0.78,  0.35, True),
    ("C", 2023,  300, "random images",  6, 0.90, "chlorophyll meter", 0.87,  0.12, False),
    ("D", 2023,  450, "new season",    18, 0.81, "logistic regression", 0.80, 0.40, True),
    ("E", 2024,   80, "random images",  2, 0.97, "SVM",               0.92,  0.50, False),
    ("F", 2025,  900, "new farms",     25, 0.88, "chlorophyll meter", 0.80,  0.30, True),
], columns=["study", "year", "n_test", "split", "farms", "accuracy",
            "baseline", "baseline_acc", "positive_rate", "code_shared"])
print(studies[["study", "n_test", "split", "farms", "accuracy", "baseline_acc", "positive_rate"]])
```

Two columns deserve a comment. `farms` counts independent sources, not images: 2,000 photos from two farms are closer to two samples than 2,000 when the question is about new farms. `positive_rate` is the fraction of deficient plots in the test set, which papers usually report somewhere in the data section even when they don't report a baseline.

## Step 3: Add the numbers the papers left out

Two numbers can be recomputed from what's already in the table. The **Wilson interval** comes from accuracy and test-set size. The **majority-class accuracy**, what you'd score by always guessing the more common class, comes from the positive rate.

```python run title="recompute.py"
from statsmodels.stats.proportion import proportion_confint

correct = (studies["accuracy"] * studies["n_test"]).round().astype(int)
low, high = proportion_confint(correct, studies["n_test"], alpha=0.05, method="wilson")
studies["ci_low"], studies["ci_high"] = low, high
studies["majority_acc"] = np.maximum(studies["positive_rate"], 1 - studies["positive_rate"])
studies["gain_over_majority"] = studies["accuracy"] - studies["majority_acc"]

print(studies[["study", "accuracy", "ci_low", "ci_high", "majority_acc", "gain_over_majority"]].round(3))
```

Study C's 90% looks respectable until you see that only 12% of its test plots were deficient, so guessing "healthy" every time scores 88%. Its model adds 2 points over a guess that needs no images at all. Study E's 97% sits on 80 images, and its interval stretches from about 91% to over 99%.

## Step 4: Flag the weak spots automatically

Writing the rules as code forces you to state them precisely, and it applies them the same way to the sixth paper as to the first.

```python run title="flags.py"
def flags_for(row):
    found = []
    if pd.isna(row["baseline_acc"]):
        found.append("no baseline")
    elif row["ci_low"] <= row["baseline_acc"]:
        found.append("baseline inside CI")
    if row["gain_over_majority"] < 0.05:
        found.append("under 5 pts above majority")
    if row["split"] == "random images":
        found.append("random-image split")
    if row["farms"] < 5:
        found.append(f"{row['farms']} farms")
    if not row["code_shared"]:
        found.append("no code")
    return "; ".join(found) or "(none)"

studies["flags"] = studies.apply(flags_for, axis=1)
for row in studies.itertuples():
    print(f"{row.study}  {row.accuracy:.2f}  {row.flags}")
```

Only B and F come through clean, and their accuracies (84% and 88%) are well below the eye-catching 93% and 97% of A and E. That pattern is common: careful evaluation on new farms produces smaller numbers than random splits of images from a few farms, because images from the same farm share soil, lighting, and camera, and a model can learn those instead of the plant.

## Step 6: Effect sizes for the field trials

Some papers in a review aren't ML papers at all. Field trials of the fertilizer schedule report mean yields with standard deviations, and the useful summary is an effect size, not a p-value. **Cohen's d** divides the difference in means by the pooled standard deviation, so it says how many "typical plot-to-plot differences" the treatment moves yield. By Cohen's rough convention, 0.2 is small, 0.5 medium, and 0.8 large.

```python run title="effect_sizes.py"
from scipy import stats

trials = pd.DataFrame([
    ("G", 3.10, 0.60,   12, 2.70, 0.55,   12),
    ("H", 7.42, 1.10, 2000, 7.35, 1.12, 2000),
    ("I", 5.60, 0.90,   40, 5.10, 1.00,   40),
], columns=["study", "mean_t", "sd_t", "n_t", "mean_c", "sd_c", "n_c"])

def cohens_d(r):
    pooled = np.sqrt(((r.n_t - 1) * r.sd_t**2 + (r.n_c - 1) * r.sd_c**2) / (r.n_t + r.n_c - 2))
    return (r.mean_t - r.mean_c) / pooled

for r in trials.itertuples():
    t, p = stats.ttest_ind_from_stats(r.mean_t, r.sd_t, r.n_t, r.mean_c, r.sd_c, r.n_c, equal_var=False)
    print(f"{r.study}: d = {cohens_d(r):.2f}, Welch p = {p:.3f}, n per group = {r.n_t}")
```

This is the most misread pattern in research. H passes the usual p < 0.05 test and has a trivial effect: with 2,000 plots per group, a 0.07 t/ha difference is detectable but agronomically meaningless. G has a large effect and p = 0.10, because 12 plots per group can't pin it down. A p-value mixes effect size with sample size; report the effect size and its interval, and the reader can judge both.

## The finished program

Here's the whole review as one standalone cell you can paste into a fresh notebook and point at your own table.

```python run title="evidence_table.py"
import numpy as np
import pandas as pd
from statsmodels.stats.proportion import proportion_confint

def add_evidence(table):
    table = table.copy()
    correct = (table["accuracy"] * table["n_test"]).round().astype(int)
    table["ci_low"], table["ci_high"] = proportion_confint(correct, table["n_test"], method="wilson")
    table["majority_acc"] = np.maximum(table["positive_rate"], 1 - table["positive_rate"])
    table["gain_over_majority"] = table["accuracy"] - table["majority_acc"]
    return table

def flags_for(row, min_farms=5, min_gain=0.05):
    found = []
    if pd.isna(row["baseline_acc"]):
        found.append("no baseline")
    elif row["ci_low"] <= row["baseline_acc"]:
        found.append("baseline inside CI")
    if row["gain_over_majority"] < min_gain:
        found.append("under 5 pts above majority")
    if row["split"] == "random images":
        found.append("random-image split")
    if row["farms"] < min_farms:
        found.append(f"{row['farms']} farms")
    if not row["code_shared"]:
        found.append("no code")
    return "; ".join(found) or "(none)"

table = pd.read_csv("leaf-nitrogen-study/results/evidence_table.csv")[
    ["study", "n_test", "split", "farms", "accuracy", "baseline_acc", "positive_rate", "code_shared"]]
table = add_evidence(table)
table["flags"] = table.apply(flags_for, axis=1)
for row in table.itertuples():
    print(f"{row.study}  {row.accuracy:.2f}  CI {row.ci_low:.2f}-{row.ci_high:.2f}  "
          f"majority {row.majority_acc:.2f}  {row.flags}")
```

:::quiz
Q: Why does the table record `farms` separately from `n_test`?
- [x] Images from the same farm share soil, light, and camera, so the number of farms limits how well results generalize to new farms
  A test set of 80 images from 2 farms is weak evidence about farm number 3, whatever the image count says.
- [ ] To compute the Wilson interval
  The interval uses `n_test` and accuracy; `farms` feeds the independence flag.
- [ ] Because papers always report both
  They often don't, which is why a missing value is worth recording.

Q: Study C reports 90% accuracy with 12% deficient plots in its test set. What does the table conclude?
- [ ] Strong evidence, since 90% is high
  The headline hides the base rate.
- [x] Weak evidence: always guessing "healthy" scores 88%, so the model adds only 2 points
  The majority-class accuracy is the floor any model must clear, and C barely clears it.
- [ ] The study must contain an error
  Nothing is wrong with the numbers; they just don't support a strong claim.

Q: Trial H has p = 0.046 and d = 0.06. How should it go in your review?
- [ ] As the strongest evidence, since its p-value is the smallest among the significant trials
  A small p-value with 2,000 plots per group mostly reflects the sample size.
- [x] As a precisely estimated but tiny effect that's unlikely to matter in practice
  Report the effect size; d = 0.06 means the groups overlap almost completely.
- [ ] Excluded, because effects under 0.2 aren't real
  Small effects can be real; they're just small. Exclusion rules belong in the plan, not after the fact.
:::

:::takeaways
- Store the research question as data with population, inputs, comparison, outcome, test set, and threshold, and check it with code.
- Recompute what papers omit: Wilson intervals from accuracy and test size, and the majority-class accuracy from the positive rate.
- Encode your evidence standards as explicit flag rules so every study is judged the same way.
- Count independent units (farms, sites, patients), not rows, when judging whether a result generalizes.
- Report Cohen's d with the p-value; a tiny p from a huge sample can hide a trivial effect.
:::

## Further reading

- [Using Effect Size, or Why the P Value Is Not Enough](https://pmc.ncbi.nlm.nih.gov/articles/PMC3444174/): a short, readable explanation of effect sizes and Cohen's conventions, written for medical researchers.
- [proportion_confint](https://www.statsmodels.org/stable/generated/statsmodels.stats.proportion.proportion_confint.html): every interval method statsmodels offers for a proportion, including Wilson and the exact Clopper-Pearson interval.
- [ttest_ind_from_stats](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_ind_from_stats.html): run a t-test from reported means and standard deviations when you don't have the raw data.
