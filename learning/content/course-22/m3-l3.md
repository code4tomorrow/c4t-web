### Exercise 1: When the sensor gives up

A wrist heart-rate sensor loses contact during hard exercise. Run the setup cell, then compute the fraction of missing heart-rate readings for each activity, the mean of the observed readings, and a corrected mean that weights each activity's observed mean by how often that activity occurs.

```python run title="wearable.py"
import numpy as np
import pandas as pd
from scipy import stats

rng = np.random.default_rng(5)
n = 900
activity = rng.choice(["rest", "walk", "run"], n, p=[0.4, 0.4, 0.2])
true_hr = np.select([activity == "rest", activity == "walk", activity == "run"], [68, 95, 150]) + rng.normal(0, 8, n)
dropout = np.select([activity == "rest", activity == "walk", activity == "run"], [0.02, 0.08, 0.45])
wearable = pd.DataFrame({"activity": activity,
                         "heart_rate": np.where(rng.random(n) < dropout, np.nan, true_hr.round())})
print(f"true mean (known only because this is a simulation): {true_hr.mean():.1f}")
```

```text
missing fraction: rest 0.02, run 0.40, walk 0.07
observed mean: 90.3
corrected mean: 95.0
```

:::hint
`wearable.groupby("activity")["heart_rate"].mean()` skips missing values within each activity. The weights come from `wearable["activity"].value_counts(normalize=True)`, which counts every row, including those with missing heart rate.
:::

:::solution
```python run
print(wearable.groupby("activity")["heart_rate"].apply(lambda s: s.isna().mean()).round(2))
observed = wearable["heart_rate"].mean()
by_activity = wearable.groupby("activity")["heart_rate"].mean()
weights = wearable["activity"].value_counts(normalize=True)
corrected = (by_activity * weights).sum()
print(f"observed mean: {observed:.1f}   corrected mean: {corrected:.1f}")
```

The plain average is too low because 40% of the running readings, the highest heart rates, are missing. Since missingness here depends only on activity, which is fully recorded, the data is missing at random given activity, and reweighting by activity recovers the true mean. If the sensor failed because of the heart rate itself (say, above 170 bpm regardless of activity), the data would be MNAR and no reweighting by recorded columns would fully fix it.
:::

### Exercise 2: Name the mechanism

Label each MCAR, MAR, or MNAR, in one sentence each.

1. A lab tech knocked over a random tray of 8 sample tubes.
2. People with higher incomes are more likely to skip the income question on a survey.
3. Older participants are more likely to miss the online follow-up, and age was recorded at enrollment.
4. A weather station's rain gauge overflows and records nothing during the heaviest storms.

:::hint
Ask what the missingness depends on: nothing, a variable you have, or the missing value itself.
:::

:::solution
1 MCAR: which tubes fell has nothing to do with their contents. 2 MNAR: the missing value (income) drives whether it's missing. 3 MAR: missingness depends on age, which you have, so you can adjust for it. 4 MNAR: the gauge fails exactly when rainfall is extreme, so complete cases understate heavy rain.
:::

ritvikmath on missing data mechanisms. What to watch for: the probability-of-missingness way of defining MCAR, MAR, and MNAR, which makes borderline cases like Exercise 2's easier to classify.

### Exercise 3: Remove plate drift with reference wells

A plate reader measured 12 sample wells and 3 wells of the same reference standard on each of four plates. The reader drifts between plates. Estimate each plate's offset from its reference wells, subtract it from every well on that plate, and compare sample means per plate before and after.

```python run title="plates.py"
offsets = {"P1": 0, "P2": 120, "P3": -80, "P4": 60}       # hidden drift, unknown in real life
rows = []
for plate, drift in offsets.items():
    for i in range(3):
        rows.append({"plate": plate, "kind": "reference", "signal": 1000 + drift + rng.normal(0, 15)})
    for i in range(12):
        rows.append({"plate": plate, "kind": "sample", "signal": 1400 + drift + rng.normal(0, 60)})
plates = pd.DataFrame(rows).round(1)
print(plates.groupby(["plate", "kind"]).size().unstack())
```

:::hint
The reference standard should read the same on every plate, so each plate's mean reference reading minus the average over all plates is its offset. Use `plates["plate"].map(...)` to give every row its plate's offset.
:::

:::solution
```python run
reference = plates.query("kind == 'reference'").groupby("plate")["signal"].mean()
plate_offset = reference - reference.mean()
plates["corrected"] = plates["signal"] - plates["plate"].map(plate_offset)
print("estimated offsets:", plate_offset.round(1).to_dict())
print(plates.query("kind == 'sample'").groupby("plate")[["signal", "corrected"]].mean().round(1))
```

Before correction, sample means range over about 225 units; afterwards, about 45, which is the sampling noise of 12 wells. The correction works because the reference is the *same material* on every plate, so any difference in its readings is the instrument. That's why a reference standard belongs on every plate in your design, not just the first.
:::

### Exercise 4: Fix a confounded layout

A student plans to test a grow light: the 10 plants on the window shelf get the grow light, and the 10 on the back shelf don't. Explain the problem, then write code that randomly assigns 5 treated and 5 control plants on each shelf, with a seed, and prints a crosstab proving the balance.

:::hint
Loop over the two shelves, and on each one shuffle a list of five `"grow light"` and five `"control"` labels with `rng.permutation`.
:::

:::solution
Shelf and treatment are the same variable: the window shelf also gets more daylight and warmth, so any difference could come from the shelf. Blocking by shelf fixes it.

```python run
layout_rng = np.random.default_rng(14)
layout = pd.DataFrame([
    {"shelf": shelf, "spot": spot, "arm": str(arm)}
    for shelf in ["window", "back"]
    for spot, arm in enumerate(layout_rng.permutation(["grow light"] * 5 + ["control"] * 5), start=1)
])
print(pd.crosstab(layout["shelf"], layout["arm"]))
print(layout.query("shelf == 'window'")["arm"].tolist())
```

Now the shelf effect can be estimated (with `C(shelf)` in a regression) and separated from the light's effect. Moving the grow light between spots also needs some care: light from a treated plant shouldn't spill onto its control neighbors, so leave gaps or use dividers.
:::

### Exercise 5: Three power questions

Use `TTestIndPower` to answer: (a) how many per group to detect d = 0.3 with 80% power; (b) the power of an experiment with 15 per group if d = 0.6; (c) the smallest effect that 30 per group can detect with 80% power.

```text
(a) 176 per group
(b) power 0.35
(c) d = 0.74
```

:::hint
`solve_power` solves for whichever of `effect_size`, `nobs1`, `alpha`, or `power` you leave out (or pass as `None`).
:::

:::solution
```python run
from statsmodels.stats.power import TTestIndPower

analysis = TTestIndPower()
print(f"(a) {np.ceil(analysis.solve_power(effect_size=0.3, alpha=0.05, power=0.8)):.0f} per group")
print(f"(b) power {analysis.solve_power(effect_size=0.6, nobs1=15, alpha=0.05):.2f}")
print(f"(c) d = {analysis.solve_power(nobs1=30, alpha=0.05, power=0.8):.2f}")
```

Answer (c) is the most useful one to report when you can't change your sample size: "with 30 per group, this study could reliably detect only large effects (d of 0.74 or more)." It tells readers how to interpret a null result.
:::

### Exercise 6: How big a test set to compare two accuracies?

You'll compare a new model with an old one, each on its own independent test set of equal size. How many images does each test set need to detect 90% versus 80% accuracy with 80% power? Use `proportion_effectsize` and `NormalIndPower`.

:::hint
`proportion_effectsize(0.9, 0.8)` converts the two proportions into Cohen's h, which plays the role of d for proportions.
:::

:::solution
```python run
from statsmodels.stats.power import NormalIndPower
from statsmodels.stats.proportion import proportion_effectsize

h = proportion_effectsize(0.90, 0.80)
n = NormalIndPower().solve_power(effect_size=h, alpha=0.05, power=0.8)
print(f"Cohen's h = {h:.3f}; about {np.ceil(n):.0f} images per test set")
```

About 200 images per test set, for a 10-point gap. Smaller gaps get expensive quickly: try 0.85 versus 0.80. Evaluating both models on the *same* test set and using a paired test needs fewer images, because each image's difficulty cancels out.
:::

### Challenge: Rebuild a Frankenstein dataset

Recreate the pediatric-controls problem. Simulate chest X-ray features where COVID cases are all adults, and controls are children (Frankenstein) or adults (matched). Features: `chest_width` and `bone_density` (both depend on age, not disease) and `opacity` (the real, modest disease signal). Train logistic regression on Frankenstein data, then report its AUC on a Frankenstein test set and on an age-matched test set, and compare with a model that uses only `opacity`.

:::hint
Write one function `xrays(n, adult_controls, seed)` that draws `covid` at 50%, sets `adult = covid | adult_controls`, and makes the age-dependent features from `adult`. Use `roc_auc_score(y, model.predict_proba(X)[:, 1])`.
:::

:::solution
```python run
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score

def xrays(n, adult_controls, seed):
    r = np.random.default_rng(seed)
    covid = r.random(n) < 0.5
    adult = covid | adult_controls
    return pd.DataFrame({
        "chest_width": np.where(adult, r.normal(300, 20, n), r.normal(200, 20, n)),
        "bone_density": np.where(adult, r.normal(1.0, 0.1, n), r.normal(0.7, 0.1, n)),
        "opacity": 1.0 * covid + r.normal(0, 1, n),
        "covid": covid.astype(int),
    })

train = xrays(400, adult_controls=False, seed=1)
tests = {"Frankenstein test": xrays(200, False, seed=2), "age-matched test": xrays(200, True, seed=3)}
features = ["chest_width", "bone_density", "opacity"]
full = LogisticRegression(max_iter=1000).fit(train[features], train["covid"])
opacity_only = LogisticRegression().fit(train[["opacity"]], train["covid"])

for name, test in tests.items():
    auc_full = roc_auc_score(test["covid"], full.predict_proba(test[features])[:, 1])
    auc_opacity = roc_auc_score(test["covid"], opacity_only.predict_proba(test[["opacity"]])[:, 1])
    print(f"{name:<18} all features AUC {auc_full:.2f}   opacity only AUC {auc_opacity:.2f}")
```

On the Frankenstein test set the full model is nearly perfect because it's detecting adults. On age-matched patients it collapses toward chance, below the opacity-only model, because the features it leaned on carry no information about disease once everyone is an adult. The opacity-only model's AUC changes only a little, since its signal was real all along. The fix is in the data, not the model: controls drawn from the same population, age, and hospitals as the cases.
:::
