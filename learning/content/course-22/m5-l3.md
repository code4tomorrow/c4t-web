## Warm-up: an accuracy in your head

A plankton-image classifier gets 0.92 accuracy on 60 test images. Without code, estimate its standard error and a rough 95% range. Then work out how many test images you'd need for the 95% range to be ±0.02.

:::hint
SE = √(p(1 − p)/n). For the second part, set 1.96 × SE = 0.02 and solve for n.
:::

:::solution
```python run
import numpy as np
from scipy import stats

p, n = 0.92, 60
se = np.sqrt(p * (1 - p) / n)
print(f"SE = {se:.3f}, rough 95% range {p - 1.96 * se:.3f} to {p + 1.96 * se:.3f}")
need = (1.96 / 0.02) ** 2 * p * (1 - p)
print(f"test images needed for ±0.02: {int(np.ceil(need))}")
```

About ±7 points on 60 images. Getting to ±2 takes more than ten times as many images, because the SE shrinks with √n. (Near 0.99 the normal approximation gets poor; Exercise 5's bootstrap or a Wilson interval handles that.)
:::

### Exercise 1: Decode a reported error bar

A paper's table says enzyme activity was **12.4 ± 2.1** in treated cultures and **10.1 ± 1.9** in controls, n = 8 cultures each, with "±" defined as SD in the methods. Compute each group's SE and 95% t-interval. Do the intervals overlap? Then run Welch's t-test from the summary numbers alone.

You should find intervals of about 10.6 to 14.2 and 8.5 to 11.7, and a p-value below 0.05.

:::hint
`scipy.stats.ttest_ind_from_stats(mean1, std1, nobs1, mean2, std2, nobs2, equal_var=False)` needs no raw data.
:::

:::solution
```python run
groups = {"treated": (12.4, 2.1, 8), "control": (10.1, 1.9, 8)}
for name, (mean, sd, n) in groups.items():
    se = sd / np.sqrt(n)
    t_crit = stats.t.ppf(0.975, df=n - 1)
    print(f"{name}: SE {se:.2f}, 95% CI {mean - t_crit * se:.2f} to {mean + t_crit * se:.2f}")

welch = stats.ttest_ind_from_stats(12.4, 2.1, 8, 10.1, 1.9, 8, equal_var=False)
print(f"Welch t = {welch.statistic:.2f}, p = {welch.pvalue:.3f}")
```

The intervals overlap by about a unit, yet the difference is significant at the 5% level. Overlapping 95% CIs do **not** mean "no difference": the uncertainty of a difference is √(SE₁² + SE₂²), which is smaller than SE₁ + SE₂. Compare groups with an interval or test on the difference itself.
:::

### Exercise 2: Bootstrap a difference in medians between two groups

Days to first flower for 24 shaded and 24 sunny plants (generated below). Bootstrap a 95% CI for *median(shaded) − median(sunny)*. The two groups are independent plants, so each group should be resampled separately.

```python run
rng = np.random.default_rng(15)
shaded = np.round(rng.lognormal(np.log(20), 0.4, size=24), 1)
sunny = np.round(rng.lognormal(np.log(14), 0.4, size=24), 1)
print("medians:", np.median(shaded), np.median(sunny))
```

You should get a gap of 8.3 days with an interval that stays above zero but is wide.

:::hint
Pass both samples in the tuple: `bootstrap((shaded, sunny), statistic, ...)`. SciPy resamples each one independently unless you set `paired=True`. Give your statistic an `axis` argument so SciPy can vectorize it.
:::

:::solution
```python run
def median_gap(a, b, axis=-1):
    return np.median(a, axis=axis) - np.median(b, axis=axis)

res = stats.bootstrap((shaded, sunny), median_gap, n_resamples=5000, rng=np.random.default_rng(0))
low, high = res.confidence_interval
print(f"median gap {median_gap(shaded, sunny):.2f} days, 95% BCa CI {low:.2f} to {high:.2f}")
```

The interval excludes zero, so shade plausibly delays flowering, but "somewhere between 1.5 and 12.5 days" is the honest size of the effect. Report the range, not just "significant."
:::

### Exercise 3: Bootstrap a correlation, keeping the pairs together

Thirty finches each have a beak-depth and a seed-hardness measurement. Bootstrap the Pearson correlation two ways: correctly (resample birds, so each bird's two numbers stay together) and incorrectly (resample each column on its own). Explain the difference.

```python run
rng = np.random.default_rng(21)
hardness = rng.normal(5, 1.2, 30)
depth = 7 + 0.6 * hardness + rng.normal(0, 0.9, 30)
print(f"observed r = {np.corrcoef(hardness, depth)[0, 1]:.3f}")
```

:::hint
`paired=True` tells `bootstrap` to draw the same row indices from every sample. For the wrong way, call `rng.choice` on each column separately.
:::

:::solution
```python run
def pearson(x, y, axis=-1):
    return stats.pearsonr(x, y, axis=axis).statistic

right = stats.bootstrap((hardness, depth), pearson, paired=True, n_resamples=5000,
                        rng=np.random.default_rng(0))
print("pairs kept together:", np.round(right.confidence_interval, 3))

wrong = [np.corrcoef(rng.choice(hardness, 30), rng.choice(depth, 30))[0, 1] for _ in range(5000)]
print("pairs broken apart: ", np.round(np.percentile(wrong, [2.5, 97.5]), 3))
```

Resampling the columns separately scrambles which beak goes with which seed, so every resample has a true correlation of zero. The "interval" is centered on 0 and describes no birds that exist. Resample the unit you measured: here, the bird.
:::

### Exercise 4: Twelve mice, six measurements each

Blood glucose was measured 6 times on each of 12 mice. Mice differ from each other (SD 1.0) much more than one mouse varies day to day (SD 0.5). Compute a 95% interval for the overall mean by (a) resampling the 72 rows and (b) resampling mice with all their measurements. Which is right, and by roughly what factor were the naive intervals too narrow?

```python run
rng = np.random.default_rng(8)
mouse = np.repeat(np.arange(12), 6)
glucose = 10 + rng.normal(0, 1.0, 12)[mouse] + rng.normal(0, 0.5, mouse.size)
per_mouse = [glucose[mouse == m] for m in range(12)]
print(f"{glucose.size} rows from {len(per_mouse)} mice, mean {glucose.mean():.2f}")
```

:::hint
For (b), draw 12 mouse indices with replacement, concatenate those mice's arrays, and take the mean. A mouse picked twice contributes all 6 of its values twice.
:::

:::solution
```python run
row_means = [rng.choice(glucose, glucose.size).mean() for _ in range(4000)]
cluster_means = []
for _ in range(4000):
    picked = rng.integers(0, 12, size=12)
    cluster_means.append(np.concatenate([per_mouse[i] for i in picked]).mean())

row_ci = np.percentile(row_means, [2.5, 97.5])
cluster_ci = np.percentile(cluster_means, [2.5, 97.5])
print("resample rows:", row_ci.round(2), " width", round(np.ptp(row_ci), 2))
print("resample mice:", cluster_ci.round(2), " width", round(np.ptp(cluster_ci), 2))
```

Resampling mice gives an interval a bit over twice as wide. The study has 12 independent animals, not 72, and a mouse's six readings mostly repeat the same information about that mouse. The **cluster bootstrap** respects that. A quick cross-check: a t-interval on the 12 per-mouse means gives a similar width.
:::

### Exercise 5: An interval for a test-set AUC

Train a logistic regression on simulated biomarker data for 300 patients and score 120 new ones. Report the test AUC with a 95% bootstrap interval.

```python run
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score

rng = np.random.default_rng(31)
def make_patients(n):
    sick = rng.random(n) < 0.4
    markers = rng.normal(0, 1, (n, 3)) + np.outer(sick, [0.9, 0.5, 0.0])
    return markers, sick.astype(int)

X_train, y_train = make_patients(300)
X_test, y_test = make_patients(120)
risk = LogisticRegression().fit(X_train, y_train).predict_proba(X_test)[:, 1]
print(f"test AUC = {roc_auc_score(y_test, risk):.3f}")
```

Expect an interval roughly ±0.1 wide around 0.67.

:::hint
The AUC needs each patient's label and score together, so use `paired=True`. `roc_auc_score` can't take an `axis` argument, so add `vectorized=False`. Use `method="percentile"` and 1,000 resamples to keep it fast.
:::

:::solution
```python run
res = stats.bootstrap((y_test, risk), roc_auc_score, paired=True, vectorized=False,
                      n_resamples=1000, method="percentile", rng=np.random.default_rng(0))
low, high = res.confidence_interval
print(f"AUC {roc_auc_score(y_test, risk):.3f}, 95% CI {low:.3f} to {high:.3f}")
```

An AUC of 0.67 on 120 patients is compatible with anything from "barely better than a coin" to "moderately useful." A test set that small can't pin down a modest AUC, which is worth saying in the abstract, not just the supplement.
:::

### Exercise 6: A prediction interval for any model

The statsmodels prediction interval only works for linear regression. **Split conformal prediction** works for any regressor: fit on one part of the data, measure absolute errors on a separate *calibration* part, and use a high quantile of those errors as the ± for new predictions. Build a 90% interval for a ridge model on `load_diabetes` and check its coverage on a test part.

Use a 50/25/25 split. You should see coverage near 90%.

:::hint
With n calibration errors, use the ⌈(n + 1)(1 − α)⌉ / n quantile, with `method="higher"`. The +1 is what makes the guarantee hold for finite n.
:::

:::solution
```python run
from sklearn.datasets import load_diabetes
from sklearn.linear_model import Ridge
from sklearn.model_selection import train_test_split

X, y = load_diabetes(return_X_y=True)
X_fit, X_rest, y_fit, y_rest = train_test_split(X, y, test_size=0.5, random_state=0)
X_cal, X_new, y_cal, y_new = train_test_split(X_rest, y_rest, test_size=0.5, random_state=0)

model = Ridge(alpha=0.1).fit(X_fit, y_fit)
errors = np.abs(y_cal - model.predict(X_cal))
n = len(errors)
q = np.quantile(errors, np.ceil((n + 1) * 0.9) / n, method="higher")

pred = model.predict(X_new)
covered = np.mean((y_new >= pred - q) & (y_new <= pred + q))
print(f"{n} calibration patients, interval = prediction ± {q:.1f}")
print(f"coverage on {len(y_new)} new patients: {covered:.1%}")
```

The guarantee is about averages over many calibration sets, so one run can land a few points above or below 90%. The interval has the same width for every patient; extensions such as conformalized quantile regression let it widen where the model is less sure.
:::

### Challenge: Does a 95% interval cover 95% of the time?

"95%" is a promise about repeated studies. Test it. Draw 1,000 datasets of size n from an exponential distribution with true mean 1. For each, build a 95% percentile-bootstrap interval for the mean (1,000 resamples) and a 95% t-interval, and count how often each contains 1. Do it for n = 10 and n = 50.

:::hint
Vectorize the resampling: `d[rng.integers(0, n, (1000, n))].mean(axis=1)` gives 1,000 bootstrap means in one line.
:::

:::solution
```python run
rng = np.random.default_rng(0)
for n in [10, 50]:
    hits_boot = hits_t = 0
    for d in rng.exponential(1.0, size=(1000, n)):
        boot = d[rng.integers(0, n, (1000, n))].mean(axis=1)
        lo, hi = np.percentile(boot, [2.5, 97.5])
        hits_boot += lo <= 1 <= hi
        half = stats.t.ppf(0.975, n - 1) * d.std(ddof=1) / np.sqrt(n)
        hits_t += d.mean() - half <= 1 <= d.mean() + half
    print(f"n = {n}: percentile bootstrap covers {hits_boot / 10:.1f}%, t-interval {hits_t / 10:.1f}%")
```

At n = 10 with skewed data, neither interval keeps its promise, and the percentile bootstrap is the worse of the two (around 84%). The bootstrap's sample is a stand-in for the population, and ten values from a skewed distribution are a poor stand-in. At n = 50 both get close to 95%. This is why BCa exists, and why "I bootstrapped it" doesn't make a tiny sample trustworthy.
:::
