## Warm-up: pick the splitter

For each study, name the scikit-learn splitter you'd use and what you'd pass as `groups`, if anything.

1. 2,000 retinal scans from 500 patients, both eyes, two visits each.
2. Hourly air-quality readings from one station for three years; the model will forecast the next day.
3. 10,000 satellite pixels labeled as forest or farmland, from one region.
4. 800 independent survey responses, 12% positive.

:::solution
1. `GroupKFold` or `StratifiedGroupKFold` with `groups=patient_id`. Eyes and visits of one patient share almost everything.
2. `TimeSeriesSplit`, ideally with a gap (`gap=24`) between training and test so the last training hours don't sit right next to the first test hour.
3. `GroupKFold` with groups set to spatial blocks (grid cells several times larger than the distance over which neighboring pixels look alike).
4. `StratifiedKFold(shuffle=True)`. The rows really are independent, and stratifying keeps the rare class in every fold.
:::

### Exercise 1: The oversampling leak

A rare-event dataset has 8% positives. A labmate duplicates positive rows until the classes balance, *then* runs 5-fold CV with a random forest and reports recall 1.00. Reproduce the leak, then oversample correctly: inside each training fold only, scoring on untouched test rows.

```python run
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import recall_score
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.utils import resample

rng = np.random.default_rng(2)
X = rng.normal(size=(400, 6))
y = (rng.random(400) < 1 / (1 + np.exp(-(-2.6 + 0.8 * X[:, 0] - 0.6 * X[:, 1])))).astype(int)

def oversample(X, y, seed=0):
    pos, neg = X[y == 1], X[y == 0]
    pos_up = resample(pos, n_samples=len(neg), replace=True, random_state=seed)
    return np.vstack([neg, pos_up]), np.r_[np.zeros(len(neg)), np.ones(len(neg))].astype(int)

print(f"{y.mean():.1%} positive")
```

Expect the correct recall to be far below 1.

:::hint
Loop over `cv.split(X, y)`. Call `oversample` on the training indices only, fit, and compute `recall_score` on the original test rows.
:::

:::solution
```python run
cv = StratifiedKFold(5, shuffle=True, random_state=0)
forest = RandomForestClassifier(n_estimators=50, random_state=0)

X_up, y_up = oversample(X, y)
leaky = cross_val_score(forest, X_up, y_up, cv=cv, scoring="recall")
print(f"oversample, then split: recall {leaky.mean():.2f}")

honest = []
for train, test in cv.split(X, y):
    X_tr, y_tr = oversample(X[train], y[train])
    honest.append(recall_score(y[test], forest.fit(X_tr, y_tr).predict(X[test])))
print(f"split, then oversample: recall {np.mean(honest):.2f}")
```

Oversampling first puts copies of the same positive row in both training and test folds, and a forest recognizes an exact copy perfectly. Done inside the training fold, recall is honest and low, which is the real news: this model barely finds the rare class. (The `imbalanced-learn` library's `Pipeline` does the in-fold version automatically.)
:::

### Exercise 2: A rolling mean that sees the future

A lake buoy logs daily chlorophyll, and you want to forecast tomorrow's value. Someone adds a 7-day smoothed feature with `rolling(7, center=True)`. Compare it with a trailing window, `rolling(7)`, and with today's value alone, using `TimeSeriesSplit` and mean absolute error.

```python run
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import TimeSeriesSplit

rng = np.random.default_rng(9)
chl = np.zeros(600)
for day in range(1, 600):
    chl[day] = 0.9 * chl[day - 1] + rng.normal(0, 1)
chl = pd.Series(10 + chl)
tomorrow = chl.shift(-1)
```

:::hint
A centered 7-day window at day *t* averages days *t* − 3 through *t* + 3. Which of those days include the value you're trying to predict?
:::

:::solution
```python run
features = {
    "centered window": pd.DataFrame({"smooth": chl.rolling(7, center=True).mean(), "today": chl}),
    "trailing window": pd.DataFrame({"smooth": chl.rolling(7).mean(), "today": chl}),
    "today only": pd.DataFrame({"today": chl}),
}
for name, feats in features.items():
    data = feats.assign(target=tomorrow).dropna()
    mae = -cross_val_score(LinearRegression(), data.drop(columns="target"), data.target,
                           cv=TimeSeriesSplit(5), scoring="neg_mean_absolute_error").mean()
    print(f"{name:16s} MAE {mae:.3f}")
```

The centered window includes tomorrow (and the two days after), so it "forecasts" better than anything honest. `TimeSeriesSplit` didn't catch it, because the leak is inside each row, not between folds. The trailing window is no better than today's value alone, which is the true answer for this series. Check every feature's time window, not just the splitter.
:::

### Exercise 3: Is the gain bigger than the seed?

A labmate reports that adding a new feature to a breast-cancer classifier raised CV accuracy from 0.937 to 0.940, using `random_state=3`. Rerun the comparison with ten split seeds (same folds for both models within a seed) and decide.

```python run
from sklearn.datasets import load_breast_cancer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X_bc, y_bc = load_breast_cancer(return_X_y=True)
X_base = X_bc[:, :10]
X_new = np.hstack([X_base, np.random.default_rng(0).normal(size=(len(y_bc), 1))])  # the "new feature"
model = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))
```

:::hint
For each seed, build one `StratifiedKFold(5, shuffle=True, random_state=seed)` and pass it to both `cross_val_score` calls. Then look at the mean and SD of the paired gains.
:::

:::solution
```python run
rows = []
for seed in range(10):
    cv_seed = StratifiedKFold(5, shuffle=True, random_state=seed)
    base = cross_val_score(model, X_base, y_bc, cv=cv_seed).mean()
    new = cross_val_score(model, X_new, y_bc, cv=cv_seed).mean()
    rows.append({"seed": seed, "baseline": base, "with new feature": new, "gain": new - base})
seeds = pd.DataFrame(rows)
print(seeds.round(4).to_string(index=False))
print(f"\nmean gain {seeds.gain.mean():+.4f}, SD {seeds.gain.std():.4f}, "
      f"positive in {(seeds.gain > 0).sum()} of 10 seeds")
```

The gain averages essentially zero and is positive in only some seeds. Seed 3 happened to be one of the best. The "new feature" here is random noise, which is the point: a +0.3-point gain is what noise looks like at this sample size. Report the mean and spread over seeds, decided before you look.
:::

### Exercise 4: Fifteen biomarkers, three corrections

You test 15 blood biomarkers between 25 patients and 25 controls with t-tests. In this simulation markers 1 to 3 truly differ and the other 12 don't. Which markers pass at p < 0.05 uncorrected, after Bonferroni, after Holm, and after Benjamini–Hochberg?

```python run
from scipy import stats
from statsmodels.stats.multitest import multipletests

rng = np.random.default_rng(3)
true_shift = np.r_[[1.2, 1.0, 0.8], np.zeros(12)]
pvals = np.array([stats.ttest_ind(rng.normal(0, 1, 25), rng.normal(shift, 1, 25)).pvalue
                  for shift in true_shift])
```

:::hint
`multipletests(pvals, alpha=0.05, method=...)` returns a tuple whose first item is a boolean array of rejections. The method names are `"bonferroni"`, `"holm"`, and `"fdr_bh"`.
:::

:::solution
```python run
table = pd.DataFrame({"marker": np.arange(1, 16), "truly differs": true_shift > 0, "p": pvals.round(4),
                      "uncorrected": pvals < 0.05})
for method in ["bonferroni", "holm", "fdr_bh"]:
    table[method] = multipletests(pvals, alpha=0.05, method=method)[0]
print(table[table[["uncorrected", "fdr_bh"]].any(axis=1)].to_string(index=False))
print("\nmarkers passing:", table[["uncorrected", "bonferroni", "holm", "fdr_bh"]].sum().to_dict())
```

Uncorrected testing finds all three real markers plus one false one. Bonferroni and Holm control the chance of *any* false positive, so they drop the false marker but also lose a real one. Benjamini–Hochberg controls the expected *share* of false discoveries, keeping all three real markers here and dropping the false one. Use Holm when a single false claim is costly; use BH for screening, where some false leads among many are acceptable.
:::

### Exercise 5: The ablation that misses redundancy

A field station predicts whether a plot needs irrigation from two soil-moisture probes (two readings each) plus air temperature and wind. Run a one-at-a-time ablation removing probe A, then probe B. Then remove both. What does the single-removal table fail to show?

```python run
rng = np.random.default_rng(3)
moisture = rng.normal(size=500)
weather = rng.normal(size=(500, 2))
plots = pd.DataFrame({
    "probeA_1": moisture + rng.normal(0, 0.3, 500), "probeA_2": moisture + rng.normal(0, 0.3, 500),
    "probeB_1": moisture + rng.normal(0, 0.3, 500), "probeB_2": moisture + rng.normal(0, 0.3, 500),
    "air_temp": weather[:, 0], "wind": weather[:, 1]})
needs_water = (rng.random(500) < 1 / (1 + np.exp(-(1.8 * moisture + 0.5 * weather[:, 0])))).astype(int)
```

:::hint
Write a helper that takes a list of columns and returns the mean 5-fold CV accuracy of `model`, then call it on four column lists.
:::

:::solution
```python run
cv5 = StratifiedKFold(5, shuffle=True, random_state=0)
def score(cols):
    return cross_val_score(model, plots[cols], needs_water, cv=cv5).mean()

every = list(plots.columns)
for label, drop in [("full", []), ("without probe A", ["probeA_1", "probeA_2"]),
                    ("without probe B", ["probeB_1", "probeB_2"]),
                    ("without both probes", ["probeA_1", "probeA_2", "probeB_1", "probeB_2"])]:
    print(f"{label:20s} {score([c for c in every if c not in drop]):.3f}")
```

Removing either probe alone costs between 0 and 3 points, which might tempt you to write "soil moisture barely matters." Removing both drops accuracy by about 21 points. Each probe covers for the other. When components are correlated, ablate them as a group too, and report which groups you tested.
:::

### Exercise 6: Spatial blocks

Six hundred soil samples are scattered over a 10 km × 10 km area, and their carbon content follows a smooth spatial pattern plus an elevation effect. Compare a 10-nearest-neighbor regressor's R² under random KFold and under `GroupKFold` on 2.5 km grid blocks.

```python run
from sklearn.model_selection import GroupKFold, KFold
from sklearn.neighbors import KNeighborsRegressor

rng = np.random.default_rng(6)
xy = rng.uniform(0, 10, (600, 2))
bumps, heights = rng.uniform(0, 10, (12, 2)), rng.normal(0, 1, 12)
pattern = sum(h * np.exp(-((xy - b) ** 2).sum(axis=1) / (2 * 1.2 ** 2)) for h, b in zip(heights, bumps))
elevation = rng.normal(size=600)
carbon = pattern + 0.3 * elevation + rng.normal(0, 0.2, 600)
samples = pd.DataFrame({"x_km": xy[:, 0], "y_km": xy[:, 1], "elevation": elevation})
```

:::hint
A block ID is `(x // 2.5) * 4 + (y // 2.5)`, which numbers the 16 cells of a 4 × 4 grid.
:::

:::solution
```python run
block = (xy[:, 0] // 2.5).astype(int) * 4 + (xy[:, 1] // 2.5).astype(int)
knn = KNeighborsRegressor(n_neighbors=10)
random_r2 = cross_val_score(knn, samples, carbon, cv=KFold(5, shuffle=True, random_state=0), scoring="r2")
blocked_r2 = cross_val_score(knn, samples, carbon, cv=GroupKFold(5), groups=block, scoring="r2")
print(f"random KFold R2: {random_r2.mean():.2f}   spatial blocks R2: {blocked_r2.mean():.2f}")
```

Random folds let every test sample borrow from neighbors a few hundred meters away, so the model looks like an excellent map-maker. With whole blocks held out it must predict into unsampled territory, and R² falls by more than half. Which number to report depends on the claim: interpolating within a densely sampled field, or mapping a new one.
:::

### Challenge: How optimistic is tuning without nesting?

On 100 rows of pure noise, tune an RBF `SVC` over 20 combinations of `C` and `gamma` with `GridSearchCV` and report `best_score_`. Then estimate performance honestly with **nested** CV: the grid search runs inside each outer training fold, and the outer test fold scores whatever it picked.

:::hint
Nested CV is one line: pass the unfitted `GridSearchCV` object as the model to `cross_val_score` with a different outer splitter.
:::

:::solution
```python run
from sklearn.model_selection import GridSearchCV
from sklearn.svm import SVC

rng = np.random.default_rng(1)
X_rand, y_rand = rng.normal(size=(100, 20)), rng.integers(0, 2, 100)
grid = {"C": [0.01, 0.1, 1, 10, 100], "gamma": [0.001, 0.01, 0.1, 1]}
inner = StratifiedKFold(5, shuffle=True, random_state=0)
outer = StratifiedKFold(5, shuffle=True, random_state=1)

search = GridSearchCV(SVC(), grid, cv=inner).fit(X_rand, y_rand)
print(f"non-nested best_score_: {search.best_score_:.2f} with {search.best_params_}")
nested = cross_val_score(GridSearchCV(SVC(), grid, cv=inner), X_rand, y_rand, cv=outer)
print(f"nested CV estimate:     {nested.mean():.2f}")
```

`best_score_` is the maximum of 20 noisy CV scores, the same forking-paths problem from the notes, so it overstates chance-level data by about 10 points. Nested CV never lets the outer test fold influence the choice, and it lands near 0.5. Use `best_score_` to choose settings, never as the result.
:::
