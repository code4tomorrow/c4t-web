*The Elements of Statistical Learning* (Hastie, Tibshirani & Friedman), Section 7.10.2, makes a claim you can reproduce in seconds. Take 50 samples in two equal classes and 5,000 standard-normal predictors that have nothing to do with the labels. Pick the 100 predictors most correlated with the labels using all 50 samples, then estimate a 1-nearest-neighbor classifier's error with cross-validation. The book reports: "Over 50 simulations from this setting, the average CV error rate was 3%." The true error of any classifier here is 50%.

This is the guided capstone. Every milestone below is one your project needs too; if you chose a different target, read each step for its pattern, then fill in the skeleton at the end.

## Milestone 1: The plan, as code

Put the plan's key decisions in variables. Later cells compare results against them, so the notebook can't drift from what you pre-registered.

```python run title="plan.py"
import numpy as np
import pandas as pd

CLAIM = {
    "source": "Hastie, Tibshirani & Friedman, The Elements of Statistical Learning, 2nd ed., Sec. 7.10.2",
    "quote": "Over 50 simulations from this setting, the average CV error rate was 3%.",
    "target": 0.03,
    "reported_as": "whole percent, so anything in [2.5%, 3.5%) rounds to 3%",
}
RULE = "consistent if our 95% CI for the mean CV error overlaps [0.025, 0.035)"
N_SAMPLES, N_PREDICTORS, N_KEEP, N_SIMS, K_FOLDS = 50, 5000, 100, 50, 5
SEED = 2009    # fixed before the first run

AMBIGUITY = ("'the 100 predictors having highest correlation': primary reading = highest signed "
             "correlation (literal wording); declared variant = highest absolute correlation "
             "(step 1 of the book's recipe says 'fairly strong' correlation).")
VARIANTS = ["absolute-correlation selection", "10-fold instead of 5-fold CV"]
print(RULE, "\n", AMBIGUITY, sep="")
```

Two ambiguities, two decisions. The book doesn't say how many folds the 3% used, but its next paragraph describes the samples "as we would do in five-fold cross-validation," so the primary analysis uses 5; 10 is a declared variant. "Highest correlation" could mean signed or absolute; the primary reading is the literal one.

## Milestone 2: The data, with provenance checks

For a simulation, the "dataset" is the generating process, and provenance means checking that it matches the description. Write those checks as `assert`s so they run every time.

```python run
def make_dataset(rng, signal=0.0):
    """N_SAMPLES x N_PREDICTORS standard normals, two equal classes; optional real signal."""
    X = rng.standard_normal((N_SAMPLES, N_PREDICTORS))
    y = np.repeat([0, 1], N_SAMPLES // 2)
    X[y == 1, :10] += signal          # signal > 0 only for the positive control
    return X, y

X_check, y_check = make_dataset(np.random.default_rng(SEED))
assert X_check.shape == (50, 5000), "wrong shape"
assert np.bincount(y_check).tolist() == [25, 25], "classes must be equal-sized"
assert abs(X_check.mean()) < 0.01 and abs(X_check.std() - 1) < 0.01, "predictors should be standard normal"
print("data match the description: 50 x 5000, 25/25, standard normal")
```

The `signal` argument is there for a control in Milestone 3. With `signal=0` the data are exactly what the book describes.

## Milestone 3: Baseline, controls, and the primary reproduction

The selection step is a vectorized correlation, so all 5,000 predictors are scored in one line. The key switch is `select_inside`: `False` is the book's "wrong way" (select once on all samples, then cross-validate), `True` is the right way (select again inside each training fold).

```python run
from sklearn.model_selection import KFold
from sklearn.neighbors import KNeighborsClassifier

def correlations(X, y):
    Xc, yc = X - X.mean(axis=0), y - y.mean()
    return Xc.T @ yc / np.sqrt((Xc ** 2).sum(axis=0) * (yc ** 2).sum())

def top_predictors(X, y, signed=True):
    r = correlations(X, y)
    return np.argsort(-(r if signed else np.abs(r)))[:N_KEEP]

def cv_error(X, y, select_inside, signed=True, k=K_FOLDS, seed=0):
    folds = KFold(n_splits=k, shuffle=True, random_state=seed)
    keep = None if select_inside else top_predictors(X, y, signed)
    errors = []
    for train, test in folds.split(X):
        if select_inside:
            keep = top_predictors(X[train], y[train], signed)
        knn = KNeighborsClassifier(n_neighbors=1).fit(X[train][:, keep], y[train])
        errors.append(np.mean(knn.predict(X[test][:, keep]) != y[test]))
    return float(np.mean(errors))

def simulate(select_inside, signed=True, k=K_FOLDS, signal=0.0, n_sims=N_SIMS, seed=SEED):
    rng = np.random.default_rng(seed)
    return np.array([cv_error(*make_dataset(rng, signal), select_inside, signed, k, seed=s)
                     for s in range(n_sims)])

wrong = simulate(select_inside=False)
right = simulate(select_inside=True)
positive = simulate(select_inside=True, signal=1.2)
print(f"baseline (always guess one class):          error 0.500 by construction")
print(f"negative control, right way on pure noise:  mean CV error {right.mean():.3f}")
print(f"positive control, right way, real signal:   mean CV error {positive.mean():.3f}")
print(f"primary reproduction, wrong way:            mean CV error {wrong.mean():.3f}")
```

Read the controls before the headline. The **negative control** (correct CV on pure noise) lands near 50%, so honest CV on this pipeline doesn't invent signal. The **positive control** adds a real shift to 10 of the 5,000 predictors, and the same correct CV now finds it, so the pipeline can detect signal when it exists. Only with both in hand does the wrong-way number mean anything: about 4%, from data with no signal at all.

The negative control sits a few points *above* 50%, which is a known quirk rather than a bug. Holding out a fold of balanced data leaves the training set tilted toward the other class, so a 1-nearest-neighbor classifier leans the wrong way slightly more often than chance.

## Milestone 4: Uncertainty and the verdict

Fifty simulations give fifty CV errors. Their mean has a standard error, and the rule from Milestone 1 compares its 95% interval with the range that rounds to 3%.

```python run
from scipy import stats

def mean_ci(values, level=0.95):
    half = stats.t.ppf(0.5 + level / 2, len(values) - 1) * values.std(ddof=1) / np.sqrt(len(values))
    return values.mean() - half, values.mean() + half

low, high = mean_ci(wrong)
consistent = low < 0.035 and high >= 0.025
print(f"wrong-way mean CV error {wrong.mean():.2%}, 95% CI {low:.2%} to {high:.2%}")
print(f"claimed 3% (i.e. 2.5% to 3.5%) -> {'consistent' if consistent else 'inconsistent'} under the pre-set rule")
print(f"right-way mean {right.mean():.2%}, 95% CI {mean_ci(right)[0]:.2%} to {mean_ci(right)[1]:.2%}")
```

The interval only just reaches the rounded range, so the honest verdict is "consistent, with our estimate slightly higher than the book's." Both halves of the qualitative claim reproduce decisively: wrong-way CV reports single-digit error, and correct CV reports roughly 50%.

## Milestone 5: Sensitivity, a secondary claim, and the error distribution

Run the declared variants, exactly the ones listed in the plan, and nothing chosen after the fact.

```python run
sensitivity = pd.DataFrame({
    "primary (signed, 5-fold)": wrong,
    "variant: absolute correlation": simulate(select_inside=False, signed=False),
    "variant: 10-fold": simulate(select_inside=False, k=10),
}).agg(["mean", "std"]).T
sensitivity["95% CI half-width"] = stats.t.ppf(0.975, N_SIMS - 1) * sensitivity["std"] / np.sqrt(N_SIMS)
print(sensitivity.round(4).to_string())
```

The fold count barely matters. The reading of "highest correlation" does: selecting by absolute correlation cuts the wrong-way error to about a third, well below the claimed 3%. So the ambiguity is real, and the two readings bracket the book's number.

The book offers a way to break the tie. Its Figure 7.10 takes the 100 predictors chosen on all 50 samples, recomputes their correlations with the labels on 10 random samples, and reports that they "average about 0.28, rather than 0." Under absolute selection, roughly half the chosen predictors correlate negatively, so their average should sit near 0. Check both, pooling one random subset from each of 50 datasets:

```python run alt="Two-panel figure. Left: overlapping histograms of 50 per-simulation CV errors, with the wrong-way errors piled up between 0 and 12 percent and the right-way errors spread around 40 to 65 percent, and a dashed line at the 50 percent true error. Right: histograms of the correlations of the 100 selected predictors with the labels on 10 held-out samples, centered well above zero for signed selection and near zero for absolute selection." caption="Left: the wrong way vs the right way across 50 simulations. Right: the book's Figure 7.10 check, under both readings."
import matplotlib.pyplot as plt

rng = np.random.default_rng(SEED)
signed_sel, absolute_sel = [], []
for _ in range(N_SIMS):                                   # one random 10-sample subset per dataset
    X_fig, y_fig = make_dataset(rng)
    subset = rng.choice(N_SAMPLES, size=10, replace=False)
    while len(set(y_fig[subset])) < 2:                    # need both classes to compute a correlation
        subset = rng.choice(N_SAMPLES, size=10, replace=False)
    r_subset = correlations(X_fig[subset], y_fig[subset])
    signed_sel.append(r_subset[top_predictors(X_fig, y_fig, signed=True)])
    absolute_sel.append(r_subset[top_predictors(X_fig, y_fig, signed=False)])
signed_sel, absolute_sel = np.concatenate(signed_sel), np.concatenate(absolute_sel)
print(f"mean correlation on 10 samples, over {N_SIMS} datasets: signed selection {signed_sel.mean():.2f}, "
      f"absolute selection {absolute_sel.mean():.2f} (book: about 0.28)")

fig, (left, right_ax) = plt.subplots(1, 2, figsize=(10, 3.2))
bins = np.linspace(0, 0.7, 29)
left.hist(wrong, bins=bins, color="C3", alpha=0.7, label="wrong way")
left.hist(right, bins=bins, color="C2", alpha=0.7, label="right way")
left.axvline(0.5, color="grey", ls="--", label="true error")
left.set_xlabel("CV error in one simulation")
left.set_ylabel("simulations")
left.legend(fontsize=8)
corr_bins = np.linspace(-1, 1, 33)
right_ax.hist(signed_sel, bins=corr_bins, color="C0", alpha=0.7, label="signed selection")
right_ax.hist(absolute_sel, bins=corr_bins, color="C1", alpha=0.5, label="absolute selection")
right_ax.set_xlabel("correlation of a selected predictor, 10 samples")
right_ax.legend(fontsize=8)
fig.tight_layout()
```

The signed reading produces a histogram centered well above zero, like the book's; the absolute reading centers on zero. That supports the primary reading, and you found it in the source, not by tuning toward the number. Our average is somewhat higher than "about 0.28", which is worth one line in the discrepancy log, not a new analysis.

The left panel is the **error analysis**. Wrong-way errors aren't just low on average; they're low in every simulation, so the optimism is systematic, not an unlucky draw. The right-way errors scatter widely around 50%, which is what honest uncertainty looks like with only 10 test samples per fold.

## Milestone 6: Tests, then the report

Tests turn your claims about the notebook into checks the notebook runs on itself. If someone changes a seed or a library update changes a result, the next "Run all" fails here instead of silently producing a different report.

```python run
assert np.array_equal(simulate(False, n_sims=3), simulate(False, n_sims=3)), "simulation is not deterministic"
assert 0.40 < right.mean() < 0.60, "negative control should sit near 50%"
assert positive.mean() < 0.40, "positive control should find the planted signal"
assert wrong.mean() < 0.10, "headline qualitative claim no longer reproduces"
print("all checks passed")

summary = pd.DataFrame([
    ["Primary: wrong way, signed, 5-fold", f"{wrong.mean():.1%}", f"{low:.1%} to {high:.1%}", "3%", "consistent" if consistent else "inconsistent"],
    ["Variant: absolute correlation", f"{sensitivity.iloc[1]['mean']:.1%}", "", "", "brackets the claim"],
    ["Negative control: right way", f"{right.mean():.1%}", f"{mean_ci(right)[0]:.1%} to {mean_ci(right)[1]:.1%}", "about 50%", "reproduced"],
], columns=["analysis", "mean CV error", "95% CI", "book", "verdict"])
print()
print(summary.to_string(index=False))
print(f"\nVerdict: the claim reproduces qualitatively; the exact 3% depends on an unstated detail "
      f"(signed vs absolute selection), and the book's Figure 7.10 supports the signed reading we pre-registered.")
```

## Your own project: the starter skeleton

Copy this into a new notebook. It runs as is on a placeholder target (LDA on the wine data, from Module 7) so you can see every piece work, then replace each marked section with your own.

```python title="reproduction_starter.py"
import numpy as np
import pandas as pd
from statsmodels.stats.proportion import proportion_confint

# ---- 1. PLAN: replace with your claim, rule, and declared variants --------------------
CLAIM = {"source": "Aeberhard, Coomans & de Vel (1992), via UCI wine notes",
         "quote": "LDA 98.9% (leave-one-out)", "target": 0.989, "n": 178}
RULE = "consistent if the claimed accuracy is inside our 95% Wilson interval"
VARIANTS = {}          # name -> function returning predictions; fill in during planning
SEED = 0

# ---- 2. DATA + PROVENANCE: load, then assert what the source says ---------------------
from sklearn.datasets import load_wine
X, y = load_wine(return_X_y=True)
assert X.shape == (178, 13) and np.bincount(y).tolist() == [59, 71, 48]

# ---- 3. BASELINE, CONTROLS, PRIMARY ANALYSIS ------------------------------------------
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.dummy import DummyClassifier
from sklearn.model_selection import LeaveOneOut, cross_val_predict

def accuracy_of(model, features, labels):
    return np.mean(cross_val_predict(model, features, labels, cv=LeaveOneOut()) == labels)

baseline = accuracy_of(DummyClassifier(strategy="most_frequent"), X, y)
shuffled = accuracy_of(LinearDiscriminantAnalysis(), X, np.random.default_rng(SEED).permutation(y))
primary = accuracy_of(LinearDiscriminantAnalysis(), X, y)

# ---- 4. UNCERTAINTY + VERDICT ----------------------------------------------------------
low, high = proportion_confint(round(primary * CLAIM["n"]), CLAIM["n"], method="wilson")
verdict = "consistent" if low <= CLAIM["target"] <= high else "inconsistent"

# ---- 5. SENSITIVITY / ABLATION: run every declared variant, report all ----------------
variant_results = {name: run() for name, run in VARIANTS.items()}

# ---- 6. TESTS + REPORT ----------------------------------------------------------------
assert abs(shuffled - 1 / 3) < 0.15, "shuffled-label control should be near chance"
print(f"baseline {baseline:.3f} | shuffled-label control {shuffled:.3f}")
print(f"primary {primary:.3f}, 95% CI [{low:.3f}, {high:.3f}] vs claimed {CLAIM['target']} -> {verdict}")
print("variants:", variant_results or "none declared yet")
```

The shuffled-label control should score near chance (about 1/3 for three classes). If your own version of that line ever scores well above chance, stop and find the leak before doing anything else.

:::takeaways
- Store the claim, rule, ambiguity decisions, and variants as variables; the notebook checks itself against what you pre-registered.
- A negative control (no signal) and a positive control (planted signal) prove the pipeline can tell the difference before you trust the headline.
- Run exactly the declared variants. When they disagree, look for clues in the source itself, like a secondary figure, rather than picking the closest number.
- End with `assert`-based tests and a generated summary, then restart and run all.
:::
