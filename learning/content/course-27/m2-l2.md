---
title: "Code-along: make the starter app your own"
summary: Create a fresh Java project, then change its name, greeting, and colors through string and color resources and run it on an emulator or phone.
---

The template's white screen with "Hello World!" is identical for every Android developer on the planet. In this build you'll turn it into an app that is recognizably yours: a custom name under the icon, a two-line greeting, and a color scheme. Along the way you'll touch the manifest, three resource files, and the layout, which is exactly the tour from the notes, but with your hands on the keyboard.

## Step 1: create the project

Create a new project with **File > New > New Project > Empty Views Activity**:

-   **Name:** `Week1Hello`
-   **Language:** Java
-   **Minimum SDK:** API 24
-   **Build configuration language:** Kotlin DSL (build.gradle.kts)

Wait for the Gradle sync to finish, then run it once unchanged so you know the starting point works.

## Step 2: rename the app

The name under the launcher icon comes from the manifest's `android:label="@string/app_name"`. Open `app > res > values > strings.xml` and change the value. While you're there, add two strings for the screen:

```xml
<resources>
    <string name="app_name">Hello C4T</string>
    <string name="greeting">Hi, I\'m Maya!</string>
    <string name="subtitle">This is my first Android app.</string>
</resources>
```

Use your own name. Notice the backslash in `I\'m`: an apostrophe inside an Android string resource must be escaped. Leave it out and Android Studio marks the line as an error.

## Step 3: add your colors

Open `res > values > colors.xml`. Keep the two template colors and add your own. Colors are written as `#AARRGGBB` (alpha, red, green, blue) or the shorter `#RRGGBB`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <color name="black">#FF000000</color>
    <color name="white">#FFFFFFFF</color>
    <color name="c4t_navy">#FF1B2A49</color>
    <color name="c4t_gold">#FFF5B700</color>
</resources>
```

Android Studio draws a small color square in the left margin next to each line. Click it to open a color picker if you'd rather choose visually.

:::tip
Resource names may only use lowercase letters, digits, and underscores, so `c4t_navy` works but `C4T-Navy` won't compile.
:::

## Step 4: update the layout

Open `res > layout > activity_main.xml` in **Split** mode. You'll make three changes:

1.  Give the root `ConstraintLayout` a background color.
2.  Point the existing `TextView` at your greeting string, give it an ID, and make it big and gold.
3.  Add a second `TextView` underneath it for the subtitle.

Replace the whole file with this:

```xml
<?xml version="1.0" encoding="utf-8"?>
<androidx.constraintlayout.widget.ConstraintLayout xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto"
    xmlns:tools="http://schemas.android.com/tools"
    android:id="@+id/main"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:background="@color/c4t_navy"
    tools:context=".MainActivity">

    <TextView
        android:id="@+id/greetingText"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="@string/greeting"
        android:textColor="@color/c4t_gold"
        android:textSize="32sp"
        android:textStyle="bold"
        app:layout_constraintBottom_toBottomOf="parent"
        app:layout_constraintEnd_toEndOf="parent"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintTop_toTopOf="parent" />

    <TextView
        android:id="@+id/subtitleText"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_marginTop="12dp"
        android:text="@string/subtitle"
        android:textColor="@color/white"
        android:textSize="18sp"
        app:layout_constraintEnd_toEndOf="parent"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintTop_toBottomOf="@id/greetingText" />

</androidx.constraintlayout.widget.ConstraintLayout>
```

What changed and why:

-   `android:background="@color/c4t_navy"` paints the whole screen. The `@color/` prefix tells Android to look the value up in `colors.xml`.
-   `android:text="@string/greeting"` replaces the hardcoded `"Hello World!"`. Keeping text in `strings.xml` is how real apps get translated: you add a second `strings.xml` for another language and never touch the layout.
-   `sp` (scale-independent pixels) is the unit for text size. It grows when the user picks a larger font in their phone's settings. `dp` is used for everything else, like the 12dp margin.
-   The subtitle is pinned to the left and right edges of the parent (which centers it) and its top is attached to the bottom of `greetingText`. The `@id/greetingText` reference has no `+` because that ID already exists.

:::warning
Keep `android:id="@+id/main"` on the root layout. `MainActivity.java` calls `findViewById(R.id.main)` to apply the system-bar padding. Delete that ID and the project stops compiling with `error: cannot find symbol` pointing at `R.id.main`.
:::

## Step 5: leave MainActivity.java alone (and know why)

Open `MainActivity.java`. You don't need to change anything: it already calls `setContentView(R.layout.activity_main)`, so it shows whatever the layout file describes. That separation is the point of the View system. Design changes go in XML; behavior goes in Java. Starting in Week 4 you'll write Java that changes these views while the app runs, which is why both text views now have IDs.

## Step 6: run it

Choose your emulator or phone and click **Run**. You should see:

-   A navy screen.
-   **Hi, I'm Maya!** (with your name) in large, bold gold text in the center.
-   **This is my first Android app.** in white, just below it.

Now press the device's home button and open the app drawer. Your app is listed as **Hello C4T**. If the old name still shows, uninstall the app from the device (long-press the icon, then **Uninstall** or **App info > Uninstall**) and run again; some launchers cache labels.

## Step 7: check the preview against the device

Switch the layout editor to **Design** and compare it to the real screen. They should match. If the preview looks wrong but the device is right, click the refresh arrow above the preview; it sometimes lags behind your edits.

## If something goes wrong

| Symptom | Likely cause |
|---|---|
| `error: resource string/greting (aka com.example.week1hello:string/greting) not found.` | A typo between the name in `strings.xml` and the `@string/` reference |
| Red error on the string mentioning an apostrophe | `I'm` written without the backslash in `strings.xml` |
| Subtitle sits at the very top of the screen | Missing `app:layout_constraintTop_toBottomOf` on the second `TextView` |
| Old screen still appears | The build failed; open the **Build** window and read the first error |
