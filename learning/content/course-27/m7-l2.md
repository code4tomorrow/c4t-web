---
title: "Code-along: a Quick Note app that remembers"
summary: Build a one-screen note app that saves with SharedPreferences, hunt down a planted bug using Logcat and a breakpoint, and export the finished app as an APK.
---

Everyone has typed a reminder into an app, closed it, and come back to find nothing. Today's app fixes that: a single note that's still there after you swipe the app away or restart the phone. Along the way you'll plant a realistic bug, catch it with Logcat and the debugger, and finish by building an APK you can send to a friend.

## 1. Project and strings

Create an **Empty Views Activity** project named **Quick Note**, package `com.example.quicknote`, Java, API 24.

`res/values/strings.xml`:

```xml
<resources>
    <string name="app_name">Quick Note</string>
    <string name="note_hint">Write something to remember</string>
    <string name="save">Save</string>
    <string name="clear">Clear</string>
</resources>
```

`res/layout/activity_main.xml`:

## 3. First version (with a bug in it)

Type this `MainActivity.java` exactly, bug included. The bug is realistic: it's the kind people make every week.

```java
package com.example.quicknote;

import android.content.SharedPreferences;
import android.os.Bundle;
import android.util.Log;
import android.widget.Button;
import android.widget.EditText;
import android.widget.TextView;

import androidx.activity.EdgeToEdge;
import androidx.appcompat.app.AppCompatActivity;
import androidx.core.graphics.Insets;
import androidx.core.view.ViewCompat;
import androidx.core.view.WindowInsetsCompat;

public class MainActivity extends AppCompatActivity {

    private static final String TAG = "QuickNote";

    private SharedPreferences prefs;
    private EditText noteInput;
    private TextView statusText;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        EdgeToEdge.enable(this);
        setContentView(R.layout.activity_main);
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), (v, insets) -> {
            Insets systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars());
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom);
            return insets;
        });

        prefs = getSharedPreferences("quick_note", MODE_PRIVATE);
        noteInput = findViewById(R.id.note_input);
        statusText = findViewById(R.id.status_text);

        String saved = prefs.getString("notes", "");
        noteInput.setText(saved);
        Log.d(TAG, "Loaded note with " + saved.length() + " characters");

        Button saveButton = findViewById(R.id.save_button);
        saveButton.setOnClickListener(v -> saveNote());
    }

    private void saveNote() {
        String text = noteInput.getText().toString();
        prefs.edit().putString("note", text).apply();
        Log.d(TAG, "Saved note with " + text.length() + " characters");
        statusText.setText("Saved");
    }
}
```

Run it, type `Buy milk`, tap **Save**, and you'll see "Saved." Now swipe the app away from recent apps and open it again. The note is gone.

## 4. Find the bug with Logcat

Open **Logcat** and type `tag:QuickNote` in the filter. You'll see something like:

```text
D  Loaded note with 0 characters
D  Saved note with 8 characters
D  Loaded note with 0 characters
```

So saving happens (8 characters is `Buy milk`), and loading happens, but loading finds nothing. The problem is somewhere between the two.

## 5. Confirm it with a breakpoint

1.  Click the gutter next to the line `String saved = prefs.getString("notes", "");` to add a red breakpoint.
2.  Click **Debug 'app'** (the bug icon).
3.  The app pauses on that line. Press **Step Over** (F8) once.
4.  In the **Variables** pane, `saved` is `""`.

Now look closely at the two keys: `getString("notes", ...)` and `putString("note", ...)`. One extra letter, and you are reading a key that was never written. SharedPreferences doesn't complain; it just returns the default.

## 6. Fix it for good

The cure is to type each key exactly once. Add constants at the top of the class:

```java
private static final String PREFS_NAME = "quick_note";
private static final String KEY_NOTE = "note";
private static final String KEY_SAVE_COUNT = "save_count";
```

Then replace the body of the class below `onCreate`'s insets code with this finished version, which also counts saves, adds a Clear button, and auto-saves when you leave:

```java
        prefs = getSharedPreferences(PREFS_NAME, MODE_PRIVATE);
        noteInput = findViewById(R.id.note_input);
        statusText = findViewById(R.id.status_text);

        String saved = prefs.getString(KEY_NOTE, "");
        noteInput.setText(saved);
        showSaveCount();
        Log.d(TAG, "Loaded note with " + saved.length() + " characters");

        Button saveButton = findViewById(R.id.save_button);
        saveButton.setOnClickListener(v -> saveNote());

        Button clearButton = findViewById(R.id.clear_button);
        clearButton.setOnClickListener(v -> {
            noteInput.setText("");
            prefs.edit().remove(KEY_NOTE).apply();
            Log.d(TAG, "Cleared note");
        });
    }

    @Override
    protected void onPause() {
        super.onPause();
        prefs.edit().putString(KEY_NOTE, noteInput.getText().toString()).apply();
        Log.d(TAG, "Auto-saved in onPause");
    }

    private void saveNote() {
        String text = noteInput.getText().toString();
        int count = prefs.getInt(KEY_SAVE_COUNT, 0) + 1;
        prefs.edit()
                .putString(KEY_NOTE, text)
                .putInt(KEY_SAVE_COUNT, count)
                .apply();
        Log.d(TAG, "Saved note with " + text.length() + " characters (save #" + count + ")");
        showSaveCount();
    }

    private void showSaveCount() {
        int count = prefs.getInt(KEY_SAVE_COUNT, 0);
        statusText.setText("Saved " + count + " times");
    }
}
```

Remove the breakpoint (click the red dot), run normally, type `Buy milk`, tap **Save**, swipe the app away, and reopen it. The note is back, and the newest lines in Logcat are:

```text
D  Saved note with 8 characters (save #1)
D  Auto-saved in onPause
D  Loaded note with 8 characters
```

The status line reads `Saved 1 times`. (Fixing that grammar is one of this week's practice exercises.)

:::tip
`onPause` runs every time the user leaves the screen, including pressing Home, so the auto-save means even an unsaved draft survives. It runs on rotation too, and since `EditText` keeps its own text across rotation, the note survives both.
:::

## 7. Build an APK

1.  Choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**. (Newer versions: **Build > Generate App Bundles or APKs > Generate APKs**.)
2.  Wait for the "APK(s) generated successfully" popup and click **locate**.
3.  You'll find `app-debug.apk` in `app/build/outputs/apk/debug/`.

Send that file to an Android phone, tap it, and allow installs from that source when asked. The app icon shows up like any other app, and your note-saving works there too, with its own separate storage.

This is a **debug** APK, signed with Android Studio's automatic debug key. It's fine for friends and testing. For a store-ready release you'd use **Build > Generate Signed Bundle / APK** with your own keystore, which the practice lesson walks through.
