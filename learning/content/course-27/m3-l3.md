Each exercise is a complete program you can write in one file and run with `javac` and `java`. The expected output is given so you can check yourself. Your code doesn't have to match the solution line for line; it does have to print the same thing.

### Exercise 1: Temperature report

Store these Celsius readings in a `double` array: `18.5, 31.0, 24.2, 35.6, 9.0`. For each one, print the Fahrenheit value to one decimal place (F = C × 9 / 5 + 32). Add `(hot)` after readings above 30 C and `(cold)` after readings below 10 C.

Expected output:

```text
18.5 C = 65.3 F
31.0 C = 87.8 F (hot)
24.2 C = 75.6 F
35.6 C = 96.1 F (hot)
9.0 C = 48.2 F (cold)
```

:::solution
```java
public class Temps {
    public static void main(String[] args) {
        double[] celsius = {18.5, 31.0, 24.2, 35.6, 9.0};
        for (double c : celsius) {
            double f = c * 9 / 5 + 32;
            String label = "";
            if (c > 30) {
                label = " (hot)";
            } else if (c < 10) {
                label = " (cold)";
            }
            System.out.println(String.format("%.1f C = %.1f F%s", c, f, label));
        }
    }
}
```

Because `c` is a `double`, `c * 9 / 5` stays a decimal the whole way. If `c` were an `int`, the division by 5 would throw away the fraction. `%.1f` rounds to one decimal place.
:::

### Exercise 2: Username rules

Write a method `static boolean isValidUsername(String name)` that returns `true` only when the name is 3 to 15 characters long, has no spaces, and starts with a letter. Test it on `maya_codes`, `jo`, `4tomorrow`, `big bird`, `android_developer_01`, and `Sam2026`.

Expected output:

```text
maya_codes -> OK
jo -> rejected
4tomorrow -> rejected
big bird -> rejected
android_developer_01 -> rejected
Sam2026 -> OK
```

:::solution
```java
public class Usernames {
    static boolean isValidUsername(String name) {
        if (name.length() < 3 || name.length() > 15) {
            return false;
        }
        if (name.contains(" ")) {
            return false;
        }
        return Character.isLetter(name.charAt(0));
    }

    public static void main(String[] args) {
        String[] tests = {"maya_codes", "jo", "4tomorrow", "big bird", "android_developer_01", "Sam2026"};
        for (String t : tests) {
            System.out.println(t + " -> " + (isValidUsername(t) ? "OK" : "rejected"));
        }
    }
}
```

Returning `false` as soon as one rule fails (an "early return") keeps each rule on its own short line. `charAt(0)` returns a `char`, and `Character.isLetter` checks it. This is the same kind of check you'll run on text typed into an Android sign-up screen.
:::

### Exercise 3: Battery drain

A phone starts at 100% and loses 7% each hour. Use a `while` loop to find how many hours pass before the battery drops below 20%. Then use nested `for` loops to draw a bar of `|` characters, one per 10%, for the levels 100, 75, 50, 25, and 0.

Expected output:

```text
Low battery warning after 12 hours (16% left).
100% ||||||||||
 75% |||||||
 50% |||||
 25% ||
  0%
```

:::solution
```java
public class Battery {
    public static void main(String[] args) {
        int battery = 100;
        int hours = 0;
        while (battery >= 20) {
            battery -= 7;
            hours++;
        }
        System.out.println("Low battery warning after " + hours + " hours (" + battery + "% left).");

        for (int level = 100; level >= 0; level -= 25) {
            String bar = "";
            for (int i = 0; i < level / 10; i++) {
                bar += "|";
            }
            System.out.println(String.format("%3d%% %s", level, bar));
        }
    }
}
```

`while` fits the first part because you don't know the number of hours in advance. Integer division does real work in the second part: `75 / 10` is `7`, so 75% gets seven bars. `%3d` pads the number to three characters so the bars line up, and `%%` prints a literal percent sign.
:::

### Exercise 4: Word tools

Write three methods: `reverse(String word)`, `countVowels(String text)` (count a, e, i, o, u in either case), and `isPalindrome(String word)` (the same forwards and backwards, ignoring case). Reuse `reverse` inside `isPalindrome`. Test them on `Android`, `Racecar`, `Java`, and `level`.

Expected output:

```text
Android: reversed diordnA, vowels 3, palindrome false
Racecar: reversed racecaR, vowels 3, palindrome true
Java: reversed avaJ, vowels 2, palindrome false
level: reversed level, vowels 2, palindrome true
```

:::solution
```java
public class Words {
    static String reverse(String word) {
        String result = "";
        for (int i = word.length() - 1; i >= 0; i--) {
            result += word.charAt(i);
        }
        return result;
    }

    static int countVowels(String text) {
        int count = 0;
        String lower = text.toLowerCase();
        for (int i = 0; i < lower.length(); i++) {
            if ("aeiou".indexOf(lower.charAt(i)) >= 0) {
                count++;
            }
        }
        return count;
    }

    static boolean isPalindrome(String word) {
        return word.equalsIgnoreCase(reverse(word));
    }

    public static void main(String[] args) {
        String[] words = {"Android", "Racecar", "Java", "level"};
        for (String w : words) {
            System.out.println(w + ": reversed " + reverse(w) + ", vowels " + countVowels(w)
                    + ", palindrome " + isPalindrome(w));
        }
    }
}
```

The reverse loop counts down from the last index, `length() - 1`, to 0. `"aeiou".indexOf(ch)` returns -1 when the character isn't a vowel, which saves writing five comparisons.
:::

### Exercise 5: Playlist classes

Create a `Song` class (title and length in seconds, both private, with getters) and a `Playlist` class that holds an `ArrayList<Song>`. `Playlist` needs `add(Song)`, `totalSeconds()`, `longest()`, a `static` helper `formatTime(int seconds)` that returns text like `3:05`, and `print()`. Build a "Study Mix" playlist with three songs: Lo-fi Morning (185 s), Rainy Window (242 s), Focus Mode (207 s).

Expected output:

```text
Study Mix (3 songs, 10:34)
  1. Lo-fi Morning 3:05
  2. Rainy Window 4:02
  3. Focus Mode 3:27
Longest: Rainy Window
```

:::solution
```java
import java.util.ArrayList;

class Song {
    private String title;
    private int seconds;

    Song(String title, int seconds) {
        this.title = title;
        this.seconds = seconds;
    }

    String getTitle() {
        return title;
    }

    int getSeconds() {
        return seconds;
    }
}

class Playlist {
    private String name;
    private ArrayList<Song> songs = new ArrayList<>();

    Playlist(String name) {
        this.name = name;
    }

    void add(Song song) {
        songs.add(song);
    }

    int totalSeconds() {
        int total = 0;
        for (Song s : songs) {
            total += s.getSeconds();
        }
        return total;
    }

    Song longest() {
        Song best = songs.get(0);
        for (Song s : songs) {
            if (s.getSeconds() > best.getSeconds()) {
                best = s;
            }
        }
        return best;
    }

    static String formatTime(int seconds) {
        return String.format("%d:%02d", seconds / 60, seconds % 60);
    }

    void print() {
        System.out.println(name + " (" + songs.size() + " songs, " + formatTime(totalSeconds()) + ")");
        for (int i = 0; i < songs.size(); i++) {
            Song s = songs.get(i);
            System.out.println("  " + (i + 1) + ". " + s.getTitle() + " " + formatTime(s.getSeconds()));
        }
        System.out.println("Longest: " + longest().getTitle());
    }
}

public class PlaylistApp {
    public static void main(String[] args) {
        Playlist study = new Playlist("Study Mix");
        study.add(new Song("Lo-fi Morning", 185));
        study.add(new Song("Rainy Window", 242));
        study.add(new Song("Focus Mode", 207));
        study.print();
    }
}
```

`formatTime` is `static` because it doesn't use any playlist's data; it only converts a number. `%02d` pads the seconds with a leading zero, so 5 seconds prints as `05` instead of `5`. Note that `longest()` would crash on an empty playlist; a real app would check `songs.isEmpty()` first.
:::

## Stretch challenge: savings accounts

Write an `Account` class with an owner, a balance, a `withdraw(double amount)` method that returns `false` (and changes nothing) for amounts that are zero, negative, or more than the balance, and a `toString()` like `Maya: $30.00`.

Then write `SavingsAccount extends Account` with an interest rate, an `addInterest()` method, and a limit of two successful withdrawals. Override `withdraw` and `toString` and use `super` in both. Test it with this `main`:

```java
public class Bank {
    public static void main(String[] args) {
        Account checking = new Account("Maya", 50);
        SavingsAccount savings = new SavingsAccount("Maya", 200, 0.05);

        System.out.println(checking.withdraw(80));
        System.out.println(checking.withdraw(20));
        savings.addInterest();
        System.out.println(savings.withdraw(10));
        System.out.println(savings.withdraw(10));
        System.out.println(savings.withdraw(10));
        System.out.println(checking);
        System.out.println(savings);
    }
}
```

Expected output:

```text
false
true
true
true
false
Maya: $30.00
Maya: $190.00 (savings, 0 withdrawals left)
```

:::solution
Put these two classes above `Bank` in `Bank.java`:

```java
class Account {
    private String owner;
    protected double balance;

    Account(String owner, double balance) {
        this.owner = owner;
        this.balance = balance;
    }

    boolean withdraw(double amount) {
        if (amount <= 0 || amount > balance) {
            return false;
        }
        balance -= amount;
        return true;
    }

    @Override
    public String toString() {
        return String.format("%s: $%.2f", owner, balance);
    }
}

class SavingsAccount extends Account {
    private double rate;
    private int withdrawalsLeft = 2;

    SavingsAccount(String owner, double balance, double rate) {
        super(owner, balance);
        this.rate = rate;
    }

    void addInterest() {
        balance += balance * rate;
    }

    @Override
    boolean withdraw(double amount) {
        if (withdrawalsLeft == 0) {
            return false;
        }
        boolean ok = super.withdraw(amount);
        if (ok) {
            withdrawalsLeft--;
        }
        return ok;
    }

    @Override
    public String toString() {
        return super.toString() + " (savings, " + withdrawalsLeft + " withdrawals left)";
    }
}
```

`super(owner, balance)` must be the first line of the subclass constructor; it runs the parent's constructor. `balance` is `protected` so the subclass can add interest to it, while `owner` stays `private`. The overridden `withdraw` adds one new rule and hands the rest to `super.withdraw`, so the balance checks live in exactly one place. That's the same relationship your `MainActivity` has with `AppCompatActivity`.
:::
