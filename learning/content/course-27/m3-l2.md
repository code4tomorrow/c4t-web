Most apps boil down to a list of things, each with some data and a few rules about that data. A to-do app has tasks, a music app has songs, a fitness app has workouts. You'll build the plain-Java core of one of these apps: a habit tracker that records which days of the week you did each habit and prints a report. No Android yet; the point is to get comfortable designing a class and using it, because that's exactly the shape of the code that sits behind an Android screen.

Create a folder called `habits` and work in a single file named `HabitTracker.java`. After each step, compile and run:

```bash
javac HabitTracker.java
java HabitTracker
```

## Step 1: a class to hold one habit

A habit has a name, a weekly goal (how many days you want to do it), and a record of the seven days. A `boolean` array is a natural fit for that record: `daysDone[0]` is Monday, `daysDone[6]` is Sunday, and every slot starts as `false`.

```java
class Habit {
    private String name;
    private int goalPerWeek;
    private boolean[] daysDone = new boolean[7];

    Habit(String name, int goalPerWeek) {
        this.name = name;
        this.goalPerWeek = goalPerWeek;
    }

    @Override
    public String toString() {
        return name + " (goal: " + goalPerWeek + " days)";
    }
}

public class HabitTracker {
    public static void main(String[] args) {
        Habit reading = new Habit("Read 20 minutes", 5);
        System.out.println(reading);
    }
}
```

```text
Read 20 minutes (goal: 5 days)
```

Two classes live in one file here. Only `HabitTracker` is `public`, and the file must be named after it. That's fine for small programs; in an Android project, each class gets its own file.

## Step 2: record days and check the goal

Add these three methods inside `Habit`, just above `toString()`:

```java
    void markDone(int day) {
        if (day < 0 || day >= daysDone.length) {
            System.out.println("Day " + day + " is not a valid day (use 0-6).");
            return;
        }
        daysDone[day] = true;
    }

    int countDone() {
        int count = 0;
        for (boolean done : daysDone) {
            if (done) {
                count++;
            }
        }
        return count;
    }

    boolean metGoal() {
        return countDone() >= goalPerWeek;
    }
```

Then replace `main` with a test that includes two mistakes a real user might make, marking the same day twice and using an invalid day:

```java
    public static void main(String[] args) {
        Habit reading = new Habit("Read 20 minutes", 5);
        reading.markDone(0);
        reading.markDone(1);
        reading.markDone(1);
        reading.markDone(9);
        System.out.println(reading + ": " + reading.countDone() + " done, goal met? " + reading.metGoal());
    }
```

```text
Day 9 is not a valid day (use 0-6).
Read 20 minutes (goal: 5 days): 2 done, goal met? false
```

Notice what the class protects you from. Marking Tuesday twice still counts once, because the array slot is simply `true` either way. Day 9 would have crashed the program with an `ArrayIndexOutOfBoundsException`, but the guard at the top of `markDone` catches it and returns early. Because `daysDone` is `private`, no other code can skip that check by writing into the array directly.

`metGoal()` reuses `countDone()` instead of repeating the counting loop. Small methods that build on each other are easier to test and fix.

## Step 3: show the week at a glance

Numbers are fine, but a quick picture is better. Add a constant at the very top of the `Habit` class, above the fields:

```java
    private static final String[] DAY_NAMES = {"Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"};
```

`static` means one shared copy for all habits (every habit uses the same day names), and `final` means it can't be reassigned. Then add two more methods inside `Habit`:

```java
    String weekBar() {
        StringBuilder bar = new StringBuilder();
        for (int i = 0; i < daysDone.length; i++) {
            bar.append(daysDone[i] ? "#" : "-");
        }
        return "[" + bar + "]";
    }

    String missedDays() {
        String missed = "";
        for (int i = 0; i < daysDone.length; i++) {
            if (!daysDone[i]) {
                missed += DAY_NAMES[i] + " ";
            }
        }
        return missed.trim();
    }
```

The `? :` in `weekBar` is the **ternary operator**, a one-line if/else: `condition ? valueIfTrue : valueIfFalse`. `StringBuilder` builds text piece by piece more efficiently than `+=`; for seven characters either works, but you'll see `StringBuilder` often in real Java code. Both loops use an index `i` because they need the position, not just the value.

Replace `main` again:

```java
    public static void main(String[] args) {
        Habit reading = new Habit("Read 20 minutes", 5);
        reading.markDone(0);
        reading.markDone(1);
        reading.markDone(3);
        System.out.println(reading.weekBar() + " " + reading);
        System.out.println("Missed: " + reading.missedDays());
    }
```

```text
[##-#---] Read 20 minutes (goal: 5 days)
Missed: Wed Fri Sat Sun
```

## Step 4: track several habits with an ArrayList

An array has a fixed size, but people add and remove habits. `ArrayList` grows as needed. Add an import as the first line of the file, then write the final `main`. Here is the complete program:

```java
import java.util.ArrayList;

class Habit {
    private static final String[] DAY_NAMES = {"Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"};

    private String name;
    private int goalPerWeek;
    private boolean[] daysDone = new boolean[7];

    Habit(String name, int goalPerWeek) {
        this.name = name;
        this.goalPerWeek = goalPerWeek;
    }

    void markDone(int day) {
        if (day < 0 || day >= daysDone.length) {
            System.out.println("Day " + day + " is not a valid day (use 0-6).");
            return;
        }
        daysDone[day] = true;
    }

    int countDone() {
        int count = 0;
        for (boolean done : daysDone) {
            if (done) {
                count++;
            }
        }
        return count;
    }

    boolean metGoal() {
        return countDone() >= goalPerWeek;
    }

    String weekBar() {
        StringBuilder bar = new StringBuilder();
        for (int i = 0; i < daysDone.length; i++) {
            bar.append(daysDone[i] ? "#" : "-");
        }
        return "[" + bar + "]";
    }

    String missedDays() {
        String missed = "";
        for (int i = 0; i < daysDone.length; i++) {
            if (!daysDone[i]) {
                missed += DAY_NAMES[i] + " ";
            }
        }
        return missed.trim();
    }

    @Override
    public String toString() {
        return name + " (goal: " + goalPerWeek + " days)";
    }
}

public class HabitTracker {
    public static void main(String[] args) {
        ArrayList<Habit> habits = new ArrayList<>();
        habits.add(new Habit("Read 20 minutes", 5));
        habits.add(new Habit("Practice Java", 3));
        habits.add(new Habit("Walk outside", 4));

        int[] readingDays = {0, 1, 2, 3, 5};
        for (int day : readingDays) {
            habits.get(0).markDone(day);
        }
        habits.get(1).markDone(1);
        habits.get(1).markDone(4);
        habits.get(2).markDone(0);
        habits.get(2).markDone(2);
        habits.get(2).markDone(4);
        habits.get(2).markDone(6);

        System.out.println("Weekly habit report");
        System.out.println("-------------------");
        int goalsMet = 0;
        Habit best = habits.get(0);
        for (Habit habit : habits) {
            String status = habit.metGoal() ? "goal met" : "keep going";
            System.out.println(habit.weekBar() + " " + habit + ": " + status);
            if (habit.metGoal()) {
                goalsMet++;
            } else {
                System.out.println("    missed: " + habit.missedDays());
            }
            if (habit.countDone() > best.countDone()) {
                best = habit;
            }
        }
        System.out.println();
        System.out.println("Goals met: " + goalsMet + " of " + habits.size());
        System.out.println("Most consistent: " + best);
    }
}
```

```text
Weekly habit report
-------------------
[####-#-] Read 20 minutes (goal: 5 days): goal met
[-#--#--] Practice Java (goal: 3 days): keep going
    missed: Mon Wed Thu Sat Sun
[#-#-#-#] Walk outside (goal: 4 days): goal met

Goals met: 2 of 3
Most consistent: Read 20 minutes (goal: 5 days)
```

A few things to notice:

-   `ArrayList<Habit>` holds only `Habit` objects; the compiler rejects anything else. The `<>` on the right lets Java fill in the type for you.
-   `ArrayList` uses methods where arrays use syntax: `add()` instead of assigning a slot, `get(0)` instead of `[0]`, and `size()` instead of `.length`.
-   The "find the best" loop is a pattern worth memorizing: assume the first item is best, then replace it whenever you find a better one.

:::warning
`ArrayList` can't hold basic types like `int` directly. Write `ArrayList<Integer>`, not `ArrayList<int>`. Java converts between `int` and `Integer` automatically when you add and get values.
:::

In Week 5 you'll show a scrolling list on screen, and the code behind it looks very much like this: a model class such as `Habit`, an `ArrayList` of those objects, and a loop-like piece of code that turns each object into a row.
