---
title: Install Android Studio
summary: Check that your computer can run Android Studio, install it on Windows, macOS, or Linux, and finish the setup wizard so the Android SDK is ready.
---

Android Studio is the official tool Google gives developers for building Android apps. It bundles an editor, the Android SDK (the libraries and build tools every app needs), an emulator that runs a virtual phone on your computer, and Gradle, the build system that turns your code into an installable app. It is also big: expect a download of roughly 1 GB for the installer and several more gigabytes for the SDK during setup. Do this before the first class, on a good internet connection, so class time goes to writing apps instead of watching progress bars.

## Check your computer first

Android Studio runs on Windows, macOS, and Linux. Google's published minimums are:

| | Windows | macOS | Linux |
|---|---|---|---|
| OS | 64-bit Windows 10 or newer | macOS 12 or newer | 64-bit distro with GNOME, KDE, or Unity; glibc 2.31+ |
| RAM | 8 GB for Studio, 16 GB to also run the emulator | same | same |
| Free disk | 8 GB, 16 GB with the emulator (SSD strongly preferred) | same | same |
| CPU | x86_64 with virtualization (Intel VT-x or AMD-V) | Apple M-series, or 6th-gen Intel Core or newer | x86_64 with virtualization |
| Screen | 1280 x 800 minimum | same | same |

Windows and Linux computers with ARM processors are not supported yet. A Chromebook can run Android Studio only through its Linux environment, and it needs the same RAM and disk as a Linux machine.

To find your RAM:

-   **Windows:** open Task Manager (Ctrl + Shift + Esc), go to **Performance**, click **Memory**. While you're there, click **CPU** and look for **Virtualization: Enabled**.
-   **macOS:** Apple menu, **About This Mac**. It shows your chip (Apple M1, M2, and so on, or Intel) and memory.
-   **Linux:** run these two commands in a terminal.

```bash
free -h
grep -c -E 'vmx|svm' /proc/cpuinfo
```

The first prints a table; read the `total` value in the `Mem:` row. The second counts CPU cores that support hardware virtualization. Any number above `0` means the emulator can be accelerated; `0` means virtualization is missing or switched off in your BIOS.

:::tip
Only 8 GB of RAM? You can still take this class. Install Android Studio, skip creating a heavy emulator, and run your apps on a real Android phone over USB instead. That uses far less memory than a virtual device.
:::

## Download

Go to the Android Studio download page (linked at the bottom) and accept the license. Pick the right file:

-   **Windows:** the `.exe` installer.
-   **macOS:** the `.dmg` for **Mac with Apple chip** or **Mac with Intel chip**. The wrong one will either refuse to open or run painfully slowly, so check About This Mac first.
-   **Linux:** the `.tar.gz` archive.

## Install on Windows

1.  Double-click the `.exe`.
2.  On the components screen, leave **Android Virtual Device** checked. That is the emulator.
3.  Accept the default install folder and finish. Launch Android Studio from the Start menu.

## Install on macOS

1.  Open the `.dmg`.
2.  Drag **Android Studio** into the **Applications** folder.
3.  Open it from Applications. macOS asks whether you trust an app downloaded from the internet; click **Open**.

## Install on Linux

Unpack the archive somewhere permanent, then start the launcher script from the `bin` folder. Adjust the file name to match your download:

```bash
cd ~/Downloads
sudo tar -xzf android-studio-*-linux.tar.gz -C /opt
/opt/android-studio/bin/studio.sh
```

Recent releases also include a launcher named just `studio` in the same folder; either one works. Once Android Studio is open, choose **Tools > Create Desktop Entry** so it shows up in your app menu. On 64-bit Ubuntu, Google also asks you to install a few 32-bit libraries:

```bash
sudo apt-get install libc6:i386 libncurses5:i386 libstdc++6:i386 lib32z1 libbz2-1.0:i386
```

## Run the setup wizard

The first launch opens a setup wizard. Choose these options:

1.  **Import settings:** "Do not import" (unless you've used Android Studio before).
2.  **Install type:** **Standard**. It picks sensible defaults for the SDK, the emulator, and a recent Android version.
3.  **UI theme:** your choice.
4.  **License agreement:** click each license in the left list and select **Accept** for every one. The **Next** button stays grey until all of them are accepted, which confuses a lot of people.
5.  Click **Finish** and let it download. On a slow connection this can take 20 minutes or more.

When it ends, you land on the **Welcome to Android Studio** window with buttons for **New Project**, **Open**, and **More Actions**. That window means the install worked.

The wizard saves the SDK here by default. Remember the path; you'll need it if something breaks later:

| OS | Default SDK location |
|---|---|
| Windows | `C:\Users\<you>\AppData\Local\Android\Sdk` |
| macOS | `~/Library/Android/sdk` |
| Linux | `~/Android/Sdk` |

:::warning
Avoid putting the SDK or your projects in a folder whose path has spaces or non-English characters, such as a Windows user name like `Zoë Kim`. Some build tools break on those paths with confusing errors. If your user name has them, create a folder like `C:\Android\Sdk` and point the wizard there.
:::

## One more tool for Week 2: a JDK

Android Studio ships its own Java runtime for building apps, so you never install Java just to make Android apps. In Week 2, though, you'll run small plain-Java programs from a terminal, which needs a separate JDK. Install **Eclipse Temurin 21 (LTS)** from adoptium.net, then open a new terminal and check it:

```bash
java -version
javac -version
```

Both should report version 21, for example:

```text
openjdk version "21.0.5" 2024-10-15 LTS
OpenJDK Runtime Environment Temurin-21.0.5+11 (build 21.0.5+11-LTS)
OpenJDK 64-Bit Server VM Temurin-21.0.5+11 (build 21.0.5+11-LTS, mixed mode, sharing)
javac 21.0.5
```

Your exact build numbers may differ. If you see `command not found` or `'java' is not recognized`, close and reopen the terminal; on Windows, rerun the installer and make sure **Set JAVA_HOME** and **Add to PATH** are selected.
