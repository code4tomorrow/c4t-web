---
title: "Code-along: a Planet Facts list and detail app"
summary: Build a two-screen app where tapping a planet in a scrolling RecyclerView opens a detail screen that receives the planet's data through an Intent.
---

Eight planets, one list, one detail page. It's small enough to finish in class, but it uses every piece of the list-to-detail pattern you'll reuse in your capstone: a model class, a RecyclerView adapter with a click callback, a second Activity, and Intent extras.

## 1. Project setup

Create a new **Empty Views Activity** project named **Planet Facts**, package `com.example.planetfacts`, Java, minimum SDK API 24.

Add RecyclerView to `gradle/libs.versions.toml`, inside the sections that already exist:

```toml
[versions]
recyclerview = "1.4.0"

[libraries]
recyclerview = { group = "androidx.recyclerview", name = "recyclerview", version.ref = "recyclerview" }
```

Then in `app/build.gradle.kts`, inside `dependencies { }`:

```kotlin
implementation(libs.recyclerview)
```

Click **Sync Now**.

## 2. The model class

A model class holds one item's data. Right-click the `com.example.planetfacts` package, choose **New > Java Class**, and name it `Planet`:

```java
package com.example.planetfacts;

public class Planet {
    private final String name;
    private final int order;
    private final String fact;

    public Planet(String name, int order, String fact) {
        this.name = name;
        this.order = order;
        this.fact = fact;
    }

    public String getName() {
        return name;
    }

    public int getOrder() {
        return order;
    }

    public String getFact() {
        return fact;
    }
}
```

This is plain Java, so you can sanity-check it outside Android Studio. Without the `package` line, this quick test compiles with `javac Planet.java PlanetCheck.java`:

```java
import java.util.ArrayList;
import java.util.List;

public class PlanetCheck {
    public static void main(String[] args) {
        List<Planet> planets = new ArrayList<>();
        planets.add(new Planet("Mercury", 1, "The closest planet to the Sun."));
        planets.add(new Planet("Venus", 2, "The hottest planet, thanks to its thick clouds."));
        planets.add(new Planet("Earth", 3, "The only planet known to have life."));
        for (int i = 0; i < planets.size(); i++) {
            Planet p = planets.get(i);
            System.out.println("position " + i + ": " + p.getName() + " (#" + p.getOrder() + " from the Sun)");
        }
        System.out.println("getItemCount() would return " + planets.size());
    }
}
```

```text
position 0: Mercury (#1 from the Sun)
position 1: Venus (#2 from the Sun)
position 2: Earth (#3 from the Sun)
getItemCount() would return 3
```

Notice that list positions start at 0 while planet order starts at 1. Mixing those up is a very common off-by-one bug.

## 3. The row layout

Create `res/layout/item_planet.xml` (**right-click layout > New > Layout Resource File**):

```xml
<?xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:background="?attr/selectableItemBackground"
    android:orientation="vertical"
    android:padding="16dp">

    <TextView
        android:id="@+id/planet_name"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:textSize="20sp"
        android:textStyle="bold" />

    <TextView
        android:id="@+id/planet_order"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content" />

</LinearLayout>
```

`?attr/selectableItemBackground` gives the row a ripple when tapped, so users can tell it's clickable.

## 4. The adapter, with a click callback

The adapter shouldn't start Activities itself; that's the screen's job. Instead it defines a small **interface** and calls it when a row is tapped. Create `PlanetAdapter.java`:

```java
package com.example.planetfacts;

import android.view.LayoutInflater;
import android.view.View;
import android.view.ViewGroup;
import android.widget.TextView;

import androidx.annotation.NonNull;
import androidx.recyclerview.widget.RecyclerView;

import java.util.List;

public class PlanetAdapter extends RecyclerView.Adapter<PlanetAdapter.PlanetViewHolder> {

    public interface OnPlanetClickListener {
        void onPlanetClick(Planet planet);
    }

    private final List<Planet> planets;
    private final OnPlanetClickListener listener;

    public PlanetAdapter(List<Planet> planets, OnPlanetClickListener listener) {
        this.planets = planets;
        this.listener = listener;
    }

    @NonNull
    @Override
    public PlanetViewHolder onCreateViewHolder(@NonNull ViewGroup parent, int viewType) {
        View row = LayoutInflater.from(parent.getContext())
                .inflate(R.layout.item_planet, parent, false);
        return new PlanetViewHolder(row);
    }

    @Override
    public void onBindViewHolder(@NonNull PlanetViewHolder holder, int position) {
        Planet planet = planets.get(position);
        holder.nameText.setText(planet.getName());
        holder.orderText.setText("Planet #" + planet.getOrder() + " from the Sun");
        holder.itemView.setOnClickListener(v -> listener.onPlanetClick(planet));
    }

    @Override
    public int getItemCount() {
        return planets.size();
    }

    public static class PlanetViewHolder extends RecyclerView.ViewHolder {
        final TextView nameText;
        final TextView orderText;

        public PlanetViewHolder(@NonNull View itemView) {
            super(itemView);
            nameText = itemView.findViewById(R.id.planet_name);
            orderText = itemView.findViewById(R.id.planet_order);
        }
    }
}
```

`holder.itemView` is the whole row, so the entire row is tappable, not just the text.

## 5. The detail screen

Choose **File > New > Activity > Empty Views Activity**, name it `DetailActivity`, and keep Java selected. Android Studio adds it to `AndroidManifest.xml` for you. Open the manifest and confirm this is inside `<application>`:

```xml
<activity
    android:name=".DetailActivity"
    android:exported="false" />
```

Replace `res/layout/activity_detail.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:tools="http://schemas.android.com/tools"
    android:id="@+id/main"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    android:padding="24dp"
    tools:context=".DetailActivity">

    <TextView
        android:id="@+id/detail_name"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:textSize="32sp"
        android:textStyle="bold" />

    <TextView
        android:id="@+id/detail_order"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_marginTop="8dp" />

    <TextView
        android:id="@+id/detail_fact"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:layout_marginTop="16dp"
        android:textSize="18sp" />

    <Button
        android:id="@+id/back_button"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_marginTop="24dp"
        android:text="Back to list" />

</LinearLayout>
```

Replace `DetailActivity.java`:

```java
package com.example.planetfacts;

import android.content.Intent;
import android.os.Bundle;
import android.widget.Button;
import android.widget.TextView;

import androidx.activity.EdgeToEdge;
import androidx.appcompat.app.AppCompatActivity;
import androidx.core.graphics.Insets;
import androidx.core.view.ViewCompat;
import androidx.core.view.WindowInsetsCompat;

public class DetailActivity extends AppCompatActivity {

    public static final String EXTRA_NAME = "com.example.planetfacts.NAME";
    public static final String EXTRA_ORDER = "com.example.planetfacts.ORDER";
    public static final String EXTRA_FACT = "com.example.planetfacts.FACT";

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        EdgeToEdge.enable(this);
        setContentView(R.layout.activity_detail);
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), (v, insets) -> {
            Insets systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars());
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom);
            return insets;
        });

        Intent intent = getIntent();
        String name = intent.getStringExtra(EXTRA_NAME);
        int order = intent.getIntExtra(EXTRA_ORDER, 0);
        String fact = intent.getStringExtra(EXTRA_FACT);

        if (name == null) {
            name = "Unknown planet";
        }
        if (fact == null) {
            fact = "";
        }

        TextView nameText = findViewById(R.id.detail_name);
        TextView orderText = findViewById(R.id.detail_order);
        TextView factText = findViewById(R.id.detail_fact);
        nameText.setText(name);
        orderText.setText("Planet #" + order + " from the Sun");
        factText.setText(fact);

        Button backButton = findViewById(R.id.back_button);
        backButton.setOnClickListener(v -> finish());
    }
}
```

Starting extra keys with your package name is the convention Android recommends, because it keeps your keys from clashing with anyone else's.

## 6. The list screen

Replace `activity_main.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<FrameLayout xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:tools="http://schemas.android.com/tools"
    android:id="@+id/main"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    tools:context=".MainActivity">

    <androidx.recyclerview.widget.RecyclerView
        android:id="@+id/planet_list"
        android:layout_width="match_parent"
        android:layout_height="match_parent" />

</FrameLayout>
```

Replace `MainActivity.java`:

```java
package com.example.planetfacts;

import android.content.Intent;
import android.os.Bundle;

import androidx.activity.EdgeToEdge;
import androidx.appcompat.app.AppCompatActivity;
import androidx.core.graphics.Insets;
import androidx.core.view.ViewCompat;
import androidx.core.view.WindowInsetsCompat;
import androidx.recyclerview.widget.LinearLayoutManager;
import androidx.recyclerview.widget.RecyclerView;

import java.util.ArrayList;
import java.util.List;

public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        EdgeToEdge.enable(this);
        setContentView(R.layout.activity_main);
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), (v, insets) -> {
            Insets systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars());
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom);
            return insets;
        });

        RecyclerView planetList = findViewById(R.id.planet_list);
        planetList.setLayoutManager(new LinearLayoutManager(this));
        planetList.setAdapter(new PlanetAdapter(makePlanets(), this::openDetail));
    }

    private void openDetail(Planet planet) {
        Intent intent = new Intent(this, DetailActivity.class);
        intent.putExtra(DetailActivity.EXTRA_NAME, planet.getName());
        intent.putExtra(DetailActivity.EXTRA_ORDER, planet.getOrder());
        intent.putExtra(DetailActivity.EXTRA_FACT, planet.getFact());
        startActivity(intent);
    }

    private List<Planet> makePlanets() {
        List<Planet> planets = new ArrayList<>();
        planets.add(new Planet("Mercury", 1, "The closest planet to the Sun."));
        planets.add(new Planet("Venus", 2, "The hottest planet, thanks to its thick clouds."));
        planets.add(new Planet("Earth", 3, "The only planet known to have life."));
        planets.add(new Planet("Mars", 4, "Home to Olympus Mons, the tallest volcano in the solar system."));
        planets.add(new Planet("Jupiter", 5, "The largest planet in the solar system."));
        planets.add(new Planet("Saturn", 6, "The least dense planet; on average it is less dense than water."));
        planets.add(new Planet("Uranus", 7, "It spins tipped over on its side."));
        planets.add(new Planet("Neptune", 8, "It has the fastest winds of any planet."));
        return planets;
    }
}
```

`this::openDetail` is a **method reference**. It's shorthand for `planet -> openDetail(planet)`, and it works because `openDetail` takes one `Planet`, just like `onPlanetClick`.

## 7. Run it

The first screen shows a scrolling list:

```text
Mercury
Planet #1 from the Sun
Venus
Planet #2 from the Sun
...
Neptune
Planet #8 from the Sun
```

Tap **Mars** and the detail screen shows:

```text
Mars
Planet #4 from the Sun
Home to Olympus Mons, the tallest volcano in the solar system.
[Back to list]
```

Tap **Back to list** or use the system Back gesture, and you're returned to the list at the same scroll position.

:::warning
If tapping a row crashes with `ActivityNotFoundException`, the `<activity>` entry is missing from the manifest. If the detail screen shows "Unknown planet," the key you used in `putExtra` doesn't match the one in `getStringExtra`. Using the `EXTRA_` constants on both sides prevents that.
:::
