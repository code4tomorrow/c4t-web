### Exercise 1: Decode BIO tags, even broken ones

Write `bio_to_spans(tags)` that returns `(label, start, end)` tuples with `end` exclusive, like Python slices. Real models produce invalid sequences, so handle them the way the standard CoNLL scorer does: an `I-` tag that doesn't continue an entity of the same type starts a new entity.

```text
["B-PER", "I-PER", "O", "B-LOC", "I-LOC", "I-LOC", "O"]  ->  [('PER', 0, 2), ('LOC', 3, 6)]
["O", "I-PER", "I-PER", "O", "B-LOC", "I-ORG", "O"]      ->  [('PER', 1, 3), ('LOC', 4, 5), ('ORG', 5, 6)]
["B-PER", "B-PER", "I-PER"]                              ->  [('PER', 0, 1), ('PER', 1, 3)]
```

:::hint
`tag.partition("-")` splits `"I-PER"` into `("I", "-", "PER")` and `"O"` into `("O", "", "")`. Track the open entity's `label` and `start`. At each tag, first decide whether it continues the open entity (an `I-` of the same type); if not, close the open one. Then decide whether this tag opens a new one. Appending an extra `"O"` to the tags closes anything still open at the end.
:::

:::solution
```python run
def bio_to_spans(tags):
    spans = []
    label, start = None, None
    for i, tag in enumerate(tags + ["O"]):
        prefix, _, kind = tag.partition("-")
        continues = prefix == "I" and kind == label
        if label is not None and not continues:
            spans.append((label, start, i))
            label = None
        if prefix == "B" or (prefix == "I" and not continues):
            label, start = kind, i
    return spans

print(bio_to_spans(["B-PER", "I-PER", "O", "B-LOC", "I-LOC", "I-LOC", "O"]))
print(bio_to_spans(["O", "I-PER", "I-PER", "O", "B-LOC", "I-ORG", "O"]))
print(bio_to_spans(["B-PER", "B-PER", "I-PER"]))
```

The appended `"O"` replaces the "don't forget the last entity" check from the Notes trace: the loop always ends on an *O*, so whatever is open gets closed. The second line shows the repair rules at work. `I-PER` after `O` starts a person, and `I-ORG` after a `B-LOC` starts an organization instead of extending the location.
:::

### Exercise 2: From character offsets to BIO tags

Labelling tools usually save entities as character offsets. Training needs one tag per token. Write `char_spans_to_bio(text, entities)` that tokenizes with `re.finditer(r"\w+|[^\w\s]", text)` and tags each token from `(start, end, label)` entities.

```python
text = "Ines Duarte flew to New York with Air Canada."
entities = [(0, 11, "PER"), (20, 28, "LOC"), (34, 44, "ORG")]
```

```text
Ines     B-PER
Duarte   I-PER
flew     O
...
Air      B-ORG
Canada   I-ORG
.        O
```

:::hint
A token belongs to an entity when it lies entirely inside it: `start <= m.start()` and `m.end() <= end`. It gets `B-` if it starts exactly where the entity starts, `I-` otherwise.
:::

:::solution
```python run
import re

def char_spans_to_bio(text, entities):
    tokens, tags = [], []
    for m in re.finditer(r"\w+|[^\w\s]", text):
        tag = "O"
        for start, end, label in entities:
            if start <= m.start() and m.end() <= end:
                tag = ("B-" if m.start() == start else "I-") + label
        tokens.append(m.group())
        tags.append(tag)
    return tokens, tags

text = "Ines Duarte flew to New York with Air Canada."
entities = [(0, 11, "PER"), (20, 28, "LOC"), (34, 44, "ORG")]
for token, tag in zip(*char_spans_to_bio(text, entities)):
    print(f"{token:8} {tag}")
```

If an entity boundary falls inside a token (say an annotator marked *York* in *Yorkshire*), no token fits entirely inside it and the entity silently disappears. Production code should count those cases and report them, since they usually mean the offsets and the tokenizer disagree.
:::

### Exercise 3: Align word labels with subword tokens

You have one label per *word*, but the model predicts one label per *subword token*. Here is the real tokenizer output for "Kofi Mensah joined Safaricom in Nairobi .", passed in as a list of words:

```python
tokens = ["[CLS]", "Ko", "##fi", "Men", "##sa", "##h", "joined", "Sa", "##fari", "##com", "in", "Nairobi", ".", "[SEP]"]
word_ids = [None, 0, 0, 1, 1, 1, 2, 3, 3, 3, 4, 5, 6, None]
word_labels = ["B-PER", "I-PER", "O", "B-ORG", "O", "B-LOC", "O"]
label2id = {"O": 0, "B-PER": 1, "I-PER": 2, "B-ORG": 3, "I-ORG": 4, "B-LOC": 5, "I-LOC": 6, "B-MISC": 7, "I-MISC": 8}
```

Write `align(word_ids, word_labels, every_piece=False)` that returns one label id per token. Special tokens get `-100`, which PyTorch's loss function skips. The first piece of each word gets the word's label. Other pieces get `-100` by default, or, with `every_piece=True`, the word's label with `B-` changed to `I-`.

```text
[CLS]     -100  -100
Ko           1     1
##fi      -100     2
Men          2     2
...
```

:::hint
`word_ids` tells you which word each token came from (`None` for special tokens). A token starts a new word when its word id differs from the previous token's.
:::

:::solution
```python run
tokens = ["[CLS]", "Ko", "##fi", "Men", "##sa", "##h", "joined", "Sa", "##fari", "##com", "in", "Nairobi", ".", "[SEP]"]
word_ids = [None, 0, 0, 1, 1, 1, 2, 3, 3, 3, 4, 5, 6, None]
word_labels = ["B-PER", "I-PER", "O", "B-ORG", "O", "B-LOC", "O"]
label2id = {"O": 0, "B-PER": 1, "I-PER": 2, "B-ORG": 3, "I-ORG": 4, "B-LOC": 5, "I-LOC": 6, "B-MISC": 7, "I-MISC": 8}

def align(word_ids, word_labels, every_piece=False):
    out, previous = [], None
    for w in word_ids:
        if w is None:
            out.append(-100)
        elif w != previous:
            out.append(label2id[word_labels[w]])
        elif every_piece:
            out.append(label2id[word_labels[w].replace("B-", "I-")])
        else:
            out.append(-100)
        previous = w
    return out

first_only, all_pieces = align(word_ids, word_labels), align(word_ids, word_labels, every_piece=True)
for token, a, b in zip(tokens, first_only, all_pieces):
    print(f"{token:8} {a:5} {b:5}")
```

Both conventions are in use; the Hugging Face course uses the second. Either way, `##fari` must not get `B-ORG`, or the model learns that a company name starts in the middle of a word. A model trained without that care is exactly how you get the three-part *Safaricom* from the Notes lesson.

To produce `word_ids` yourself in Colab, call `tokenizer(words, is_split_into_words=True).word_ids()`.
:::

### Exercise 4: Token accuracy flatters NER

For "Maria del Carmen joined the World Bank in Lima .", a model predicts the tags below. Compute token-level accuracy, then span-level precision, recall, and F1 using `bio_to_spans` from Exercise 1.

```python
gold = ["B-PER", "I-PER", "I-PER", "O", "O", "B-ORG", "I-ORG", "O", "B-LOC", "O"]
pred = ["B-PER", "O", "B-PER", "O", "O", "B-ORG", "I-ORG", "O", "B-LOC", "O"]
```

```text
token accuracy 0.80
span precision 0.50  recall 0.67  F1 0.57
```

:::hint
Turn both span lists into sets; the correct spans are their intersection, exactly as in the build-along.
:::

:::solution
```python run
gold = ["B-PER", "I-PER", "I-PER", "O", "O", "B-ORG", "I-ORG", "O", "B-LOC", "O"]
pred = ["B-PER", "O", "B-PER", "O", "O", "B-ORG", "I-ORG", "O", "B-LOC", "O"]

token_acc = sum(g == p for g, p in zip(gold, pred)) / len(gold)
g, p = set(bio_to_spans(gold)), set(bio_to_spans(pred))
precision, recall = len(g & p) / len(p), len(g & p) / len(g)
f1 = 2 * precision * recall / (precision + recall)
print(f"token accuracy {token_acc:.2f}")
print(f"span precision {precision:.2f}  recall {recall:.2f}  F1 {f1:.2f}")
print("missed:", g - p, " extra:", p - g)
```

Two wrong tags out of ten look like 80% accuracy, but they turned one person into two fragments: one missed entity and two false ones. In real text, 80 to 90% of tokens are usually *O*, so a model that predicts *O* everywhere already scores high token accuracy while finding nothing. That's why NER papers report span-level F1, computed by tools like `seqeval`.
:::

### Exercise 5: From logits to entities

The cell below simulates logits for the Exercise 3 tokens (random numbers with a boost on a planned label, since real logits need the model). One planned label is deliberately inconsistent: `##fari` leans toward `B-ORG`. Apply a softmax, take each token's best label, keep the label of each word's **first** piece (the `first` aggregation strategy), and decode the word labels into entities.

```python run
import numpy as np

labels = ["O", "B-PER", "I-PER", "B-ORG", "I-ORG", "B-LOC", "I-LOC"]
words = ["Kofi", "Mensah", "joined", "Safaricom", "in", "Nairobi", "."]
rng = np.random.default_rng(0)
planned = [0, 1, 2, 2, 2, 2, 0, 3, 3, 4, 0, 5, 0, 0]
logits = rng.normal(0, 1, (len(planned), len(labels))).round(1)
logits[np.arange(len(planned)), planned] += 4
print(logits.shape)
```

```text
PER Kofi Mensah
ORG Safaricom
LOC Nairobi
```

:::hint
Softmax each row: `np.exp(logits) / np.exp(logits).sum(axis=1, keepdims=True)`. Then walk `word_ids` alongside the token labels, keeping a label only when the word id is not `None` and differs from the previous one.
:::

:::solution
```python run
probs = np.exp(logits) / np.exp(logits).sum(axis=1, keepdims=True)
token_labels = [labels[i] for i in probs.argmax(axis=1)]
print(list(zip(tokens, token_labels))[7:10])

word_labels_pred, previous = [], None
for w, label in zip(word_ids, token_labels):
    if w is not None and w != previous:
        word_labels_pred.append(label)
    previous = w

for label, start, end in bio_to_spans(word_labels_pred):
    print(label, " ".join(words[start:end]))
```

At the token level, *Safaricom* is `B-ORG`, `B-ORG`, `I-ORG`, which `simple` aggregation would split in two. Taking only the first piece's label gives one clean word-level `B-ORG`. Softmax doesn't change which label is largest, so for picking labels the argmax of the logits gives the same answer; you need the probabilities only for the confidence score.
:::

### Exercise 6: Attention weights, with and without a causal mask

Attention scores are turned into weights with a softmax along each row. Given these made-up scores for four tokens, compute the weights, check that every row sums to 1, and print which token each token attends to most. Then apply a **causal mask**, the one GPT-style models use so a token can't look at later tokens: set every score above the diagonal to minus infinity before the softmax.

```python
import numpy as np

tokens = ["the", "cat", "sat", "down"]
scores = np.array([
    [2.0, 0.5, 0.1, 0.0],
    [1.0, 2.5, 0.3, 0.2],
    [0.2, 2.0, 1.0, 0.5],
    [0.1, 0.4, 2.2, 1.0],
])
```

:::hint
Subtract each row's maximum before `np.exp` so large scores can't overflow; it doesn't change the result. `np.triu(np.ones((4, 4), dtype=bool), k=1)` marks the positions above the diagonal, and `np.where(mask, -np.inf, scores)` applies the mask. `exp(-inf)` is exactly 0.
:::

:::solution
```python run
tokens = ["the", "cat", "sat", "down"]
scores = np.array([
    [2.0, 0.5, 0.1, 0.0],
    [1.0, 2.5, 0.3, 0.2],
    [0.2, 2.0, 1.0, 0.5],
    [0.1, 0.4, 2.2, 1.0],
])

def softmax_rows(x):
    e = np.exp(x - x.max(axis=1, keepdims=True))
    return e / e.sum(axis=1, keepdims=True)

weights = softmax_rows(scores)
print(weights.round(2))
print("row sums:", weights.sum(axis=1))
for token, row in zip(tokens, weights):
    print(f"{token:5} attends most to {tokens[row.argmax()]!r} ({row.max():.2f})")

future = np.triu(np.ones_like(scores, dtype=bool), k=1)
print(softmax_rows(np.where(future, -np.inf, scores)).round(2))
```

With the mask, *the* can only look at itself, so its row becomes `[1, 0, 0, 0]`, and every row's weight is redistributed over earlier tokens only. The last row is unchanged, because *down* is last and had no future to hide. The NER model in this course is an encoder with no mask, which is why its tokens can use words on both sides; Module 5 picks up from here.
:::

### Challenge: A tested redaction tool

Write `redact(text, model_spans)` that replaces people, emails, and phone numbers with `[PERSON]`, `[EMAIL]`, and `[PHONE]`, and leaves everything else alone. Emails and phone numbers (pattern `\b\d{3}-\d{4}\b`) come from regex rules; people come from the model, given as `(start, end, label)` spans. A rule span beats any overlapping model span. Test it with `unittest`, including a made-up model span that overlaps an email. The model spans for this sentence are the real output of the course's model:

```python
text = "Call Ana Lima on 555-0142 or email ana.lima@example.net; she leaves Lisbon on 9 July."
model_spans = [(5, 13, "PER"), (68, 74, "LOC")]
```

```text
Call [PERSON] on [PHONE] or email [EMAIL]; she leaves Lisbon on 9 July.
```

:::hint
Replacing a span changes the length of the text, which shifts every offset after it. Replace from the **end** of the text backwards (`sorted(spans, reverse=True)`), and earlier offsets stay valid. Print test results to the output with `unittest.TextTestRunner(stream=sys.stdout, verbosity=2)`.
:::

:::solution
```python run
import re
import sys
import unittest

PLACEHOLDER = {"PER": "[PERSON]", "EMAIL": "[EMAIL]", "PHONE": "[PHONE]"}
RULES = [
    ("EMAIL", r"[\w.+-]+@[\w-]+(?:\.[\w-]+)+"),
    ("PHONE", r"\b\d{3}-\d{4}\b"),
]

def redact(text, model_spans):
    spans = [(m.start(), m.end(), label) for label, pattern in RULES for m in re.finditer(pattern, text)]
    for start, end, label in model_spans:
        if not any(start < e and s < end for s, e, _ in spans):
            spans.append((start, end, label))
    for start, end, label in sorted(spans, reverse=True):
        if label in PLACEHOLDER:
            text = text[:start] + PLACEHOLDER[label] + text[end:]
    return text

text = "Call Ana Lima on 555-0142 or email ana.lima@example.net; she leaves Lisbon on 9 July."
model_spans = [(5, 13, "PER"), (68, 74, "LOC")]
print(redact(text, model_spans))

class RedactTests(unittest.TestCase):
    def test_example(self):
        self.assertEqual(redact(text, model_spans),
                         "Call [PERSON] on [PHONE] or email [EMAIL]; she leaves Lisbon on 9 July.")

    def test_rule_beats_overlapping_model_span(self):
        # a made-up model span: "lima" inside the email address tagged as a person
        self.assertEqual(redact("Email ana.lima@example.net", [(10, 14, "PER")]), "Email [EMAIL]")

    def test_no_entities(self):
        self.assertEqual(redact("Nothing to hide here.", []), "Nothing to hide here.")

suite = unittest.defaultTestLoader.loadTestsFromTestCase(RedactTests)
unittest.TextTestRunner(stream=sys.stdout, verbosity=2).run(suite)
```

Without the overlap check, the second test replaces *lima* first, then cuts the email's original character range out of text that has already changed length, leaving a stray `.net` behind. Redaction is a task where recall matters more than precision: a missed name leaks, while an extra placeholder only costs some readability. The model scored *Ana Lima* at 0.831, the lowest score in its output; a real tool would log low-confidence spans for a person to check rather than trusting the threshold.
