The school newsletter just ran this chart under the headline "Tutoring sends scores soaring!" The tutored bar towers over the other one. Before reading on, guess: how much higher do you think the tutored group's average actually is?

```python run alt="A red and gray bar chart titled TUTORING SENDS SCORES SOARING. The y-axis runs from 72 to 77, so the red Tutored bar looks nearly three times as tall as the gray Not tutored bar." caption="The newsletter's chart, exactly as printed"
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

rng = np.random.default_rng(21)
scores = pd.DataFrame({
    "group": ["Tutored"] * 60 + ["Not tutored"] * 60,
    "score": np.concatenate([
        rng.normal(76, 10, 60),
        rng.normal(74, 10, 60),
    ]).clip(35, 100).round(),
})
means = scores.groupby("group")["score"].mean().reindex(["Not tutored", "Tutored"])

fig, ax = plt.subplots(figsize=(5, 4))
ax.bar(means.index, means.values, color=["#999999", "#ff0000"])
ax.set_ylim(72, 77)
ax.set_title("TUTORING SENDS SCORES SOARING!")
```

The scores here are simulated with a fixed seed (`default_rng(21)`), so you get exactly the same 120 students every time you run it. By the end of this lesson you'll have replaced this chart with a two-panel figure that shows the real gap and every student behind it, and you'll have fixed a second, sneakier chart from the same newsletter.

## Step 1: Check the claim with numbers first

A chart is a claim about numbers, so start with the numbers. `agg` computes several summaries per group in one call:

```python run
summary = scores.groupby("group")["score"].agg(["count", "mean", "median", "std", "min", "max"])
print(summary.round(1))

gap = means["Tutored"] - means["Not tutored"]
print(f"\nGap between the means: {gap:.1f} points")
print(f"Spread within the tutored group (std): {summary.loc['Tutored', 'std']:.1f} points")
```

The tutored group's mean is 2.8 points higher. Meanwhile each group's scores spread about 9 or 10 points either side of its mean, and each group spans more than 40 points from its lowest score to its highest. The gap is real in this sample, but it is small compared with how much students differ from each other. Whether it's worth a headline is a separate question, and one the chart answered dishonestly.

## Step 2: Measure how much the chart exaggerates

Edward Tufte, who wrote some of the most influential books on statistical graphics, proposed a number for this: the **lie factor**, the size of the effect shown in the graphic divided by the size of the effect in the data. A truthful chart scores 1.

```python run
def lie_factor(low, high, axis_start):
    shown = (high - axis_start) / (low - axis_start) - 1
    actual = high / low - 1
    return shown / actual

low, high = means["Not tutored"], means["Tutored"]
print(f"Tutored bar is drawn {(high - 72) / (low - 72):.1f}x as tall as the other")
print(f"Tutored mean is actually {high / low:.3f}x the other")
print(f"Lie factor with the axis starting at 72: {lie_factor(low, high, 72):.0f}")
print(f"Lie factor with the axis starting at 0:  {lie_factor(low, high, 0):.0f}")
```

Bars encode a number by their length. Cutting off the bottom 72 points of both bars leaves only the tips, and the tips differ by a huge ratio even though the totals don't. With the axis at zero, the lie factor drops to exactly 1, because the drawn lengths are proportional to the values again.

## Step 3: Rebuild the bars from zero, with labels

Three changes: start at zero, print the value on each bar so nobody has to squint at gridlines, and write a title that states what the chart shows (computed from the data, so it can't drift out of date).

```python run alt="Two bars on a 0 to 100 axis. Not tutored, in orange, is labeled 73.7. Tutored, in blue, is labeled 76.5. The bars look almost the same height. Title: Tutored students averaged 2.8 points higher." caption="Same data, axis from zero"
BLUE, ORANGE, INK, MUTED = "#2a78d6", "#eb6834", "#0b0b0b", "#52514e"
colors = {"Not tutored": ORANGE, "Tutored": BLUE}
plt.rcParams.update({"axes.spines.top": False, "axes.spines.right": False})

fig, ax = plt.subplots(figsize=(5, 4))
bars = ax.bar(means.index, means.values, color=[colors[g] for g in means.index], width=0.6)
ax.bar_label(bars, fmt="%.1f", padding=3, color=INK)
ax.set_ylim(0, 100)
ax.set_ylabel("Mean final exam score (out of 100)")
ax.set_title(f"Tutored students averaged {gap:.1f} points higher", loc="left")
```

Now the bars look nearly equal, because they nearly are. Notice that the honest version is less exciting. That's the point: the exciting version was manufactured by the axis, not found in the data.

:::warning
**"Start at zero" is a rule for bars, not for every chart.** A line chart encodes values by position and slope, not length, so a temperature line from 18 to 24 °C is fine. But a line's range still makes a claim: zoom in far enough and noise looks like a crisis. Pick a range that matches a change that would matter, and label the axis so readers can see what you chose.
:::

## Step 4: Show every student, not just two averages

Two bars hide the most important fact: how much the groups overlap. A **strip plot** draws one dot per student, jittered up and down so they don't sit on top of each other. A short black tick marks each mean.

```python run alt="Strip plot with one dot per student. The Not tutored row in orange spans about 45 to 91, and the Tutored row in blue about 58 to 98. A black tick marks each mean, 73.7 and 76.5, very close together compared with the spread of the dots." caption="Each dot is one student"
import seaborn as sns

order = ["Not tutored", "Tutored"]
fig, ax = plt.subplots(figsize=(7, 3.2))
sns.stripplot(data=scores, x="score", y="group", order=order, hue="group", palette=colors,
              legend=False, jitter=0.25, size=4, alpha=0.7, ax=ax)
for row, group in enumerate(order):
    ax.plot(means[group], row, marker="|", markersize=28, markeredgewidth=3, color=INK)
    ax.annotate(f"mean {means[group]:.1f}", (means[group], row), xytext=(0, 18),
                textcoords="offset points", ha="center", color=INK,
                bbox={"boxstyle": "round,pad=0.2", "fc": "white", "ec": "none"})
ax.set_xlim(30, 100)
ax.set_xlabel("Final exam score (out of 100)")
ax.set_ylabel("")
ax.set_title("The two groups overlap almost completely", loc="left")

below = (scores.loc[scores["group"] == "Tutored", "score"] < low).mean()
print(f"{below:.0%} of tutored students scored below the non-tutored average")
```

More than a third of tutored students scored below the other group's average. This chart would stop any reader from concluding that tutoring transforms everyone's grades, and it does it without a single extra word. (Whether tutoring *caused* even the 2.8-point gap is a different question. Students chose to sign up, and Module 6 is about why that matters.)

## Step 5: Replace the dual-axis chart

Page two of the newsletter had this one. It plots two different measures, each with its own y-axis:

```python run alt="Dual-axis line chart from September to May. A green line for tutoring sessions uses the left axis, 40 to 240. A purple line for the school average score uses the right axis, 70.8 to 74.1. The two lines rise together and almost lie on top of each other." caption="Two y-axes, each scaled by the chart maker"
months = ["Sep", "Oct", "Nov", "Dec", "Jan", "Feb", "Mar", "Apr", "May"]
sessions = [40, 85, 120, 150, 160, 190, 210, 230, 240]
school_avg = [71.0, 71.4, 71.9, 72.1, 72.6, 72.8, 73.3, 73.5, 73.9]
AQUA, VIOLET = "#1baf7a", "#6250d6"

fig, ax1 = plt.subplots(figsize=(7, 3.5))
ax1.plot(months, sessions, color=AQUA, linewidth=2)
ax1.set_ylabel("Tutoring sessions per month")
ax2 = ax1.twinx()
ax2.plot(months, school_avg, color=VIOLET, linewidth=2)
ax2.set_ylim(70.8, 74.1)
ax2.set_ylabel("School average score")
ax2.spines["right"].set_visible(True)
ax1.set_title("More tutoring, higher scores?", loc="left")
```

The lines hug each other, which looks like strong evidence. It isn't evidence of anything: whoever makes the chart picks both axis ranges independently, so **any two rising series can be stretched to overlap**. Change `set_ylim(70.8, 74.1)` to `set_ylim(0, 100)` and the purple line goes flat.

The fix is to put both series on one shared, meaningful scale. Here that's percent change since September:

```python run alt="Line chart of percent change since September on a single axis. Tutoring sessions climb steeply to plus 500 percent by May. The school average score stays near zero, ending at plus 4 percent." caption="One axis, one unit: percent change since September"
monthly = pd.DataFrame({"Tutoring sessions": sessions, "School average score": school_avg}, index=months)
pct = (monthly / monthly.iloc[0] - 1) * 100

fig, ax = plt.subplots(figsize=(7, 3.5))
for column, color in [("Tutoring sessions", AQUA), ("School average score", VIOLET)]:
    ax.plot(months, pct[column], color=color, linewidth=2)
    ax.annotate(f"{column}: +{pct[column].iloc[-1]:.0f}%", (len(months) - 1, pct[column].iloc[-1]),
                xytext=(-4, 8), textcoords="offset points", ha="right", color=INK)
ax.axhline(0, color=MUTED, linewidth=0.8)
ax.set_ylabel("Change since September (%)")
ax.set_title("Sessions grew sixfold; the school average rose 4%", loc="left")
print(pct.round(1).tail(3))
```

Two other honest fixes work too: two separate panels stacked with a shared x-axis, or a scatter plot of one measure against the other. And even with an honest chart, two things that both rise across a school year don't show that one drives the other. Scores often climb as the year goes on anyway.

## Step 6: Make color and labels carry their weight

Look back at the newsletter's choices: red for "our" group and gray for the other, a shouting title, no units. Each of the rebuilt charts follows a few rules you can apply to any figure:

| Choice | Rule | Why |
| --- | --- | --- |
| Color | One color per group, the same in every chart | Readers learn "blue = tutored" once |
| Palette | Blue and orange, not red and green | About 1 in 12 men has some color vision deficiency, usually red-green |
| Labels | Name lines and bars directly, not only in a legend | Identity never depends on color alone |
| Title | State the finding, computed from the data | The reader knows what to look for, and it stays correct |
| Axes | Name the measure and its unit | "Score (out of 100)" beats "score" |

Combine Steps 3 and 4 into one figure, with a figure-level title that summarizes both panels.

## The finished program

This cell is self-contained: it rebuilds the data and the final figure from scratch, which is how you'd keep it in a real notebook.

```python run alt="Two-panel figure. Left: bars from zero showing mean scores of 73.7 for Not tutored and 76.5 for Tutored. Right: one dot per student for each group, overlapping heavily between about 45 and 98, with the means marked. Overall title: Tutored students averaged 2.8 points higher, but the groups overlap almost completely." caption="The honest replacement for the newsletter chart"
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

BLUE, ORANGE, INK = "#2a78d6", "#eb6834", "#0b0b0b"


def honest_comparison(df, group_col, value_col, order, colors, unit):
    means = df.groupby(group_col)[value_col].mean().reindex(order)
    gap = means.iloc[1] - means.iloc[0]
    fig, (left, right) = plt.subplots(1, 2, figsize=(10, 3.8), width_ratios=[1, 2])

    bars = left.bar(order, means.values, color=[colors[g] for g in order], width=0.6)
    left.bar_label(bars, fmt="%.1f", padding=3, color=INK)
    left.set_ylim(0, 100)
    left.set_ylabel(f"Mean {unit}")
    left.set_title("Averages, axis from zero", loc="left")

    sns.stripplot(data=df, x=value_col, y=group_col, order=order, hue=group_col,
                  palette=colors, legend=False, jitter=0.25, size=4, alpha=0.7, ax=right)
    for row, group in enumerate(order):
        right.plot(means[group], row, marker="|", markersize=28, markeredgewidth=3, color=INK)
    right.set_xlabel(unit.capitalize())
    right.set_ylabel("")
    right.set_title("Every student", loc="left")

    for ax in (left, right):
        ax.spines[["top", "right"]].set_visible(False)
    fig.suptitle(f"{order[1]} averaged {gap:.1f} points higher, but the groups overlap almost completely",
                 x=0.01, ha="left", fontsize=12)
    fig.tight_layout()
    return fig


rng = np.random.default_rng(21)
scores = pd.DataFrame({
    "group": ["Tutored"] * 60 + ["Not tutored"] * 60,
    "score": np.concatenate([rng.normal(76, 10, 60), rng.normal(74, 10, 60)]).clip(35, 100).round(),
})
honest_comparison(scores, "group", "score", ["Not tutored", "Tutored"],
                  {"Not tutored": ORANGE, "Tutored": BLUE}, "final exam score (out of 100)")
```

The function takes the column names, group order, colors, and unit as arguments, so the same honest layout works for any two-group comparison: sleep hours by grade, commute minutes by bus route, or anything you meet in the capstone.

:::quiz
Q: In Step 2, why did the lie factor fall to exactly 1 when the axis started at 0?
- [x] Bar lengths became proportional to the values, so the drawn ratio matched the real ratio
  With a zero baseline, a bar for 76.5 is 76.5 units long, and the ratio of lengths equals the ratio of means.
- [ ] Starting at zero rounds the means
  The means are unchanged; only how much of each bar is drawn changes.
- [ ] The lie factor function always returns 1 for small gaps
  It returned 44 for the same gap with the axis at 72. The baseline is what changed.

Q: Why did Step 4 add a strip plot instead of error bars or a bigger title?
- [ ] Strip plots are required whenever bars start at zero
  No such rule. The strip plot answers a different question than the bars do.
- [x] It shows how much individual students overlap, which two averages can't show
  Seeing that more than a third of tutored students fall below the other group's mean keeps readers from imagining that every tutored student did better.
- [ ] Seaborn can't draw bar charts
  It can (`sns.barplot`). We used matplotlib for the bars because it's simpler to label.

Q: A teammate fixes the dual-axis chart by setting both y-axes to start at zero. What's still wrong?
- [ ] Nothing; zero baselines make any chart honest
  The two axes still have different units and ranges chosen independently, so how the lines line up is still the chart maker's choice.
- [x] There are still two scales, so the visual overlap still depends on arbitrary axis choices
  The fix is one shared scale (like percent change), separate panels, or a scatter plot of one measure against the other.
- [ ] Line charts must never start at zero
  Lines can start at zero or not. The problem here is having two independent y-axes.
:::

:::takeaways
- Check the numbers before you trust the picture. A big-looking gap can be small next to the spread within each group.
- Bars encode length, so they start at zero. The lie factor measures how far a chart strays from that.
- Show the data points (or a distribution) next to averages so readers can see the overlap.
- Dual axes let the chart maker line up any two series. Use one shared scale, separate panels, or a scatter plot.
- Keep one color per group across every chart, label things directly, put units on axes, and compute titles from the data.
:::
