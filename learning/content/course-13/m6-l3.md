### Exercise 1: Find the strongest relationship in a survey

```python run
n = 200
phone = rng.gamma(3, 1.2, n)
sleep = 8.6 - 0.35 * phone + rng.normal(0, 0.6, n)
study = rng.gamma(4, 0.5, n)
gpa = (2.0 + 0.25 * study + 0.12 * sleep + rng.normal(0, 0.35, n)).clip(0, 4)
survey = pd.DataFrame({"phone_hours": phone.round(1), "sleep_hours": sleep.round(1),
                       "study_hours": study.round(1), "gpa": gpa.round(2)})
```

Print the correlation matrix, then find the pair of *different* columns with the largest absolute correlation using code (not by eye). Draw that pair as a scatter plot with labeled axes and r in the title.

Sample output: the matrix, then a line like `Strongest pair: ('phone_hours', 'sleep_hours') r = -0.77`.

:::hint
`survey.corr().unstack()` turns the matrix into a Series indexed by pairs. Drop the self-pairs (where the value is exactly 1), take `.abs()`, and use `.idxmax()`.
:::

:::solution
```python run alt="Scatter plot of daily phone hours against sleep hours for 200 students, sloping clearly downhill: students with more phone time report less sleep. Title: r = -0.77." caption="The strongest pair in the survey"
corr = survey.corr()
print(corr.round(2))

pairs = corr.unstack()
pairs = pairs[pairs < 1]
best = pairs.abs().idxmax()
print(f"\nStrongest pair: {best} r = {pairs[best]:.2f}")

fig, ax = plt.subplots(figsize=(6, 3.8))
ax.scatter(survey[best[0]], survey[best[1]], s=14, color=BLUE, alpha=0.6)
ax.set_xlabel("Phone use (hours per day)")
ax.set_ylabel("Sleep (hours per night)")
ax.set_title(f"r = {pairs[best]:.2f}", loc="left")
```

Taking `.abs()` before `idxmax` matters: the strongest relationship here is negative, and without `.abs()` you'd pick the strongest *positive* pair instead. Each pair appears twice in the unstacked Series (A with B, and B with A), which is harmless here.
:::

### Exercise 2: Does tutoring lower grades?

A different school's data seems to show that tutored students finish with *lower* scores. But students choose tutoring when they're struggling.

```python run
n = 300
prior = rng.normal(75, 10, n).clip(40, 100)
chose_tutoring = rng.random(n) < 1 / (1 + np.exp((prior - 68) / 4))
final = (0.9 * prior + 8 + 5 * chose_tutoring + rng.normal(0, 5, n)).clip(0, 100).round()
tutoring = pd.DataFrame({"prior_grade": prior.round(),
                         "group": np.where(chose_tutoring, "Tutored", "Not tutored"),
                         "final": final})
```

1. Compare the mean `final` score of the two groups overall.
2. Split students into prior-grade bands (under 65, 65–74, 75–84, 85+) and compare the groups within each band.
3. Draw a grouped bar chart of the within-band means, and write one sentence on what explains the overall result.

:::hint
`pd.cut(tutoring["prior_grade"], [0, 65, 75, 85, 101], labels=[...], right=False)` makes the bands. Then `pivot_table(index="band", columns="group", values="final", aggfunc="mean", observed=True)` builds the comparison table.
:::

:::solution
```python run alt="Grouped bar chart of mean final score by prior-grade band. In each band where both groups exist (under 65, 65-74, and 75-84), the blue Tutored bar is 2 to 5 points higher than the orange Not tutored bar. The 85+ band has only a Not tutored bar." caption="Within every band with tutored students, they did better"
print(tutoring.groupby("group")["final"].agg(["count", "mean"]).round(1))

tutoring["band"] = pd.cut(tutoring["prior_grade"], [0, 65, 75, 85, 101],
                          labels=["under 65", "65-74", "75-84", "85+"], right=False)
table = tutoring.pivot_table(index="band", columns="group", values="final", aggfunc="mean", observed=True)
counts = tutoring.pivot_table(index="band", columns="group", values="final", aggfunc="count", observed=True)
print("\nMean final score by band:\n", table.round(1))
print("\nStudents per band:\n", counts.fillna(0).astype(int))

positions = np.arange(len(table))
fig, ax = plt.subplots(figsize=(7, 3.6))
for offset, group, color in [(-0.2, "Not tutored", ORANGE), (0.2, "Tutored", BLUE)]:
    ax.bar(positions + offset, table[group], width=0.38, color=color, label=group)
ax.set_xticks(positions, table.index)
ax.set_ylim(0, 100)
ax.set_xlabel("Prior grade band")
ax.set_ylabel("Mean final score")
ax.legend(frameon=False, loc="upper left")
```

Overall, tutored students averaged about 8 points lower. Within each band they scored 2 to 5 points higher. Prior grade is the confounder: weaker students were much more likely to sign up, and weaker students score lower whether tutored or not. Notice the counts too: the under-65 band is mostly tutored students and the 85+ band has none, which is exactly the uneven mix that produces a reversal.
:::

### Exercise 3: Fix a lopsided survey

The cafeteria survey was handed out at lunch, when ninth graders eat on campus far more than seniors. The school has 300 students in each grade.

```python run
grades = np.repeat(["9th", "10th", "11th", "12th"], 300)
base = pd.Series(grades).map({"9th": 7.5, "10th": 6.5, "11th": 5.5, "12th": 4.5}).to_numpy()
school = pd.DataFrame({"grade": grades,
                       "satisfaction": (base + rng.normal(0, 1.5, 1200)).clip(1, 10).round()})
responses = {"9th": 100, "10th": 50, "11th": 30, "12th": 20}
sample = pd.concat([school[school["grade"] == g].sample(k, random_state=1) for g, k in responses.items()])
```

In real life you only see `sample`. Compute its raw mean satisfaction. Then compute a **reweighted** mean: each grade's sample mean, weighted by that grade's share of the *whole school* (25% each). Compare both with the true school mean, which you can see here only because the data is simulated.

Sample output: three lines, `raw sample mean`, `reweighted mean`, and `true school mean`.

:::hint
`sample.groupby("grade")["satisfaction"].mean()` gives one mean per grade. Multiply it by a Series of population shares (`school["grade"].value_counts(normalize=True)`) and `.sum()` the result.
:::

:::solution
```python run
raw = sample["satisfaction"].mean()
grade_means = sample.groupby("grade")["satisfaction"].mean()
population_share = school["grade"].value_counts(normalize=True)
reweighted = (grade_means * population_share).sum()

print(f"raw sample mean:  {raw:.2f}")
print(f"reweighted mean:  {reweighted:.2f}")
print(f"true school mean: {school['satisfaction'].mean():.2f}")
print("\nSample share vs school share:")
print(pd.DataFrame({"sample": sample["grade"].value_counts(normalize=True),
                    "school": population_share}).round(2))
```

Half the responses came from ninth graders, the happiest group, so the raw mean overstates satisfaction by more than half a point. Reweighting gives each grade the voice its size deserves and lands close to the truth. This only fixes bias you can see: if the unhappy seniors who *did* answer differ from the ones who didn't, no weighting by grade can repair that.
:::

### Exercise 4: Measure survivorship bias in investment funds

An advertisement says, "The average fund in our family returned 6.6% a year over five years!" Funds that lose money get closed, and closed funds disappear from the list.

```python run
funds, years = 1000, 5
returns = rng.normal(0.05, 0.12, (funds, years))
value = np.cumprod(1 + returns, axis=1)
closed = (value < 0.85).any(axis=1)
```

Each row is one fund's yearly returns; a fund closes if its value ever drops below 85% of where it started. Print how many funds closed, the average yearly return of all 1,000 funds, and the average of the survivors only. Then draw two histograms (all funds, survivors) on the same bins.

:::hint
`returns.mean(axis=1)` gives each fund's average yearly return. Use `closed` as a mask: `fund_avg[~closed]` keeps the survivors.
:::

:::solution
```python run alt="Two overlaid histograms of funds' average yearly returns. The gray histogram of all 1,000 funds is centered near 5 percent and spreads from about minus 15 to plus 21 percent. The blue histogram of survivors is missing most of the left tail, so its center sits further right." caption="Closing the losers removes the left tail"
fund_avg = returns.mean(axis=1) * 100
print(f"Funds closed: {closed.sum()} of {funds}")
print(f"Average yearly return, all funds:      {fund_avg.mean():.1f}%")
print(f"Average yearly return, survivors only: {fund_avg[~closed].mean():.1f}%")

bins = np.arange(-15, 25, 1.5)
fig, ax = plt.subplots(figsize=(7, 3.5))
ax.hist(fund_avg, bins=bins, color=MUTED, alpha=0.35, label="All funds")
ax.hist(fund_avg[~closed], bins=bins, color=BLUE, alpha=0.75, label="Survivors")
ax.set_xlabel("Average yearly return (%)")
ax.set_ylabel("Funds")
ax.legend(frameon=False)
```

Every fund was drawn from the same distribution with a true average of 5%, so no fund was "skilled." Yet the survivors average about 6.6% because the unlucky ones were removed. The advertisement's number is true and still misleading.
:::

### Exercise 5: Choose a kidney stone treatment

These are real results from a 1986 study comparing open surgery (A) with a less invasive procedure, percutaneous nephrolithotomy (B). Each row is successes out of patients treated.

```python run
stones = pd.DataFrame({
    "treatment": ["A", "A", "B", "B"],
    "size": ["small", "large", "small", "large"],
    "success": [81, 192, 234, 55],
    "patients": [87, 263, 270, 80],
})
```

Compute each treatment's pooled success rate and its rate for each stone size. Which treatment would you recommend for a patient with a small stone? With a large one? Draw a chart that makes your recommendation obvious.

:::hint
This is the same structure as the Berkeley data: group, stratum, successes, and totals. Pool by summing counts before dividing. Then look at how many small and large stones each treatment received.
:::

:::solution
```python run alt="Grouped bar chart of success rates. Small stones: A 93 percent, B 87 percent. Large stones: A 73 percent, B 69 percent. Pooled: A 78 percent, B 83 percent. A is higher for both sizes but lower when pooled." caption="A wins within each size and loses when pooled"
pooled = stones.groupby("treatment")[["success", "patients"]].sum()
pooled["rate"] = pooled["success"] / pooled["patients"]
stones["rate"] = stones["success"] / stones["patients"]
rates = stones.pivot(index="size", columns="treatment", values="rate").reindex(["small", "large"])
rates.loc["pooled"] = pooled["rate"]
print((rates * 100).round(1))
print("\nPatients by size:\n", stones.pivot(index="size", columns="treatment", values="patients"))

positions = np.arange(len(rates))
fig, ax = plt.subplots(figsize=(7, 3.6))
for offset, treatment, color in [(-0.2, "A", BLUE), (0.2, "B", ORANGE)]:
    bars = ax.bar(positions + offset, rates[treatment] * 100, width=0.38, color=color, label=f"Treatment {treatment}")
    ax.bar_label(bars, fmt="%.0f%%", padding=2, color=INK)
ax.set_xticks(positions, ["Small stones", "Large stones", "Pooled"])
ax.set_ylim(0, 100)
ax.set_ylabel("Success rate (%)")
ax.legend(frameon=False, loc="lower left")
```

Recommend A for both sizes: it's better for small stones (93% vs 87%) and for large stones (73% vs 69%). B only looks better pooled because doctors gave B mostly to small stones, which are easier to treat, and A mostly to large ones. Stone size is the lurking variable, playing the role that department played at Berkeley.
:::

### Exercise 6: Rewrite three overclaims

Rewrite each claim so it matches what the evidence can support. Name the sample, describe the strength, and give at least one alternative explanation or limit.

1. "A survey of 400 students at our school found that breakfast eaters have higher grades (r = 0.3). Breakfast makes you smarter."
2. "Our app makes people happy: 92% of users who answered our in-app survey gave it five stars."
3. "Schools with more computers per student have higher test scores, so buying computers will raise scores."

:::hint
For each one, ask the four questions from the Notes: could it be reverse causation, a confounder, chance, or a sample that only includes certain people?
:::

:::solution
1. "Among 400 students at one school, those who ate breakfast had somewhat higher grades (r = 0.3, a modest correlation). This doesn't show breakfast causes higher grades: family routines, sleep, or income could affect both. It may not hold at other schools."
2. "Of the users who chose to answer an in-app survey, 92% gave five stars. People who stopped using the app never saw the survey, and happy users may be more likely to answer, so this likely overstates satisfaction among everyone who tried it."
3. "Schools with more computers per student tended to have higher test scores. Wealthier districts can afford both more computers and other advantages, so this doesn't show that adding computers would raise scores. An experiment that randomly assigns computers to schools could test that."
:::

### Challenge: Build your own Simpson's paradox

Write a function `simpson_check(df, group, stratum, success, total)` that prints each group's pooled rate and per-stratum rates, and returns `True` when the group that wins pooled is **not** the group that wins in most strata. Test it on `stones`. Then invent a dataset of your own (two teaching methods in two schools, say) where Method X has the higher pass rate in *both* schools but the lower pass rate overall, and confirm your function returns `True`.

:::hint
The reversal needs two things: one school is much easier than the other, and the two methods are used in very different proportions in the two schools. Try making Method X common in the hard school and rare in the easy one.
:::

:::solution
```python run
def simpson_check(df, group, stratum, success, total):
    pooled = df.groupby(group)[[success, total]].sum()
    pooled_rate = pooled[success] / pooled[total]
    by_stratum = df.assign(rate=df[success] / df[total]).pivot(index=stratum, columns=group, values="rate")
    first, second = pooled_rate.index[:2]

    pooled_winner = first if pooled_rate[first] > pooled_rate[second] else second
    first_wins = (by_stratum[first] > by_stratum[second]).sum()
    stratum_winner = first if first_wins > len(by_stratum) / 2 else second

    print("Pooled rates:", (pooled_rate * 100).round(1).to_dict())
    print("Rates by", stratum, "\n", (by_stratum * 100).round(1))
    print(f"Pooled winner: {pooled_winner}; wins most {stratum}s: {stratum_winner}")
    return pooled_winner != stratum_winner


print("Reversal in kidney data:", simpson_check(stones, "treatment", "size", "success", "patients"))

made_up = pd.DataFrame({
    "method": ["X", "X", "Y", "Y"],
    "school": ["Easy", "Hard", "Easy", "Hard"],
    "passed": [9, 30, 80, 2],
    "students": [10, 100, 100, 10],
})
print("\nReversal in my dataset:", simpson_check(made_up, "method", "school", "passed", "students"))
```

In the made-up data, X passes 90% vs 80% at the easy school and 30% vs 20% at the hard school, but 100 of X's 110 students are at the hard school, so X's pooled rate is only 35.5%, while Y's is 74.5%. A reversal always needs that combination: a stratum that strongly affects the outcome, and groups spread across the strata in very different proportions.
:::
