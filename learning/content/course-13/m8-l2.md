## Milestone 2: Load, document, clean, and check

The diabetes data ships with scikit-learn, so there's nothing to upload. `scaled=False` gives the original units instead of the standardized values scikit-learn uses by default.

```python run
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.datasets import load_diabetes

BLUE, ORANGE, AQUA, INK, MUTED = "#2a78d6", "#eb6834", "#1baf7a", "#0b0b0b", "#52514e"
BMI_COLORS = {"under 25": BLUE, "25 to 29.9": ORANGE, "30 or more": AQUA}
plt.rcParams.update({"axes.spines.top": False, "axes.spines.right": False})

raw = load_diabetes(as_frame=True, scaled=False).frame
print(raw.shape)
print(raw.head(3))
```

Before cleaning anything, write a **data dictionary**: one row per column you'll use, saying what it means and where that meaning came from. Here it comes from the scikit-learn documentation, which also reveals a gap:

```python run
data_dictionary = pd.DataFrame([
    ("age", "age in years", "sklearn docs"),
    ("sex", "coded 1 or 2; the docs don't say which code is which", "sklearn docs (gap)"),
    ("bmi", "body mass index, kg/m²", "sklearn docs"),
    ("bp", "average blood pressure", "sklearn docs"),
    ("target", "disease progression one year after baseline; units not given", "sklearn docs (gap)"),
], columns=["column", "meaning", "source"])
print(data_dictionary.to_string(index=False))
```

Two gaps already: we don't know which sex code means what, and "progression" has no stated units. Neither stops the analysis, but both go in the limitations, and the sex codes stay as "group 1" and "group 2" in every chart. Guessing would put an invented fact into the report.

Now clean and check. This dataset is unusually tidy, so the cleaning log is short, but the checks still earn their place: they'd catch a wrong file or a future version with different units.

```python run
cleaning_log = [("rows in raw data", len(raw))]
patients = raw.drop_duplicates().rename(columns={"target": "progression"})
cleaning_log.append(("duplicate rows removed", len(raw) - len(patients)))

assert patients.notna().all().all(), "missing values found"
assert patients["age"].between(18, 100).all(), "ages outside 18-100"
assert patients["bmi"].between(12, 70).all(), "BMI values outside a plausible range"
assert set(patients["sex"].unique()) == {1.0, 2.0}, "unexpected sex codes"

patients["age_group"] = pd.cut(patients["age"], [0, 40, 55, 120], right=False,
                               labels=["under 40", "40 to 54", "55 and over"])
patients["bmi_group"] = pd.cut(patients["bmi"], [0, 25, 30, 100], right=False,
                               labels=["under 25", "25 to 29.9", "30 or more"])
cleaning_log.append(("rows analyzed", len(patients)))
for step, count in cleaning_log:
    print(f"{step:<25}{count:>5}")
```

The BMI groups use the standard adult cut-offs of 25 and 30. The age groups are a choice made to give each group well over 100 patients; write choices like that down, because a reader might reasonably pick different ones.

## Milestone 3: Summaries and distributions

Look at each key variable on its own before looking at relationships. The outcome first:

```python run alt="Two histograms side by side. Left: disease progression scores for 442 patients, from about 25 to 346, piled up on the left with a long tail to the right; the median line sits at 140.5, left of the mean at 152. Right: BMI from 18 to 42, centered around 25 with a tail toward higher values." caption="Both variables are right-skewed, so medians lead the summary"
print(patients[["age", "bmi", "progression"]].describe().round(1))

fig, axes = plt.subplots(1, 2, figsize=(10, 3.4))
for ax, column, label in [(axes[0], "progression", "Disease progression (units not given)"),
                          (axes[1], "bmi", "BMI (kg/m²)")]:
    ax.hist(patients[column], bins=20, color=BLUE, edgecolor="white")
    ax.axvline(patients[column].median(), color=INK, linestyle="--", linewidth=1)
    ax.axvline(patients[column].mean(), color=MUTED, linestyle=":", linewidth=1)
    ax.set_xlabel(label)
    ax.set_title(f"median {patients[column].median():.1f} (dashed), mean {patients[column].mean():.1f} (dotted)",
                 loc="left", fontsize=10)
axes[0].set_ylabel("Patients")
fig.tight_layout()
```

Progression is right-skewed: most patients cluster below 150, and a long tail stretches past 300. That's why the summaries below use medians. The ages run from 19 to 79, so this study says nothing about children or people over 79.

## Milestone 4: The relationship, then the bias checks

The main question is about two numeric variables, so it's a scatter plot with r:

```python run alt="Scatter plot of BMI against disease progression for 442 patients. The cloud rises from lower left to upper right with a lot of spread, and a straight best-fit line rises about 10 progression points per BMI unit. Title: r = 0.59." caption="A clear upward trend with a lot of spread around it"
r = patients["bmi"].corr(patients["progression"])
slope, intercept = np.polyfit(patients["bmi"], patients["progression"], 1)

fig, ax = plt.subplots(figsize=(7, 4))
ax.scatter(patients["bmi"], patients["progression"], s=12, color=BLUE, alpha=0.5)
line_x = np.array([patients["bmi"].min(), patients["bmi"].max()])
ax.plot(line_x, slope * line_x + intercept, color=ORANGE, linewidth=2)
ax.set_xlabel("BMI (kg/m²)")
ax.set_ylabel("Disease progression")
ax.set_title(f"r = {r:.2f}: about {slope:.0f} more progression points per BMI unit", loc="left")
```

A correlation of 0.59 is moderately strong, and the scatter shows it's roughly a straight-line trend, not a curve r would misread. Now be your own skeptic. Older patients might have both higher BMI and faster progression, which would make age a confounder. So check whether the BMI link survives **within** each age group, and within each sex group:

```python run
checks = []
for column in ["age_group", "sex"]:
    for value, group in patients.groupby(column, observed=True):
        checks.append({"split by": column, "group": value, "patients": len(group),
                       "r (BMI vs progression)": round(group["bmi"].corr(group["progression"]), 2)})
print(pd.DataFrame(checks).to_string(index=False))
print(f"\nAge vs BMI correlation: {patients['age'].corr(patients['bmi']):.2f}")
```

The BMI link is about the same strength in every age group (r from 0.55 to 0.59), and it's clearly present in both sex groups (0.53 and 0.65). Age and BMI are only weakly related (r = 0.19), so age can't be what's producing the pattern. That's a real finding: the relationship isn't an artifact of the one confounder we can test.

What this check *can't* rule out is anything not in the data: diet, exercise, medication, income. And it's still correlation. Nothing here shows that changing a patient's BMI would change their progression.

## Milestone 5: Three charts and a dashboard

Each chart answers a different question, and the BMI groups keep the same colors throughout:

| Chart | Question it answers |
| --- | --- |
| Strip plot of progression by BMI group | How different are the groups, and how much do they overlap? |
| Scatter of BMI and progression | Is it a steady trend, and how strong? |
| Median progression by BMI group, within each age group | Does the pattern hold at every age? |

```python run alt="Dashboard with three panels. Left: progression for each BMI group as dots with medians marked, rising from 95 for under 25 to 168 for 25 to 29.9 to 230 for 30 or more, with heavy overlap. Middle: scatter of BMI against progression with an upward best-fit line, r = 0.59. Right: grouped bars of median progression for the three BMI groups within each of three age groups; in every age group the bars rise from the lowest BMI group to the highest." caption="The capstone dashboard"
order = list(BMI_COLORS)
medians = patients.groupby("bmi_group", observed=True)["progression"].median()
by_age = patients.pivot_table(index="age_group", columns="bmi_group", values="progression",
                              aggfunc="median", observed=True)

dashboard, (left, middle, right) = plt.subplots(1, 3, figsize=(15, 4.3), width_ratios=[1, 1.1, 1.2])
for row, group in enumerate(order):
    values = patients.loc[patients["bmi_group"] == group, "progression"]
    jitter = np.random.default_rng(row).uniform(-0.2, 0.2, len(values))
    left.scatter(values, row + jitter, s=10, color=BMI_COLORS[group], alpha=0.6)
    left.plot(medians[group], row, marker="|", markersize=24, markeredgewidth=3, color=INK)
left.set_yticks(range(3), [f"BMI {g}" for g in order])
left.set_xlabel("Disease progression (black tick = median)")
left.set_title(f"Median rises from {medians.iloc[0]:.0f} to {medians.iloc[-1]:.0f}", loc="left")

middle.scatter(patients["bmi"], patients["progression"], s=10, color=MUTED, alpha=0.5)
middle.plot(line_x, slope * line_x + intercept, color=INK, linewidth=2)
middle.set_xlabel("BMI (kg/m²)")
middle.set_ylabel("Disease progression")
middle.set_title(f"Steady upward trend, r = {r:.2f}", loc="left")

x = np.arange(len(by_age))
for i, group in enumerate(order):
    right.bar(x + (i - 1) * 0.27, by_age[group], width=0.26, color=BMI_COLORS[group], label=f"BMI {group}")
right.set_xticks(x, by_age.index)
right.set_ylabel("Median progression")
right.legend(frameon=False, fontsize=8, loc="upper left")
right.set_title("The pattern holds in every age group", loc="left")

dashboard.suptitle(f"BMI and diabetes progression one year later, {len(patients)} patients in one study",
                   x=0.01, ha="left", fontsize=13)
dashboard.tight_layout()
```

Notice the middle panel is gray, not a fourth color: it shows all patients, not a group, so it shouldn't borrow a group's color. To export, add the lines from the Module 7 build-along to the end of this cell, with your own file names:

## Milestone 6: Executive summary and limits

Everything in the summary comes from variables computed above. The limits are just as specific as the findings, which is what makes them useful.

```python run
low_bmi, high_bmi = medians.iloc[0], medians.iloc[-1]
age_r = [c["r (BMI vs progression)"] for c in checks if c["split by"] == "age_group"]

summary = f"""EXECUTIVE SUMMARY
Question: Among {len(patients)} patients in one diabetes study, is BMI linked to disease progression
one year later, and does the link hold within age groups?

1. Yes. BMI and progression were moderately correlated (r = {r:.2f}); each extra BMI unit went
   with about {slope:.0f} more progression points on average.
2. Patients with BMI of 30 or more had a median progression of {high_bmi:.0f}, against {low_bmi:.0f}
   for BMI under 25, though individual patients in the two groups overlapped heavily.
3. The link held within every age group (r from {min(age_r):.2f} to {max(age_r):.2f}) and in both sex groups,
   so age does not explain it.

Limits: {len(patients)} adults aged {patients['age'].min():.0f} to {patients['age'].max():.0f} from a single study, so results may not
generalize. The data is observational: it shows association, not that lowering BMI would slow progression.
Diet, exercise, and medication were not recorded and could confound the link. The progression measure has no
stated units, and the documentation does not say which sex code is which."""
print(summary)
```

A reader who stops after this paragraph knows the answer, how big it is, how sure to be, and what it doesn't cover.

:::takeaways
- Start from a skeleton with a parameters cell, and read data from a link when you can.
- A data dictionary records meanings and their sources, including the gaps you must not fill with guesses.
- Look at each variable alone before looking at relationships, and let skew decide between mean and median.
- Test a relationship within groups of any confounder you have, and list the confounders you can't test.
- Build each chart for one question, keep colors tied to entities, and compute every number in the summary.
:::
