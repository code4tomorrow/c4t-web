### Exercise 1: Report the right center for sleep data

A health class surveyed 80 ninth graders and 80 twelfth graders about last night's sleep. Some twelfth graders had pulled near all-nighters before an exam.

```python run
sleep = pd.DataFrame({
    "grade": ["9th"] * 80 + ["12th"] * 80,
    "hours": np.concatenate([
        rng.normal(7.8, 0.8, 80),
        rng.normal(7.0, 0.7, 70),
        rng.uniform(2.5, 4.5, 10),
    ]).round(1),
})
print(sleep.sample(5, random_state=1))
```

Print the mean, median, standard deviation, and IQR of `hours` for each grade in one table. Then decide which center you'd report for twelfth graders, and why.

Sample output (your table should have these columns):

```text
       mean  median   std   iqr
grade
...
```

:::hint
`groupby("grade")["hours"].agg([...])` accepts strings like `"mean"` and also your own functions. Write a small `iqr(s)` function that returns `s.quantile(0.75) - s.quantile(0.25)`.
:::

:::solution
```python run
def iqr(s):
    return s.quantile(0.75) - s.quantile(0.25)

print(sleep.groupby("grade")["hours"].agg(["mean", "median", "std", iqr]).round(2))
```

For twelfth graders the ten short nights drag the mean down and inflate the standard deviation, while the median and IQR barely notice them. Report the median (and the IQR), and mention the short nights separately: "Most seniors slept about 7 hours; 10 of 80 slept under 5."
:::

### Exercise 2: Find the two groups in commute times

Here are commute times, in minutes, for 200 students. Some walk; some ride a bus with a long route.

```python run
commute = pd.Series(np.concatenate([rng.normal(9, 3, 120), rng.normal(34, 6, 80)]).clip(1).round())
```

Draw the histogram twice, side by side: once with `bins=4` and once with `bins=np.arange(0, 56, 2)`. Describe the shape you see in the second one, and estimate how many students are in each group by counting commutes under 20 minutes.

Sample output: two histograms, plus one printed line like `Under 20 min: ___ students, 20 min or more: ___ students`.

:::hint
`fig, axes = plt.subplots(1, 2, figsize=(9, 3))` gives you two axes. For the count, `(commute < 20).sum()` counts the `True` values.
:::

:::solution
```python run alt="Two histograms of commute times. With 4 bins, one tall bar on the left and smaller bars to the right, with no clear gap. With 2-minute bins, a tall peak near 9 minutes and a second, lower peak near 34 minutes, separated by a near-empty gap around 20." caption="The 2-minute bins reveal two groups"
fig, axes = plt.subplots(1, 2, figsize=(9, 3))
axes[0].hist(commute, bins=4, color=BLUE, edgecolor="white")
axes[0].set_title("bins=4", loc="left")
axes[1].hist(commute, bins=np.arange(0, 56, 2), color=BLUE, edgecolor="white")
axes[1].set_title("2-minute bins", loc="left")
for ax in axes:
    ax.set_xlabel("Commute (minutes)")
axes[0].set_ylabel("Students")
fig.tight_layout()

short = (commute < 20).sum()
print(f"Under 20 min: {short} students, 20 min or more: {len(commute) - short} students")
```

The narrow bins show a **bimodal** shape: walkers around 9 minutes and bus riders around 34. With 4 bins the gap between them is swallowed. Any single average of this column describes neither group well.
:::

### Exercise 3: Compare four grades with box plots

```python run
screen = pd.DataFrame({
    "grade": np.repeat(["9th", "10th", "11th", "12th"], 50),
    "hours": np.concatenate([
        rng.gamma(5, 0.5, 50), rng.gamma(4, 0.7, 50),
        rng.gamma(2, 2.0, 50), rng.gamma(6, 0.7, 50),
    ]).round(1),
})
```

Draw horizontal box plots of daily screen-time `hours` for the four grades, in grade order. Then print each grade's IQR and the number of points beyond the whiskers (more than 1.5 × IQR above the third quartile). Which grade varies the most?

Sample output: four box plots and a small table with columns `iqr` and `outliers`.

:::hint
Pass `order=["9th", "10th", "11th", "12th"]` to `sns.boxplot`. For outliers, write a function that computes `q3 + 1.5 * (q3 - q1)` for a Series and counts the values above it, then use it in `.agg`.
:::

:::solution
```python run alt="Four horizontal box plots of daily screen time for 9th through 12th grade. Medians rise from about 2 hours in 9th grade to about 4 in 12th. The 11th grade box is clearly the widest, and only 11th grade has outlier dots, two of them on the high side, the largest near 12.6 hours." caption="Screen time by grade"
order = ["9th", "10th", "11th", "12th"]
fig, ax = plt.subplots(figsize=(7, 3.5))
sns.boxplot(data=screen, x="hours", y="grade", order=order, color=BLUE,
            boxprops={"alpha": 0.5}, width=0.5, ax=ax)
ax.set_xlabel("Screen time (hours per day)")
ax.set_ylabel("")

def high_outliers(s):
    q1, q3 = s.quantile([0.25, 0.75])
    return int((s > q3 + 1.5 * (q3 - q1)).sum())

table = screen.groupby("grade")["hours"].agg([iqr, high_outliers]).reindex(order)
table.columns = ["iqr", "outliers"]
print(table.round(2))
```

Eleventh grade has the largest IQR, about 3.4 hours, so its middle half is the most spread out, and it's the only grade with outliers. Outlier dots are worth a second look (a 12-hour day might be a typo), but they're not automatically errors. Never delete one just because the plot drew it as a dot.
:::

### Exercise 4: Match each question to a chart

For each question, name the chart you'd use: bar, line, scatter, or histogram.

1. Did library visits change across the school year?
2. Which of five clubs raised the most money?
3. Do students who sleep more tend to have higher grades?
4. How long do most students spend on homework each night?

Then draw the chart for question 1 using this data, with labeled axes and a title that states what you see.

```python run
visits = pd.Series([820, 910, 1040, 980, 760, 1100, 1180, 1230, 1150, 640],
                   index=["Sep", "Oct", "Nov", "Dec", "Jan", "Feb", "Mar", "Apr", "May", "Jun"])
```

:::hint
Ask what the x-axis would be. Months have an order, clubs don't, and two numeric measures per student call for one dot per student.
:::

:::solution
1 is a **line** (ordered time), 2 a **bar** (amounts across categories, from zero), 3 a **scatter** (two numbers per student), and 4 a **histogram** (one number's distribution).

```python run alt="Line chart of monthly library visits from September to June. Visits rise from 820 to a peak of 1,230 in April, with dips in January to 760 and in June to 640." caption="Question 1 answered with a line"
fig, ax = plt.subplots(figsize=(7, 3.5))
ax.plot(visits.index, visits.values, color=BLUE, marker="o", linewidth=2)
ax.set_ylim(0, 1400)
ax.set_ylabel("Library visits per month")
ax.set_title("Visits climbed through spring, with dips in January and June", loc="left")
ax.annotate("Winter break", ("Jan", visits["Jan"]), xytext=(0, -18), textcoords="offset points", ha="center", color=INK)
```

The y-axis starts at zero here because the dips are big enough to see anyway. For a line that wasn't required, but it keeps the January dip in proportion.
:::

### Exercise 5: Repair the bake-sale chart

```python run alt="A bar chart of bake sale revenue for four grades with the y-axis starting at 390, so the 11th grade bar looks about five times taller than the 10th grade bar. Title: 11th grade CRUSHES the bake sale." caption="The chart to repair"
bake_sale = pd.Series({"9th": 412, "10th": 398, "11th": 431, "12th": 405})
fig, ax = plt.subplots(figsize=(5, 3.5))
ax.bar(bake_sale.index, bake_sale.values)
ax.set_ylim(390, 435)
ax.set_title("11th grade CRUSHES the bake sale")
```

First, compute the lie factor comparing the 10th and 11th grade bars. Then redraw the chart with a zero baseline, dollar labels on each bar, a y-axis label, and a title that states the actual finding.

Sample output: a line like `Lie factor: __`, and the repaired chart.

:::hint
The lie factor is (effect shown) ÷ (effect in the data). The shown effect is `(431 - 390) / (398 - 390) - 1`; the real effect is `431 / 398 - 1`. `ax.bar_label(bars, fmt="$%d")` adds dollar labels.
:::

:::solution
```python run alt="Repaired bar chart on a zero baseline with four similar blue bars labeled $412, $398, $431, and $405. Title: 11th grade raised the most, $33 more than 10th grade." caption="The bars now look as close as the totals are"
shown = (431 - 390) / (398 - 390) - 1
actual = 431 / 398 - 1
print(f"Lie factor: {shown / actual:.0f}")

fig, ax = plt.subplots(figsize=(5, 3.5))
bars = ax.bar(bake_sale.index, bake_sale.values, color=BLUE, width=0.6)
ax.bar_label(bars, fmt="$%d", padding=3)
ax.set_ylim(0, 500)
ax.set_ylabel("Revenue (US dollars)")
top = bake_sale.idxmax()
ax.set_title(f"{top} grade raised the most, ${bake_sale[top] - bake_sale['10th']} more than 10th grade", loc="left")
```

A lie factor near 50 means the original chart made the gap look about fifty times bigger, in relative terms, than it was. The title is computed from the data, so it stays correct if a late donation arrives.
:::

### Exercise 6: Make a chart readable without color

This chart works only if you can tell red from green, and only after hunting through a legend.

```python run alt="Two lines in pure red and pure green showing monthly sign-ups for Robotics and Drama from September to February, with a legend in the corner and no axis labels." caption="The chart to repair"
months = ["Sep", "Oct", "Nov", "Dec", "Jan", "Feb"]
signups = pd.DataFrame({"Robotics": [12, 18, 25, 24, 31, 36], "Drama": [20, 22, 21, 23, 24, 27]}, index=months)
fig, ax = plt.subplots(figsize=(6, 3.5))
ax.plot(signups.index, signups["Robotics"], color="red")
ax.plot(signups.index, signups["Drama"], color="green")
ax.legend(["Robotics", "Drama"])
```

Redraw it with blue and orange, a label at the end of each line instead of a legend, axis labels, and a title that states the finding. Then build and print an alt-text sentence from the data (so it would update if the numbers changed).

:::hint
Loop over `[("Robotics", BLUE), ("Drama", ORANGE)]`. To label the end of a line, `ax.annotate(name, (len(months) - 1, last_value), xytext=(6, 0), textcoords="offset points", va="center")`.
:::

:::solution
```python run alt="Repaired line chart with Robotics in blue rising from 12 to 36 sign-ups and Drama in orange rising from 20 to 27, each named by a label at the right end of its line." caption="Labels sit on the lines, so color is a bonus, not a requirement"
fig, ax = plt.subplots(figsize=(6.5, 3.5))
for club, color in [("Robotics", BLUE), ("Drama", ORANGE)]:
    ax.plot(months, signups[club], color=color, linewidth=2, marker="o")
    ax.annotate(club, (len(months) - 1, signups[club].iloc[-1]), xytext=(6, 0),
                textcoords="offset points", va="center", color=INK)
ax.set_ylim(0, 40)
ax.set_ylabel("Members signed up")
ax.set_title("Robotics tripled since September and has led Drama since November", loc="left")

r, d = signups["Robotics"], signups["Drama"]
alt = (f"Line chart of club sign-ups from {months[0]} to {months[-1]}. "
       f"Robotics rose from {r.iloc[0]} to {r.iloc[-1]}; Drama rose from {d.iloc[0]} to {d.iloc[-1]}.")
print(alt)
```

With the names on the lines, a reader who sees no color at all can still read the chart. The markers help too: a printout in grayscale still shows where each month's value is.
:::

### Challenge: Four datasets, one set of statistics

In 1973 the statistician Francis Anscombe published four small datasets to make a point. Type them in, then for each set print the mean of x, mean of y, standard deviation of y, and the correlation between x and y. Finally, draw all four as scatter plots in a 2×2 grid with the best-fit line on each.

```python run
x = [10, 8, 13, 9, 11, 14, 6, 4, 12, 7, 5]
anscombe = {
    "I": (x, [8.04, 6.95, 7.58, 8.81, 8.33, 9.96, 7.24, 4.26, 10.84, 4.82, 5.68]),
    "II": (x, [9.14, 8.14, 8.74, 8.77, 9.26, 8.10, 6.13, 3.10, 9.13, 7.26, 4.74]),
    "III": (x, [7.46, 6.77, 12.74, 7.11, 7.81, 8.84, 6.08, 5.39, 8.15, 6.42, 5.73]),
    "IV": ([8, 8, 8, 8, 8, 8, 8, 19, 8, 8, 8], [6.58, 5.76, 7.71, 8.84, 8.47, 7.04, 5.25, 12.50, 5.56, 7.91, 6.89]),
}
```

:::hint
`np.corrcoef(xs, ys)[0, 1]` gives the correlation. `slope, intercept = np.polyfit(xs, ys, 1)` gives the best-fit line. `plt.subplots(2, 2, sharex=True, sharey=True)` keeps the four panels comparable.
:::

:::solution
```python run alt="Four scatter plots with the same best-fit line. Set I is a loose upward cloud. Set II is a smooth curve that rises and then falls. Set III is a perfect straight line except for one high outlier. Set IV has ten points stacked at x equals 8 and a single point far to the right at x equals 19." caption="Identical summaries, four completely different stories"
rows = []
for name, (xs, ys) in anscombe.items():
    rows.append({"set": name, "mean x": np.mean(xs), "mean y": np.mean(ys),
                 "std y": np.std(ys, ddof=1), "corr": np.corrcoef(xs, ys)[0, 1]})
print(pd.DataFrame(rows).set_index("set").round(2))

fig, axes = plt.subplots(2, 2, figsize=(8, 6), sharex=True, sharey=True)
line_x = np.array([3, 20])
for ax, (name, (xs, ys)) in zip(axes.flat, anscombe.items()):
    slope, intercept = np.polyfit(xs, ys, 1)
    ax.scatter(xs, ys, color=BLUE, s=30)
    ax.plot(line_x, slope * line_x + intercept, color=ORANGE, linewidth=1.5)
    ax.set_title(f"Set {name}", loc="left")
fig.tight_layout()
```

Every row of the table matches to two decimal places, and every set gets the same line (y ≈ 3 + 0.5x). The pictures disagree completely: only set I looks like the "moderate linear relationship" the numbers describe. Summaries compress; charts show what got compressed away. Draw the data before you trust a statistic.
:::
