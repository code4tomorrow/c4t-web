## Warm-up: arrays vs. lists

Predict all three lines before you run them:

```python run
a = np.array([1, 2, 3])
print(a * a)
print([1, 2, 3] * 2)
print(a + 10)
```

Arrays multiply element by element (`[1 4 9]`), lists repeat, and adding a single number to an array adds it to every element. That last behavior is called **broadcasting**.

### Exercise 1: Delete the loop

A shop computes each line's total, with 8% tax, using a loop. Rewrite the calculation as one NumPy expression and check that every answer matches.

```python run
prices = [2.50, 4.00, 1.25, 9.99, 3.75]
quantities = [4, 1, 10, 2, 3]

loop_totals = []
for p, q in zip(prices, quantities):
    loop_totals.append(round(p * q * 1.08, 2))
print(loop_totals)
```

```text
[10.8   4.32 13.5  21.58 12.15]
Match: True
Order total: 62.35
```

:::hint
Turn both lists into arrays with `np.array(...)`. Then the same formula works on all five lines at once. `np.allclose(a, b)` checks that two sets of decimals agree.
:::

:::solution
```python run
p = np.array(prices)
q = np.array(quantities)
totals = (p * q * 1.08).round(2)
print(totals)
print("Match:", np.allclose(loop_totals, totals))
print("Order total:", round(totals.sum(), 2))
```

`p * q` multiplies matching positions, `* 1.08` broadcasts the tax onto every line, and `.round(2)` rounds all five at once. No list, no `append`, no index.
:::

### Exercise 2: Questions about 200 exam scores

Using the scores below, print: (a) how many scores are 90 or above, (b) the share of scores from 70 to 80 inclusive, and (c) the average of the failing scores (below 60) and how many there are.

```python run
rng = np.random.default_rng(11)
scores = rng.normal(76, 12, 200).clip(0, 100).round()
```

```text
90 or above: 22
Share 70-80: 0.34
Failing: 17 scores, average 56.2
```

:::hint
Each question is a mask. `.sum()` counts it, `.mean()` turns it into a share, and `scores[mask]` keeps only the matching scores. For "between", combine two comparisons with `&` and wrap each in parentheses.
:::

:::solution
```python run
print("90 or above:", (scores >= 90).sum())
print("Share 70-80:", ((scores >= 70) & (scores <= 80)).mean())
failing = scores < 60
print(f"Failing: {failing.sum()} scores, average {scores[failing].mean():.1f}")
```

The mask `failing` is used twice: summed to count the failing scores, and as a filter to average them. Naming a mask makes code like this easier to read.
:::

### Exercise 3: loc, iloc, and a sort

Load the planets table below, with the planet name as the index. Then:

1.  Get the number of moons of Mars, by label.
2.  Get the first three rows and first two columns, by position.
3.  Sort by moons, most first. What does `iloc[0]` give now, and does `loc["Earth"]` still work?

```python run
planets = pd.DataFrame({
    "planet": ["Mercury", "Venus", "Earth", "Mars", "Jupiter", "Saturn", "Uranus", "Neptune"],
    "diameter_km": [4879, 12104, 12756, 6792, 142984, 120536, 51118, 49528],
    "moons": [0, 0, 1, 2, 95, 146, 28, 16],
    "distance_au": [0.39, 0.72, 1.0, 1.52, 5.2, 9.54, 19.2, 30.06],
}).set_index("planet")
```

:::hint
`loc[row_label, column_label]` and `iloc[row_positions, column_positions]`. After sorting, positions change but labels stay with their rows.
:::

:::solution
```python run
print("Mars moons:", planets.loc["Mars", "moons"])
print(planets.iloc[:3, :2])

by_moons = planets.sort_values("moons", ascending=False)
print("First row after sorting:", by_moons.iloc[0].name)
print("Earth's moons, still by label:", by_moons.loc["Earth", "moons"])
```

After the sort, position 0 is Saturn, not Mercury, but `loc["Earth"]` still finds Earth because the label travels with its row. This is why `loc` is safer in analysis code: code that says *which* row you mean keeps working when the order changes. (The moon counts are NASA's 2023 figures. Astronomers keep finding small moons, so newer counts are higher, especially for Saturn.)
:::

### Exercise 4: Columns from rules

Add three columns to `planets`:

-   `vs_earth`: each diameter divided by Earth's diameter, rounded to 2 places.
-   `has_moons`: `"yes"` or `"no"`.
-   `kind`: `"rocky"` below 15,000 km, `"ice giant"` from 15,000 to 60,000 km, `"gas giant"` above that.

```text
         diameter_km  moons  vs_earth has_moons       kind
planet
Mercury         4879      0      0.38        no      rocky
...
Jupiter       142984     95     11.21       yes  gas giant
```

:::hint
Earth's diameter is `planets.loc["Earth", "diameter_km"]`. For two outcomes use `np.where`. For several ranges, `pd.cut(column, bins=[...], labels=[...])` sorts each value into a bin.
:::

:::solution
```python run
earth = planets.loc["Earth", "diameter_km"]
planets["vs_earth"] = (planets["diameter_km"] / earth).round(2)
planets["has_moons"] = np.where(planets["moons"] > 0, "yes", "no")
planets["kind"] = pd.cut(planets["diameter_km"],
                         bins=[0, 15000, 60000, 200000],
                         labels=["rocky", "ice giant", "gas giant"])
print(planets[["diameter_km", "moons", "vs_earth", "has_moons", "kind"]])
```

`pd.cut` uses each bin as "above the left edge, up to and including the right edge", so with 3 bins you need 4 edges. Jupiter is 11.21 Earths across.
:::

### Exercise 5: Which grade won the food drive?

Each homeroom reports how many cans it collected. Grade 11 collected the most cans in total. Is it really the winner? Group by grade and report total cans, number of homerooms, total students, and **cans per student**, sorted best first. Draw a bar chart of cans per student.

```python run
drive = pd.DataFrame({
    "homeroom": ["9A", "9B", "9C", "10A", "10B", "11A", "11B", "11C", "12A", "12B"],
    "grade": [9, 9, 9, 10, 10, 11, 11, 11, 12, 12],
    "cans": [84, 120, 66, 140, 95, 60, 72, 150, 45, 210],
    "students": [28, 30, 25, 31, 27, 26, 29, 30, 24, 28],
})
```

:::hint
Use named aggregation: `cans=("cans", "sum")`, `homerooms=("homeroom", "count")`, and so on. Compute cans per student **after** grouping, from the totals.
:::

:::solution
```python run alt="Bar chart of cans collected per student by grade: grade 12 about 4.9, grade 10 about 4.0, grade 11 about 3.3, grade 9 about 3.3"
by_grade = drive.groupby("grade").agg(
    cans=("cans", "sum"),
    homerooms=("homeroom", "count"),
    students=("students", "sum"),
)
by_grade["cans_per_student"] = (by_grade["cans"] / by_grade["students"]).round(2)
by_grade = by_grade.sort_values("cans_per_student", ascending=False)
print(by_grade)

ax = by_grade["cans_per_student"].plot(kind="bar", color="#2a78d6", rot=0, figsize=(5, 3))
ax.set_xlabel("Grade")
ax.set_ylabel("Cans per student")
ax.set_title("Grade 12 gave the most per student")
```

Grade 11 has the biggest total only because it has three homerooms and 85 students. Per student, grade 12 gave the most. Dividing the summed cans by the summed students is the right calculation; averaging each homeroom's per-student rate would weight a 24-student room the same as a 30-student room.
:::

### Exercise 6: Who's missing from the club list?

Join `students` and `signups` so that **every** row from both tables survives. Then list (a) students who signed up for nothing, and (b) signups whose `student_id` doesn't match any student.

```python run
students = pd.DataFrame({
    "student_id": [101, 102, 103, 104, 105, 106],
    "name": ["Aisha", "Ben", "Carla", "Dev", "Elena", "Femi"],
})
signups = pd.DataFrame({
    "student_id": [101, 103, 103, 105, 107, 102],
    "club": ["Robotics", "Chess", "Art", "Robotics", "Chess", "Debate"],
})
```

```mermaid caption="With indicator=True, every merged row says where it came from"
flowchart LR
    S["students (6 rows)"] --> M{"merge how='outer'"}
    C["signups (6 rows)"] --> M
    M --> B["both: matched"]
    M --> L["left_only: no club"]
    M --> R["right_only: unknown ID"]
```

:::hint
`how="outer"` keeps unmatched rows from both sides. `indicator=True` adds a `_merge` column whose values are `both`, `left_only`, or `right_only`.
:::

:::solution
```python run
audit = students.merge(signups, on="student_id", how="outer", indicator=True)
print(audit)
print("No club:", audit.loc[audit["_merge"] == "left_only", "name"].tolist())
print(audit.loc[audit["_merge"] == "right_only", ["student_id", "club"]])
```

Dev and Femi haven't joined anything. Student 107 signed up for Chess but doesn't exist in the student list, probably a typo for a real ID. Notice that Carla appears twice: one student with two clubs gives two rows. A default merge (`how="inner"`) would have silently dropped Dev, Femi, and the 107 signup, and you'd never have known.
:::

### Challenge: Best score, or best compared to their class?

Three teachers gave the same test. Add a `class_avg` column (each student's own class average, repeated on every row) and a `vs_class` column (score minus class average). Who has the top score overall, and who is furthest above their own class average? Plot every score by class, with a line at each class average.

```python run
rng = np.random.default_rng(2)
exam = pd.DataFrame({
    "student": [f"S{i:02d}" for i in range(1, 25)],
    "teacher": np.repeat(["Ms. Ortiz", "Mr. Chen", "Dr. Patel"], 8),
    "score": np.concatenate([rng.normal(mean, 7, 8) for mean in [70, 86, 77]]).clip(0, 100).round(),
})
```

:::hint
`groupby(...).agg(...)` shrinks each group to one row. `groupby("teacher")["score"].transform("mean")` returns one value **per original row** instead, so you can assign it straight to a new column.
:::

:::solution
```python run alt="Dot plot of 24 test scores in three classes. Mr. Chen's class is highest with an average near 86, Dr. Patel's is near 78, and Ms. Ortiz's is lowest near 70; one Ortiz student at 83 sits far above her class line."
exam["class_avg"] = exam.groupby("teacher")["score"].transform("mean").round(1)
exam["vs_class"] = exam["score"] - exam["class_avg"]

print(exam.sort_values("score", ascending=False).head(1))
print(exam.sort_values("vs_class", ascending=False).head(1))

teachers = exam["teacher"].unique()
fig, ax = plt.subplots(figsize=(6, 3.4))
for x, teacher in enumerate(teachers):
    group = exam[exam["teacher"] == teacher]
    ax.scatter(np.full(len(group), x), group["score"], color="#2a78d6", alpha=0.7, s=30)
    ax.hlines(group["class_avg"].iloc[0], x - 0.25, x + 0.25, color="#eb6834", linewidth=2)
ax.set_xticks(range(len(teachers)), teachers)
ax.set_ylabel("Score")
ax.set_title("Scores by class (orange line = class average)")
```

The top score overall is in Mr. Chen's class, where everyone scored high. The student furthest above their own class is in Ms. Ortiz's class, with a score that would be ordinary in Mr. Chen's room. Which one is "best" depends on the question, and `transform` is what lets you ask the second one: it broadcasts a group summary back onto every row.
:::
