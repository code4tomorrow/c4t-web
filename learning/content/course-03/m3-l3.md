### Exercise 1: Predict the string results

Write down what each line prints, then run it to check:

```python
word = "Thonny"
print(word[0] + word[-1])
print(word[1:4])
print(word.upper().count("N"))
print(len(word * 2))
```

:::hint
Write the word out with its indexes underneath (T is 0, h is 1, and so on). For line 3, think about what `.upper()` does to the lowercase `n`s before they're counted.
:::

:::solution
```python run
word = "Thonny"
print(word[0] + word[-1])
print(word[1:4])
print(word.upper().count("N"))
print(len(word * 2))
```

`word[0]` is `T` and `word[-1]` is `y`, and `+` joins them. `[1:4]` takes indexes 1, 2 and 3. `.upper()` makes `THONNY`, which has two capital Ns; without it, `count("N")` would find none, because the original word's `n`s are lowercase. `word * 2` is `ThonnyThonny`, which has 12 characters.
:::

### Exercise 2: Name badge

Ask for a first name and a last name, then print a badge with the initials underneath. It must look right even when the person types `  ada` and `LOVELACE `.

```text
First name:   ada
Last name: LOVELACE 
HELLO, my name is
Ada Lovelace
(A.L.)
```

:::hint
Clean each answer as you read it with `.strip().title()`. The first letter of a string is at index 0.
:::

:::solution
```python run title="badge.py" input="  ada|LOVELACE "
first = input("First name: ").strip().title()
last = input("Last name: ").strip().title()
print("HELLO, my name is")
print(f"{first} {last}")
print(f"({first[0]}.{last[0]}.)")
```

If you skipped `.strip()`, `first[0]` would be a space and the initials would come out as `( .L.)`. Cleaning first makes every later step simpler.
:::

### Exercise 3: Fix the storage checker

This program estimates how many more photos fit on a phone, at about 300 photos per gigabyte. Run it with the answer `12.5`:

```python run raises input="12.5"
free = int(input("GB of free space: "))
photos = free * 300
print("Room for about " + photos + " more photos")
```

Fix it so that typing `12.5` prints `Room for about 3,750 more photos`. There are two bugs; the second only shows up after you fix the first.

:::hint
First: which converter accepts text with a decimal point? Second: you can't join text and a number with `+`. An f-string with `:,` can also add the comma, and `int()` can drop the `.0` from a float.
:::

:::solution
```python run title="storage.py" input="12.5"
free = float(input("GB of free space: "))
photos = int(free * 300)
print(f"Room for about {photos:,} more photos")
```

`int("12.5")` raises a `ValueError` because that text isn't a whole number, so `float()` is the right converter. Once that's fixed, `"Room for about " + photos` raises a `TypeError`, because `+` can't join a string and a number. The f-string solves that, and `int()` turns `3750.0` into `3750`, so nobody sees a decimal point in a count of photos.
:::

### Exercise 4: Line up the race results

Three runners finished a 400 m race in `61.237`, `59.8`, and `62.05` seconds. Store each name and time in variables, then print a table where the names line up on the left and the times line up on the right, all with two decimal places:

```text
Runner      Time (s)
Ava            61.24
Benedikt       59.80
Chen           62.05
```

:::hint
Each line is two columns: the name left-aligned in 10 characters (`:<10`) and the time right-aligned in 10 characters with 2 decimals (`:>10.2f`). Format the heading the same way so it lines up too.
:::

:::solution
```python run title="race_table.py"
name1, time1 = "Ava", 61.237
name2, time2 = "Benedikt", 59.8
name3, time3 = "Chen", 62.05

print(f"{'Runner':<10}{'Time (s)':>10}")
print(f"{name1:<10}{time1:>10.2f}")
print(f"{name2:<10}{time2:>10.2f}")
print(f"{name3:<10}{time3:>10.2f}")
```

`.2f` rounds `61.237` to `61.24` and pads `59.8` to `59.80`, so every time has the same number of characters and the decimal points sit in one column. The first lines use the two-at-once assignment from Module 2 to keep each runner's name and time together.
:::

### Exercise 5: Username maker

A school makes usernames from the first three letters of your first name, the first letter of your last name, and the last two digits of the year you were born, all in lowercase. Ask for all three and print the username.

```text
First name:  Ada
Last name: Lovelace
Birth year: 2011
Your username is adal11
```

:::hint
Every part is a slice: `[:3]`, `[0]`, and `[-2:]`. Should the birth year be converted with `int()`? Think about whether you'll do math with it or slice it.
:::

:::solution
```python run title="username.py" input=" Ada|Lovelace|2011"
first = input("First name: ").strip().lower()
last = input("Last name: ").strip().lower()
year = input("Birth year: ").strip()
username = first[:3] + last[0] + year[-2:]
print(f"Your username is {username}")
```

The year stays a string on purpose. You can slice text, but numbers don't have characters to slice: `int("2011")[-2:]` crashes with `TypeError: 'int' object is not subscriptable`. Convert only when you need to calculate.
:::

### Exercise 6: How long will the download take?

Internet speed is measured in megabits per second (Mbps), but file sizes are in megabytes (MB), and one byte is 8 bits. Ask for a file size in MB and a speed in Mbps, and print the time in seconds and in minutes:

```text
File size (MB): 750
Speed (Mbps): 25
750 MB at 25 Mbps takes about 240 seconds (4.0 minutes).
```

:::hint
Seconds = size × 8 ÷ speed. Both answers can have decimals, so use `float()`. To print `25` rather than `25.0`, the format spec `:g` drops a pointless `.0`. Use `:.0f` for seconds and `:.1f` for minutes.
:::

:::solution
```python run title="download_time.py" input="750|25"
size = float(input("File size (MB): "))
speed = float(input("Speed (Mbps): "))
seconds = size * 8 / speed
minutes = seconds / 60
print(f"{size:,.0f} MB at {speed:g} Mbps takes about {seconds:.0f} seconds ({minutes:.1f} minutes).")
```

Python works left to right through `size * 8 / speed`: 750 × 8 is 6000 megabits, and 6000 ÷ 25 is 240 seconds. Try a 4200 MB game update on a 100 Mbps connection; it should come out at 336 seconds, or 5.6 minutes.
:::

### Challenge: A banner that fits any message

Ask for a short message and print it in capitals, inside a box of stars that is exactly the right width, with a blank row above and below:

```text
Message: Go Owls!
************
*          *
* GO OWLS! *
*          *
************
```

Type `Python rocks` instead, and the box must stretch to fit. Don't count the characters yourself; make the program do it.

:::hint
Each row inside the box is `"* "`, then something as long as the message, then `" *"`. So the full width is `len(message) + 4`. `"*" * width` makes the top row, and `" " * len(message)` makes the blank space inside.
:::

:::solution
```python run title="banner.py" input="Go Owls!"
message = input("Message: ").strip().upper()
width = len(message) + 4
print("*" * width)
print("* " + " " * len(message) + " *")
print(f"* {message} *")
print("* " + " " * len(message) + " *")
print("*" * width)
```

Every row is built from `len(message)`, so the box always fits. The `+ 4` covers the star and space on each side. Step through it below to watch `width` get worked out from the message's length.
:::

:::trace The banner works out its own width
