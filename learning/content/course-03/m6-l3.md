Every exercise here asks for a function, not a whole program. Test each one with the sample calls given, and compare your output line by line. If a result surprises you, start the debugger with **Ctrl+F5** and press **F7** (Step into) on the call to see the function's local variables.

## Warm-up: print or return?

Predict the three lines this prints, in order, before opening the solution.

```python
def mystery(n):
    print("checking", n)
    return n * 2

result = mystery(3) + mystery(4)
print(result)
```

:::solution
```python run title="mystery.py"
def mystery(n):
    print("checking", n)
    return n * 2

result = mystery(3) + mystery(4)
print(result)
```

Each call prints its "checking" line *while it runs*, and only the returned values (6 and 8) are added. So you see both "checking" lines first, then 14.
:::

### Exercise 1: Initials

Write `initials(first, last)` that returns a person's initials in capitals with dots.

```text
initials("ada", "lovelace")    ->  A.L.
initials("Grace", "hopper")    ->  G.H.
```

:::hint
`first[0]` is the first character of a string, and `.upper()` capitalizes it. Join the pieces with `+` and return the result.
:::

:::solution
```python run title="initials.py"
def initials(first, last):
    """Return initials like 'A.L.' for first and last names."""
    return first[0].upper() + "." + last[0].upper() + "."

print(initials("ada", "lovelace"))
print(initials("Grace", "hopper"))
```

The function returns a string, so the caller decides what to do with it: print it, store it, or put it on a name badge.
:::

### Exercise 2: Is this username allowed?

A game allows usernames of 3 to 15 characters with no spaces. Write `is_valid_username(name)` that returns `True` or `False`.

```text
is_valid_username("pixelfox")        ->  True
is_valid_username("al")              ->  False
is_valid_username("night owl")       ->  False
is_valid_username("thisnameiswaytoolong")  ->  False
```

:::hint
`len(name)` gives the length, and `" " in name` is `True` if there's a space anywhere. A comparison already *is* `True` or `False`, so you can return it directly without an `if`.
:::

:::solution
```python run title="username.py"
def is_valid_username(name):
    """Return True if name is 3 to 15 characters long with no spaces."""
    return 3 <= len(name) <= 15 and " " not in name

for test in ["pixelfox", "al", "night owl", "thisnameiswaytoolong"]:
    print(test, "->", is_valid_username(test))
```

`3 <= len(name) <= 15` is a chained comparison: it means `3 <= len(name) and len(name) <= 15`. Functions that return `True` or `False` read nicely in an `if`: `if is_valid_username(name):`.
:::

### Exercise 3: Keep a value in range

Games keep health between 0 and 100 no matter what happens. Write `clamp(value, low, high)` that returns `low` if `value` is below it, `high` if it's above, and `value` otherwise.

```text
clamp(120, 0, 100)  ->  100
clamp(-5, 0, 100)   ->  0
clamp(42, 0, 100)   ->  42
```

:::hint
Use early returns: one `if` that returns `low`, one that returns `high`, and a final `return value` for everything else.
:::

:::solution
```python run title="clamp.py"
def clamp(value, low, high):
    """Return value, limited to the range low to high."""
    if value < low:
        return low
    if value > high:
        return high
    return value

print(clamp(120, 0, 100))
print(clamp(-5, 0, 100))
print(clamp(42, 0, 100))
```

You'll use exactly this function in the next module's game, to keep a pet's hunger and energy between 0 and 10.
:::

### Exercise 4: The average that won't compare

This program should print `Honor roll!` because the average of the scores is above 85. Instead it prints a number and then crashes. Find the bug and fix it.

```python run raises title="honor_roll.py"
def average(numbers):
    total = 0
    for n in numbers:
        total = total + n
    print(total / len(numbers))

scores = [88, 92, 79]
if average(scores) > 85:
    print("Honor roll!")
```

:::hint
Read the last line of the error. What type is on the left side of `>`? What does a function give back when it has no `return`?
:::

:::solution
```python run title="honor_roll.py"
def average(numbers):
    """Return the mean of a list of numbers."""
    total = 0
    for n in numbers:
        total = total + n
    return total / len(numbers)

scores = [88, 92, 79]
if average(scores) > 85:
    print("Honor roll!")
print(f"Average: {average(scores):.1f}")
```

`print` showed 86.33… on the screen, but the function handed back `None`, and `None > 85` makes no sense to Python. Changing `print` to `return` sends the number to the `if`.
:::

### Exercise 5: Experience points that won't add up

This function is supposed to add experience points to a global total. It crashes the first time it's called.

```python run raises title="xp.py"
xp = 0

def gain_xp(amount):
    xp = xp + amount
    print("XP is now", xp)

gain_xp(50)
gain_xp(25)
```

Rewrite it so the function takes the current XP as a parameter and **returns** the new total, and the main code stores the result. It should print 50 and then 75.

:::hint
Because the function assigns to `xp`, Python treats `xp` as a local variable for the whole function, so `xp + amount` tries to read a local that doesn't exist yet. (Older versions of Python word this as "local variable 'xp' referenced before assignment.") Pass the value in with a parameter, return the new value, and assign it back with `xp = gain_xp(xp, 50)`.
:::

:::solution
```python run title="xp.py"
def gain_xp(current, amount):
    """Return the new XP total after gaining amount."""
    return current + amount

xp = 0
xp = gain_xp(xp, 50)
print("XP is now", xp)
xp = gain_xp(xp, 25)
print("XP is now", xp)
```

Python does have a `global` keyword that lets a function change a global variable, but parameters and return values are easier to follow and test: you can read `xp = gain_xp(xp, 50)` and know exactly what changed.
:::

### Exercise 6: A text progress bar

Write `progress_bar(done, total, width=20)` that returns a bar made of `#` and `-` characters plus a percentage. Then use a loop to print the bar for 0 to 5 tasks out of 5.

```text
[--------------------] 0%
[####----------------] 20%
[########------------] 40%
[############--------] 60%
[################----] 80%
[####################] 100%
```

:::hint
The number of `#` characters is `done / total * width`, rounded to a whole number. The rest of the width is `-`. `"#" * 8` makes eight `#` characters. Build the string with `+` and return it.
:::

:::solution
```python run title="progress.py"
def progress_bar(done, total, width=20):
    """Return a text bar like '[####------] 40%'."""
    filled = round(done / total * width)
    percent = round(done / total * 100)
    return "[" + "#" * filled + "-" * (width - filled) + f"] {percent}%"

for step in range(6):
    print(progress_bar(step, 5))
print(progress_bar(1, 3, width=10))
```

The default `width=20` covers the common case, and the last line shows a caller choosing a shorter bar with a keyword argument.
:::

### Challenge: A secret-message cipher

The **Caesar cipher** shifts every letter a fixed number of places along the alphabet. With a shift of 3, `a` becomes `d`, `b` becomes `e`, and `z` wraps around to `c`. Write two functions:

-   `encode(message, shift)` returns the message with every letter shifted. Make everything lowercase, and leave spaces and punctuation alone.
-   `decode(message, shift)` turns it back. Write it in one line by calling `encode`.

```text
encode("Meet at noon!", 3)  ->  phhw dw qrrq!
decode("phhw dw qrrq!", 3)  ->  meet at noon!
encode("xyz", 3)            ->  abc
```

Step through a tiny version first to see how one letter's position is found and shifted:

:::trace Shift each letter of "hi" by 3
```python
ALPHABET = "abcdefghijklmnopqrstuvwxyz"

def encode(message, shift):
    result = ""
    for ch in message:
        position = ALPHABET.find(ch)
        result = result + ALPHABET[(position + shift) % 26]
    return result

print(encode("hi", 3))
```
:::

:::hint
Keep the alphabet in a string. `ALPHABET.find(ch)` gives a letter's position (0 for `a`), or `-1` if `ch` isn't a letter. `(position + shift) % 26` wraps past `z` back to the start. And decoding is just encoding with the shift going the other way.
:::

:::solution
```python run title="cipher.py"
ALPHABET = "abcdefghijklmnopqrstuvwxyz"


def encode(message, shift):
    """Shift every letter in message by shift places; leave other characters alone."""
    result = ""
    for ch in message.lower():
        position = ALPHABET.find(ch)
        if position == -1:
            result = result + ch
        else:
            result = result + ALPHABET[(position + shift) % 26]
    return result


def decode(message, shift):
    """Undo encode() by shifting the other way."""
    return encode(message, -shift)


secret = encode("Meet at noon!", 3)
print(secret)
print(decode(secret, 3))
print(encode("xyz", 3))
```

`decode` works because Python's `%` always gives a result from 0 to 25 here, even for negative numbers: `(0 - 3) % 26` is 23, which is `x`. Reusing `encode` means there's only one loop to get right. Try sending a friend a message with shift 13; encoding it twice gives back the original, because 13 + 13 = 26.
:::
