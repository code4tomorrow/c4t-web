Ask the calculator on your phone for 2 to the power of 100. Most will show something like `1.2676506e30`, a rounded guess. Python gives you every one of the 31 digits: `1267650600228229401496703205376`. Twenty minutes from now, your own computer will do that.

## What you're installing, and why Thonny

Python is a language, and the **Python interpreter** is the program that reads Python code and carries it out. You also need an **editor**, a place to type code and save it. Thonny packs both into one download: install Thonny and you have Python.

There are many Python editors. This course uses Thonny because it was designed at the University of Tartu for people writing their first programs. Two of its features matter a lot later: a **Variables** panel that lists every value your program is holding, and a **debugger** that runs your program one step at a time so you can watch it think. Thonny is free and open source, with no account to make.

You need:

-   A Windows 10 or 11 PC, a Mac with macOS Catalina (10.15) or newer, or a Chromebook that allows Linux apps.
-   About 15 minutes (closer to 30 on a Chromebook, because switching on Linux takes a while).
-   No administrator password on Windows or a Chromebook. A Mac will ask for the password you log in with.

:::note
Already installed Python from python.org? Keep it. Thonny uses its own private copy of Python, so the two don't get in each other's way.
:::

## Install it, step by step

:::tabs
@tab Windows
1.  Find out what kind of processor your PC has. Open **Settings › System › About** and look at **System type**. Most PCs say **x64-based processor**. Some newer laptops with Snapdragon chips say **ARM-based processor**.
2.  Go to **thonny.org**. In the download box at the top, under Windows, click **Installer with Python 3.14 for Intel or AMD computers** (a file named like `thonny-5.0.1-x64.exe`). If your PC is ARM-based, pick the installer **for Arm** instead. If the version number on the site is newer than 5.0.1, take the newer one.
3.  Open the downloaded file from your **Downloads** folder.
4.  If a blue box says **Windows protected your PC**, click **More info**, then **Run anyway**. Windows shows this for programs it hasn't seen installed very often; it is not a virus warning.
5.  If you're asked how to install, choose **Install for me only**. This puts Thonny in your own user folder, which is why no administrator password is needed.
6.  Click **Next** past the license (it's already accepted for you) and the suggested folder. Tick **Create desktop icon** if you want one. Click **Install**, and when the last page says **Great success!**, click **Finish**.
7.  Open Thonny: press the **Windows** key, type `Thonny`, and press Enter.
@tab macOS
1.  Open the Apple menu (top left) and choose **About This Mac**. If you see **Chip** followed by Apple M1, M2, M3, M4 or similar, you have an Apple silicon Mac. If you see **Processor** with Intel in the name, you have an Intel Mac.
2.  Go to **thonny.org**. Under Mac, click **Installer with Python 3.14 for Apple Silicon Macs** (a file named like `thonny-5.0.1-arm64.pkg`) or the one **for Intel Macs** (`thonny-5.0.1-x64.pkg`). If the site shows a newer version, take it.
3.  Open the `.pkg` file from **Downloads**. Click **Continue**, agree to the license, and click **Install**. Type your Mac login password when asked.
4.  When it says the installation was successful, click **Close**. If it offers to move the installer to the Trash, that's fine; you won't need it again.
5.  Open **Thonny** from your **Applications** folder or from Launchpad. If macOS checks that you really want to open an app downloaded from the internet, click **Open**.
6.  The first time you save into Documents or Desktop, macOS may ask whether Thonny can use that folder. Click **Allow**, or Thonny won't be able to save there.
@tab Chromebook
Thonny runs inside the Chromebook's Linux environment, which is switched off until you turn it on.

1.  Click the time in the bottom-right corner, then **Settings**. Go to **About ChromeOS › Developers**. Next to **Linux development environment**, click **Set up** and follow the prompts. Setup can take 10 minutes or more. When it finishes, a **Terminal** window opens.
2.  In the Terminal, type the first line below and press Enter. When it finishes, type the second line and press Enter. The first refreshes the list of available software, and the second installs Thonny.

```bash
sudo apt update
sudo apt install -y thonny
```

3.  Open the launcher (the circle in the bottom-left corner) and look in the **Linux apps** folder for **Thonny**.

This installs the copy of Thonny packaged for Linux, which can be a version or two behind the Windows and Mac downloads. Every lesson in this course works with it.

If **Developers** or **Linux development environment** is missing, the Chromebook is probably managed by a school that has switched Linux off. See the fixes at the bottom of this page.
:::

## Open Thonny for the first time

The very first launch shows a small window titled **Welcome to Thonny!** with two menus. Leave **Language** on English (or pick yours), leave **Initial settings** on **Standard**, and click **Let's go!** The other choice, Raspberry Pi (simple), hides the menu bar, and this course uses the menus.

The main window has two parts you'll use every day:

-   **The editor**, the big area at the top, with a tab labeled `<untitled>`. This is where you'll write programs and save them as files.
-   **The Shell**, the area underneath. It starts with a line that begins `Python 3.` followed by a version number, and then a `>>>` prompt. The Shell runs a single line of Python the moment you press Enter.

Across the top is a row of buttons: **New**, **Load**, **Save**, a green **Run** button, a **Debug** button with a bug on it, the step buttons **Over**, **Into**, and **Out**, a **Resume** button, and a red **Stop** sign. You'll meet the ones that matter over the next few lessons.

## Prove it works

Click just to the right of `>>>` in the Shell. Type each line below and press Enter after each one:

```text
print("Thonny is ready")
2 ** 100
7 / 2
```

Your Shell should now look like this:

```text
>>> print("Thonny is ready")
Thonny is ready
>>> 2 ** 100
1267650600228229401496703205376
>>> 7 / 2
3.5
```

`print(...)` displays whatever is inside the brackets. `**` means "to the power of", so `2 ** 100` is 2 multiplied by itself 100 times. The Shell also shows the value of any calculation you type, even without `print`, which makes it a handy calculator. Programs saved in files don't do that, so the next lesson uses `print` for everything.

If you got those three answers, Python and Thonny are installed and working. If you got red text instead, the next section covers the usual causes.

:::tip
Text too small? Use **View › Increase font size** (Ctrl and + on Windows and Chromebook, Cmd and + on a Mac). Bigger text means fewer typos.
:::

## When setup goes wrong

### Windows says "This app can't run on your PC"

The installer doesn't match your processor. Check **System type** again (step 1) and download the other Windows installer.

### The installer is blocked and there's no Run anyway button

School and library computers often block installers. Ask whoever runs the computer, or try Thonny's **portable variant**: on thonny.org, under Windows, download the `.zip` labeled **Portable variant**. Right-click it, choose **Extract All**, put the folder in your Documents, then open the folder and double-click `thonny.exe`. Nothing gets installed, so it often works where installers don't.

### The Shell shows red text or never shows `>>>`

The hidden Python process that Thonny talks to didn't start properly. Click the red **Stop** button (or choose **Run › Stop/Restart backend**, Ctrl+F2). That restarts Python and usually brings the prompt back. If it keeps happening, close Thonny and open it again.

### On a Mac, Thonny can't save files or says "Operation not permitted"

You probably clicked **Don't Allow** when macOS asked about folder access. Open **System Settings › Privacy & Security**, find the section for files and folders, and switch on access for Thonny. Then quit Thonny and open it again.

### The Chromebook has no Linux option

Schools can turn Linux off on managed Chromebooks, and only their administrator can turn it back on. Ask your teacher or school tech team. Until then, Python Tutor (pythontutor.com) runs short Python programs in the browser and shows variables step by step, much like Thonny does. It's enough to follow along with the first few modules while you sort out a computer that can run Thonny, such as a home or public-library PC.

:::takeaways
- Thonny's installer includes Python, so one download sets up both.
- The editor (top) is for programs you save; the Shell (bottom) runs one line at a time.
- `2 ** 100` printing all 31 digits proves your setup works.
- The red Stop button restarts Python when the Shell gets stuck.
:::
