Every lesson in this course is something you type and run, not something you just read. Model evaluation is a hands-on skill: you only learn why a 97% accuracy can be a lie by watching it happen on your own screen. So before week 1, you need a notebook that runs Python and has four libraries installed: **scikit-learn**, **pandas**, **numpy**, and **matplotlib**.

You have two good options. Both are free, and the code in this course runs the same way in either one.

## Option A: Google Colab (recommended for most students)

Colab is a Jupyter notebook that runs on Google's computers. You open it in a browser, and all four libraries are already installed.

**Pick Colab if:** you use a Chromebook, a school laptop where you can't install software, or you just want to start in two minutes.

### Steps

1. Sign in to a Google account in your browser. A personal Gmail account works best; some school accounts block Colab.
2. Go to `colab.research.google.com`.
3. In the window that pops up, click **New notebook**. (If no window appears, use **File → New notebook in Drive**.)
4. Click the title at the top left (it starts as `Untitled0.ipynb`) and rename it to `c4t-setup.ipynb`.
5. Click into the first gray box (a **code cell**), type `print("hello")`, and press **Shift + Enter**.

The first run takes a few seconds while Colab connects you to a machine. In the top right you will see **Connected** with RAM and Disk bars once it is ready.

:::tip
Colab notebooks save automatically into a folder called **Colab Notebooks** in your Google Drive. You can find them later at `drive.google.com`.
:::

## Option B: JupyterLab on your own computer

JupyterLab is the same kind of notebook, but it runs locally. It works without internet once installed, and your files live in normal folders on your computer.

**Pick JupyterLab if:** you have your own Windows, Mac, or Linux computer, you already have Python 3.9 or newer, and you are comfortable typing commands in a terminal.

### Steps

1. Check that Python is installed. Open a terminal (on Windows, open **Command Prompt** or **PowerShell**) and run:

```bash
python3 --version
```

On Windows the command may be `python --version` or `py --version` instead. You want to see `Python 3.9` or higher. If you get "command not found," install Python from python.org first. On Windows, tick the **Add python.exe to PATH** box in the installer.

2. Make a folder for the course and move into it:

```bash
mkdir c4t-ml
cd c4t-ml
```

3. Install JupyterLab and the four libraries in one command:

```bash
pip install jupyterlab pandas scikit-learn matplotlib
```

numpy installs automatically because pandas and scikit-learn depend on it. If `pip` is not found, try `pip3`, or `python3 -m pip install ...` (on Windows: `py -m pip install ...`).

4. Start JupyterLab:

```bash
jupyter lab
```

Your browser opens a page at an address like `http://localhost:8888/lab`. Leave the terminal window open. Closing it shuts JupyterLab down.

5. In the **Launcher** tab, click the **Python 3 (ipykernel)** tile under **Notebook**. Right-click the new `Untitled.ipynb` in the left file panel and rename it to `c4t-setup.ipynb`.

:::warning
Run `jupyter lab` from inside your `c4t-ml` folder. JupyterLab can only see files in the folder where you start it and the folders below it, so starting it somewhere else makes your notebooks seem to disappear.
:::

## Check your libraries

Whichever option you picked, paste this into a code cell and run it with **Shift + Enter**:

```python
import sys
import sklearn, pandas, numpy, matplotlib

print("Python", sys.version.split()[0])
print("scikit-learn", sklearn.__version__)
print("pandas", pandas.__version__)
print("numpy", numpy.__version__)
print("matplotlib", matplotlib.__version__)
```

You will see something like this. Your version numbers will probably be different, and that is fine:

```text
Python 3.13.0
scikit-learn 1.8.0
pandas 2.2.3
numpy 2.1.3
matplotlib 3.10.1
```

What matters:

- **scikit-learn 1.2 or newer.** Everything in this course works from 1.2 up. Colab currently ships a recent version.
- **No `ModuleNotFoundError`.** If one library is missing, install it. In Colab, run `!pip install scikit-learn` in a cell (the `!` sends the line to the system shell). In JupyterLab, run `%pip install scikit-learn` in a cell, then restart the kernel with **Kernel → Restart Kernel**.

:::tip
Use `%pip` instead of `!pip` in a local notebook. `%pip` installs into the exact Python that your notebook is using, which avoids the common "I installed it but it still says missing" problem.
:::

## Which one should I use?

If you are unsure, start with Colab. You can always switch later because both use the same `.ipynb` file format: a notebook made in Colab opens in JupyterLab and the other way around. Some students use Colab at school and JupyterLab at home.

| | Google Colab | JupyterLab |
|---|---|---|
| Install needed | No | Yes (Python + pip) |
| Needs internet | Yes | Only to install |
| Where files live | Google Drive | Folders on your computer |
| Works on Chromebook | Yes | No |
| Sessions time out | After idle time | No |

Once your version check prints without errors, you are ready for the next lesson, where you load a real dataset and train a quick model to prove the whole setup works.
