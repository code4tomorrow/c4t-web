summary: Build a small evaluation notebook that scores three dummy baselines and two real models on the same stratified split, ranks them, and checks whether the ranking survives different random splits.

Today you build a tool you will keep reusing: a **leaderboard** that puts every candidate model, including do-nothing baselines, in one table scored on the same test set. By the end you will be able to say "the tree beats the best baseline by 53 points, and that holds across ten different splits," which is a much stronger claim than "I got 93%."

We use the wine dataset: 178 wines, 13 chemical measurements, 3 growers (classes 0, 1, 2). Make a new notebook called `w1-codealong-baseline.ipynb` and put each step in its own cell.

## Step 1: Load and inspect the target

```python
from sklearn.datasets import load_wine
from sklearn.model_selection import train_test_split

wine = load_wine(as_frame=True)
X, y = wine.data, wine.target
print(X.shape)
print(y.value_counts(normalize=True).sort_index().round(3))

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=7
)
print("train:", len(X_train), " test:", len(X_test))
```

```text
(178, 13)
target
0    0.331
1    0.399
2    0.270
Name: proportion, dtype: float64
train: 133  test: 45
```

`normalize=True` turns counts into shares. Class 1 is the biggest at about 40%, so before running anything you can predict that "always guess class 1" will score close to 0.40. Predicting your baseline before computing it is a good habit; if the number surprises you, something is off.

The split happens **once**, before any model exists. Every candidate below uses these exact four variables.

## Step 2: Write one evaluation function

Repeating `fit` and `score` for each model invites copy-paste mistakes, like scoring model B on model A's split. Put it in a function:

```python
def evaluate(name, model):
    model.fit(X_train, y_train)
    train_acc = model.score(X_train, y_train)
    test_acc = model.score(X_test, y_test)
    return {"model": name, "train": round(train_acc, 3), "test": round(test_acc, 3)}
```

The function returns a dictionary rather than printing. A list of dictionaries turns straight into a pandas table in the next step.

We record training accuracy too. A large gap between train and test is an early sign of overfitting, which you'll study properly in week 4.

## Step 3: Score the candidates

```python
import pandas as pd
from sklearn.dummy import DummyClassifier
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier

candidates = {
    "dummy: most_frequent": DummyClassifier(strategy="most_frequent"),
    "dummy: stratified": DummyClassifier(strategy="stratified", random_state=0),
    "dummy: uniform": DummyClassifier(strategy="uniform", random_state=0),
    "k-NN (k=5)": KNeighborsClassifier(n_neighbors=5),
    "tree (depth 3)": DecisionTreeClassifier(max_depth=3, random_state=0),
}

results = pd.DataFrame([evaluate(n, m) for n, m in candidates.items()])
print(results.to_string(index=False))
```

```text
               model  train  test
dummy: most_frequent  0.398 0.400
   dummy: stratified  0.323 0.311
      dummy: uniform  0.361 0.333
          k-NN (k=5)  0.820 0.711
      tree (depth 3)  0.992 0.933
```

Read it row by row:

- **most_frequent** lands at 0.400, as predicted in step 1.
- **stratified** and **uniform** guess randomly, so they score around one in three. They need a `random_state` too, or their score changes every run.
- **k-NN** clearly beats the baselines but trails the tree. k-NN measures distance between rows, and wine features have very different scales (`proline` runs into the hundreds and beyond, while `hue` stays near 1), so one feature dominates. You'll fix exactly this with scaling next week.
- **The tree** fits training data almost perfectly and still does well on test.

:::tip
`to_string(index=False)` prints the whole table without the row numbers. In a notebook you could just put `results` on the last line to get a formatted table, but printing keeps your output identical to the lesson.
:::

## Step 4: Rank against the best baseline

The question that matters is "how much better than doing nothing?" Add a column for that:

```python
best_baseline = results[results["model"].str.startswith("dummy")]["test"].max()
results["beats_baseline_by"] = (results["test"] - best_baseline).round(3)
print(results.sort_values("test", ascending=False).to_string(index=False))
```

```text
               model  train  test  beats_baseline_by
      tree (depth 3)  0.992 0.933              0.533
          k-NN (k=5)  0.820 0.711              0.311
dummy: most_frequent  0.398 0.400              0.000
      dummy: uniform  0.361 0.333             -0.067
   dummy: stratified  0.323 0.311             -0.089
```

We compare against the **strongest** baseline, not the weakest. Beating random guessing is easy; beating "always say the common class" is the real minimum.

## Step 5: Does the ranking survive a different split?

A test set of 45 rows is small. One or two lucky rows move accuracy by more than 2 points. So rerun the comparison over ten different splits:

```python
import numpy as np
from sklearn.datasets import load_wine
from sklearn.dummy import DummyClassifier
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier

X, y = load_wine(return_X_y=True)

scores = {"baseline": [], "k-NN": [], "tree": []}
for seed in range(10):
    X_tr, X_te, y_tr, y_te = train_test_split(
        X, y, test_size=0.25, stratify=y, random_state=seed
    )
    for name, model in [("baseline", DummyClassifier()),
                        ("k-NN", KNeighborsClassifier()),
                        ("tree", DecisionTreeClassifier(max_depth=3, random_state=0))]:
        scores[name].append(model.fit(X_tr, y_tr).score(X_te, y_te))

for name, s in scores.items():
    s = np.array(s)
    print(f"{name:9s} mean {s.mean():.3f}  min {s.min():.3f}  max {s.max():.3f}")
```

```text
baseline  mean 0.400  min 0.400  max 0.400
k-NN      mean 0.684  min 0.644  max 0.756
tree      mean 0.904  min 0.778  max 0.978
```

Three things to notice:

- The tree's test accuracy ranges from 0.778 to 0.978 just by changing which rows are in the test set. The 0.933 from step 3 was one draw from that range, a bit above average.
- The **ranking** never changes: the tree's worst split still beats k-NN's best. That is a trustworthy conclusion.
- The baseline is identical on every split because stratification keeps class 1 at the same share each time.

`fit()` returns the model itself, which is why `model.fit(X_tr, y_tr).score(X_te, y_te)` works on one line. `DummyClassifier()` with no arguments uses `most_frequent`.

:::warning
Don't pick the seed that gives your favorite model its best score and report that number. That's cheating yourself. Report the average and the spread, or (from week 4) use cross-validation, which does this loop for you more carefully.
:::
