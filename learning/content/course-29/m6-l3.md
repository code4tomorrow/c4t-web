Most hyperparameter-search bugs aren't math bugs. They're a misspelled parameter name, a grid that takes three hours, or an "improvement" that turns out to be noise. These exercises go after each of those. Solutions use only bundled datasets.

### Exercise 1: Fix the parameter name

This search has a bug, and it crashes with an error:

```python
pipe = Pipeline([("scale", StandardScaler()),
                 ("clf", LogisticRegression(max_iter=5000))])
GridSearchCV(pipe, {"C": [0.1, 1, 10]}, cv=5).fit(X, y)
```

On `load_wine`, catch the error and print its first 60 characters. Then use `pipe.get_params()` to find the correct name, fix the grid, and print the best parameters and score.

:::solution
```python
from sklearn.datasets import load_wine
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import GridSearchCV
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

X, y = load_wine(return_X_y=True)
pipe = Pipeline([("scale", StandardScaler()),
                 ("clf", LogisticRegression(max_iter=5000))])

try:
    GridSearchCV(pipe, {"C": [0.1, 1, 10]}, cv=5).fit(X, y)
except ValueError as e:
    print("Error:", str(e)[:60], "...")

names = [k for k in pipe.get_params() if k.startswith("clf__C")]
print("Valid name:", names)
search = GridSearchCV(pipe, {"clf__C": [0.1, 1, 10]}, cv=5).fit(X, y)
print("Best:", search.best_params_, round(search.best_score_, 3))
```

```text
Error: Invalid parameter 'C' for estimator Pipeline(steps=[('scale' ...
Valid name: ['clf__C']
Best: {'clf__C': 0.1} 0.983
```

The prefix is whatever **you** named the step. Here that's `clf`, so it's `clf__C`, not `model__C`. With `make_pipeline` the name would be `logisticregression__C`.
:::

### Exercise 2: Budget a grid before you run it

A teammate proposes this grid for a decision tree with 5-fold CV:

```python
grid = {
    "model__max_depth": [3, 5, 8, None],
    "model__min_samples_leaf": [1, 5, 10],
    "model__criterion": ["gini", "entropy"],
}
```

Without fitting anything, compute how many settings and how many model fits it will run. Use `sklearn.model_selection.ParameterGrid` to check your arithmetic.

:::solution
```python
from sklearn.model_selection import ParameterGrid

grid = {
    "model__max_depth": [3, 5, 8, None],
    "model__min_samples_leaf": [1, 5, 10],
    "model__criterion": ["gini", "entropy"],
}
n_settings = len(ParameterGrid(grid))
k = 5
print("Settings:", n_settings)
print("Fits during search:", n_settings * k)
print("Plus the final refit:", n_settings * k + 1)
```

```text
Settings: 24
Fits during search: 120
Plus the final refit: 121
```

4 × 3 × 2 = 24 settings, times 5 folds. Trees are fast, so this is fine. For a random forest with 500 trees it would be slow, and that's when you switch to `RandomizedSearchCV` with a fixed `n_iter`.
:::

### Exercise 3: Paired folds vs. mismatched folds

On breast cancer, compare `DecisionTreeClassifier(max_depth=4, random_state=0)` with `RandomForestClassifier(random_state=0)` using one shared `StratifiedKFold(5, shuffle=True, random_state=3)`. Print the per-fold difference (forest − tree) and how many folds the forest wins. Then cross-validate the tree again with `random_state=99` folds and compare its two means. What does that second number tell you about comparing models on *different* folds?

:::solution
```python
from sklearn.datasets import load_breast_cancer
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.tree import DecisionTreeClassifier

X, y = load_breast_cancer(return_X_y=True)
tree = DecisionTreeClassifier(max_depth=4, random_state=0)
forest = RandomForestClassifier(random_state=0)

shared = StratifiedKFold(n_splits=5, shuffle=True, random_state=3)
t = cross_val_score(tree, X, y, cv=shared)
f = cross_val_score(forest, X, y, cv=shared)
print("Same folds")
print("  forest - tree per fold:", (f - t).round(3))
print(f"  forest wins {(f > t).sum()} of 5, mean gain {(f - t).mean():.3f}")

t_other = cross_val_score(tree, X, y, cv=StratifiedKFold(5, shuffle=True, random_state=99))
print("Different folds")
print(f"  tree mean: {t.mean():.3f} (seed 3) vs {t_other.mean():.3f} (seed 99)")
```

```text
Same folds
  forest - tree per fold: [-0.009  0.018  0.026  0.009  0.018]
  forest wins 4 of 5, mean gain 0.012
Different folds
  tree mean: 0.947 (seed 3) vs 0.935 (seed 99)
```

Just re-shuffling the folds moves the *same tree* by 0.012, which is exactly the size of the forest's advantage. If you had scored the two models on different folds, you couldn't tell skill from luck. On shared folds, the forest wins 4 of 5 paired matchups, and that consistency is the real evidence.
:::

### Exercise 4: Tune a preprocessing step

Copy breast cancer and blank out about 10% of values at random (`np.random.default_rng(0)`, `rng.random(X.shape) < 0.10`). Build `Pipeline([("impute", SimpleImputer()), ("scale", StandardScaler()), ("model", LogisticRegression(max_iter=5000))])` and grid-search **both** `impute__strategy` (`"mean"`, `"median"`) and `model__C` (0.1, 1, 10) using F1. Print all six results.

:::solution
```python
import numpy as np
from sklearn.datasets import load_breast_cancer
from sklearn.impute import SimpleImputer
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import GridSearchCV, StratifiedKFold
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

X, y = load_breast_cancer(return_X_y=True)
rng = np.random.default_rng(0)
X = X.copy()
X[rng.random(X.shape) < 0.10] = np.nan
print(f"Missing values: {np.isnan(X).mean():.1%}")

pipe = Pipeline([("impute", SimpleImputer()),
                 ("scale", StandardScaler()),
                 ("model", LogisticRegression(max_iter=5000))])
grid = {"impute__strategy": ["mean", "median"],
        "model__C": [0.1, 1, 10]}
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)
search = GridSearchCV(pipe, grid, cv=cv, scoring="f1").fit(X, y)

for p, m in zip(search.cv_results_["params"], search.cv_results_["mean_test_score"]):
    print(f"{p['impute__strategy']:>6}  C={p['model__C']:<4}  F1 {m:.4f}")
print("Best:", search.best_params_)
```

```text
Missing values: 10.2%
  mean  C=0.1   F1 0.9740
  mean  C=1     F1 0.9807
  mean  C=10    F1 0.9749
median  C=0.1   F1 0.9767
median  C=1     F1 0.9738
median  C=10    F1 0.9706
Best: {'impute__strategy': 'mean', 'model__C': 1}
```

Any step in a pipeline can be tuned, not just the model. Because the imputer is inside the pipeline, each fold computes its means or medians from its own training rows only. All six scores fall within one point of each other, so the imputation choice barely matters here, and that's a finding worth reporting too.
:::

### Exercise 5: Sample C on a log scale

Use `RandomizedSearchCV` with `{"model__C": loguniform(1e-3, 1e2)}`, `n_iter=12`, ROC AUC, and `random_state=0` on a scaled logistic regression for breast cancer. Load `cv_results_` into a DataFrame and print the top three C values with their mean and std, plus the smallest and largest C that were sampled.

:::solution
```python
import pandas as pd
from scipy.stats import loguniform
from sklearn.datasets import load_breast_cancer
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import RandomizedSearchCV, StratifiedKFold
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

X, y = load_breast_cancer(return_X_y=True)
pipe = Pipeline([("scale", StandardScaler()),
                 ("model", LogisticRegression(max_iter=5000))])
search = RandomizedSearchCV(pipe, {"model__C": loguniform(1e-3, 1e2)},
                            n_iter=12, scoring="roc_auc", random_state=0,
                            cv=StratifiedKFold(5, shuffle=True, random_state=0))
search.fit(X, y)

res = pd.DataFrame(search.cv_results_)
res["C"] = res["param_model__C"].astype(float)
top = res.sort_values("rank_test_score")[["C", "mean_test_score", "std_test_score"]]
print(top.head(3).round(4).to_string(index=False))
print("Smallest C tried:", round(res["C"].min(), 4), "| Largest:", round(res["C"].max(), 2))
```

```text
     C  mean_test_score  std_test_score
0.4410           0.9956          0.0058
0.5547           0.9955          0.0058
1.0323           0.9955          0.0056
Smallest C tried: 0.0826 | Largest: 65.81
```

The top three are tied to three decimals. Any C from about 0.4 to 1 is equally good, so don't over-read "0.4410." `loguniform` spreads the samples across orders of magnitude. A plain `uniform(0.001, 100)` would put almost all its samples above 1.
:::

### Stretch challenge: Nested CV for two tuned models

Wrap a tuned logistic regression (`model__C` in 0.01–10) and a tuned random forest (`n_estimators=150`; `model__max_depth` in `[4, 8, None]`, `model__min_samples_leaf` in `[1, 3]`) each in `GridSearchCV` with 3 inner folds. Score both with the **same** 5 outer folds using `cross_val_score`, then print each nested AUC and the per-outer-fold difference.

:::solution
```python
from sklearn.datasets import load_breast_cancer
from sklearn.ensemble import RandomForestClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import GridSearchCV, StratifiedKFold, cross_val_score
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

X, y = load_breast_cancer(return_X_y=True)
inner = StratifiedKFold(n_splits=3, shuffle=True, random_state=0)
outer = StratifiedKFold(n_splits=5, shuffle=True, random_state=1)

candidates = {
    "logistic": GridSearchCV(
        Pipeline([("scale", StandardScaler()),
                  ("model", LogisticRegression(max_iter=5000))]),
        {"model__C": [0.01, 0.1, 1, 10]}, cv=inner, scoring="roc_auc"),
    "forest": GridSearchCV(
        Pipeline([("model", RandomForestClassifier(n_estimators=150, random_state=0))]),
        {"model__max_depth": [4, 8, None], "model__min_samples_leaf": [1, 3]},
        cv=inner, scoring="roc_auc"),
}

outer_scores = {}
for name, search in candidates.items():
    s = cross_val_score(search, X, y, cv=outer, scoring="roc_auc")
    outer_scores[name] = s
    print(f"{name:>8}: nested AUC {s.mean():.4f} ± {s.std():.4f}")

diff = outer_scores["logistic"] - outer_scores["forest"]
print("logistic - forest per outer fold:", diff.round(4))
```

```text
logistic: nested AUC 0.9954 ± 0.0045
  forest: nested AUC 0.9896 ± 0.0063
logistic - forest per outer fold: [0.0039 0.0003 0.003  0.0056 0.0159]
```

Logistic regression wins every outer fold, so tuning and all, it's the better *procedure* on this dataset. This run trains 5 outer × (4 + 6) settings × 3 inner folds, plus refits, which is over 150 models, so expect it to take a while. That cost is why nested CV is usually saved for final, high-stakes comparisons.
:::
