Suppose a classmate says their tumor classifier is 63% accurate. Is that good? On the breast cancer dataset bundled with scikit-learn, a "model" that ignores every measurement and always answers "benign" scores about 63%. So their model may have learned nothing at all. This week is about making sure you can tell the difference.

## The supervised learning workflow

You trained a first model before this course. Here is that same process written out as the five steps we will use, and improve, all term:

1. **Load** the data into features `X` (the inputs) and labels `y` (the answers).
2. **Split** it into a training set and a test set.
3. **Fit** a model on the training set only.
4. **Predict** on the test set, which the model has never seen.
5. **Evaluate** by comparing predictions with the true test labels.

```python
from sklearn.datasets import load_breast_cancer
from sklearn.metrics import accuracy_score
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

# 1. Load the data: X = features, y = labels
X, y = load_breast_cancer(return_X_y=True, as_frame=True)
print("Rows, features:", X.shape)

# 2. Split into training and test sets
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=42
)

# 3. Choose a model and fit it on the training set only
model = DecisionTreeClassifier(max_depth=3, random_state=42)
model.fit(X_train, y_train)

# 4. Predict on rows the model has never seen
y_pred = model.predict(X_test)
print("First 10 predictions:", y_pred[:10])
print("First 10 true labels:", y_test.to_numpy()[:10])

# 5. Evaluate
print("Train accuracy:", round(model.score(X_train, y_train), 3))
print("Test accuracy: ", round(accuracy_score(y_test, y_pred), 3))
```

```text
Rows, features: (569, 30)
First 10 predictions: [1 0 0 1 1 0 0 0 0 1]
First 10 true labels: [1 0 1 1 0 0 0 0 0 1]
Train accuracy: 0.977
Test accuracy:  0.944
```

In this dataset, label `1` means benign and `0` means malignant. Two of the first ten predictions are wrong. Training accuracy is higher than test accuracy, which is normal: the model has already seen the training rows. **Only the test number tells you how the model will do on new patients.**

`model.score(X, y)` is a shortcut. For classifiers it computes accuracy, exactly like `accuracy_score(y, model.predict(X))`.

## Why we split at all

A model is only useful on data it hasn't seen yet. If you score it on the same rows it trained on, you are grading a student with the exact questions they studied. A deep enough decision tree can memorize every training row and score 100% there while doing worse on new rows.

The test set is your stand-in for the future. Treat it like a sealed exam:

- Don't fit anything on it: not the model, and (next week) not the scaler or imputer either.
- Don't keep tweaking your model until the test score looks good. If you do, the test set quietly becomes training data. In week 4 you'll learn cross-validation, which lets you compare choices without touching the test set.

### The arguments that matter

- **`test_size=0.25`**: hold out 25% of rows. Anything from 0.2 to 0.3 is typical for small datasets.
- **`random_state=42`**: the split is random. Fixing the seed makes it the same every run and on every computer, so your results can be reproduced. The number itself means nothing; 0 and 42 are just habits.
- **`stratify=y`**: keep the class proportions the same in train and test.

## Stratify: keeping the classes balanced across the split

Without `stratify`, a random split can give the test set noticeably more or fewer of one class than the full dataset has. With small test sets this happens a lot:

```python
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split

X, y = load_breast_cancer(return_X_y=True)
print("Whole dataset, share benign:", round(y.mean(), 3))

for seed in [0, 1, 2]:
    _, _, _, y_test = train_test_split(X, y, test_size=0.1, random_state=seed)
    _, _, _, y_test_s = train_test_split(X, y, test_size=0.1, random_state=seed, stratify=y)
    print(f"seed {seed}: plain {y_test.mean():.3f}   stratified {y_test_s.mean():.3f}")
```

```text
Whole dataset, share benign: 0.627
seed 0: plain 0.614   stratified 0.632
seed 1: plain 0.596   stratified 0.632
seed 2: plain 0.684   stratified 0.632
```

Because the labels are 0s and 1s, `y.mean()` is the share of 1s. The plain splits swing from 59.6% to 68.4% benign depending on luck. The stratified splits stay at the dataset's rate every time. Use `stratify=y` for classification unless you have a reason not to. (You can't stratify a regression target directly, since every value is different.)

## Baselines: the score to beat

A **baseline** is the score you get with no real learning. If your model can't beat it, the model isn't useful, no matter how impressive the number looks.

scikit-learn's `DummyClassifier` gives you baselines that fit and score exactly like real models:

```python
from sklearn.datasets import load_breast_cancer
from sklearn.dummy import DummyClassifier
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=42
)

baseline = DummyClassifier(strategy="most_frequent")
baseline.fit(X_train, y_train)
print("Baseline always predicts:", baseline.predict(X_test[:5]))
print("Baseline test accuracy:", round(baseline.score(X_test, y_test), 3))

model = DecisionTreeClassifier(max_depth=3, random_state=42)
model.fit(X_train, y_train)
print("Tree test accuracy:    ", round(model.score(X_test, y_test), 3))
```

```text
Baseline always predicts: [1 1 1 1 1]
Baseline test accuracy: 0.629
Tree test accuracy:     0.944
```

`most_frequent` looks only at `y_train`, finds the most common class (benign), and predicts it for every row. It completely ignores `X`. That alone gets 62.9%. The tree's 94.4% is a real improvement, because it cuts the error rate from about 37% to about 6%.

Other strategies:

- `strategy="stratified"`: guesses randomly, in proportion to the training classes.
- `strategy="uniform"`: guesses every class with equal chance.
- `strategy="constant", constant=0`: always predicts the class you name.

For **regression**, `DummyRegressor(strategy="mean")` predicts the training average for every row:

```python
from sklearn.datasets import load_diabetes
from sklearn.dummy import DummyRegressor
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error
from sklearn.model_selection import train_test_split

X, y = load_diabetes(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=42)

for name, reg in [("mean baseline", DummyRegressor(strategy="mean")),
                  ("linear model ", LinearRegression())]:
    reg.fit(X_train, y_train)
    mae = mean_absolute_error(y_test, reg.predict(X_test))
    print(f"{name}: MAE = {mae:.1f}")
```

```text
mean baseline: MAE = 65.5
linear model : MAE = 41.5
```

Mean absolute error (MAE) is the average size of a prediction's miss, in the target's units (here, a disease-progression score). Lower is better. The linear model's typical miss is about 24 points smaller than guessing the average.

:::warning
High accuracy on its own means nothing. When 95% of emails are not spam, a filter that never flags anything is 95% accurate and completely useless. Always print the baseline next to your model's score.
:::

## What usually goes wrong

- **Fitting on everything, then splitting.** The test rows have already influenced the model, so the score is too optimistic.
- **Forgetting `random_state`.** Your score changes every run, and you can't tell whether a change you made helped or you just got a luckier split.
- **Comparing models on different splits.** Use the same `X_train`/`X_test` for every model you compare.
- **Skipping the baseline.** Do it every time. It takes three lines.
