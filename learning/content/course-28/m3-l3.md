---
title: "Practice: Make it react, repeat, and make noise"
summary: Solve five challenges with key, click, and backdrop events, repeat and forever loops, and sounds, then build a fish tank with two loops running at once.
---

Every challenge here uses at least one event hat block, and most use a loop. Build it, test it with the green flag (or the key or click it listens for), then compare with the solution. If your version works but looks different, great. Programmers solve the same problem in lots of ways.

### Exercise 1: Four-way arrows

Last week's code-along only moved the dancer left and right. Make the cat move in **all four** directions with the arrow keys, 10 steps at a time. Use `change x by` and `change y by`. Add a green flag script that puts the cat in the middle.

:::solution
Four key scripts, one for each arrow, plus a reset.

```scratch
when green flag clicked
go to x: (0) y: (0)

when [right arrow v] key pressed
change x by (10)

when [left arrow v] key pressed
change x by (-10)

when [up arrow v] key pressed
change y by (10)

when [down arrow v] key pressed
change y by (-10)
```

What happens:

```text
Each arrow key moves the cat 10 steps that way.
Hold a key down and the cat keeps moving.
```

We used `change x by` and `change y by` instead of `move`, so the cat never has to turn. It always faces right, even when it goes up.
:::

### Exercise 2: Click to spin

When you click the cat, it should spin around exactly one full circle, smoothly, and then say "Wheee!" for 1 second.

Hint: one full circle is 360 degrees. If each turn is 15 degrees, how many turns do you need?

:::solution
360 divided by 15 is 24, so we repeat 24 times.

```scratch
when this sprite clicked
repeat (24)
    turn right (15) degrees
end
say [Wheee!] for (1) seconds
```

What happens:

```text
Click the cat: it spins once all the way around
and ends up facing the same way it started.
Bubble: "Wheee!"
```

If the cat doesn't spin, check its rotation style. If an earlier script set it to `left-right`, add `set rotation style [all around v]` at the top of this script.
:::

### Exercise 3: Flapping bat

Add the **Bat** sprite from the library and delete the cat. When the green flag is clicked, the bat should fly back and forth across the stage forever, flapping its wings the whole time. It must not fly upside down.

:::solution
One forever loop can do several things each time around: move, flap, bounce.

```scratch
when green flag clicked
go to x: (0) y: (50)
set rotation style [left-right v]
point in direction (90)
forever
    move (6) steps
    next costume
    if on edge, bounce
    wait (0.05) seconds
end
```

What happens:

```text
The bat flies right, flapping its wings,
turns around at the edge, flies left, and keeps going until you click stop.
```

The bat's costumes are drawn as a flapping animation, so `next costume` is all it takes.
:::

### Exercise 4: A metronome

A metronome ticks at a steady beat to help musicians keep time. Make one:

1.  Add the **Pop** sound to a sprite (Sounds tab, **Choose a Sound**).
2.  When the green flag is clicked, play the Pop sound once every half second, forever.
3.  Make the sprite change color a little on every tick so you can *see* the beat too.

:::solution
`start sound` plus a `wait` keeps a perfect beat, because the wait controls the timing.

```scratch
when green flag clicked
clear graphic effects
forever
    start sound (Pop v)
    change [color v] effect by (10)
    wait (0.5) seconds
end
```

What happens:

```text
Pop... pop... pop... two pops every second, forever.
The sprite slowly cycles through colors.
```

Try `wait (0.25) seconds` for a beat twice as fast.
:::

### Exercise 5: Day and night switch

Add two backdrops (one day, one night). Make these two things happen:

1.  **On the Stage:** clicking the stage switches to the next backdrop.
2.  **On the cat:** when the backdrop switches to the night one, the cat says "Good night!" for 2 seconds. When it switches to the day one, the cat says "Good morning!" for 2 seconds.

:::solution
The Stage uses `when stage clicked`. The cat uses `when backdrop switches to`, which runs no matter *what* switched the backdrop.

On the Stage:

```scratch
when stage clicked
next backdrop
```

On the cat:

```scratch
when backdrop switches to [Stars v]
say [Good night!] for (2) seconds

when backdrop switches to [Blue Sky v]
say [Good morning!] for (2) seconds
```

What happens:

```text
Click an empty part of the stage: the scene changes.
The cat says "Good night!" or "Good morning!" to match.
```

Use your own backdrop names in the dropdowns if they're different.
:::

### Stretch challenge: Fish tank

Build a fish tank:

-   Use an underwater backdrop and the **Fish** sprite.
-   The fish swims around forever, bouncing off the edges, without going upside down.
-   Every time it bounces, it should wander in a new direction, not the same zigzag. (Hint: look in **Operators** for `pick random (1) to (10)`.)
-   **At the same time**, the fish makes a bubble sound every 3 seconds. Pick any sound you like.

The tricky part: the swimming and the sound need different timing. Think about using two separate scripts.

:::solution
Two green flag scripts on the same sprite run side by side. One handles swimming, the other handles sound, and neither has to wait for the other.

```scratch
when green flag clicked
go to x: (0) y: (0)
set rotation style [left-right v]
forever
    move (4) steps
    if <touching (edge v)?> then
        turn right (pick random (120) to (240)) degrees
        move (10) steps
    end
    next costume
    wait (0.05) seconds
end

when green flag clicked
forever
    wait (3) seconds
    play sound (Bubbles v) until done
end
```

What happens:

```text
The fish swims, and each time it reaches an edge it turns
a random amount and heads off a new way.
Every 3 seconds or so, you hear a bubble sound.
```

The `if <touching (edge v)?> then` block is a sneak peek at next week. It checks whether the fish hit the edge, and only then does it turn. Turning between 120 and 240 degrees points the fish roughly back the way it came, and the extra `move (10) steps` gets it away from the edge so it doesn't turn twice. If you'd rather use only this week's blocks, `if on edge, bounce` works too. The fish just follows a more predictable path.

If you don't have a sound called **Bubbles**, choose the name of the sound you added in the dropdown.
:::

Save your favorite as `week2-practice.sb3`.
