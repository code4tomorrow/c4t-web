:::objectives
- Start scripts with keys, clicks, stage clicks, and backdrop changes.
- Replace stacks of repeated blocks with a `repeat` loop.
- Combine moving, costume changes, and bouncing inside one `forever` loop.
- Keep a steady beat with sounds and waits.
- Put one loop inside another.
- Run two loops with different timing on the same sprite.
:::

Every challenge here uses at least one event hat block, and most use a loop. Build it, test it with the green flag (or the key or click it listens for), then compare with the solution. If your version works but looks different, that's normal: programmers solve the same problem in lots of ways.

## Warm-up: squash the frog

Remember last week's frog, with twenty blocks for three hops? Rebuild it with a `repeat (3)` loop. Put the six blocks of one hop inside the loop, and keep the `go to` above it. You should end up with nine blocks, counting the hat. Then change 3 to 6 and watch the frog cross the whole stage. (Start it at x: -220 so it has room.)

### Exercise 1: Four-way arrows

The dance party only slid left and right. Make the cat move in **all four** directions with the arrow keys, 10 steps at a time. Add a green flag script that puts the cat in the middle.

:::hint
You need five scripts: one green flag script and one for each arrow key. `change x by` moves sideways and `change y by` moves up and down, without the cat having to turn.
:::

:::solution
```scratch title="On the cat"
when green flag clicked
go to x: (0) y: (0)

when [right arrow v] key pressed
change x by (10)

when [left arrow v] key pressed
change x by (-10)

when [up arrow v] key pressed
change y by (10)

when [down arrow v] key pressed
change y by (-10)
```

Each arrow nudges the cat 10 steps that way, and holding a key keeps it going after the usual key-repeat pause. Because we used `change x by` and `change y by` instead of `move`, the cat never turns. It faces right even while it walks up.
:::

### Exercise 2: Click to spin

When you click the cat, it should spin around one full circle, smoothly, and then say "Wheee!" for 1 second.

:::hint
One full circle is 360 degrees. If each turn is 15 degrees, how many turns do you need? Put one `turn` block inside a `repeat` loop so you can watch each small turn.
:::

:::solution
360 ÷ 15 = 24, so the loop repeats 24 times.

```scratch title="On the cat"
when this sprite clicked
point in direction (90)
repeat (24)
    turn right (15) degrees
end
say [Wheee!] for (1) seconds
```

The cat spins once all the way around, ends facing right, and says "Wheee!"

Why `point in direction (90)` at the top? Click the cat twice quickly. A new click **restarts** a sprite-clicked script that's already running, so without that block the second spin would start from wherever the first one got to, and the cat would finish tilted. Pointing right first makes every spin start from the same place.

If the cat doesn't spin at all, an earlier script may have set its rotation style to `left-right`. Add `set rotation style [all around v]` at the top.
:::

### Exercise 3: Flapping bat

Add the **Bat** sprite from the library and delete the cat. When the green flag is clicked, the bat flies back and forth across the stage forever, flapping its wings the whole time. It must never fly upside down.

:::hint
One `forever` loop can do several jobs on each pass: move a little, show the next costume, and check the edge. Which Motion block stops a sprite from turning upside down?
:::

:::solution
```scratch title="On the Bat"
when green flag clicked
go to x: (0) y: (50)
set rotation style [left-right v]
point in direction (90)
forever
    move (6) steps
    next costume
    if on edge, bounce
    wait (0.05) seconds
end
```

The bat flies right, flapping, turns around at the edge, flies left, and keeps going until you click stop. Its four costumes are drawn as wing positions, so `next costume` is all the flapping takes. Try `wait (0.1) seconds` for a lazier bat.
:::

### Exercise 4: A metronome

A metronome ticks at a steady beat to help musicians keep time. Make one:

1.  Add the **Pop** sound to a sprite (Sounds tab, **Choose a Sound**).
2.  When the green flag is clicked, play Pop once every half second, forever.
3.  Make the sprite change color a little on every tick, so you can *see* the beat too.

:::hint
The `wait` block should decide the timing, not the sound. Which sound block starts a sound without making the script wait for it?
:::

:::solution
```scratch
when green flag clicked
clear graphic effects
forever
    start sound (Pop v)
    change [color v] effect by (10)
    wait (0.5) seconds
end
```

Pop, pop, pop: two ticks every second, while the sprite slowly cycles through colors. `start sound` doesn't wait, so the half-second `wait` sets the beat exactly. Try `wait (0.25) seconds` for a beat twice as fast.
:::

### Exercise 5: Day and night switch

Add two backdrops, one day and one night (like **Blue Sky** and **Stars**). Make these two things happen:

1.  **On the Stage:** clicking the stage switches to the next backdrop.
2.  **On the cat:** when the backdrop switches to night, the cat says "Good night!" for 2 seconds. When it switches to day, it says "Good morning!" for 2 seconds.

:::hint
Click the Stage button and look in its Events blocks for a hat that only the Stage has. On the cat, there's a hat that runs when the backdrop changes, no matter who changed it.
:::

:::solution
```scratch title="On the Stage"
when stage clicked
next backdrop
```

```scratch title="On the cat"
when backdrop switches to [Stars v]
say [Good night!] for (2) seconds

when backdrop switches to [Blue Sky v]
say [Good morning!] for (2) seconds
```

Click an empty part of the stage and the scene changes. The cat greets the new time of day. Notice the cat never checks *who* switched the backdrop. It just reacts to the change. Pick your own backdrop names in the dropdowns if they're different.
:::

### Exercise 6: Walk a square

Make the cat walk around a square, 200 steps on each side, and end up exactly where it started. The legs don't need to move. Here's the catch: use **two** loops, one inside the other.

:::hint
Walking one side is "move a little, many times." Then the cat turns 90 degrees. A square is four sides, so "walk a side, then turn" happens four times. Which loop goes on the outside?
:::

:::solution
```scratch
when green flag clicked
go to x: (-100) y: (-100)
point in direction (90)
repeat (4)
    repeat (10)
        move (20) steps
        wait (0.05) seconds
    end
    turn left (90) degrees
end
```

The inside loop walks one side (10 × 20 = 200 steps). The outside loop does that four times, turning after each side. The cat goes right, up, left, and down, and ends at `(-100, -100)` facing right, where it began.

On the way around, the cat tips onto its side and then upside down, because its rotation style is "all around." Add `set rotation style [don't rotate v]` at the top if you'd rather it stayed upright.
:::

### Challenge: Fish tank

Build a fish tank:

-   Use an underwater backdrop, like **Underwater 1**, and the **Fish** sprite.
-   The fish swims around forever, bouncing off the edges, without going upside down.
-   It shouldn't follow the same zigzag every time. Make it wander. (Look in **Operators** for `pick random (1) to (10)`.)
-   **At the same time**, the fish makes a bubble sound every 3 seconds. The Fish sprite already has a sound called **bubbles**.

The tricky part is timing. The swimming needs to update many times a second, but the sound only every 3 seconds. Put a `wait (3) seconds` in the swimming loop and the fish would freeze for 3 seconds at a time. So give each job its own script:

```mermaid caption="Two scripts on one fish, each with its own rhythm, running side by side"
sequenceDiagram
    participant Swim as Swimming script
    participant Bubbles as Sound script
    Note over Swim,Bubbles: green flag starts both
    par
        loop many times a second
            Swim->>Swim: move, turn a little, bounce
        end
    and
        loop every 3 seconds
            Bubbles->>Bubbles: wait, then play bubbles
        end
    end
```

:::hint
For wandering, put `turn right (pick random (-10) to (10)) degrees` inside the swimming loop. A random number between -10 and 10 means each step turns a tiny bit left or right, so the path is never the same twice.
:::

:::solution
Two green flag scripts on the same sprite. One handles swimming, the other handles sound, and neither has to wait for the other.

```scratch title="On the Fish"
when green flag clicked
go to x: (0) y: (0)
set rotation style [left-right v]
point in direction (90)
forever
    move (4) steps
    turn right (pick random (-10) to (10)) degrees
    if on edge, bounce
end

when green flag clicked
forever
    wait (3) seconds
    play sound (bubbles v) until done
end
```

The fish drifts across the tank in a wobbly path, bounces back from the walls, and never swims the same route twice. Every 3 seconds or so you hear bubbles, while the swimming carries on.

We left out `next costume` on purpose. The Fish sprite's four costumes are four *different* fish, not swimming frames, so switching them would turn your fish into a new fish every step. Open its Costumes tab to see.
:::

Save your favorite as `week2-practice.sb3`.
