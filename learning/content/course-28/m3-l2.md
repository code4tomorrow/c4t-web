---
title: "Code-along: Keyboard dance party"
summary: Build a dance party where music loops, the lights change, and you control the dancer with the keyboard and mouse.
---

Turn the music up! Today you're building a dance party. The music never stops, the backdrop flashes like party lights, and you're the DJ: press keys to make the dancer move, jump, and grow, and click it to hear it sing. It's a perfect project for practicing events, loops, and sounds, because almost every part of it uses all three.

Here's what each part will do:

| Who | Script | What it does |
| --- | --- | --- |
| Stage | music loop | plays music forever |
| Stage | lights | switches backdrops every 2 seconds |
| Cat | dance | walks in place to the beat, forever |
| Cat | arrow keys | moves left and right |
| Cat | space | jumps |
| Cat | up arrow | grows and shrinks, like a pulse |
| Cat | click | meows |

## Step 1: Set up the stage

Start a new project (**File > New**).

1.  Click **Choose a Backdrop** and add two or three party-looking backdrops (anything with lights or color works).
2.  Click the **Stage** button (bottom right), then the **Backdrops** tab. Right-click the plain white `backdrop1` and choose **delete**, so it doesn't show up in the light show.

## Step 2: The music loop

With the **Stage** still selected, open the **Sounds** tab. Click **Choose a Sound**, pick the **Loops** category, and choose a song. We used **Dance Celebrate**. Any loop works.

Now go to the **Code** tab (still on the Stage) and build this:

```scratch
when green flag clicked
forever
    play sound (Dance Celebrate v) until done
end
```

Click the green flag. Music plays, and when the song ends it starts right over. Click the stop sign to stop it.

:::warning
Use `play sound until done` here, not `start sound`. With `start sound`, the loop would start the song again thousands of times a second, all piled on top of each other. That sounds terrible!
:::

## Step 3: Party lights

Still on the Stage, add a second script. Both stage scripts will run at the same time when you click the flag.

```scratch
when green flag clicked
forever
    wait (2) seconds
    next backdrop
end
```

What happens:

```text
Music plays, and every 2 seconds the backdrop changes.
After the last backdrop, it goes back to the first one.
```

## Step 4: The dancer

Click the **cat** in the sprite pane. This first script resets the cat and then makes it dance forever:

```scratch
when green flag clicked
go to x: (0) y: (-60)
set rotation style [left-right v]
point in direction (90)
set size to (100) %
clear graphic effects
forever
    next costume
    wait (0.3) seconds
end
```

Click the green flag. The cat stands in the middle and steps in place, switching costumes about three times a second.

:::tip
Want the dance to match the music? Tap your foot to the song and change the `wait` number. Smaller numbers mean faster dancing. Try `0.25` or `0.5`.
:::

## Step 5: Dance moves with the arrow keys

Add two new scripts to the cat. Each one has its own key hat block:

```scratch
when [right arrow v] key pressed
point in direction (90)
change x by (15)

when [left arrow v] key pressed
point in direction (-90)
change x by (-15)
```

Press the arrow keys. The cat slides left and right, turning to face the way it's going. Because we set the rotation style to `left-right` in Step 4, it flips instead of turning upside down.

## Step 6: Jump!

A jump is two loops: one going up, one coming down. Add this script:

```scratch
when [space v] key pressed
repeat (10)
    change y by (10)
end
repeat (10)
    change y by (-10)
end
```

Press space. The cat rises 100 steps (10 times 10) and comes back down to exactly where it started. Both loops use the same numbers, so it always lands in the same spot.

## Step 7: The pulse move

Make the cat grow and shrink when you press the up arrow:

```scratch
when [up arrow v] key pressed
repeat (5)
    change size by (10)
end
repeat (5)
    change size by (-10)
end
```

The cat grows to 150% and back down to 100% in a quick pulse. Notice it's the same pattern as the jump: do something, then undo it the same number of times.

## Step 8: Click to sing

Last script. When you click the cat, it should meow *while* the dance keeps going:

```scratch
when this sprite clicked
change [color v] effect by (25)
start sound (Meow v)
say [Meow!] for (1) seconds
```

What happens:

```text
Click the cat: it changes color, meows, and says "Meow!" for 1 second.
The music and dancing keep going the whole time.
```

We used `start sound` here because we want the meow and the speech bubble at the same moment.

## Test the whole party

Click the green flag and try everything at once:

-   Music plays without stopping.
-   The backdrop changes every 2 seconds.
-   The cat dances in place.
-   Left and right arrows move it.
-   Space makes it jump, up arrow makes it pulse.
-   Clicking it changes its color and makes it meow.
-   The stop sign stops everything.

Now click the green flag again. The cat should go back to the middle with its normal color and size. If it doesn't, check the reset blocks at the top of Step 4.

### Common bugs

-   **No music.** The sound was added to the cat instead of the Stage, so the Stage's dropdown doesn't show it. Add the sound to the Stage, or move the music script onto the cat.
-   **The cat lands lower after each jump.** Your up and down loops don't match. Both should repeat 10 times by 10.
-   **Pressing space scrolls the web page.** Click on the stage once so Scratch catches the key presses.
-   **The cat gets bigger and bigger.** The two pulse loops don't match, or you pressed up arrow again in the middle of a pulse. The reset in Step 4 fixes it on the next green flag.

## Make it yours

-   Add a second dancer from the library with its own dance loop and keys (like `w`, `a`, and `d`).
-   Use `when backdrop switches to` on the cat to do a special move on one of the backdrops.
-   Press a key to `stop all sounds` for a dramatic pause.

Save your project as `week2-dance-party.sb3` (or **File > Save now**).
