---
title: "Practice: corner tours, frog hops, and a balloon that pops"
summary: Solve six challenges with coordinates, gliding, costumes, sizes, effects, and backdrops, then time a conversation between two sprites.
---

:::objectives
- Send a sprite to exact spots with `go to` and `glide`.
- Predict where a sprite will land by adding up `change x` and `change y` numbers.
- Use waits so quick changes are visible.
- Reset size, effects, and visibility so a project works on every run.
- Time two sprites so they take turns talking.
:::

Every exercise here uses something from this week's Notes. Build your answer first, click the green flag, and only then open the hint. Open the solution last, to compare. There's usually more than one right answer, so if yours does what the task asks, it's correct, even if it looks different from ours.

Start each exercise with a fresh project (**File > New**) unless it says otherwise.

## Warm-up: read the map

Drag the cat to each corner of the stage, one at a time, and read the **x** and **y** boxes in the sprite pane. Which corner has both numbers negative? Which has both positive? (Answer: bottom left is negative and negative, top right is positive and positive.) Now drag it until both boxes say 0. Where is it?

### Exercise 1: Center stage

Make the cat jump to the exact middle of the stage and say "Ta-da!" for 2 seconds when the green flag is clicked. Drag the cat into a corner before you test, to prove it really moves.

:::hint
The middle of the stage is the spot where x and y are both zero.
:::

:::solution
```scratch
when green flag clicked
go to x: (0) y: (0)
say [Ta-da!] for (2) seconds
```

Wherever you leave the cat, the flag sends it to `(0, 0)`, and it says "Ta-da!" for 2 seconds.
:::

### Exercise 2: Predict the landing spot

Don't build this one yet. Read it and work out, on paper or in your head, where the cat ends up:

```scratch
when green flag clicked
go to x: (-100) y: (50)
change x by (150)
change y by (-100)
change x by (-30)
```

Write down your answer as (x, y). Then build the script, click the flag, and check the x and y boxes in the sprite pane.

:::hint
Keep two running totals, one for x and one for y. `change x` only touches the x total, and `change y` only touches the y total. Start x at -100 and y at 50.
:::

:::solution
The cat lands at **(20, -50)**.

```text
x: -100 + 150 = 50, then 50 - 30 = 20
y:   50 - 100 = -50
```

The order of the blocks doesn't change the final spot here, because each block only adds to one number. It would change the *path* the cat takes, though, if you added waits to watch it.
:::

### Exercise 3: Corner tour

Make the cat visit all four corners, gliding one second to each, then come back to the middle. Use these spots so the cat stays fully on the stage:

| Corner | x | y |
| --- | --- | --- |
| top left | -200 | 140 |
| top right | 200 | 140 |
| bottom right | 200 | -140 |
| bottom left | -200 | -140 |

:::hint
Start with a `go to` that puts the cat in the middle. Then you need five `glide` blocks: four corners and the trip home.
:::

:::solution
```scratch
when green flag clicked
go to x: (0) y: (0)
glide (1) secs to x: (-200) y: (140)
glide (1) secs to x: (200) y: (140)
glide (1) secs to x: (200) y: (-140)
glide (1) secs to x: (-200) y: (-140)
glide (1) secs to x: (0) y: (0)
```

The cat slides to each corner clockwise, then back to the middle, in 5 seconds. Going the other way around is fine too, as long as it hits all four.
:::

### Exercise 4: Frog hops

Add the **Frog** sprite from the library (delete the cat, or keep it as an audience). The frog starts at x: -180, y: -100 and does three hops to the right. Each hop goes up 60, over 60, and back down 60. Make sure you can actually *see* each hop.

:::hint
`change y by` moves up and down, and `change x by` moves sideways. If the frog just slides to the right without hopping, Scratch is running the blocks too fast to see. What block slows things down?
:::

:::solution
Each hop is up, pause, over, pause, down, pause. Three hops means the same six blocks three times.

```scratch title="On the Frog"
when green flag clicked
go to x: (-180) y: (-100)
change y by (60)
wait (0.15) seconds
change x by (60)
wait (0.15) seconds
change y by (-60)
wait (0.3) seconds
change y by (60)
wait (0.15) seconds
change x by (60)
wait (0.15) seconds
change y by (-60)
wait (0.3) seconds
change y by (60)
wait (0.15) seconds
change x by (60)
wait (0.15) seconds
change y by (-60)
wait (0.3) seconds
```

The frog ends at x = 0, because -180 + 60 + 60 + 60 = 0. Without the waits, all three hops finish before the screen redraws, and the frog seems to teleport 180 steps to the right. Counting the hat, that's twenty blocks for three hops. Next week a loop will do the same job in nine.
:::

### Exercise 5: The balloon that pops

Use the **Balloon1** sprite. When the green flag is clicked:

1.  Reset it to size 50% with no effects, and make sure it's showing.
2.  Make it grow by 30 three times, with half a second between each.
3.  Make it say "Uh oh..." for 1 second.
4.  Play its **Pop** sound and make it disappear.

Click the flag a second time. The balloon must come back!

:::hint
Look at the very first thing your script does. If the balloon is hidden at the end of run one, what makes it appear on run two?
:::

:::solution
```scratch title="On Balloon1"
when green flag clicked
show
set size to (50) %
clear graphic effects
wait (0.5) seconds
change size by (30)
wait (0.5) seconds
change size by (30)
wait (0.5) seconds
change size by (30)
say [Uh oh...] for (1) seconds
start sound (Pop v)
hide
```

The balloon grows from 50% to 80%, 110%, and 140%, worries out loud, then pops and vanishes. The `show` at the top is the key: without it the balloon stays hidden forever after the first run.

We used `start sound` so the balloon disappears at the same moment the pop begins. Want a slow fade instead of a pop? Replace `hide` with three `change [ghost v] effect by (30)` blocks, each followed by a short wait.
:::

### Exercise 6: Good night

Add two backdrops: one daytime picture and one nighttime picture (for example **Blue Sky** and **Stars**). When the flag is clicked, the cat should:

1.  Start in the daytime backdrop, looking normal.
2.  Say "Time for bed!" for 2 seconds.
3.  Switch to the nighttime backdrop.
4.  Get darker, using the `brightness` effect.
5.  Think "Zzz..." for 3 seconds.

:::hint
Find `set [color v] effect to (0)` in Looks and open its dropdown. Brightness runs from -100 (black) to 100 (white). Which side means "darker"?
:::

:::solution
```scratch
when green flag clicked
switch backdrop to (Blue Sky v)
clear graphic effects
say [Time for bed!] for (2) seconds
switch backdrop to (Stars v)
set [brightness v] effect to (-40)
think [Zzz...] for (3) seconds
```

Negative brightness darkens the cat, so it looks like the lights went out. `clear graphic effects` near the top brings back the daytime cat on the next run. Try -80 for a nearly black cat.
:::

### Challenge: A two-sprite conversation

Add a second sprite (any character) and make the two of them talk, taking turns:

```text
Cat:    Hi! Who are you?
Friend: I'm new here.
Cat:    Want to explore?
Friend: Yes! Let's go!
```

Each sprite needs **its own** green flag script, and both scripts start at the same moment. That's the tricky part: while one sprite talks, the other has to stay quiet for exactly as long. Plan it with this picture first:

```mermaid caption="Who speaks when: every line lasts 2 seconds, and nobody talks over anyone"
sequenceDiagram
    participant Cat
    participant Friend
    Note over Cat,Friend: green flag clicked
    Cat->>Friend: Hi! Who are you?
    Friend->>Cat: I'm new here.
    Cat->>Friend: Want to explore?
    Friend->>Cat: Yes! Let's go!
```

:::hint
Use `say [] for (2) seconds` for every line, and the `wait () seconds` block from Control for the quiet parts. The friend's first line starts 2 seconds after the flag. How long must the cat wait between its two lines?
:::

:::solution
Every line is 2 seconds, so every quiet part is a 2-second wait.

```scratch title="On the cat"
when green flag clicked
go to x: (-120) y: (-60)
say [Hi! Who are you?] for (2) seconds
wait (2) seconds
say [Want to explore?] for (2) seconds
```

Click the friend sprite in the sprite pane, then build its script there:

```scratch title="On the friend"
when green flag clicked
go to x: (120) y: (-60)
wait (2) seconds
say [I'm new here.] for (2) seconds
wait (2) seconds
say [Yes! Let's go!] for (2) seconds
```

```text
0 seconds: Cat says "Hi! Who are you?"
2 seconds: Friend says "I'm new here."
4 seconds: Cat says "Want to explore?"
6 seconds: Friend says "Yes! Let's go!"
```

This works, but try changing the cat's first line to 3 seconds. Now the friend interrupts! Lining up waits by hand breaks every time you change a line. In Week 4 you'll learn **broadcasts**, which let one sprite tell the other "your turn" instead.
:::
