Time to try it yourself. Each challenge starts easy and gets a little harder. Build your answer first, click the green flag, and only then open the solution to compare. There's usually more than one right answer, so if yours works, it's correct!

Start each challenge with a fresh project (**File > New**) unless it says otherwise.

### Exercise 1: Center stage

Make the cat jump to the exact middle of the stage and say "Ta-da!" for 2 seconds when the green flag is clicked. Drag the cat into a corner before you test, to prove it really moves.

:::solution
The middle of the stage is x: 0, y: 0.

```scratch
when green flag clicked
go to x: (0) y: (0)
say [Ta-da!] for (2) seconds
```

What happens:

```text
The cat jumps to the middle and says "Ta-da!" for 2 seconds.
```
:::

### Exercise 2: Corner tour

Make the cat visit all four corners of the stage, gliding one second to each, and then come back to the middle. Use these spots so the cat stays fully on the stage:

-   top left: x -200, y 140
-   top right: x 200, y 140
-   bottom right: x 200, y -140
-   bottom left: x -200, y -140

:::solution
Start at the middle, then glide to each corner in order.

```scratch
when green flag clicked
go to x: (0) y: (0)
glide (1) secs to x: (-200) y: (140)
glide (1) secs to x: (200) y: (140)
glide (1) secs to x: (200) y: (-140)
glide (1) secs to x: (-200) y: (-140)
glide (1) secs to x: (0) y: (0)
```

What happens:

```text
The cat slides to each corner, clockwise, then back to the middle.
The whole trip takes 5 seconds.
```

Did yours go the other way around? That's fine too, as long as it hits all four corners.
:::

### Exercise 3: Frog hops

Add the **Frog** sprite from the library (or keep the cat). Make it start at x -180, y -100 and do three hops to the right. Each hop goes up 60, moves right 60, and comes back down 60. Add a short wait so you can see each part of the hop.

Hint: `change y by` moves up and down. `change x by` moves sideways.

:::solution
Each hop is the same four blocks. Up, over, down, pause.

```scratch
when green flag clicked
go to x: (-180) y: (-100)
change y by (60)
change x by (60)
change y by (-60)
wait (0.3) seconds
change y by (60)
change x by (60)
change y by (-60)
wait (0.3) seconds
change y by (60)
change x by (60)
change y by (-60)
wait (0.3) seconds
```

What happens:

```text
The frog makes three quick hops to the right.
It ends at x = 0, y = -100 (because -180 + 60 + 60 + 60 = 0).
```

If the hops look too fast, add `wait (0.1) seconds` after each `change y by (60)` too.
:::

### Exercise 4: The balloon that pops

Pick the **Balloon1** sprite (or any sprite). When the green flag is clicked:

1.  Reset it to size 50% with no effects.
2.  Make it grow by 30 three times, with half a second between each.
3.  Make it say "Uh oh..." for 1 second.
4.  Make it disappear with `hide`.

Make sure it shows up again the next time you click the flag!

:::solution
The reset blocks at the top are the key. Without `show`, the balloon stays hidden forever after the first run.

```scratch
when green flag clicked
show
set size to (50) %
clear graphic effects
wait (0.5) seconds
change size by (30)
wait (0.5) seconds
change size by (30)
wait (0.5) seconds
change size by (30)
say [Uh oh...] for (1) seconds
hide
```

What happens:

```text
The balloon grows from 50% to 80%, 110%, then 140%.
Bubble: "Uh oh..." (1 second)
The balloon vanishes.
```

Want a fade instead of a pop? Replace `hide` with three `change [ghost v] effect by (30)` blocks with waits in between.
:::

### Exercise 5: Good night

Add two backdrops: one daytime picture and one nighttime picture (for example **Blue Sky** and **Stars**). When the flag is clicked, the cat should:

1.  Start in the daytime backdrop, at full brightness.
2.  Say "Time for bed!" for 2 seconds.
3.  Switch to the nighttime backdrop.
4.  Get darker using the `brightness` effect.
5.  Think "Zzz..." for 3 seconds.

:::solution
The brightness effect goes from -100 (black) to 100 (white). Negative numbers make the cat darker, like it's in the dark.

```scratch
when green flag clicked
switch backdrop to (Blue Sky v)
clear graphic effects
say [Time for bed!] for (2) seconds
switch backdrop to (Stars v)
set [brightness v] effect to (-40)
think [Zzz...] for (3) seconds
```

What happens:

```text
Daytime. Bubble: "Time for bed!"
The scene turns to night, and the cat gets darker.
Thought: "Zzz..." for 3 seconds.
```
:::

### Stretch challenge: A two-sprite conversation

Add a second sprite (any character). Make the two sprites have a conversation of four lines, taking turns:

```text
Cat:    "Hi! Who are you?"
Friend: "I'm new here."
Cat:    "Want to explore?"
Friend: "Yes! Let's go!"
```

Each sprite needs **its own script**. Here's the trick: while one sprite talks, the other has to wait the same amount of time. If every line lasts 2 seconds, how long should each sprite wait before its turn?

:::solution
Each line is 2 seconds. The friend waits 2 seconds before its first line (while the cat talks), and each sprite waits 2 seconds between its own lines (while the other one talks).

Cat's script:

```scratch
when green flag clicked
go to x: (-120) y: (-60)
say [Hi! Who are you?] for (2) seconds
wait (2) seconds
say [Want to explore?] for (2) seconds
```

Friend's script (click the friend sprite first, then build this):

```scratch
when green flag clicked
go to x: (120) y: (-60)
wait (2) seconds
say [I'm new here.] for (2) seconds
wait (2) seconds
say [Yes! Let's go!] for (2) seconds
```

What happens:

```text
0 seconds: Cat says "Hi! Who are you?"
2 seconds: Friend says "I'm new here."
4 seconds: Cat says "Want to explore?"
6 seconds: Friend says "Yes! Let's go!"
```

Lining up waits like this works, but it's easy to get wrong if you change one line's time. In Week 4 you'll learn **broadcasts**, a much better way for sprites to take turns.
:::

Save your favorite answer as `week1-practice.sb3`.
