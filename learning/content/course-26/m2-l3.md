### Exercise 1: Three facts about you

Write a program that prints three lines: your name, your favorite food, and something you want to build with code someday. Each fact goes on its own line.

Expected output (with your own facts):

```text
My name is Jordan.
My favorite food is dumplings.
I want to build a video game one day.
```

:::solution
One `print()` per line of output:

```python
print("My name is Jordan.")
print("My favorite food is dumplings.")
print("I want to build a video game one day.")
```
:::

### Exercise 2: Fix the quiz

This program has **three** bugs. Copy it into IDLE, run it, and fix one error at a time.

```python
Print("Welcome to the quiz!")
print("Question 1: What is 4 + 4?)
print("Answer:", 4 + 4
```

When it works, it should print:

```text
Welcome to the quiz!
Question 1: What is 4 + 4?
Answer: 8
```

:::tip
Python checks the whole file's shape before it runs anything, so it reports `SyntaxError`s first and shows only one at a time. Fix it, run again, and see what is next.
:::

:::solution
The first run points at line 2:

```text
  File "quiz.py", line 2
    print("Question 1: What is 4 + 4?)
          ^
SyntaxError: unterminated string literal (detected at line 2)
```

Add the closing quote. The next run complains about line 3: `SyntaxError: '(' was never closed`. Add the `)`. The third run finally starts the program and stops at line 1:

```text
NameError: name 'Print' is not defined. Did you mean: 'print'?
```

Change `Print` to `print`. The fixed program:

```python
print("Welcome to the quiz!")
print("Question 1: What is 4 + 4?")
print("Answer:", 4 + 4)
```
:::

### Exercise 3: Glue text together with sep and end

Print exactly the lines below. The catch: the `-` and `@` characters must come from `sep`, and the dots must come from `end`.

```text
555-867-5309
ada@example.com
Ready... Set... Go!
```

Hint: the phone number is three separate strings, `"555"`, `"867"`, and `"5309"`. The email is two strings, `"ada"` and `"example.com"`. The last line is made by three separate `print()` calls.

:::solution
```python
print("555", "867", "5309", sep="-")
print("ada", "example.com", sep="@")
print("Ready", end="... ")
print("Set", end="... ")
print("Go!")
```

`sep="@"` puts the `@` between the two parts of the email. `end="... "` replaces the usual new line with dots and a space, so the next print continues on the same line.
:::

### Exercise 4: Draw a tree

Print this tree. The top star has four spaces in front of it, and each row has one less space and two more stars than the row above.

```text
    *
   ***
  *****
 *******
*********
   | |
```

:::solution
The straightforward way is to type each row:

```python
print("    *")
print("   ***")
print("  *****")
print(" *******")
print("*********")
print("   | |")
```

A sneakier way uses string repetition and `+`, which glues two strings together. It prints exactly the same tree:

```python
print(" " * 4 + "*" * 1)
print(" " * 3 + "*" * 3)
print(" " * 2 + "*" * 5)
print(" " * 1 + "*" * 7)
print("*" * 9)
print("   | |")
```
:::

### Exercise 5: Make it readable

Here is a program with no comments at all:

```python
print("WEATHER REPORT")
print("Monday: sunny")
print("Tuesday: rain")
print("Wednesday: snow")
print("Stay warm!")
```

Improve it:

1.  Add a header comment saying what the file does.
2.  Split it into a "Forecast" section and a "Sign-off" section, each with a comment label and a blank line before it.
3.  Comment out the Wednesday line, with a note explaining why, so it does not print.

Expected output:

```text
WEATHER REPORT
Monday: sunny
Tuesday: rain
Stay warm!
```

:::solution
```python
# weather_report.py
# Prints a three-day forecast for the class newsletter.

print("WEATHER REPORT")

# ----- Forecast -----
print("Monday: sunny")
print("Tuesday: rain")
# print("Wednesday: snow")  # forecast not confirmed yet

# ----- Sign-off -----
print("Stay warm!")
```

The comment after the Wednesday line explains *why* it is turned off, which is far more useful than just hiding it.
:::

### Exercise 6: Snack-bar receipt (stretch challenge)

Print a receipt for a pretzel ($3), a lemonade ($2), and two cookies ($2 each). The rules:

-   Python must calculate the cookie price and the total. Do not type `4` or `9` yourself.
-   No space between the `$` and the price.
-   Borders are made with string repetition.
-   "Thanks!" and "Come back soon." must come from **one** `print()` call but appear on two lines.

Expected output:

```text
======================
    C4T SNACK BAR
======================
Pretzel        $3
Lemonade       $2
Cookie x2      $4
----------------------
TOTAL          $9
======================
Thanks!
Come back soon.
```

:::solution
```python
# receipt.py
# Prints a snack-bar receipt. Python does the math.

print("=" * 22)
print("    C4T SNACK BAR")
print("=" * 22)
print("Pretzel        $", 3, sep="")
print("Lemonade       $", 2, sep="")
print("Cookie x2      $", 2 * 2, sep="")
print("-" * 22)
print("TOTAL          $", 3 + 2 + 2 * 2, sep="")
print("=" * 22)
print("Thanks!", "Come back soon.", sep="\n")
```

`sep=""` removes the space `print()` would normally add between `$` and the number. The spaces inside each label string line the prices up in one column. In the last line, `sep="\n"` puts a new line between the two strings instead of a space.
:::
