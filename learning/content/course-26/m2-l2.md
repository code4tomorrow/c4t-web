The Riverside Animal Shelter needs a poster for its adoption day, and you are going to print one entirely with Python. By the end you will have a 30-line program with a border, a cat drawn in text characters, pet details, and event info, all organized with comments. Make a new file in IDLE and save it as `week1/adoption_poster.py` before you start.

## Step 1: Plan with comments

Good programmers often write the plan before the code. Type these comments first. They do nothing when run, but they give your file a shape to fill in.

```python
# adoption_poster.py
# Prints a poster for an animal shelter's adoption day.
# Week 1 code-along: practice print(), sep, end, and comments.

# ----- Top border and title -----

# ----- Picture -----

# ----- About the pet -----

# ----- Event details -----

# ----- Bottom border -----
```

Press **F5**. Nothing prints, and that is correct: a file of only comments is a program that does nothing.

## Step 2: Border and title

Under the "Top border and title" comment, add the first three lines of the poster.

```python
print("*" * 32)
print("*      ADOPT A FRIEND!         *")
print("*" * 32)
```

```text
********************************
*      ADOPT A FRIEND!         *
********************************
```

`"*" * 32` repeats the star 32 times so you do not have to type them all. The middle line is also exactly 32 characters wide, which is why the box lines up. If your right edge looks crooked, count the spaces on either side of the title.

## Step 3: Draw the cat (and meet the backslash)

Under "Picture", you might try this:

```python
print(" /\_/\ ")
```

Save that single line in a scratch file called `ears.py` and run it. It does print the cat's ears, but Python also complains:

```text
ears.py:1: SyntaxWarning: invalid escape sequence '\_'
  print(" /\_/\ ")
 /\_/\ 
```

Remember `\n` from the Notes? Inside a string, a backslash `\` starts a special code. Python sees `\_`, does not recognize it, and warns you. To print a real backslash, type **two** of them: `\\`. Here is the fixed picture:

```python
print("    /\\_/\\")
print("   ( o.o )")
print("    > ^ <")
```

```text
    /\_/\
   ( o.o )
    > ^ <
```

Add a `print()` before and after the picture to give it breathing room.

## Step 4: About the pet

Now the details. Commas let you mix text and numbers in one line.

```python
print("Name:", "Biscuit")
print("Age:", 2, "years")
print("Likes:", "naps", "boxes", "tuna", sep=" | ")
```

```text
Name: Biscuit
Age: 2 years
Likes: | naps | boxes | tuna
```

The last line has a stray bar after `Likes:`. That is because `sep` goes between **every** item, including the label. The fix is to print the label on its own with `end=" "` so the next print continues on the same line:

```python
print("Likes:", end=" ")
print("naps", "boxes", "tuna", sep=" | ")
```

```text
Likes: naps | boxes | tuna
```

Bugs like this are normal. You ran the code, looked at the output, noticed it was not quite right, and fixed it. That loop is the heart of programming.

## Step 5: Event details

Combine `sep` and `end` to build the date line in two pieces:

```python
print("Saturday", "Nov", "21", sep=" - ", end="")
print(" @ 10am")
print("Riverside Animal Shelter")
```

```text
Saturday - Nov - 21 @ 10am
Riverside Animal Shelter
```

The first print uses `end=""`, so the time from the second print lands on the same line.

## Step 6: The finished program

Add a bottom border, and your whole file should look like this:

```python
# adoption_poster.py
# Prints a poster for an animal shelter's adoption day.
# Week 1 code-along: practice print(), sep, end, and comments.

# ----- Top border and title -----
print("*" * 32)
print("*      ADOPT A FRIEND!         *")
print("*" * 32)
print()

# ----- Picture -----
# Each backslash is doubled so Python prints one real backslash.
print("    /\\_/\\")
print("   ( o.o )")
print("    > ^ <")
print()

# ----- About the pet -----
print("Name:", "Biscuit")
print("Age:", 2, "years")
print("Likes:", end=" ")
print("naps", "boxes", "tuna", sep=" | ")
print()

# ----- Event details -----
print("Saturday", "Nov", "21", sep=" - ", end="")
print(" @ 10am")
print("Riverside Animal Shelter")
print()

# ----- Bottom border -----
print("=" * 32)
```

Run it with **F5**:

```text
********************************
*      ADOPT A FRIEND!         *
********************************

    /\_/\
   ( o.o )
    > ^ <

Name: Biscuit
Age: 2 years
Likes: naps | boxes | tuna

Saturday - Nov - 21 @ 10am
Riverside Animal Shelter

================================
```

Read your file from top to bottom. Thanks to the section comments, anyone could find the part that prints the date in a couple of seconds, even without running it.
