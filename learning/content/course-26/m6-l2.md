title: "Code-along: To-Do List Manager"
summary: Build a menu-driven to-do list app that adds, shows, and checks off tasks stored in a Python list.
---

Apps like Google Tasks are built around the same idea as a Python list: an ordered group of items you can add to, read, and remove from. In this code-along you'll build a small to-do app that runs in the IDLE Shell. It shows a menu, the user types a letter, and the program changes the list to match. When the user quits, it reports what they got done.

You'll use a list, `append`, `len()`, indexes, `for` loops over a list, and a `while True` loop with `break`. Create a new file called `todo.py`.

## Step 1: Show a list with numbers

Start with a few tasks already in the list so there's something to look at:

```python
tasks = ["finish math homework", "feed the cat", "practice piano"]

for i in range(len(tasks)):
    print(str(i + 1) + ".", tasks[i])
```

```text
1. finish math homework
2. feed the cat
3. practice piano
```

`range(len(tasks))` gives the indexes 0, 1, 2. We print `i + 1` because people count from 1, even though Python counts from 0. Keep this in mind for Step 4.

## Step 2: A menu that repeats

An app should keep running until the user decides to stop. `while True` repeats forever, and `break` gets us out when the user types `q`. Replace everything in your file with this:

```python
tasks = []

while True:
    print()
    print("a = add, q = quit")
    choice = input("Choose: ")

    if choice == "a":
        task = input("New task: ")
        tasks.append(task)
        print("Added:", task)
    elif choice == "q":
        print("Bye!")
        break
    else:
        print("Please type a or q.")
```

Test all three paths: a real choice, a wrong letter, and quitting.

```text

a = add, q = quit
Choose: a
New task: walk dog
Added: walk dog

a = add, q = quit
Choose: x
Please type a or q.

a = add, q = quit
Choose: q
Bye!
```

`print()` with nothing inside prints a blank line, so each menu is easier to read. Now the list starts empty (`[]`) and grows with `append`.

:::tip
Always include an `else` for "none of the above". Without it, a typo like `x` does nothing at all, and the user can't tell whether the app is broken.
:::

## Step 3: Show the tasks

Add a new `elif` branch for `s`. If the list is empty, a friendly message is better than printing nothing:

```python
    elif choice == "s":
        if len(tasks) == 0:
            print("Nothing to do. Nice!")
        else:
            for i in range(len(tasks)):
                print(str(i + 1) + ".", tasks[i])
```

Watch the indentation here. The `elif` lines up with `if choice == "a":`, and the `for` loop sits inside the `else`. Update the menu line to `"a = add, s = show, q = quit"` too.

## Step 4: Check off a task

To remove an item by position, use `pop` with an index. `tasks.pop(1)` removes the item at index 1 and gives it back, so you can print it.

The user sees task **2**, but that's index **1**. That's why we `pop(number - 1)`. We also check the number is in range first, because `tasks.pop(7)` on a three-item list crashes with an `IndexError`.

```python
    elif choice == "d":
        number = int(input("Which task number is done? "))
        if number >= 1 and number <= len(tasks):
            finished = tasks.pop(number - 1)
            print("Finished:", finished)
        else:
            print("There is no task number", number)
```

## Step 5: Keep score and say goodbye

A second list, `done`, collects finished tasks. Each time you `pop` from `tasks`, `append` the same item to `done`. When the user quits, loop over `done` to celebrate.

Here's the finished program:

```python
tasks = []
done = []

print("=== My To-Do List ===")
while True:
    print()
    print("a = add, s = show, d = done, q = quit")
    choice = input("Choose: ")

    if choice == "a":
        task = input("New task: ")
        tasks.append(task)
        print("Added:", task)

    elif choice == "s":
        if len(tasks) == 0:
            print("Nothing to do. Nice!")
        else:
            for i in range(len(tasks)):
                print(str(i + 1) + ".", tasks[i])

    elif choice == "d":
        number = int(input("Which task number is done? "))
        if number >= 1 and number <= len(tasks):
            finished = tasks.pop(number - 1)
            done.append(finished)
            print("Finished:", finished)
        else:
            print("There is no task number", number)

    elif choice == "q":
        print("You finished", len(done), "tasks today:")
        for task in done:
            print("  *", task)
        print("Still to do:", len(tasks))
        break

    else:
        print("Please type a, s, d, or q.")
```

A full test run. The user adds three tasks, shows them, finishes task 2, tries a task number that doesn't exist, shows the list again, and quits:

```text

a = add, s = show, d = done, q = quit
Choose: a
New task: finish math homework
Added: finish math homework

a = add, s = show, d = done, q = quit
Choose: a
New task: feed the cat
Added: feed the cat

a = add, s = show, d = done, q = quit
Choose: a
New task: practice piano
Added: practice piano

a = add, s = show, d = done, q = quit
Choose: s
1. finish math homework
2. feed the cat
3. practice piano

a = add, s = show, d = done, q = quit
Choose: d
Which task number is done? 2
Finished: feed the cat

a = add, s = show, d = done, q = quit
Choose: d
Which task number is done? 7

a = add, s = show, d = done, q = quit
```

Look at the second `s`. After "feed the cat" was popped, "practice piano" moved up from number 3 to number 2. Lists close up the gap when an item is removed.

## Things to test (and what breaks)

-   Type `s` before adding anything. You should see "Nothing to do. Nice!"
-   Type `d`, then `0` or `-1`. The range check should catch both.
-   Type `d`, then `two`. This one crashes with a `ValueError`, because `int()` can't convert a word. Next week you'll learn to read that error and write a function that keeps asking until it gets a number.
