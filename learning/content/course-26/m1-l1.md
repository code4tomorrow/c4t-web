title: Install Python 3 and IDLE
summary: Install Python 3 and its IDLE editor on Windows, macOS, or a Chromebook, then confirm the install with one line of code.
---

Before the first live class you need two things on your computer: **Python 3**, the program that reads and runs Python code, and **IDLE**, the small editor that comes with it. IDLE is where you will type, save, and run every program in this course. It is plain on purpose: no plugins, no settings to break, and it shows your errors clearly.

The good news is that installing Python also installs IDLE. You only download one thing. Plan for about 15 minutes, and do it before class so we can start coding on day one.

## Before you start

-   You need a Windows PC, a Mac, or a Chromebook that lets you turn on Linux. Phones and tablets will not work for this class.
-   You need permission to install software. On a school-managed laptop that may be blocked, so check early and tell your instructor if it is.
-   Always download Python from **python.org**, the official site. Other "free Python" download sites sometimes bundle junk software.

## Windows

1.  Go to [python.org/downloads](https://www.python.org/downloads/) and click the big yellow **Download Python** button. The site detects Windows for you.
2.  Open the file you downloaded (it will be in your Downloads folder).
3.  Follow the prompts:
    -   Newer releases install through the **Python install manager**. If a black window opens and asks questions, type `y` and press Enter to say yes to installing the latest Python and to the PATH question.
    -   If you see the classic installer screen instead, tick the box **Add python.exe to PATH** at the bottom *before* clicking **Install Now**.
4.  When it finishes, click the **Start** button and type `IDLE`. You should see an app called something like **IDLE (Python 3.15)**. Pin it to your taskbar so it is easy to find.

:::warning
On the classic installer, forgetting the **Add python.exe to PATH** box is the most common Windows mistake. IDLE still works without it, but typing `python` in a terminal will fail. If you missed it, run the installer again and choose **Modify** to add it.
:::

## macOS

1.  Go to [python.org/downloads](https://www.python.org/downloads/) and click **Download Python** to get the macOS installer (a `.pkg` file).
2.  Open it and click **Continue**, **Agree**, and **Install**. Enter your Mac password when asked.
3.  When it finishes, a Finder window opens showing a folder named **Python 3.x** inside **Applications**. IDLE lives there.
4.  Drag **IDLE** to your Dock so you can open it with one click.

:::tip
Your Mac may already have a `python3` command from Apple's developer tools. Ignore it. For this class, always open IDLE from the **Applications → Python 3.x** folder so everyone is using the same, current version.
:::

## Chromebook

Chromebooks run Python through the built-in Linux environment.

1.  Open **Settings**, go to **About ChromeOS → Developers**, find **Linux development environment**, and click **Set up**. Accept the defaults. This takes a few minutes.
2.  A **Terminal** window opens when setup finishes. Type these two commands, pressing Enter after each one:

```bash
sudo apt update
sudo apt install -y python3 idle3
```

3.  Open your app launcher and look in the **Linux apps** folder for **IDLE**. If it is not there yet, you can start it from the Terminal:

```bash
python3 -m idlelib
```

:::warning
If you do not see **Linux development environment** in Settings, your school or family account has probably turned it off. Tell your instructor before the first class so we can sort out another computer.
:::

## Check that it worked

Open IDLE. The window that appears is called the **Shell**. Its first line shows your Python version, and below that is a prompt that looks like `>>>`. Click after the prompt, type this line exactly, and press Enter:

```python
print("I installed Python!")
```

Python answers right away:

```text
I installed Python!
```

Now try some math. Type each line after the `>>>` prompt and press Enter:

```python
7 + 5
10 * 3
```

The Shell shows each answer on its own line:

```text
12
30
```

If you saw those results, you are ready. The exact version number in the first line does not matter much: anything starting with **3** is fine, and 3.12 or newer is ideal.

## What usually goes wrong

-   **You typed the `>>>` yourself.** The prompt is already there. Type only the code after it.
-   **You see `NameError: name 'Print' is not defined`.** Python cares about capital letters. It is `print`, all lowercase. Newer versions even add a hint: `Did you mean: 'print'?`
-   **You see `SyntaxError`.** Check that both quote marks and both parentheses are there: `print("...")`.
-   **You opened Python but not IDLE.** On Windows, an app named just **Python 3.x** opens a black window with no menus. That is not IDLE. Look for the one with **IDLE** in its name.
-   **A Python 2 version shows up.** Very old computers sometimes have Python 2. Close it and install Python 3 from python.org as described above.

Bring your working setup to the first class. If you get stuck anywhere on this page, write down the exact error message (or take a screenshot) and share it with your instructor. A precise error message is the fastest way for someone to help you.
