:::objectives
- Download Python 3 from python.org and install it on Windows, macOS, or a Chromebook.
- Find and open IDLE, the editor we use in every class.
- Run a one-line test in the IDLE Shell and recognize a working setup.
- Fix the setup problems that catch most new students.
:::

The first ten minutes of week 1 always split the room in two. Half the class types `print("hi")`, sees `hi` appear, and starts coding. The other half is watching a download bar crawl across the screen. This page exists so you end up in the first half.

You are installing two things, and one download gives you both. **Python 3** is the interpreter: the program that reads your code and carries out each line. **IDLE** is the small editor that ships with Python. You will write, save, and run every program for this class in it. IDLE looks plain because it is plain. There are no plugins to set up and no settings to break, and when your code has a mistake, IDLE points straight at it.

Budget about 15 minutes, and do it before the first class.

## Three checks before you download

-   **The right kind of computer.** A Windows 10 or 11 PC, a Mac, or a Chromebook that allows Linux. Phones and tablets can't run IDLE.
-   **Permission to install.** School-managed laptops often block new software. Find out now, not five minutes before class, and tell your instructor if you're blocked.
-   **The real download site.** Get Python only from **python.org**. Lookalike "free Python download" sites sometimes bundle junk software with it.

## Install it, step by step

Pick the tab for your computer.

:::tabs
@tab Windows
1.  Go to [python.org/downloads](https://www.python.org/downloads/) and click the yellow **Download Python** button. The site detects Windows for you.
2.  Open the file you downloaded. It will be in your **Downloads** folder.
3.  What you see next depends on the release:
    -   Recent releases set up the **Python install manager**. Click **Install** if Windows asks. A black terminal window may then ask a few yes/no questions, such as whether to add a folder to your PATH or install the latest Python now. Type `y` and press **Enter** for each one.
    -   If you get the classic installer instead (a window with an **Install Now** button), tick **Add python.exe to PATH** at the bottom *first*, then click **Install Now**.
4.  Click **Start** and type `IDLE`. Open the app named something like **IDLE (Python 3.15)**. Right-click it and choose **Pin to taskbar** so you can find it on class day.

If no IDLE app shows up in Start, open **Terminal** (or **Command Prompt**), type the line below, and press Enter. It starts IDLE directly.

```powershell
python -m idlelib
```
@tab macOS
1.  Go to [python.org/downloads](https://www.python.org/downloads/) and click **Download Python**. You get a `.pkg` installer file.
2.  Open it and click through **Continue**, **Agree**, and **Install**. Type your Mac password when asked.
3.  When it finishes, Finder opens a folder named **Python 3.x** inside **Applications**. IDLE lives there.
4.  Drag **IDLE** onto your Dock so it's one click away.

Your Mac may already have a `python3` command that came with Apple's developer tools. Ignore it. Always open IDLE from **Applications › Python 3.x**, so you're running the same current version as the rest of the class.
@tab Chromebook
1.  Open **Settings**, then go to **About ChromeOS › Developers**. Next to **Linux development environment**, click **Set up** and accept the defaults. Google says this can take 10 minutes or more, so start it well before class.
2.  A **Terminal** window opens when setup is done. Type these two commands, pressing Enter after each one. Both print lots of text while they work, which is normal.

```bash
sudo apt update
sudo apt install -y python3 idle
```

3.  Open the app launcher and look for **IDLE**. Linux apps usually land together in a folder named **Linux apps**. If it isn't there yet, start it from the Terminal instead:

```bash
python3 -m idlelib
```

If you can't find **Linux development environment** in Settings at all, your school or family account has turned it off. Tell your instructor before class so we can sort out another computer.
:::

## What success looks like

Open IDLE. The window that appears is the **Shell**. Its first line names your Python version, and below that sits a prompt: `>>>`. The prompt means "I'm listening." Click after it, type this line exactly, and press Enter:

```python
print("I installed Python!")
```

Python answers on the very next line. Then try a little math, one line at a time. The Shell works out each answer and shows it immediately, so a full session looks like this:

```text
>>> print("I installed Python!")
I installed Python!
>>> 7 + 5
12
>>> 2 ** 100
1267650600228229401496703205376
```

That last line is 2 multiplied by itself 100 times. A calculator gives up and shows you an approximation; Python prints every digit.

If your screen matches, you're ready for class. The exact version number doesn't matter much: anything starting with **3** works, and 3.12 or newer is ideal.

:::note
The Shell forgets everything when you close it. That's fine for a quick test. In the next lesson you'll write programs in files that you can save and reopen.
:::

## Fixes for the problems students actually hit

**You typed the `>>>` yourself.** The prompt is already on screen, so typing another one confuses Python. It stops with `SyntaxError: invalid syntax` and points at the extra arrows. Type only what comes after the prompt.

**You typed `Print` with a capital P.** Python treats capital and lowercase letters as different, so `Print` is a name it has never heard of. Here is the real message, including the hint newer versions add:

```python run raises
Print("I installed Python!")
```

The last line is the one to read: `print` must be all lowercase.

**You opened plain Python, not IDLE.** On Windows there's also an app named just **Python 3.x**. It opens a black window with no menus. That works for one-line tests but it isn't IDLE, and it can't save files. Close it and open the app with **IDLE** in its name.

**`python` is "not recognized" in a terminal on Windows.** This only matters if you start IDLE from a terminal. Try `py` instead of `python`. If that fails too, run the installer again: on the classic installer choose **Modify** and add Python to PATH, and on the install manager answer `y` to the PATH question.

:::warning
A Chromebook that says `Unable to locate package` after `sudo apt install` usually missed the first command. Run `sudo apt update` again, wait for it to finish, then repeat the install line.
:::

If you're still stuck, write down the exact error message (or take a screenshot) and what you clicked just before it appeared. Send that to your instructor before the first class. "It doesn't work" takes twenty minutes to diagnose; a screenshot of the error usually takes one.
