Suppose you're keeping track of the quiz scores for a class of 25. You could make `score1`, `score2`, ... all the way to `score25`, but then working out the average means typing 25 variable names, and a 26th student breaks your program. A **list** fixes this. It's one variable that holds many values, in order.

## Making a list

Put the items in square brackets, separated by commas:

```python
snacks = ["chips", "apples", "popcorn", "pretzels"]
print(snacks)
print(snacks[0])
print(snacks[2])
print(snacks[-1])
print("We have", len(snacks), "snacks.")
```

```text
['chips', 'apples', 'popcorn', 'pretzels']
chips
popcorn
pretzels
We have 4 snacks.
```

A list can hold strings, numbers, Booleans, or a mix. `[]` is an **empty list** with nothing in it yet.

## Indexes start at 0

Each item has a position number called its **index**. Python counts from 0, the same way `range()` does:

| Index | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| Item | `"chips"` | `"apples"` | `"popcorn"` | `"pretzels"` |
| Negative index | -4 | -3 | -2 | -1 |

-   `snacks[0]` is the **first** item.
-   `snacks[-1]` is the **last** item, whatever the length. `-2` is second to last.
-   `len(snacks)` is the number of items, 4 here. The last index is always `len(snacks) - 1`.

### What happens when you go too far

```python
snacks = ["chips", "apples", "popcorn"]
print(snacks[3])
```

```text
Traceback (most recent call last):
  File "/Users/you/snacks.py", line 2, in <module>
    print(snacks[3])
          ~~~~~~^^^
IndexError: list index out of range
```

There are three snacks, so the indexes are 0, 1, and 2. Index 3 doesn't exist. When you see `IndexError`, check whether you forgot that counting starts at 0.

:::tip
The file path in an error message will show where *your* file is saved. Older versions of Python don't print the `~~~^^^` line. It's only there to point at the part of the line that caused the problem.
:::

## Changing a list

Unlike a string, a list can be changed after you make it. Here are the moves you'll use most:

| Code | What it does |
| --- | --- |
| `snacks[1] = "grapes"` | replace the item at index 1 |
| `snacks.append("cookies")` | add to the end |
| `snacks.insert(0, "carrots")` | add at index 0 and shift the rest over |
| `snacks.remove("chips")` | remove the first `"chips"` it finds |
| `snacks.pop()` | remove the last item and give it back to you |
| `"popcorn" in snacks` | `True` if the item is in the list |

```python
snacks = ["chips", "apples", "popcorn", "pretzels"]
snacks[1] = "grapes"
snacks.append("cookies")
snacks.insert(0, "carrots")
print(snacks)

snacks.remove("chips")
last = snacks.pop()
print("Removed", last)
print(snacks)

if "popcorn" in snacks:
    print("Popcorn is on the list!")
```

```text
['carrots', 'chips', 'grapes', 'popcorn', 'pretzels', 'cookies']
Removed cookies
['carrots', 'grapes', 'popcorn', 'pretzels']
Popcorn is on the list!
```

:::warning
`snacks.remove("pizza")` crashes with `ValueError` if `"pizza"` isn't in the list. Check first with `if "pizza" in snacks:`.
:::

## Looping over a list

A `for` loop hands you each item in order. You don't need indexes at all:

```python
scores = [88, 92, 75, 100, 64]

for score in scores:
    print("Score:", score)

total = 0
for score in scores:
    total = total + score
print("Average:", total / len(scores))
print("Highest:", max(scores), "Lowest:", min(scores), "Sum:", sum(scores))
```

```text
Score: 88
Score: 92
Score: 75
Score: 100
Score: 64
Average: 83.8
Highest: 100 Lowest: 64 Sum: 419
```

The average uses `len(scores)` instead of the number 5, so it still works if you add a sixth score. Python also has the built-in functions `sum()`, `max()`, and `min()` for lists of numbers. Writing the total loop yourself first, though, shows you what `sum()` is doing for you.

### Looping with indexes

Sometimes you need the position as well as the item, for example to number a list. `range(len(chores))` gives you every valid index:

```python
chores = ["dishes", "laundry", "walk the dog"]
for i in range(len(chores)):
    print(str(i + 1) + ".", chores[i])
```

```text
1. dishes
2. laundry
3. walk the dog
```

We print `i + 1` so people see 1, 2, 3, even though Python is using 0, 1, 2 behind the scenes.

## Updating every item

This trips up almost everyone the first time. Read both loops and guess what each one prints before you look at the output:

```python
prices = [2.0, 3.5, 1.25]

for price in prices:
    price = price * 2
print("After the first loop:", prices)

for i in range(len(prices)):
    prices[i] = prices[i] * 2
print("After the second loop:", prices)
```

```text
After the first loop: [2.0, 3.5, 1.25]
After the second loop: [4.0, 7.0, 2.5]
```

In the first loop, `price` is a *copy* of each value. Doubling the copy leaves the list alone. To change the list itself, you have to assign to `prices[i]`, and that means looping over the indexes.

## Building a list as you go

Start with an empty list and `append` inside a loop. This program keeps asking until the user presses Enter without typing anything, which gives back an empty string `""`:

```python
friends = []
name = input("Friend's name (blank to finish): ")
while name != "":
    friends.append(name)
    name = input("Friend's name (blank to finish): ")

print("You invited", len(friends), "friends:")
for friend in friends:
    print("-", friend)
```

```text
Friend's name (blank to finish): Maya
Friend's name (blank to finish): Luis
Friend's name (blank to finish): Priya
Friend's name (blank to finish):
You invited 3 friends:
- Maya
- Luis
- Priya
```

## Common mistakes

-   **Off by one:** the last item is `my_list[len(my_list) - 1]`, not `my_list[len(my_list)]`.
-   **Round brackets:** `snacks(0)` gives a `TypeError`. Use square brackets: `snacks[0]`.
-   **Forgetting the dot:** it's `snacks.append("x")`, not `append(snacks, "x")`.
-   **Changing the loop variable** and expecting the list to change. Use `my_list[i] = ...` instead.
