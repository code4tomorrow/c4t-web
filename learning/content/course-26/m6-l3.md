These exercises use the list skills from this week: indexes, `len()`, `append`, looping over items, and changing items by index. They start with a quick warm-up and finish with programs that use loops, conditions, and lists all together. Type each one yourself rather than pasting. Typing is how your fingers learn where the brackets and colons go.

:::tip
If a list isn't doing what you expect, `print()` the whole list in the middle of your program. Seeing `[71.0, 80.5, 64.0]` tells you much more than guessing.
:::

### Exercise 1: Favorite foods

Make a list of your three favorite foods. Print the first one, the last one (use a negative index), and how many foods are in the list.

:::solution
```python
foods = ["tacos", "ramen", "mango"]
print("First:", foods[0])
print("Last:", foods[-1])
print("I listed", len(foods), "foods.")
```

```text
First: tacos
Last: mango
I listed 3 foods.
```

`foods[-1]` still gives the last item if you add a fourth food later. `foods[2]` would not.
:::

### Exercise 2: Receipt

You have `prices = [4.50, 12.00, 3.25, 8.75]`. Using **one** loop, and without `sum()` or `max()`, work out the total and the most expensive item.

:::solution
Track two things at once. `biggest` starts as the first price, and the loop replaces it whenever it finds something larger.

```python
prices = [4.50, 12.00, 3.25, 8.75]

total = 0
biggest = prices[0]
for price in prices:
    total = total + price
    if price > biggest:
        biggest = price

print("Total:", total)
print("Most expensive:", biggest)
```

```text
Total: 28.5
Most expensive: 12.0
```

Why not start `biggest` at 0? It works here, but if every value were negative (like temperatures in winter), 0 would wrongly "win". Starting with a real item from the list is always safe.
:::

### Exercise 3: Who passed?

Given `scores = [72, 55, 90, 68, 100, 70, 43]`, count how many scores are 70 or higher and print `4 out of 7 students passed.` Don't type the 7 yourself.

:::solution
```python
scores = [72, 55, 90, 68, 100, 70, 43]

passing = 0
for score in scores:
    if score >= 70:
        passing = passing + 1

print(passing, "out of", len(scores), "students passed.")
```

```text
4 out of 7 students passed.
```

Use `>=`, not `>`. The 70 counts as passing.
:::

### Exercise 4: Weather report

Ask for five daily high temperatures (they can have decimals) and store them in a list. Then print the list, the average rounded to 1 decimal place, the hottest temperature, and how many days were above average.

:::solution
```python
temps = []
for day in range(1, 6):
    temp = float(input("Day " + str(day) + " high temperature: "))
    temps.append(temp)

average = sum(temps) / len(temps)
warm_days = 0
for temp in temps:
    if temp > average:
        warm_days = warm_days + 1

print("Temperatures:", temps)
print("Average:", round(average, 1))
print("Hottest:", max(temps))
print("Days above average:", warm_days)
```

```text
Day 1 high temperature: 71
Day 2 high temperature: 80.5
Day 3 high temperature: 64
Day 4 high temperature: 90
Day 5 high temperature: 77
Temperatures: [71.0, 80.5, 64.0, 90.0, 77.0]
Average: 76.5
Hottest: 90.0
Days above average: 3
```

You need two loops here. You can't know which days are above average until you've collected every temperature.
:::

### Exercise 5: Ten percent off

A store is having a sale. Change every price in `prices = [20.0, 15.0, 9.99, 42.5]` to 90% of what it was, rounded to 2 decimal places. You must change the list itself, not print new numbers.

:::solution
```python
prices = [20.0, 15.0, 9.99, 42.5]

for i in range(len(prices)):
    prices[i] = round(prices[i] * 0.9, 2)

print("Sale prices:", prices)
```

```text
Sale prices: [18.0, 13.5, 8.99, 38.25]
```

If you wrote `for price in prices: price = price * 0.9`, the list didn't change. That loop only updates a copy. Assigning to `prices[i]` is what changes the list.
:::

### Exercise 6: Find your spot in line

`lineup = ["Ava", "Ben", "Chloe", "Dev", "Eli"]`. Ask for a name. If it's in the list, print its position counting from 1. If not, say so.

:::solution
A **flag** variable remembers whether something happened during the loop.

```python
lineup = ["Ava", "Ben", "Chloe", "Dev", "Eli"]
name = input("Who are you looking for? ")

found = False
for i in range(len(lineup)):
    if lineup[i] == name:
        print(name, "is number", i + 1, "in line.")
        found = True

if not found:
    print(name, "is not in line.")
```

```text
Who are you looking for? Chloe
Chloe is number 3 in line.
```

```text
Who are you looking for? Zara
Zara is not in line.
```

The "not in line" message has to come *after* the loop. If you put it in an `else` inside the loop, it would print once for every name that doesn't match.
:::

## Stretch challenge: Lunch vote

The class voted on a party lunch:

```python
votes = ["pizza", "tacos", "pizza", "sushi", "tacos", "pizza", "salad"]
```

1.  Build a new list `unique` with each option only once, in the order it first appears.
2.  Print how many repeat votes were left out.
3.  Print how many votes each option got.

Hint: `not in` is the opposite of `in`. For part 3, try putting one loop inside another.

:::solution
```python
votes = ["pizza", "tacos", "pizza", "sushi", "tacos", "pizza", "salad"]

unique = []
for vote in votes:
    if vote not in unique:
        unique.append(vote)

print("Options:", unique)
print("Removed", len(votes) - len(unique), "repeats.")

for option in unique:
    count = 0
    for vote in votes:
        if vote == option:
            count = count + 1
    print(option, "got", count, "votes")
```

```text
Options: ['pizza', 'tacos', 'sushi', 'salad']
Removed 3 repeats.
pizza got 3 votes
tacos got 2 votes
sushi got 1 votes
salad got 1 votes
```

The outer loop picks one option, and the inner loop counts it through the whole `votes` list. `count = 0` sits inside the outer loop so every option starts counting from zero. Lists also have a built-in shortcut, `votes.count("pizza")`, but now you know how it works.
:::
