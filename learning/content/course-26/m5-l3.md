The best way to get comfortable with loops is to write lots of small ones. Do these in order, since each one builds on a skill from the one before. Make a new IDLE file for each exercise, run it, and compare what you see with the expected output. Only open the solution once you've given it a real try. Ten minutes stuck teaches you more than ten seconds of reading an answer.

:::tip
When a loop doesn't do what you expect, add a `print()` inside the loop body that shows your variables, like `print("i is", i, "total is", total)`. Watching the values change one iteration at a time usually shows you the bug right away.
:::

### Exercise 1: Cheer squad

Print the even numbers from 2 to 20, one per line, then print `Who do we appreciate?`. Use a single `range()` with three numbers, and don't use `if`.

Expected output (shortened):

```text
2
4
6
...
20
Who do we appreciate?
```

:::solution
The third number in `range()` is the step. Start at 2 and add 2 each time. Stop *before* 21 so that 20 is included.

```python
for n in range(2, 21, 2):
    print(n)
print("Who do we appreciate?")
```

The last `print` isn't indented, so it runs once after the loop finishes.
:::

### Exercise 2: Times table

Ask the user for a number and print its times table from 1 to 10.

```text
Which times table? 7
7 x 1 = 7
7 x 2 = 14
...
7 x 10 = 70
```

:::solution
```python
n = int(input("Which times table? "))
for i in range(1, 11):
    print(n, "x", i, "=", n * i)
```

Running it with 7 prints:

```text
Which times table? 7
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
```

`range(1, 11)` gives 1 through 10. A common mistake is `range(10)`, which starts at 0 and ends at 9.
:::

### Exercise 3: Add it all up

Ask for a number `n` and print the sum 1 + 2 + 3 + ... + n. Check that 100 gives `5050`.

:::solution
This is the accumulator pattern. Start the total at 0 *before* the loop and add to it inside.

```python
n = int(input("Add up 1 to what number? "))
total = 0
for i in range(1, n + 1):
    total = total + i
print("The total is", total)
```

```text
Add up 1 to what number? 100
The total is 5050
```

We write `n + 1` because `range` stops before its second number. With `range(1, n)` you'd get 4950, because 100 itself would be left out.
:::

### Exercise 4: Three strikes

The secret password is `tacocat`. Keep asking for the password until the user gets it right **or** has tried 3 times. Print `Wrong password.` after each wrong try. At the end, print `Access granted.` or `Locked out. Try again later.`

:::solution
```python
password = "tacocat"
attempts = 0
entry = ""

while entry != password and attempts < 3:
    entry = input("Password: ")
    attempts = attempts + 1
    if entry != password:
        print("Wrong password.")

if entry == password:
    print("Access granted.")
else:
    print("Locked out. Try again later.")
```

Getting it right on the third try:

```text
Password: taco
Wrong password.
Password: Tacocat
Wrong password.
Password: tacocat
Access granted.
```

Three wrong tries:

```text
Password: pizza
Wrong password.
Password: pasta
Wrong password.
Password: soup
Wrong password.
Locked out. Try again later.
```

`Tacocat` doesn't match because string comparison cares about capital letters. `entry = ""` before the loop gives `entry` a starting value that can't be the password.
:::

### Exercise 5: Savings goal

Ask for a savings goal and how much is saved each week (both can have decimals). Use a `while` loop to add one week of savings at a time, printing the running total, and then say how many weeks it took.

:::solution
```python
goal = float(input("Savings goal in dollars: "))
weekly = float(input("Amount saved each week: "))

saved = 0
weeks = 0
while saved < goal:
    saved = saved + weekly
    weeks = weeks + 1
    print("Week", weeks, "- saved", saved)

print("You reach your goal in", weeks, "weeks!")
```

```text
Savings goal in dollars: 50
Amount saved each week: 15
Week 1 - saved 15.0
Week 2 - saved 30.0
Week 3 - saved 45.0
Week 4 - saved 60.0
You reach your goal in 4 weeks!
```

`while` fits here because we don't know the number of weeks ahead of time. What happens if someone types `0` for the weekly amount? `saved` never grows, so the loop never ends. You'd need Ctrl+C. Can you add an `if` before the loop that catches this?
:::

### Exercise 6: Vowel counter

Ask for a word and count how many vowels it has, capital or lowercase. You'll need a `for` loop over the string, plus a new trick: `letter in "aeiouAEIOU"` is `True` if `letter` is one of those characters.

```text
Type a word: Education
Education has 5 vowels
```

:::solution
```python
word = input("Type a word: ")
vowels = 0
for letter in word:
    if letter in "aeiouAEIOU":
        vowels = vowels + 1
print(word, "has", vowels, "vowels")
```

```text
Type a word: Education
Education has 5 vowels
```

The loop variable `letter` holds one character on each iteration: `E`, `d`, `u`, and so on. The counter only goes up when the `if` is `True`.
:::

## Stretch challenge: Star pyramid

Ask for a height and print a centered pyramid of stars. One handy fact: multiplying a string by a number repeats it, so `"*" * 3` is `"***"` and `" " * 2` is two spaces.

```text
Height: 4
   *
  ***
 *****
*******
```

Hint: row 1 has 1 star, row 2 has 3, row 3 has 5. How many spaces go in front of each row?

:::solution
Row `row` (counting from 1) has `2 * row - 1` stars and `height - row` spaces in front of them.

```python
height = int(input("Height: "))
for row in range(1, height + 1):
    print(" " * (height - row) + "*" * (2 * row - 1))
```

```text
Height: 4
   *
  ***
 *****
*******
```

Want more? Print the pyramid upside down by counting `row` down with `range(height, 0, -1)`.
:::
