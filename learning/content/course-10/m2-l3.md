**Warm-up.** Without code: what current flows when 5 V is across 1 kΩ? And 3.3 V across 330 Ω? (Answers: 5 mA and 10 mA. If you got 0.005 and 0.01, those are the same answers in amps.)

### Exercise 1: Predict three currents

A 5 V supply is connected across a 330 Ω resistor, then a 1 kΩ resistor, then a 10 kΩ resistor. Predict the three currents in milliamps, then write a loop that prints them.

```text
330 ohms -> 15.15 mA
1000 ohms -> 5.0 mA
10000 ohms -> 0.5 mA
```

:::hint
I = V / R gives amps. Multiply by 1000 for milliamps. Each time the resistance grows 10 times, what happens to the current?
:::

:::solution
```python run
for ohms in [330, 1000, 10_000]:
    milliamps = 5.0 / ohms * 1000
    print(ohms, "ohms ->", round(milliamps, 2), "mA")
```

Ten times the resistance gives one tenth the current. That pattern lets you sanity-check any answer: a 10 kΩ resistor on 5 V can never carry more than half a milliamp.
:::

### Exercise 2: Resistors for two new LEDs

Find a standard resistor (from the E12 list: 10, 12, 15, 18, 22, 27, 33, 39, 47, 56, 68, 82, times 1, 10, 100, …) for each design, rounding **up**, and report the real current:

1.  A white LED (forward voltage 3.1 V) on 5 V, aiming for 15 mA.
2.  A red LED (forward voltage 2.0 V) on a 3.3 V board, aiming for 10 mA.

:::hint
R = (supply − forward) / current, with the current in amps. For the white LED that's 1.9 / 0.015. Then find the smallest standard value at least that big.
:::

:::solution
```python run
E12 = [10, 12, 15, 18, 22, 27, 33, 39, 47, 56, 68, 82]

def next_standard(ohms):
    decade = 1
    while True:
        for base in E12:
            if base * decade >= ohms:
                return base * decade
        decade *= 10

for label, supply, forward, target_ma in [("white on 5 V", 5.0, 3.1, 15), ("red on 3.3 V", 3.3, 2.0, 10)]:
    exact = (supply - forward) / (target_ma / 1000)
    chosen = next_standard(exact)
    real_ma = (supply - forward) / chosen * 1000
    print(f"{label}: exact {exact:.1f} ohms, use {chosen} ohms, real current {real_ma:.1f} mA")
```

Both land on 150 Ω, for different reasons. The 3.3 V board has less voltage left over after the LED (1.3 V), so it needs less resistance for the same current.
:::

### Exercise 3: Will this resistor overheat?

A student connects a 100 Ω, ¼ W resistor directly across a 9 V battery "to test it". Calculate the current and the power. Is the resistor safe? How long would a roughly 500 mAh battery last like this?

:::hint
Find I first, then P = V × I. Battery life in hours is roughly capacity (mAh) divided by current (mA).
:::

:::solution
```python run
volts, ohms, rating = 9.0, 100, 0.25
current = volts / ohms
power = volts * current
print(f"Current: {current * 1000:.0f} mA")
print(f"Power:   {power:.2f} W, rating {rating} W, so {power / rating:.1f}x the rating")
print(f"Battery life: about {500 / (current * 1000):.1f} hours")
```

At 0.81 W the resistor carries more than three times its rating. It will get hot enough to burn a finger and may char. A 100 Ω load on 9 V would need a 1 W resistor, or a much larger resistance.
:::

### Exercise 4: Make a value you don't have

Your kit has plenty of 220 Ω resistors and nothing else.

1.  What do two 220 Ω resistors give in **series** (end to end) and in **parallel** (side by side)?
2.  Which of those is safe for a red LED (forward voltage 2.0 V) on a 5 V pin? Use the 20 mA pin limit.
3.  A friend needs about 150 Ω for a blue LED (forward voltage 3.0 V) but only has 100 Ω and 47 Ω resistors. What should they do, and what current results?

```text
series 440 ohms -> red LED 6.8 mA
parallel 110 ohms -> red LED 27.3 mA
```

:::hint
Series resistances add: R = R1 + R2. In parallel, current has two paths, so the total is *smaller* than either: R = (R1 × R2) / (R1 + R2).
:::

:::solution
```python run
def series(r1, r2):
    return r1 + r2

def parallel(r1, r2):
    return r1 * r2 / (r1 + r2)

for name, total in [("series", series(220, 220)), ("parallel", parallel(220, 220))]:
    milliamps = (5.0 - 2.0) / total * 1000
    verdict = "safe" if milliamps <= 20 else "over the 20 mA limit"
    print(f"{name} {total:.0f} ohms -> red LED {milliamps:.1f} mA ({verdict})")

blue_total = series(100, 47)
print(f"100 + 47 in series = {blue_total} ohms -> blue LED {(5.0 - 3.0) / blue_total * 1000:.1f} mA")
```

Series 440 Ω is safe but dim. Parallel 110 Ω pushes 27 mA, over the limit. For the blue LED, 100 Ω and 47 Ω in series make 147 Ω, close enough to 150 Ω, giving about 13.6 mA.
:::

### Exercise 5: Spot the dangerous circuits

No code for this one. Which of these circuits are dangerous, and why?

-   **A.** 5V → 220 Ω → red LED → GND.
-   **B.** Pin 9 (set HIGH) → red LED → GND. No resistor.
-   **C.** 5V → pushbutton → GND.
-   **D.** 5V → 10 kΩ → pin 2, and also pin 2 → pushbutton → GND.
-   **E.** A loose 9 V battery in a pencil case full of paperclips.

:::hint
For each one, ask: when everything is connected (and any button is pressed), what is the total resistance in the loop? Then use I = V / R.
:::

:::solution
-   **A is safe.** 3 V across 220 Ω is 13.6 mA.
-   **B is dangerous.** Nothing limits the LED's current except the pin itself. The LED and the pin can both be damaged.
-   **C is dangerous, but only when pressed.** Pressing the button connects 5V to GND through almost zero resistance: a short circuit. It looks harmless until someone presses it.
-   **D is safe.** This is a **pull-up resistor**. Pressing the button puts 5 V across the 10 kΩ resistor, so only 0.5 mA flows, and pin 2 reads LOW. Module 3 uses exactly this idea (with a resistor built into the chip).
-   **E is dangerous.** A 9 V battery's terminals sit side by side, so one paperclip can short them, and the paperclip heats up fast. Cover the terminals or keep the battery in its packaging.
:::

### Exercise 6: How long will the batteries last?

A robot project will run from either a 9 V battery (roughly 500 mAh) or a pack of four AA cells (roughly 2000 mAh). Plot estimated run time against the project's current draw, from 20 mA to 200 mA, for both.

:::hint
Hours = capacity / current, with both in milliamp units. Make a list of currents, compute two lists of hours, and plot both against the currents.
:::

:::solution
```python run alt="Two falling curves of battery run time against current draw. The 4 x AA pack starts at 100 hours at 20 mA and falls to 10 hours at 200 mA; the 9 V battery starts at 25 hours and falls to 2.5 hours." caption="Estimated run time. Real batteries deliver less than their rated capacity at high currents, so treat these as best cases."
import matplotlib.pyplot as plt

currents = list(range(20, 201, 10))
for name, capacity, color in [("4 x AA (about 2000 mAh)", 2000, "#2a78d6"), ("9 V (about 500 mAh)", 500, "#eb6834")]:
    hours = [capacity / ma for ma in currents]
    plt.plot(currents, hours, color=color, linewidth=2, label=name)

plt.xlabel("Project current draw (mA)")
plt.ylabel("Estimated run time (hours)")
plt.title("Battery life falls fast as current rises")
plt.legend()
plt.grid(alpha=0.3)
```

The AA pack lasts four times longer at every current, because it stores four times the charge. That is one reason robot kits use AA packs rather than 9 V batteries: motors draw hundreds of milliamps.
:::

### Challenge: A tested LED circuit checker

Write `check_led(supply, forward, resistor)` that returns a tuple: the current in mA, the resistor's power in watts, and a verdict string. The verdict is `"OK"`, `"pin overload"` if the current is over 20 mA, or `"resistor too hot"` if the power is over 0.25 W (check the resistor first, since it's the bigger hazard). Then test it with `unittest`, and print a table for red (2.0 V), green (2.2 V), and blue (3.0 V) LEDs with 150, 220, and 330 Ω on 5 V.

:::hint
Power in the resistor is current squared times resistance, or (supply − forward) × current. Write the tests first: what should `check_led(5.0, 2.0, 220)` return, and what about `check_led(5.0, 2.0, 100)`?
:::

:::solution
```python run
import sys
import unittest

def check_led(supply, forward, resistor):
    current_a = (supply - forward) / resistor
    watts = current_a ** 2 * resistor
    if watts > 0.25:
        verdict = "resistor too hot"
    elif current_a * 1000 > 20:
        verdict = "pin overload"
    else:
        verdict = "OK"
    return round(current_a * 1000, 1), round(watts, 3), verdict

class CheckLedTests(unittest.TestCase):
    def test_normal_red_led(self):
        self.assertEqual(check_led(5.0, 2.0, 220), (13.6, 0.041, "OK"))

    def test_small_resistor_overloads_pin(self):
        self.assertEqual(check_led(5.0, 2.0, 100)[2], "pin overload")

    def test_tiny_resistor_overheats(self):
        self.assertEqual(check_led(9.0, 2.0, 47)[2], "resistor too hot")

suite = unittest.TestLoader().loadTestsFromTestCase(CheckLedTests)
unittest.TextTestRunner(stream=sys.stdout, verbosity=2).run(suite)

print()
print(f"{'LED':<6}{'ohms':>6}{'mA':>8}{'watts':>8}  verdict")
for color, forward in [("red", 2.0), ("green", 2.2), ("blue", 3.0)]:
    for ohms in [150, 220, 330]:
        ma, watts, verdict = check_led(5.0, forward, ohms)
        print(f"{color:<6}{ohms:>6}{ma:>8}{watts:>8}  {verdict}")
```

Every combination in the table is OK, which matches what you found by hand: 150 Ω is the smallest safe choice for a red LED on 5 V, and anything larger only makes it dimmer. The `47 Ω on 9 V` test proves the resistor check runs before the pin check.
:::
