## Warm-up: guess, then check

Without running anything, guess the sigmoid of 0, of 2, and of −2. Then run this:

```python run
import math

for z in [0, 2, -2]:
    print(z, round(1 / (1 + math.exp(-z)), 3))
```

Did you notice that the answers for 2 and −2 add up to exactly 1? The sigmoid is symmetric around 0.5, which is why a score of −2 means "as sure it's a no as a score of 2 is sure it's a yes".

### Exercise 1: Write `sigmoid` and test it

Write a function `sigmoid(z)` using `math.exp`. Print it for `z = -6, -3, 0, 3, 6`, then check the symmetry from the warm-up for every value: `sigmoid(z) + sigmoid(-z)` should be 1.

```text
-6 0.0025 symmetric: True
-3 0.0474 symmetric: True
0 0.5 symmetric: True
3 0.9526 symmetric: True
6 0.9975 symmetric: True
```

:::hint
Floating-point math can give `0.9999999999999999` instead of `1.0`. Compare with `abs(total - 1) < 1e-9` instead of `==`.
:::

:::solution
```python run
import math

def sigmoid(z):
    return 1 / (1 + math.exp(-z))

for z in [-6, -3, 0, 3, 6]:
    total = sigmoid(z) + sigmoid(-z)
    print(z, round(sigmoid(z), 4), "symmetric:", abs(total - 1) < 1e-9)
```

The tolerance check matters: computers store decimals approximately, so two values that "should" be equal are often off in the 16th digit.
:::

### Exercise 2: Find the petal width where a flower becomes "probably virginica"

Load the iris flowers with `load_iris(as_frame=True)`. Make a target that is 1 for virginica (`target == 2`) and 0 otherwise. Fit `LogisticRegression` on the single feature `petal width (cm)`. Print the width where the model's probability is exactly 0.5, then the probabilities for widths 1.0, 1.6, and 2.2.

```text
50/50 width: 1.66 cm
     P(other)  P(virginica)
1.0     0.946         0.054
1.6     0.565         0.435
2.2     0.088         0.912
```

:::hint
The score is `w * width + b`, and the sigmoid gives 0.5 when the score is 0. Solve `w * width + b = 0` for `width`. Remember the double brackets for a one-column `X`.
:::

:::solution
```python run
import pandas as pd
from sklearn.datasets import load_iris
from sklearn.linear_model import LogisticRegression

iris = load_iris(as_frame=True)
X = iris.data[["petal width (cm)"]]
y = (iris.target == 2).astype(int)

model = LogisticRegression().fit(X, y)
w, b = model.coef_[0][0], model.intercept_[0]
print(f"50/50 width: {-b / w:.2f} cm")

widths = pd.DataFrame({"petal width (cm)": [1.0, 1.6, 2.2]})
probs = model.predict_proba(widths)
print(pd.DataFrame(probs, columns=["P(other)", "P(virginica)"], index=[1.0, 1.6, 2.2]).round(3))
```

`w` is positive here (wider petals mean more likely virginica), so the probability rises with width, the opposite direction from the basketball shots in the Notes.
:::

### Exercise 3: Decide at three thresholds

A weather model gives these probabilities that school closes for snow on eight days, and `closed` records what actually happened:

```python
p_close = [0.92, 0.15, 0.55, 0.71, 0.08, 0.38, 0.64, 0.97]
closed  = [1,    0,    0,    1,    0,    1,    0,    1]
```

Write `decide(probs, threshold)` that returns a list of 0s and 1s. For thresholds 0.3, 0.5, and 0.7, print the decisions and count how many days the model was wrong.

```text
0.3 [1, 0, 1, 1, 0, 1, 1, 1] wrong: 2
0.5 [1, 0, 1, 1, 0, 0, 1, 1] wrong: 3
0.7 [1, 0, 0, 1, 0, 0, 0, 1] wrong: 1
```

:::hint
A list comprehension does the deciding in one line: `[1 if p >= threshold else 0 for p in probs]`. To count mistakes, `zip` the decisions with `closed` and count pairs that differ.
:::

:::solution
```python run
p_close = [0.92, 0.15, 0.55, 0.71, 0.08, 0.38, 0.64, 0.97]
closed  = [1,    0,    0,    1,    0,    1,    0,    1]

def decide(probs, threshold):
    return [1 if p >= threshold else 0 for p in probs]

for threshold in [0.3, 0.5, 0.7]:
    calls = decide(p_close, threshold)
    wrong = sum(1 for call, truth in zip(calls, closed) if call != truth)
    print(threshold, calls, "wrong:", wrong)
```

Notice the kinds of mistakes change. At 0.3 the two errors are both false alarms (days 3 and 7). At 0.7 the single error is a missed closure (day 6). Fewest mistakes isn't automatically best: a student who misses a closure walks to a locked school.
:::

### Exercise 4: Write a Gini function for any number of classes

Write `gini(counts)`, where `counts` is a list like `[8, 2]` (8 of one class, 2 of another) or `[3, 3, 3]`. It returns `1 − (sum of each share squared)`. Test it on the four groups below.

```text
[10, 0] 0.0
[5, 5] 0.5
[8, 2] 0.32
[3, 3, 3] 0.667
```

:::hint
Divide each count by the total to get its share, square each share, add them up, and subtract from 1. Notice the three-class group can go above 0.5.
:::

:::solution
```python run
def gini(counts):
    total = sum(counts)
    return 1 - sum((c / total) ** 2 for c in counts)

for group in [[10, 0], [5, 5], [8, 2], [3, 3, 3]]:
    print(group, round(gini(group), 3))
```

The maximum depends on the number of classes. With two it's 0.5; with three equal classes it's 2/3. Zero always means "pure".
:::

### Exercise 5: Find the best first split, then check scikit-learn

You logged ten days of phone use: hours of screen time, and whether the battery lasted until bedtime.

```python
hours  = [2.0, 3.5, 4.0, 5.5, 6.0, 6.5, 7.0, 8.5, 9.0, 10.0]
lasted = [1,   1,   1,   1,   0,   1,   0,   1,   0,   0]
```

Try every midpoint between neighboring `hours` values as a cutoff. For each, compute the weighted Gini of the two groups (`<=` cutoff and `>` cutoff) and keep the lowest. Then fit `DecisionTreeClassifier(max_depth=1)` and print `tree.tree_.threshold[0]`, the cutoff scikit-learn chose for its root.

```text
2.75 0.444
3.75 0.4
...
Best cutoff: 5.75
scikit-learn chose: 5.75
```

:::hint
Midpoints are `(hours[i] + hours[i + 1]) / 2` for `i` from 0 to 8. Build each group's labels with a list comprehension, turn the labels into counts `[ones, zeros]`, and reuse `gini` from Exercise 4.
:::

:::solution
```python run
from sklearn.tree import DecisionTreeClassifier

hours  = [2.0, 3.5, 4.0, 5.5, 6.0, 6.5, 7.0, 8.5, 9.0, 10.0]
lasted = [1,   1,   1,   1,   0,   1,   0,   1,   0,   0]

def counts(labels):
    return [labels.count(1), labels.count(0)]

best_cut, best_score = None, 1.0
for i in range(len(hours) - 1):
    cut = (hours[i] + hours[i + 1]) / 2
    left = [l for h, l in zip(hours, lasted) if h <= cut]
    right = [l for h, l in zip(hours, lasted) if h > cut]
    score = (len(left) * gini(counts(left)) + len(right) * gini(counts(right))) / len(hours)
    print(cut, round(score, 3))
    if score < best_score:
        best_cut, best_score = cut, score
print("Best cutoff:", best_cut)

tree = DecisionTreeClassifier(max_depth=1).fit(pd.DataFrame({"screen_hours": hours}), lasted)
print("scikit-learn chose:", tree.tree_.threshold[0])
```

Your loop and scikit-learn agree, because they run the same search: midpoints as candidates, weighted Gini as the score. The 5.75 cut puts four "lasted" days on the left with no exceptions, and leaves only two surprises on the right.
:::

### Exercise 6: How deep should an iris tree go?

Split the full iris data (all four measurements, three species) with `test_size=0.3`, `stratify=y`, and `random_state=1`. Train trees with `max_depth` of 1, 2, 3, 4, 5, and `None`, and print training and test accuracy for each. Then draw the depth-2 tree with `plot_tree`. Which is the smallest depth that reaches the best test score?

```text
depth 1: train 0.667, test 0.667
depth 2: train 0.952, test 0.956
...
depth None: train 1.000, test 0.978
```

:::hint
A depth-1 tree has only two leaves, so it can name at most two of the three species. Look at that before you look at anything else.
:::

:::solution
```python run alt="A depth-2 iris tree: the root splits off all setosa flowers by petal size, and the second question separates versicolor from virginica using petal length" caption="Two questions are almost enough for iris."
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.tree import plot_tree

X, y = iris.data, iris.target
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, stratify=y, random_state=1)

for depth in [1, 2, 3, 4, 5, None]:
    t = DecisionTreeClassifier(max_depth=depth, random_state=0).fit(X_train, y_train)
    print(f"depth {depth}: train {t.score(X_train, y_train):.3f}, test {t.score(X_test, y_test):.3f}")

small = DecisionTreeClassifier(max_depth=2, random_state=0).fit(X_train, y_train)
plt.figure(figsize=(9, 5))
plot_tree(small, feature_names=X.columns, class_names=iris.target_names, filled=True, rounded=True, fontsize=9)
plt.show()
```

Depth 3 is the smallest that reaches the best test score of 0.978. Beyond it, training accuracy keeps climbing to a perfect 1.000 while test accuracy doesn't move: the extra questions memorize a few training flowers without helping on new ones. Depth 1 is stuck at 0.667 because two leaves can't name three species.
:::

### Challenge: When a straight boundary isn't enough

`make_moons` makes two interlocking crescents. Make 300 points with `noise=0.25` and `random_state=0`, split off 30% for testing, and train `LogisticRegression` and `DecisionTreeClassifier(max_depth=5)`. Print both test accuracies, then draw each model's decision regions side by side with `DecisionBoundaryDisplay.from_estimator`. Explain the difference in one sentence.

:::hint
`DecisionBoundaryDisplay` lives in `sklearn.inspection`. Pass `ax=` to put each one on its own subplot, then add the points with `ax.scatter(X[:, 0], X[:, 1], c=y)`.
:::

:::solution
```python run alt="Two side-by-side plots of crescent-shaped data: logistic regression splits the plane with one straight diagonal line, while the decision tree's regions form a blocky staircase that follows the curves" caption="Logistic regression draws one straight boundary; a tree builds a boundary out of boxes."
from sklearn.datasets import make_moons
from sklearn.inspection import DecisionBoundaryDisplay

X, y = make_moons(n_samples=300, noise=0.25, random_state=0)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

models = {
    "Logistic regression": LogisticRegression().fit(X_train, y_train),
    "Tree, depth 5": DecisionTreeClassifier(max_depth=5, random_state=0).fit(X_train, y_train),
}
fig, axes = plt.subplots(1, 2, figsize=(10, 4))
for ax, (name, model) in zip(axes, models.items()):
    DecisionBoundaryDisplay.from_estimator(model, X, response_method="predict", alpha=0.3, ax=ax)
    ax.scatter(X[:, 0], X[:, 1], c=y, s=12, edgecolor="k", linewidth=0.3)
    ax.set_title(f"{name}: test {model.score(X_test, y_test):.3f}")
    print(name, round(model.score(X_test, y_test), 3))
plt.show()
```

Logistic regression's score is a straight-line combination of the features, so its boundary (where the probability is 0.5) is a straight line, and it can't follow the crescents. The tree asks one cutoff question at a time, so its boundary is made of horizontal and vertical edges, and enough of them can trace a curve. That flexibility is also why a deep tree can memorize noise.
:::
