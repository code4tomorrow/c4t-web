:::objectives
- Organize a vision study as five milestones, each ending in something you can check.
- Keep every setting in one config object, and every run in one log.
- Compare experiments against a baseline across seeds, choosing on validation data that looks like deployment.
- Audit the chosen model by condition with intervals, and look at its failures.
- Generate a model card from the results instead of retyping numbers.
:::

This lesson is a complete, working version of project 1 from the brief: a digit reader that will face scanned forms in three conditions it never saw in training (shifted, faded, and blurred). The study's question is: **which augmentation makes a digit CNN robust to these conditions, and what does it cost on clean images?**

Every section below is one milestone. If you chose a different project, run this once to see the whole shape, then replace the parts marked in the last section. The code is short on purpose; your project's version will grow, but the structure should stay this simple.

## Milestone 1: Config, data, and the datasheet

All settings live in one dataclass, so a run is fully described by one object you can log.

```python run
import csv
import time
import numpy as np
import pandas as pd
import torch
import torch.nn as nn
import torch.nn.functional as F
import matplotlib.pyplot as plt
import torchvision.transforms.v2.functional as TF
from dataclasses import dataclass, asdict
from torchvision.transforms import v2
from torch.utils.data import Dataset, DataLoader
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split

@dataclass
class Config:
    augment: str = "none"        # "none", "shift", or "all"
    lr: float = 3e-3
    epochs: int = 12
    width: int = 16
    seed: int = 0

digits = load_digits()
X = torch.tensor(digits.images, dtype=torch.float32).unsqueeze(1) / 16
y = torch.tensor(digits.target)
idx = np.arange(len(y))
train_idx, rest = train_test_split(idx, test_size=0.4, random_state=0, stratify=y)
val_idx, test_idx = train_test_split(rest, test_size=0.5, random_state=0, stratify=y[rest])

def shifted(x):
    out = torch.zeros_like(x)
    out[..., 1:, 1:] = x[..., :-1, :-1]                       # one pixel right and down
    return out

CONDITIONS = {
    "clean": lambda x: x,
    "shifted": shifted,
    "faded": lambda x: x * 0.5 + 0.25,
    "blurred": lambda x: TF.gaussian_blur(x, kernel_size=3, sigma=1.0),
}

datasheet = {
    "source": "scikit-learn load_digits (UCI optical recognition of handwritten digits, test portion)",
    "size": f"{len(y)} images, 8x8 grayscale, 10 classes, {np.bincount(y.numpy()).min()}-{np.bincount(y.numpy()).max()} per class",
    "splits": f"train {len(train_idx)} / val {len(val_idx)} / test {len(test_idx)}, stratified by digit, seed 0",
    "conditions": "training images are clean; val and test are scored under all four conditions",
}
images_as_bytes = [X[i].numpy().tobytes() for i in idx]
shared = set(images_as_bytes[i] for i in train_idx) & set(images_as_bytes[i] for i in test_idx)
datasheet["duplicates train/test"] = len(shared)
for key, value in datasheet.items():
    print(f"{key:<22} {value}")
```

The duplicate check compares the exact pixels of every training image against every test image. Zero here; on your own photos, also look for near-duplicates (bursts of the same shot) by eye or with a perceptual hash. Next, the habit that catches label and loading bugs early: plot random examples with their labels, under every condition.

```python run alt="A grid of four rows and eight columns of digits with their labels. Row one is clean, row two is shifted one pixel right and down, row three is faded with a gray background, row four is blurred." caption="Eight random test digits under each of the four conditions"
rng = np.random.default_rng(0)
picks = rng.choice(test_idx, 8, replace=False)
fig, axes = plt.subplots(4, 8, figsize=(8, 4.4))
for row, (name, condition) in enumerate(CONDITIONS.items()):
    for col, i in enumerate(picks):
        axes[row, col].imshow(condition(X[i:i + 1])[0, 0], cmap="gray_r", vmin=0, vmax=1)
        axes[row, col].set_xticks([])
        axes[row, col].set_yticks([])
        if row == 0:
            axes[row, col].set_title(str(y[i].item()), fontsize=9)
    axes[row, 0].set_ylabel(name, fontsize=9)
plt.tight_layout()
plt.show()
```

## Milestone 2: A logged, seeded baseline

The runner is the one from Module 7, trimmed: seed, build, train, and append each epoch to `runs.csv`. Validation accuracy is recorded under **every** condition, because the deployment will see all of them.

```python run
class RandomFade:
    def __init__(self, max_lift=0.6):
        self.max_lift = max_lift
    def __call__(self, image):
        lift = torch.rand(1).item() * self.max_lift
        return image * (1 - lift) + lift / 2

AUGMENTS = {
    "none": None,
    "shift": v2.RandomAffine(degrees=0, translate=(0.15, 0.15)),
    "all": v2.Compose([
        v2.RandomAffine(degrees=0, translate=(0.15, 0.15)),
        RandomFade(0.6),
        v2.RandomApply([v2.GaussianBlur(kernel_size=3, sigma=(0.5, 1.2))], p=0.5),
    ]),
}

class Images(Dataset):
    def __init__(self, indices, transform=None):
        self.indices, self.transform = indices, transform
    def __len__(self):
        return len(self.indices)
    def __getitem__(self, i):
        image = X[self.indices[i]]
        return (self.transform(image) if self.transform else image), y[self.indices[i]]

def make_cnn(width):
    return nn.Sequential(
        nn.Conv2d(1, width, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
        nn.Conv2d(width, 2 * width, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
        nn.Flatten(), nn.Linear(8 * width, 10),
    )

def scores(model, indices):
    model.eval()
    with torch.no_grad():
        return {name: (model(cond(X[indices])).argmax(1) == y[indices]).float().mean().item()
                for name, cond in CONDITIONS.items()}

def run_experiment(cfg, log_path="runs.csv"):
    torch.manual_seed(cfg.seed)
    model = make_cnn(cfg.width)
    loader = DataLoader(Images(train_idx, AUGMENTS[cfg.augment]), batch_size=64, shuffle=True)
    opt = torch.optim.Adam(model.parameters(), lr=cfg.lr)
    start = time.perf_counter()
    with open(log_path, "a", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=[*asdict(cfg), "epoch", "seconds", *[f"val_{c}" for c in CONDITIONS]])
        if f.tell() == 0:
            writer.writeheader()
        for epoch in range(1, cfg.epochs + 1):
            model.train()
            for xb, yb in loader:
                loss = F.cross_entropy(model(xb), yb)
                opt.zero_grad()
                loss.backward()
                opt.step()
            val = scores(model, val_idx)
            writer.writerow({**asdict(cfg), "epoch": epoch, "seconds": round(time.perf_counter() - start, 2),
                             **{f"val_{c}": round(v, 4) for c, v in val.items()}})
    return model

baseline = run_experiment(Config())
print(pd.read_csv("runs.csv").tail(1).to_string(index=False))
```

The baseline does well on clean validation images and much worse under the conditions it never trained on. That gap is the study's starting point, and it's on record before any experiment runs.

## Milestone 3: Experiments against the baseline, with seeds

Each experiment changes one thing: the augmentation. Every configuration runs with two seeds (use three or more in your project if time allows), so you can see how much of a difference is just noise.

```python run
models = {("none", 0): baseline}
for augment in ["none", "shift", "all"]:
    for seed in [0, 1]:
        if (augment, seed) not in models:
            models[(augment, seed)] = run_experiment(Config(augment=augment, seed=seed))

log = pd.read_csv("runs.csv")
final = log[log["epoch"] == log["epoch"].max()].copy()
val_cols = [f"val_{c}" for c in CONDITIONS]
final["val_mean"] = final[val_cols].mean(axis=1)
table = final.groupby("augment")[val_cols + ["val_mean", "seconds"]].agg(["mean", "std"]).round(3)
print(table[[(c, "mean") for c in val_cols + ["val_mean"]] + [("val_mean", "std"), ("seconds", "mean")]].to_string())
```

The table's last columns are the spread across seeds and the training time. A difference between two augmentations that's smaller than their seed-to-seed spread isn't a finding yet.

## Milestone 4: Choose on validation, test once, and audit

The plan fixed the primary metric in advance: **mean validation accuracy across the four conditions**. The winner is chosen by that number alone, then the test set is used once.

```python run
winner = final.groupby("augment")["val_mean"].mean().idxmax()
model = models[(winner, 0)]
print("winner:", winner)

def wilson(correct, n, z=1.96):
    p = correct / n
    centre = (p + z * z / (2 * n)) / (1 + z * z / n)
    half = z * np.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / (1 + z * z / n)
    return centre - half, centre + half

rows = []
for name in CONDITIONS:
    for label, m in [("baseline", baseline), (winner, model)]:
        acc = scores(m, test_idx)[name]
        low, high = wilson(round(acc * len(test_idx)), len(test_idx))
        rows.append({"condition": name, "model": label, "accuracy": acc, "low": low, "high": high})
audit = pd.DataFrame(rows)
print(audit.round(3).to_string(index=False))
```

Read the table row by row. The chosen model gains a lot on shifted digits and a little on blurred ones, matches the baseline on faded ones, and gives up about eight points on clean images. Its margin over the baseline in mean validation accuracy was about the size of the seed-to-seed spread, so the honest summary is a trade-off, not a clear win. That's a normal outcome for a first round, and it tells you the next experiment: the augmented model has a harder training task and may simply need more epochs or a wider network.

Now the failure gallery for the chosen model, under its weakest condition:

```python run alt="A row of up to ten misclassified test digits under the chosen model's weakest condition, each titled with the true digit, the predicted digit, and the confidence." caption="The chosen model's mistakes under its weakest test condition"
weakest = audit[audit["model"] == winner].sort_values("accuracy").iloc[0]["condition"]
model.eval()
with torch.no_grad():
    shown = CONDITIONS[weakest](X[test_idx])
    probs = F.softmax(model(shown), dim=1)
pred, true = probs.argmax(1), y[test_idx]
wrong = torch.nonzero(pred != true).flatten()[:10]

fig, axes = plt.subplots(1, 10, figsize=(9, 1.6))
for ax in axes:
    ax.axis("off")
for ax, k in zip(axes, wrong):
    ax.imshow(shown[k, 0], cmap="gray_r", vmin=0, vmax=1)
    ax.set_title(f"{true[k].item()}→{pred[k].item()} ({probs[k].max():.2f})", fontsize=8)
plt.show()
print(f"weakest condition: {weakest}, {len(torch.nonzero(pred != true))} mistakes in {len(true)}")
```

Write down what you see in plain words before moving on; that sentence goes straight into the model card's limitations.

## Milestone 5: Generate the model card

Typing numbers into a document by hand is how reports drift away from results. Generate the card from the variables instead, then edit the prose around them:

```python run
params = sum(p.numel() for p in model.parameters())
train_seconds = final[(final["augment"] == winner) & (final["seed"] == 0)]["seconds"].item()
lines = [f"| {r.condition} | {r.model} | {r.accuracy:.1%} | {r.low:.1%} to {r.high:.1%} |" for r in audit.itertuples()]
card = f"""# Model card: robust 8x8 digit reader

## Model
Small CNN (two conv blocks, {params:,} parameters), augmentation "{winner}", chosen by mean
validation accuracy over four conditions from {final['augment'].nunique()} configurations x 2 seeds.
Training: {train_seconds:.1f} s on a laptop CPU.

## Intended use
Reading single, pre-cropped handwritten digits from scanned forms, as one step in a pipeline
where a person reviews low-confidence results.

## Out of scope
Photos of digits in the wild, multi-digit strings, any decision about a person without review.

## Data
{datasheet['source']}. {datasheet['size']}. {datasheet['splits']}.

## Results on the test set (95% Wilson intervals, n = {len(test_idx)} per condition)
| condition | model | accuracy | interval |
| --- | --- | --- | --- |
""" + "\n".join(lines) + f"""

## Limitations
- Conditions are simulated; real scanners produce other artifacts.
- The test set is the same images under each condition, so conditions are not independent samples.
- Weakest condition for the chosen model: {weakest}.
"""
with open("MODEL_CARD.md", "w") as f:
    f.write(card)
print(card)
```

## Adapting the starter to your project

| Part | Project 1 (this page) | What to change for yours |
| --- | --- | --- |
| Data | `load_digits` tensors | An `ImageFolder`, `Flowers102`, or `CIFAR10` dataset with `train_tf` and `eval_tf` |
| Conditions or subgroups | Simulated shift, fade, blur | Metadata you recorded (lighting, location, camera) or object size for detection |
| Model | `make_cnn(width)` | `resnet18` with a new head, frozen or partly unfrozen (Module 6) |
| Config | `augment`, `lr`, `epochs`, `width`, `seed` | Add `freeze`, `image_size`, `batch_size`; keep everything in the dataclass |
| Metric | Mean accuracy over conditions | The metric in your plan, fixed before any run |
| Resources | CPU seconds | Add `torch.cuda.max_memory_allocated()` and the GPU name on Colab |

Keep the order of the milestones even when the code changes. In particular, don't skip ahead to Milestone 4's test evaluation "just to see"; once you've seen test numbers, every later choice is tainted by them.

:::tip
In Colab, write `runs.csv`, checkpoints, and `MODEL_CARD.md` into a folder on Google Drive (mount it from the Files panel) so a disconnected session doesn't erase your log.
:::
