Three friends finish dinner. The bill is $37.40, they want to tip 15%, and someone has to work out what each person pays. Here's the calculator you'll build. Change the numbers and press **Calculate**:

```html preview height="300" title="tip-calculator.html"
<h1>Tip calculator</h1>
<label>Bill ($) <input id="bill" type="number" min="0" step="0.01" value="37.40"></label>
<label>Tip (%) <input id="tip" type="number" min="0" step="1" value="15"></label>
<label>People <input id="people" type="number" min="1" step="1" value="3"></label>
<button id="calculate" type="button">Calculate</button>
<p id="result" aria-live="polite"></p>

<script>
  function calculateTip(bill, tipPercent, people) {
    const groupSize = Math.max(1, Math.floor(people));
    const billCents = Math.round(bill * 100);
    const tipCents = Math.round(billCents * (tipPercent / 100));
    const totalCents = billCents + tipCents;
    const perPersonCents = Math.ceil(totalCents / groupSize);
    return {
      tip: tipCents / 100,
      total: totalCents / 100,
      perPerson: perPersonCents / 100,
      people: groupSize,
    };
  }

  const formatMoney = (amount) => `$${amount.toFixed(2)}`;

  const billInput = document.querySelector("#bill");
  const tipInput = document.querySelector("#tip");
  const peopleInput = document.querySelector("#people");
  const resultText = document.querySelector("#result");

  document.querySelector("#calculate").addEventListener("click", () => {
    const result = calculateTip(
      Number(billInput.value),
      Number(tipInput.value),
      Number(peopleInput.value)
    );
    resultText.textContent =
      `Tip ${formatMoney(result.tip)}, total ${formatMoney(result.total)}, ` +
      `${formatMoney(result.perPerson)} each for ${result.people}.`;
  });
</script>
<style>
  body { font-family: system-ui, sans-serif; padding: 4px 16px; }
  label { display: block; margin: 8px 0; }
  input { width: 7em; font-size: 1rem; padding: 4px; }
  button { font-size: 1rem; padding: 8px 14px; }
  #result { font-size: 1.15rem; font-weight: bold; }
</style>
```

Most of that code is one function, `calculateTip`, that knows nothing about web pages. You'll build it first in plain JavaScript, find three bugs that real input causes, and connect it to the page last. Building the logic separately from the page is a habit worth keeping: you can test it in seconds without clicking anything.

## Step 1: Do the math once

Start with plain variables and the obvious formula: the tip is the bill times the percentage, the total is the bill plus the tip, and each person pays a share of the total.

```javascript run title="step1.js"
const bill = 37.4;
const tipPercent = 15;
const people = 3;

const tip = bill * (tipPercent / 100);
const total = bill + tip;
const perPerson = total / people;

console.log(tip, total, perPerson);
```

The formula is right, but look at the tip: `5.609999999999999`, not `5.61`. That's the decimal surprise from the last lesson. And `14.336666666666666` isn't something you can pay. Keep both problems in mind; Step 4 fixes them.

## Step 2: Turn it into a function

Three variables at the top of a file can only describe one dinner. A function with three parameters can describe any dinner. It returns an object so the caller gets all three answers, each with a name:

```javascript run title="step2.js"
function calculateTip(bill, tipPercent, people) {
  const tip = bill * (tipPercent / 100);
  const total = bill + tip;
  return { tip, total, perPerson: total / people };
}

console.log(calculateTip(37.4, 15, 3));
console.log(calculateTip(80, 20, 4));
```

`{ tip, total }` is shorthand for `{ tip: tip, total: total }`: when a property has the same name as the variable holding its value, you can write the name once.

Returning an object instead of printing matters. Printing would show the answer to you, but the page needs the numbers themselves so it can display them its own way.

## Step 3: Feed it what a form actually gives you

On the page, the numbers will come from `input` elements, and `input.value` is always a string. Here's what happens when the function gets strings:

```javascript run title="step3-bug.js"
function calculateTip(bill, tipPercent, people) {
  const tip = bill * (tipPercent / 100);
  const total = bill + tip;
  return { tip, total, perPerson: total / people };
}

console.log(calculateTip("37.40", "15", "3"));
```

The tip is still correct, because `*` and `/` convert strings to numbers. But `bill + tip` joined `"37.40"` and `5.609…` into the string `"37.405.609999999999999"`, and dividing that nonsense by 3 gave `NaN`.

The fix is to convert the moment the text enters your program, so the function always receives numbers:

```javascript run title="step3-fixed.js"
function calculateTip(bill, tipPercent, people) {
  const tip = bill * (tipPercent / 100);
  const total = bill + tip;
  return { tip, total, perPerson: total / people };
}

const fromForm = { bill: "37.40", tip: "15", people: "3" };

console.log(calculateTip(Number(fromForm.bill), Number(fromForm.tip), Number(fromForm.people)));
```

Converting at the edge, where the data arrives, keeps `calculateTip` simple: it can trust that it gets numbers and focus on the math.

## Step 4: Count money in whole cents

Now the decimals. Rounding at the end with `toFixed(2)` hides them, but there's a second, sneakier problem. Split $100.00 three ways and round normally, and everyone pays $33.33. Three times $33.33 is $99.99: the group is a cent short, and the restaurant notices.

Two changes fix both problems:

1.  **Work in cents.** Whole numbers of cents are exact, so convert the bill to cents first, round the tip to a whole cent, and add integers.
2.  **Round each share up** with `Math.ceil`, so the shares always cover the total. Paying a cent extra beats being a cent short.

```javascript run title="step4.js"
function calculateTip(bill, tipPercent, people) {
  const billCents = Math.round(bill * 100);
  const tipCents = Math.round(billCents * (tipPercent / 100));
  const totalCents = billCents + tipCents;
  const perPersonCents = Math.ceil(totalCents / people);
  return {
    tip: tipCents / 100,
    total: totalCents / 100,
    perPerson: perPersonCents / 100,
  };
}

console.log(calculateTip(37.4, 15, 3));
console.log(calculateTip(100, 0, 3));
```

The tip is now exactly `5.61`. For the $100 bill, each share is `33.34`, and three of those ($100.02) cover the bill. `Math.round(bill * 100)` matters too: in JavaScript `19.99 * 100` is `1998.9999999999998`, and rounding snaps it back to `1999` cents.

## Step 5: Don't divide by zero people

Someone will clear the **People** box. An empty input converts to `0`, and dividing by zero in JavaScript doesn't crash. It gives `Infinity`:

```javascript run title="step5.js"
console.log(4301 / 0);
console.log(Math.max(1, 0));
console.log(Math.max(1, Math.floor(2.7)));
```

`Math.max(1, people)` picks whichever is larger, so the group size can never drop below 1. `Math.floor` removes fractions, because 2.7 people can't split a bill. Module 3 shows how to make decisions with `if` and show a message instead; for a calculator, quietly treating "nobody" as one person is reasonable.

## Step 6: Format the answer for people

The function's job ends at numbers. Turning them into text is a separate, small job, so give it its own function:

```javascript run title="step6.js"
function calculateTip(bill, tipPercent, people) {
  const groupSize = Math.max(1, Math.floor(people));
  const billCents = Math.round(bill * 100);
  const tipCents = Math.round(billCents * (tipPercent / 100));
  const totalCents = billCents + tipCents;
  const perPersonCents = Math.ceil(totalCents / groupSize);
  return {
    tip: tipCents / 100,
    total: totalCents / 100,
    perPerson: perPersonCents / 100,
    people: groupSize,
  };
}

const formatMoney = (amount) => `$${amount.toFixed(2)}`;

const result = calculateTip(37.4, 15, 3);
console.log(`Tip:        ${formatMoney(result.tip)}`);
console.log(`Total:      ${formatMoney(result.total)}`);
console.log(`Each of ${result.people}:  ${formatMoney(result.perPerson)}`);
```

In `` `$${amount.toFixed(2)}` `` the first `$` is a plain dollar sign, and `${` starts the slot for the value. `toFixed(2)` always shows two decimals, so $43.10 doesn't appear as $43.1.

## Step 7: Put it on a page

Make a folder `02-tip-calculator` in `js-course` with these two files. The HTML gives each input an `id` so the script can find it, and wraps each input in its `label`, so clicking the words focuses the box and screen readers announce what the box is for.

```html title="02-tip-calculator/index.html"
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Tip calculator</title>
    <script src="script.js" defer></script>
</head>
<body>
    <h1>Tip calculator</h1>
    <label>Bill ($) <input id="bill" type="number" min="0" step="0.01" value="37.40"></label>
    <label>Tip (%) <input id="tip" type="number" min="0" step="1" value="15"></label>
    <label>People <input id="people" type="number" min="1" step="1" value="3"></label>
    <button id="calculate" type="button">Calculate</button>
    <p id="result" aria-live="polite"></p>
</body>
</html>
```

The script is the function from Step 6, plus the part that talks to the page:

```javascript title="02-tip-calculator/script.js"
function calculateTip(bill, tipPercent, people) {
  const groupSize = Math.max(1, Math.floor(people));
  const billCents = Math.round(bill * 100);
  const tipCents = Math.round(billCents * (tipPercent / 100));
  const totalCents = billCents + tipCents;
  const perPersonCents = Math.ceil(totalCents / groupSize);
  return {
    tip: tipCents / 100,
    total: totalCents / 100,
    perPerson: perPersonCents / 100,
    people: groupSize,
  };
}

const formatMoney = (amount) => `$${amount.toFixed(2)}`;

const billInput = document.querySelector("#bill");
const tipInput = document.querySelector("#tip");
const peopleInput = document.querySelector("#people");
const resultText = document.querySelector("#result");

document.querySelector("#calculate").addEventListener("click", () => {
  const result = calculateTip(
    Number(billInput.value),
    Number(tipInput.value),
    Number(peopleInput.value)
  );
  resultText.textContent =
    `Tip ${formatMoney(result.tip)}, total ${formatMoney(result.total)}, ` +
    `${formatMoney(result.perPerson)} each for ${result.people}.`;
});
```

Open `index.html` with Live Server and press **Calculate**. You should see:

```text
Tip $5.61, total $43.01, $14.34 each for 3.
```

The click handler does three things in order: read the inputs and convert them (Step 3), call the function, and write the formatted result into the page with `textContent`. The `aria-live="polite"` on the result paragraph asks screen readers to announce the new text when it changes, so someone who can't see the screen still hears the answer.

:::quiz
Q: Why does the click handler call `Number(billInput.value)` instead of passing `billInput.value` straight in?
- [ ] `Number()` rounds the value to cents
  `Number()` only converts text to a number; rounding happens inside `calculateTip`.
- [x] `input.value` is always a string, and `bill + tip` would join text instead of adding
  That's the Step 3 bug: `"37.40" + 5.61` becomes `"37.405.61"`.
- [ ] `textContent` only accepts numbers
  `textContent` accepts any text; the problem is in the math, before anything is displayed.

Q: Why does the calculator use `Math.ceil` for each person's share instead of `Math.round`?
- [x] So the shares always add up to at least the total
  Rounding $33.333 down to $33.33 leaves the group a cent short; rounding up never does.
- [ ] Because `Math.round` doesn't work on decimals
  `Math.round` works fine on decimals; it just sometimes rounds down.
- [ ] To make the tip bigger
  The tip is calculated before the split and isn't affected.

Q: `calculateTip` returns an object and never touches the page. What does that buy you?
- [ ] It makes the page load faster
  Speed isn't the reason; the function runs in microseconds either way.
- [x] You can test the math on its own, and display the numbers however you like
  You tested every step in plain JavaScript without clicking anything, and the page decides the wording.
- [ ] Functions can't use `document`
  They can; this one just doesn't need to.
:::

:::takeaways
- Build the logic as a function that takes parameters and returns an object, then connect it to the page.
- Convert input text to numbers with `Number()` where it enters the program.
- Do money math in whole cents with `Math.round`, and round shares up with `Math.ceil`.
- Guard against impossible input like zero people. `Math.max(1, n)` sets a floor.
- Keep formatting separate: `formatMoney` turns a number into `$0.00` text.
:::
