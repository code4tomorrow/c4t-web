- Find the top scorer in each subject with `max(..., key=...)`.

A teacher exports a class's scores from a spreadsheet and pastes the text into a message. Somebody typed some of it by hand, so it's a little messy. Your job is to turn it into a ranked report with averages and letter grades, without fixing the data by hand. Here's the plan, and the shape the data takes at each stage:

```mermaid caption="Each step turns the data into a shape that makes the next step easy"
flowchart LR
    A["Raw text lines"] --> B["List of record dicts"]
    B --> C["Dict: name to list of scores"]
    C --> D["Dict: name to average"]
    D --> E["Ranked list of pairs"]
    E --> F["Printed report"]
```

Make a folder `m2-gradebook` and a file `gradebook.py` inside it. Each step below adds code to the bottom of that file. Run the file after every step and check that you see what the page shows.

## Step 1: Look at the raw data

Module 4 shows how to read text like this from a file. For now it lives in a multi-line string, which starts and ends with three quote marks:

```python run title="gradebook.py"
RAW = """name,subject,score
Ava,math,88
Ben,math,72
Cleo,math,95
Dev,math,64
Ava,science,91
ben ,science, 68
Cleo,Science,89
Dev,science,
Ava,history,79
Ben,history,85
Cleo,history,90
Dev,history,73
"""

lines = RAW.splitlines()
print(len(lines), "lines")
print(lines[0])
print(repr(lines[6]))
```

Thirteen lines: one header and twelve scores. `repr` exposes the mess in line 6: a lowercase name with a trailing space and a score with a leading space. Look closer at the raw text and you'll spot two more problems: `Science` has a capital letter, and Dev's science score is blank. A good parser handles all of that.

## Step 2: Parse one line into a record

Write the cleanup for a single line first. It's much easier to test one line than twelve:

```python run
def parse_line(line):
    parts = [part.strip() for part in line.split(",")]
    if len(parts) != 3 or not parts[2]:
        return None
    name, subject, score = parts
    return {"name": name.title(), "subject": subject.lower(), "score": int(score)}


print(parse_line("ben ,science, 68"))
print(parse_line("Cleo,Science,89"))
print(parse_line("Dev,science,"))
```

The comprehension splits the line and strips every piece in one go. Then `.title()` turns `ben` into `Ben`, `.lower()` turns `Science` into `science`, and `int()` turns the text `"68"` into the number 68. When a line doesn't have three pieces, or the score is empty, the function returns `None` to mean "not a usable record" instead of crashing on `int("")`.

## Step 3: Parse every line, and keep a list of rejects

```python run
records = []
skipped = []
for line in lines[1:]:
    record = parse_line(line)
    if record is None:
        skipped.append(line)
    else:
        records.append(record)

print(len(records), "records")
print(records[0])
print("Skipped:", skipped)
```

`lines[1:]` is every line except the header. You could build `records` with a comprehension, but this loop also collects the rejected lines. Throwing bad data away silently is how grade books end up wrong without anyone noticing. Keeping the rejects means the report can say what it ignored.

## Step 4: Group the scores by student

To average each student you need all of their scores together. A dictionary whose values are lists does that:

```python run
by_student = {}
for record in records:
    name = record["name"]
    if name not in by_student:
        by_student[name] = []
    by_student[name].append(record["score"])

print(by_student)
```

The first time a name shows up, it gets an empty list; every time after that, the score is appended to the list that's already there. This "group into a dict of lists" pattern comes up constantly. Python even has a shortcut for the middle three lines, `by_student.setdefault(name, []).append(record["score"])`, which you'll see in the final program.

## Step 5: Averages and letter grades

A dict comprehension turns each list into its average. `.items()` hands over each name with its list:

```python run
averages = {name: sum(scores) / len(scores) for name, scores in by_student.items()}


def letter(average):
    if average >= 90:
        return "A"
    if average >= 80:
        return "B"
    if average >= 70:
        return "C"
    return "D"


for name, average in averages.items():
    print(name, round(average, 1), letter(average))
```

Dev's average comes from two scores, not three, because his blank science score was skipped. That's a decision worth making on purpose. The alternative, counting a missing score as zero, would drag his average from 68.5 down to 45.7 for a test that may simply not have been entered yet.

## Step 6: Rank the students

Sorting `averages.items()` gives a list of `(name, average)` pairs. The key returns `(-average, name)`, so the highest average comes first and ties are broken alphabetically:

```python run
ranking = sorted(averages.items(), key=lambda pair: (-pair[1], pair[0]))
print(ranking[0])
print([name for name, average in ranking])
```

`pair[1]` is the average and `pair[0]` is the name. The comprehension on the last line unpacks each pair into two variables and keeps just the names, which is a quick way to check the order.

## Step 7: Top scorer in each subject

The teacher also wants the best score in each subject. That's a different grouping: a dict of subjects, each holding a dict of names to scores.

```python run
by_subject = {}
for record in records:
    by_subject.setdefault(record["subject"], {})[record["name"]] = record["score"]

print(by_subject["science"])
for subject in sorted(by_subject):
    scores = by_subject[subject]
    top = max(scores, key=scores.get)
    print(subject, "->", top, scores[top])
```

`max(scores, key=scores.get)` is worth reading slowly. Looping over a dict gives its keys (the names), and `key=scores.get` tells `max` to compare each name by the score stored under it. The result is the *name* with the highest score, which you then use to look the score up.

## Step 8: Print a report that lines up

An f-string can pad a value to a width: `:<6` left-aligns in 6 characters, `:>6.1f` right-aligns a number in 6 characters with one decimal place.

```python run
print(f"{'Rank':<6}{'Name':<6}{'Avg':>6}  Grade")
for rank, (name, average) in enumerate(ranking, start=1):
    print(f"{rank:<6}{name:<6}{average:>6.1f}  {letter(average)}")
```

`enumerate(ranking, start=1)` numbers the pairs from 1, and `(name, average)` unpacks each pair right in the `for` line.

## The finished program

Here's everything tidied into functions, each with one job, plus a `main()` that runs them in order. Replace the contents of `gradebook.py` with it:

```python run title="gradebook.py"
RAW = """name,subject,score
Ava,math,88
Ben,math,72
Cleo,math,95
Dev,math,64
Ava,science,91
ben ,science, 68
Cleo,Science,89
Dev,science,
Ava,history,79
Ben,history,85
Cleo,history,90
Dev,history,73
"""


def parse_line(line):
    parts = [part.strip() for part in line.split(",")]
    if len(parts) != 3 or not parts[2]:
        return None
    name, subject, score = parts
    return {"name": name.title(), "subject": subject.lower(), "score": int(score)}


def parse_all(text):
    records, skipped = [], []
    for line in text.splitlines()[1:]:
        record = parse_line(line)
        if record is None:
            skipped.append(line)
        else:
            records.append(record)
    return records, skipped


def group_scores(records, field):
    groups = {}
    for record in records:
        groups.setdefault(record[field], []).append(record["score"])
    return groups


def letter(average):
    for cutoff, grade in [(90, "A"), (80, "B"), (70, "C")]:
        if average >= cutoff:
            return grade
    return "D"


def main():
    records, skipped = parse_all(RAW)
    averages = {name: sum(s) / len(s) for name, s in group_scores(records, "name").items()}
    ranking = sorted(averages.items(), key=lambda pair: (-pair[1], pair[0]))

    print(f"{'Rank':<6}{'Name':<6}{'Avg':>6}  Grade")
    for rank, (name, average) in enumerate(ranking, start=1):
        print(f"{rank:<6}{name:<6}{average:>6.1f}  {letter(average)}")

    print()
    for subject, scores in sorted(group_scores(records, "subject").items()):
        print(f"{subject:<8} class average {sum(scores) / len(scores):.1f}")

    if skipped:
        print(f"\nIgnored {len(skipped)} line(s) with missing data: {skipped}")


main()
```

Two things changed on the way. `group_scores` now takes the field to group by, so the same function makes both the per-student and per-subject groups. And `letter` loops over a list of `(cutoff, grade)` tuples, so changing the grading scale means editing one list instead of a chain of `if`s.

:::quiz
Q: Why does `parse_line` return `None` for Dev's blank science score instead of calling `int()` on it?
- [ ] `int("")` returns 0, which would be wrong
  It doesn't return 0; it crashes with `ValueError`.
- [x] `int("")` would crash, and one bad line shouldn't stop the whole report
  Returning `None` lets the caller skip the line and list it at the end.
- [ ] Python can't convert text to numbers
  It can: `int("68")` gives 68. Only text that isn't a number fails.

Q: In `sorted(averages.items(), key=lambda pair: (-pair[1], pair[0]))`, why the minus sign?
- [x] So higher averages sort first while names still sort A to Z
  `reverse=True` would flip the names too. Negating only the average flips just that part.
- [ ] To turn the average into a whole number
  A minus sign changes the sign, not the type. `-87.5` is still a float.
- [ ] Because `sorted` can't handle positive numbers
  It handles any numbers; the minus sign is about direction.

Q: What does `max(scores, key=scores.get)` return when `scores = {"Ava": 91, "Ben": 68}`?
- [ ] `91`
  `max` loops over the dict's keys, so it returns a key. 91 is the value stored under it.
- [x] `"Ava"`
  Each name is compared by `scores.get(name)`, and Ava's 91 is the largest.
- [ ] `("Ava", 91)`
  That would need `max(scores.items(), ...)`. A plain dict gives just keys.
:::

:::takeaways
- Write and test the code for one line before you loop over all of them.
- Keep rejected input in its own list so the program can report what it ignored.
- "Dict of lists" is the standard way to group records; `setdefault` shortens it.
- A key that returns a tuple sorts on several things at once; negate a number to flip just that part.
- f-string widths such as `:<6` and `:>6.1f` line up columns without counting spaces.
:::
