:::objectives
- Store a program's content (quiz questions) in a JSON file instead of in the code.
- Write one safe pair of helpers for reading and writing JSON, and reuse it.
- Check every loaded record and report problems instead of crashing.
- Keep a score history that grows each time the program runs.
- Recover from a damaged data file without losing its contents.
:::

Most quiz programs beginners write keep the questions inside the code, so adding a question means editing Python. This one keeps them in `questions.json`, which anyone can edit in VS Code, and it remembers everyone's scores in `scores.json`. Here's how the pieces fit:

```mermaid caption="Two data files: one the program only reads, one it reads and rewrites"
flowchart LR
    Q["questions.json"] -->|load and check| P["quiz.py"]
    U["Player's answers"] --> P
    P -->|append score, save safely| S["scores.json"]
    S -->|load history| P
```

Make a folder `m4-quiz`. Every step adds code to the bottom of `quiz.py` inside it.

:::tip
While you build, run the program from the terminal inside the folder: type `cd m4-quiz` once, then `python quiz.py` each time. Until Step 7 the code opens files by bare name, and the terminal's current folder decides where those files land.
:::

## Step 1: Create the questions file

The question file is a list of objects. Each has a `prompt`, a list of `choices`, and the `answer`, stored as the text of the right choice rather than its position. That way, reordering or shuffling the choices can never make the answer point at the wrong one. You can type the file by hand, or run this little script once to create it:

```python run title="make_questions.py"
import json
from pathlib import Path

questions = [
    {"prompt": "Which collection keeps only unique items?",
     "choices": ["list", "tuple", "set"], "answer": "set"},
    {"prompt": "Which open() mode erases a file as soon as it opens?",
     "choices": ["r", "w", "a"], "answer": "w"},
    {"prompt": "What does a function with no return statement give back?",
     "choices": ["0", "None", "an empty string"], "answer": "None"},
]

Path("questions.json").write_text(json.dumps(questions, indent=2), encoding="utf-8")
print(Path("questions.json").read_text(encoding="utf-8"))
```

That printout is exactly what's in the file now. Open it in VS Code: it's plain text, so adding a fourth question is just a matter of copying one block and editing it. Be careful with commas, though. JSON needs a comma *between* items and forbids one after the last item, and that's the most common way a hand-edited file breaks.

## Step 2: One safe way to read and write JSON

The quiz reads two files, so write the careful version once. `read_json` returns a pair: the data, and a warning message or `None`.

```python run
import json
from pathlib import Path


def read_json(path, default):
    try:
        return json.loads(path.read_text(encoding="utf-8")), None
    except FileNotFoundError:
        return default, None
    except json.JSONDecodeError as error:
        backup = path.with_name(path.name + ".bak")
        path.replace(backup)
        return default, f"{path.name} was damaged ({error}); moved it to {backup.name}"


def write_json(path, data):
    temp = path.with_name(path.name + ".tmp")
    temp.write_text(json.dumps(data, indent=2), encoding="utf-8")
    temp.replace(path)


print(read_json(Path("nothing_here.json"), []))
Path("oops.json").write_text('{"name": "Ava", ', encoding="utf-8")
print(read_json(Path("oops.json"), []))
print(Path("oops.json.bak").exists())
```

These two functions are the lessons of the Notes page packed into fifteen lines. A missing file quietly gives the default. A damaged file is renamed to `.bak` so nothing in it is lost, and the caller gets a message to show. Writing goes through a `.tmp` file and `replace`, so a crash mid-save can't leave half a file. Neither function prints, so the rest of the program decides what the user sees.

## Step 3: Check every question

A JSON file can be perfectly valid and still wrong: a question with no choices, or an answer that isn't one of the choices. A guard-clause function finds the first problem with a question, or returns `None` if there isn't one:

```python run
def question_problem(question):
    if not isinstance(question, dict):
        return "is not an object with a prompt, choices, and answer"
    if not isinstance(question.get("prompt"), str) or not question["prompt"].strip():
        return "has no prompt"
    choices = question.get("choices")
    if not isinstance(choices, list) or len(choices) < 2:
        return "needs a list of at least two choices"
    if question.get("answer") not in choices:
        return "has an answer that isn't one of its choices"
    return None


def load_questions(path):
    data, warning = read_json(path, [])
    problems = [warning] if warning else []
    if not isinstance(data, list):
        return [], problems + [f"{path.name} should hold a list of questions"]
    questions = []
    for number, question in enumerate(data, start=1):
        problem = question_problem(question)
        if problem:
            problems.append(f"question {number} {problem}")
        else:
            questions.append(question)
    return questions, problems


test = [
    {"prompt": "2 + 2?", "choices": ["3", "4"], "answer": "4"},
    {"prompt": "Capital of France?", "choices": ["Paris"], "answer": "Paris"},
    {"prompt": "Best color?", "choices": ["red", "blue"], "answer": "green"},
]
write_json(Path("test_questions.json"), test)
print(load_questions(Path("test_questions.json")))

questions, problems = load_questions(Path("questions.json"))
print(len(questions), "good questions,", len(problems), "problems")
```

`isinstance(value, list)` checks what type a value is, which matters because a JSON file can hold anything. `question.get("prompt")` gives `None` instead of crashing when the key is missing. The test file shows the point of `load_questions`: one good question gets through, and the two bad ones become readable messages with their position in the file, which is exactly what a person needs to fix them.

## Step 4: Ask one question

`ask` is a "talking" function like `main` in the contacts manager: it prints and reads input. It keeps asking until the reply is a number in range, then returns whether the answer was right.

```python run input="5|two|2"
def ask(question, number):
    choices = question["choices"]
    print(f"\nQ{number}. {question['prompt']}")
    for option, choice in enumerate(choices, start=1):
        print(f"  {option}) {choice}")
    while True:
        reply = input("Your answer: ").strip()
        if reply.isdigit() and 1 <= int(reply) <= len(choices):
            break
        print(f"Type a number from 1 to {len(choices)}.")
    chosen = choices[int(reply) - 1]
    if chosen == question["answer"]:
        print("Correct!")
        return True
    print(f"Not quite. The answer is: {question['answer']}")
    return False


print(ask(questions[1], 2))
```

`reply.isdigit()` comes first in the `and`, so `int(reply)` only runs on text that really is digits; `int("two")` would crash. Python stops checking an `and` as soon as one side is false, which is what makes that order safe. The player types `2`, but the code compares the *text* of choice 2 with the answer.

## Step 5: Run the whole quiz

```python run input="3|1|2"
def run_quiz(questions):
    score = 0
    for number, question in enumerate(questions, start=1):
        if ask(question, number):
            score += 1
    return score


score = run_quiz(questions)
print(f"\nScore: {score}/{len(questions)}")
```

`run_quiz` returns the score instead of printing it, because the next step needs to save it.

## Step 6: Remember every score

Each finished quiz adds one record to `scores.json`. The history is loaded, appended to, and saved straight away:

```python run
def record_score(path, name, score, total):
    history, warning = read_json(path, [])
    history.append({"name": name, "score": score, "total": total})
    write_json(path, history)
    return history, warning


def best_scores(history, count=3):
    ranked = sorted(history, key=lambda s: (-s["score"] / s["total"], s["name"]))
    return ranked[:count]


record_score(Path("scores.json"), "Ava", 2, 3)
history, warning = record_score(Path("scores.json"), "Ben", 3, 3)
print(len(history), "scores saved")
print(best_scores(history))
```

Each call to `record_score` starts by reading the file, so the second call sees Ava's score from the first. That's the whole trick of persistence: read at the start, write after the change. Ranking by `score / total` instead of raw score keeps the leaderboard fair if you add questions later.

## Step 7: Put it together in main()

`main` finds the data files, warns about problems, runs the quiz, and saves the result. `data_folder()` returns the folder the script is saved in, so the program finds its files however it's started. When there's no saved file at all (pasted into the interactive prompt, or run on this page), `__file__` doesn't exist and it falls back to the current folder.

```python run input="Cleo|3|2|2"
def data_folder():
    try:
        return Path(__file__).parent
    except NameError:
        return Path.cwd()


def main():
    folder = data_folder()
    questions, problems = load_questions(folder / "questions.json")
    for problem in problems:
        print("Warning:", problem)
    if not questions:
        print("No usable questions, so there's no quiz today.")
        return

    name = input("Your name: ").strip() or "Anonymous"
    score = run_quiz(questions)
    print(f"\n{name}, you scored {score} out of {len(questions)}.")

    history, warning = record_score(folder / "scores.json", name, score, len(questions))
    if warning:
        print("Warning:", warning)
    print("\nBest scores so far:")
    for entry in best_scores(history):
        print(f"  {entry['name']:<10}{entry['score']}/{entry['total']}")


main()
```

Cleo's result joins Ava's and Ben's from Step 6, because they were saved to disk.

## Step 8: Break the scores file on purpose

Simulate someone hand-editing `scores.json` badly, then play again:

```python run input="Dev|3|2|1"
Path("scores.json").write_text('[{"name": "Ava", "score": 2', encoding="utf-8")
main()
print(Path("scores.json.bak").read_text(encoding="utf-8"))
```

The quiz itself runs normally. When it goes to save Dev's score, `read_json` finds the damage, so the program warns, keeps the damaged text in `scores.json.bak`, and starts a fresh history with Dev's score. Nothing crashed, and nothing was thrown away; someone can open the `.bak` file and repair it by hand.

## The finished program

Here's all of `quiz.py`. Run it from VS Code a few times, then open `scores.json` in the editor and watch it grow.

```python run title="quiz.py" input="Eli|3|2|2"
import json
from pathlib import Path


def data_folder():
    try:
        return Path(__file__).parent
    except NameError:
        return Path.cwd()


def read_json(path, default):
    try:
        return json.loads(path.read_text(encoding="utf-8")), None
    except FileNotFoundError:
        return default, None
    except json.JSONDecodeError as error:
        backup = path.with_name(path.name + ".bak")
        path.replace(backup)
        return default, f"{path.name} was damaged ({error}); moved it to {backup.name}"


def write_json(path, data):
    temp = path.with_name(path.name + ".tmp")
    temp.write_text(json.dumps(data, indent=2), encoding="utf-8")
    temp.replace(path)


def question_problem(question):
    if not isinstance(question, dict):
        return "is not an object with a prompt, choices, and answer"
    if not isinstance(question.get("prompt"), str) or not question["prompt"].strip():
        return "has no prompt"
    choices = question.get("choices")
    if not isinstance(choices, list) or len(choices) < 2:
        return "needs a list of at least two choices"
    if question.get("answer") not in choices:
        return "has an answer that isn't one of its choices"
    return None


def load_questions(path):
    data, warning = read_json(path, [])
    problems = [warning] if warning else []
    if not isinstance(data, list):
        return [], problems + [f"{path.name} should hold a list of questions"]
    questions = []
    for number, question in enumerate(data, start=1):
        problem = question_problem(question)
        if problem:
            problems.append(f"question {number} {problem}")
        else:
            questions.append(question)
    return questions, problems


def ask(question, number):
    choices = question["choices"]
    print(f"\nQ{number}. {question['prompt']}")
    for option, choice in enumerate(choices, start=1):
        print(f"  {option}) {choice}")
    while True:
        reply = input("Your answer: ").strip()
        if reply.isdigit() and 1 <= int(reply) <= len(choices):
            break
        print(f"Type a number from 1 to {len(choices)}.")
    chosen = choices[int(reply) - 1]
    if chosen == question["answer"]:
        print("Correct!")
        return True
    print(f"Not quite. The answer is: {question['answer']}")
    return False


def run_quiz(questions):
    score = 0
    for number, question in enumerate(questions, start=1):
        if ask(question, number):
            score += 1
    return score


def record_score(path, name, score, total):
    history, warning = read_json(path, [])
    history.append({"name": name, "score": score, "total": total})
    write_json(path, history)
    return history, warning


def best_scores(history, count=3):
    ranked = sorted(history, key=lambda s: (-s["score"] / s["total"], s["name"]))
    return ranked[:count]


def main():
    folder = data_folder()
    questions, problems = load_questions(folder / "questions.json")
    for problem in problems:
        print("Warning:", problem)
    if not questions:
        print("No usable questions, so there's no quiz today.")
        return

    name = input("Your name: ").strip() or "Anonymous"
    score = run_quiz(questions)
    print(f"\n{name}, you scored {score} out of {len(questions)}.")

    history, warning = record_score(folder / "scores.json", name, score, len(questions))
    if warning:
        print("Warning:", warning)
    print("\nBest scores so far:")
    for entry in best_scores(history):
        print(f"  {entry['name']:<10}{entry['score']}/{entry['total']}")


if __name__ == "__main__":
    main()
```

The last two lines are new. `if __name__ == "__main__":` is true only when this file is the program being run, not when another file imports it. That lets a separate test file import `question_problem` and check it without a quiz starting.

:::quiz
Q: Why store the answer as `"set"` instead of as the number `3`?
- [x] The answer stays correct even if the choices are reordered or shuffled
  A position breaks the moment the list changes order. The text of the choice moves with it.
- [ ] JSON can't store numbers
  JSON stores numbers fine. This is a design choice about robustness.
- [ ] Python compares strings faster than numbers
  The speed difference is irrelevant here; the reason is correctness.

Q: `scores.json` is damaged. What does the program do with it?
- [ ] Deletes it and starts again
  Deleting would throw away every score that could have been repaired.
- [x] Renames it to `scores.json.bak`, warns, and starts a fresh history
  The data is kept for a person to fix, and the quiz still works.
- [ ] Crashes with `JSONDecodeError`
  `read_json` catches that error. Crashing every launch would make the quiz unusable until someone fixed the file.

Q: In `if reply.isdigit() and 1 <= int(reply) <= len(choices)`, what happens when the player types `two`?
- [ ] `int("two")` crashes the program
  It never runs: `isdigit()` is false, so Python skips the rest of the `and`.
- [x] The condition is false without calling `int`, so the loop asks again
  `and` stops at the first false part, which is why the safe check comes first.
:::

:::takeaways
- Keep content such as questions in a data file so it can change without touching code.
- Write one careful `read_json` / `write_json` pair and reuse it for every file.
- Valid JSON can still be wrong data. Check each record and report problems by position.
- Persistence is "read at the start, write after the change"; save immediately, not only on exit.
- `if __name__ == "__main__": main()` runs the program only when the file is run directly.
:::
