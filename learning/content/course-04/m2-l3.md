## Warm-up: predict four lines

Write down what you think each line prints, then run it:

```python run title="warmup.py"
print(len({"a", "b", "a"}))
print([w.upper() for w in "to do list".split()])
print(sorted(["pear", "fig", "banana"], key=len))
print({n: n * n for n in range(1, 4)})
```

The third one surprises people. `key=len` sorts by each word's length, so `fig` (3 letters) comes before `pear` (4) and `banana` (6), whatever the alphabet says.

### Exercise 1: Count the words

Count how often each word appears in this text, ignoring capital letters and the punctuation `. , ! ?`. Print the three most common words with their counts, breaking ties alphabetically.

```python
text = """The quiz is on Friday. The quiz covers lists, dicts, and sets.
Study the lists first! Then study the dicts."""
```

Expected output:

```text
the 4
dicts 2
lists 2
```

:::hint
Loop over `text.lower().split()`, and clean each word with `.strip(".,!?")`. `counts.get(word, 0) + 1` adds one whether or not the word has been seen before. To rank, sort `counts.items()` with a key that returns `(-count, word)`.
:::

:::solution
```python run title="ex1_word_count.py"
text = """The quiz is on Friday. The quiz covers lists, dicts, and sets.
Study the lists first! Then study the dicts."""

counts = {}
for word in text.lower().split():
    word = word.strip(".,!?")
    counts[word] = counts.get(word, 0) + 1

top = sorted(counts.items(), key=lambda pair: (-pair[1], pair[0]))
for word, count in top[:3]:
    print(word, count)
```

`.strip(".,!?")` removes any of those characters from both ends of a word, so `Friday.` and `lists,` come out clean. Four words tie with 2 (`dicts`, `lists`, `quiz`, and `study`), and breaking ties on the word itself keeps the output the same every run.
:::

### Exercise 2: Every tag, once

Each task has a list of tags. Print all the different tags in alphabetical order, then how many tasks use each one.

```python
tasks = [
    {"title": "Worksheet 4", "tags": ["math", "homework"]},
    {"title": "Lab report", "tags": ["bio", "homework", "writing"]},
    {"title": "Quiz review", "tags": ["math", "exam"]},
    {"title": "Essay draft", "tags": ["english", "writing"]},
]
```

Expected output:

```text
['bio', 'english', 'exam', 'homework', 'math', 'writing']
bio: 1
english: 1
exam: 1
homework: 2
math: 2
writing: 2
```

:::hint
You need a loop inside a loop: one over tasks, one over each task's tags. Add every tag to a set for the first line, and count with a dict for the rest. A set can also come from a comprehension with two `for` parts, written in the same order as the nested loops.
:::

:::solution
```python run title="ex2_tags.py"
tasks = [
    {"title": "Worksheet 4", "tags": ["math", "homework"]},
    {"title": "Lab report", "tags": ["bio", "homework", "writing"]},
    {"title": "Quiz review", "tags": ["math", "exam"]},
    {"title": "Essay draft", "tags": ["english", "writing"]},
]

all_tags = {tag for task in tasks for tag in task["tags"]}
print(sorted(all_tags))

tag_counts = {}
for task in tasks:
    for tag in task["tags"]:
        tag_counts[tag] = tag_counts.get(tag, 0) + 1
for tag in sorted(tag_counts):
    print(f"{tag}: {tag_counts[tag]}")
```

Read `{tag for task in tasks for tag in task["tags"]}` left to right as two nested loops: for each task, for each of its tags, keep the tag. The curly braces make it a set, so `math` and `homework` appear once even though two tasks use them.
:::

### Exercise 3: What's urgent?

From the list below, print the titles of tasks that are **not done** and due within **3 days** (`due_in <= 3`), soonest first.

```python
tasks = [
    {"title": "Worksheet 4", "due_in": 2, "done": False},
    {"title": "Lab report", "due_in": 5, "done": False},
    {"title": "Quiz review", "due_in": 1, "done": False},
    {"title": "Read ch. 6", "due_in": 0, "done": True},
    {"title": "Essay draft", "due_in": 3, "done": False},
]
```

Expected output:

```text
['Quiz review', 'Worksheet 4', 'Essay draft']
```

:::hint
One comprehension with an `if` that checks two things joined by `and`. Then sort the result with `key=lambda t: t["due_in"]`, and finally pull out just the titles.
:::

:::solution
```python run title="ex3_urgent.py"
tasks = [
    {"title": "Worksheet 4", "due_in": 2, "done": False},
    {"title": "Lab report", "due_in": 5, "done": False},
    {"title": "Quiz review", "due_in": 1, "done": False},
    {"title": "Read ch. 6", "due_in": 0, "done": True},
    {"title": "Essay draft", "due_in": 3, "done": False},
]

urgent = [t for t in tasks if not t["done"] and t["due_in"] <= 3]
urgent.sort(key=lambda t: t["due_in"])
print([t["title"] for t in urgent])
```

Filtering first and sorting second means the sort only has to handle the tasks you care about. `Read ch. 6` is due today but already done, so `not t["done"]` keeps it out.
:::

### Exercise 4: Sort contacts by last name

Sort these names by last name, then by first name, ignoring capital letters. Print one per line, exactly as they were typed.

```python
contacts = ["Maya Patel", "Leo Chen", "ava patel", "Sam Okafor", "Ben Chen"]
```

Expected output:

```text
Ben Chen
Leo Chen
Sam Okafor
ava patel
Maya Patel
```

:::hint
Write a small function `last_then_first(full_name)` that lowercases the name, splits it into first and last, and returns the tuple `(last, first)`. Pass the function itself, without parentheses, as `key=`.
:::

:::solution
```python run title="ex4_contacts_sort.py"
contacts = ["Maya Patel", "Leo Chen", "ava patel", "Sam Okafor", "Ben Chen"]


def last_then_first(full_name):
    first, last = full_name.lower().split()
    return (last, first)


for name in sorted(contacts, key=last_then_first):
    print(name)
```

The key only decides the order; it never changes what's in the list. That's why `ava patel` still prints in lowercase. Without `.lower()`, she'd jump to the end, because Python sorts all capital letters before all lowercase ones.
:::

### Exercise 5: Flip the dictionary

You have each student's clubs. The club advisors want the opposite: for each club, its members. Build that dictionary and print the clubs alphabetically.

```python
clubs_by_student = {
    "Ava": ["chess", "robotics"],
    "Ben": ["robotics"],
    "Cleo": ["chess", "debate", "robotics"],
    "Dev": ["debate"],
}
```

Expected output:

```text
chess ['Ava', 'Cleo']
debate ['Cleo', 'Dev']
robotics ['Ava', 'Ben', 'Cleo']
```

```mermaid caption="Inverting: every student-to-club arrow becomes a club-to-student arrow"
flowchart LR
    Ava --> chess
    Ava --> robotics
    Ben --> robotics
    Cleo --> chess
    Cleo --> debate
    Cleo --> robotics
    Dev --> debate
```

:::hint
Every arrow in the diagram is one pass of a nested loop: outer loop over `clubs_by_student.items()`, inner loop over that student's clubs. For each pair, append the student to the club's list, creating the list the first time you see the club.
:::

:::solution
```python run title="ex5_invert.py"
clubs_by_student = {
    "Ava": ["chess", "robotics"],
    "Ben": ["robotics"],
    "Cleo": ["chess", "debate", "robotics"],
    "Dev": ["debate"],
}

students_by_club = {}
for student, clubs in clubs_by_student.items():
    for club in clubs:
        students_by_club.setdefault(club, []).append(student)

for club in sorted(students_by_club):
    print(club, students_by_club[club])
```

`setdefault(club, [])` returns the club's existing list, or puts in an empty one and returns that. Either way `.append(student)` has a list to work on. The members come out in alphabetical order only because the students were typed that way; add `sorted()` around each list if you need to be sure.
:::

### Exercise 6: Study log totals

Each entry in the log is a `(day, subject, minutes)` tuple. Print the total minutes for each day as a dict, then the busiest day and the most-studied subject.

```python
log = [
    ("Mon", "math", 30),
    ("Mon", "bio", 20),
    ("Tue", "math", 45),
    ("Wed", "english", 25),
    ("Wed", "math", 15),
    ("Wed", "bio", 40),
]
```

Expected output:

```text
{'Mon': 50, 'Tue': 45, 'Wed': 80}
Busiest day: Wed 80 min
Most studied: math 90 min
```

:::hint
Unpack each tuple right in the loop: `for day, subject, minutes in log:`. Keep two dicts of running totals, and update both in the same pass. `max(totals, key=totals.get)` finds the key with the biggest value.
:::

:::solution
```python run title="ex6_study_log.py"
log = [
    ("Mon", "math", 30),
    ("Mon", "bio", 20),
    ("Tue", "math", 45),
    ("Wed", "english", 25),
    ("Wed", "math", 15),
    ("Wed", "bio", 40),
]

per_day = {}
per_subject = {}
for day, subject, minutes in log:
    per_day[day] = per_day.get(day, 0) + minutes
    per_subject[subject] = per_subject.get(subject, 0) + minutes

print(per_day)
busiest = max(per_day, key=per_day.get)
favorite = max(per_subject, key=per_subject.get)
print("Busiest day:", busiest, per_day[busiest], "min")
print("Most studied:", favorite, per_subject[favorite], "min")
```

One loop fills both dictionaries because each log entry contributes to a day *and* a subject. Tuples suit the log well: each entry is a fixed bundle of three values that nobody should edit after the fact.
:::

### Challenge: A study planner's data model

Design the data for a study planner, then write three functions for it:

-   Courses must be looked up by code (`"MATH"`), tasks inside a course kept in the order they were added, and each task's tags stored without duplicates.
-   `add_task(planner, code, title, due, tags)` adds a not-done task and returns `True`, or returns `False` if the course code doesn't exist. Store `due` as text like `"2026-11-18"`.
-   `tasks_with_tag(planner, tag)` returns `(due, code, title)` tuples for every task with that tag, soonest first.
-   `next_due(planner)` returns the soonest task that isn't done, as the same kind of tuple, or `None`.

Finish by printing how many tasks in each course are done, like `MATH: 1/2 done`.

:::hint
A dict of courses, each holding a list of task dicts, each with a set of tags. Dates written year-month-day sort correctly as plain text, so a tuple that starts with `due` sorts by date for free. `min()` of a list of tuples gives the soonest.
:::

:::solution
```python run title="challenge_planner.py"
planner = {
    "MATH": {"title": "Algebra II", "tasks": []},
    "BIO": {"title": "Biology", "tasks": []},
    "ENG": {"title": "English 10", "tasks": []},
}


def add_task(planner, code, title, due, tags):
    if code not in planner:
        return False
    task = {"title": title, "due": due, "tags": set(tags), "done": False}
    planner[code]["tasks"].append(task)
    return True


def tasks_with_tag(planner, tag):
    found = [
        (task["due"], code, task["title"])
        for code, course in planner.items()
        for task in course["tasks"]
        if tag in task["tags"]
    ]
    return sorted(found)


def next_due(planner):
    pending = [
        (task["due"], code, task["title"])
        for code, course in planner.items()
        for task in course["tasks"]
        if not task["done"]
    ]
    return min(pending) if pending else None


add_task(planner, "MATH", "Worksheet 4", "2026-11-18", ["homework"])
add_task(planner, "BIO", "Lab report", "2026-11-21", ["homework", "writing"])
add_task(planner, "ENG", "Essay draft", "2026-11-19", ["writing", "writing"])
add_task(planner, "MATH", "Unit test", "2026-11-24", ["exam"])
print(add_task(planner, "ART", "Sketchbook", "2026-11-20", []))

planner["MATH"]["tasks"][0]["done"] = True

print(tasks_with_tag(planner, "writing"))
print(next_due(planner))
for code, course in planner.items():
    done = sum(1 for task in course["tasks"] if task["done"])
    print(f"{code}: {done}/{len(course['tasks'])} done")
```

Each collection answers one of the requirements: the outer dict gives lookup by code, the list keeps tasks in order, and `set(tags)` silently drops the doubled `"writing"`. The worksheet is marked done, so `next_due` skips it and finds the essay. Keep this file: in Module 4 you'll try to save it as JSON and discover that JSON has no sets.
:::
